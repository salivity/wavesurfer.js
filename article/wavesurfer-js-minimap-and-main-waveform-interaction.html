Wavesurfer.js Minimap and Main Waveform Interaction

The Wavesurfer.js Minimap plugin functions as a real-time, synchronized navigation tool that provides an overview of an entire audio file alongside the main waveform. By mapping playback states, zoom levels, and viewport positions between a miniature overview and a detailed view, the plugin allows users to inspect zoomed-in audio details while maintaining continuous spatial awareness of the entire track.

Full-Length Audio Representation

While the primary Wavesurfer.js waveform can be zoomed in to show micro-details of milliseconds of audio, the minimap renders the entire duration of the audio within a fixed container. Both components share the same underlying decoded audio buffer or pre-rendered peak data, ensuring that the waveform geometry depicted in the minimap is an accurate, condensed miniature of the main waveform.

The Viewport Selection Box

The most prominent visual interaction between the two components is the visible viewport overlay on the minimap. When the main waveform is zoomed beyond the width of its container, a highlighted rectangular overlay appears over the minimap.

The dimensions and position of this overlay correspond mathematically to the visible portion of the main waveform:

  • Width: Proportional to the ratio between the main waveform container width and its total zoomed scrollable width.
  • Horizontal Position: Maps directly to the scroll offset (scrollLeft) of the main waveform container.

As a user zooms in on the main waveform, the minimap's viewport box shrinks. When the user zooms out, the viewport box expands until it covers the full width of the minimap when no horizontal scrolling is required.

Bidirectional Event Synchronization

The minimap and the main waveform communicate via an internal event-driven architecture that listens for playback, scroll, and user interaction events:

  1. Main to Minimap Synchronization:
    • Playback and Seeking: As the main waveform plays or seeks via the audioprocess or timeupdate events, the minimap updates its own playhead position synchronously.
    • Scrolling: When the user scrolls the main container horizontally, the minimap updates the position of its viewport box in real time.
    • Zooming: Changes to the minPxPerSec property on the main instance trigger recalculations of the minimap overlay width.
  2. Minimap to Main Synchronization:
    • Dragging the Viewport Box: Users can click and drag the highlighted overlay across the minimap. This directly manipulates the scroll position of the main waveform, panning through the audio smoothly.
    • Click-to-Seek: Clicking outside the highlighted box on the minimap jumps both the playhead and the main waveform's scroll position directly to that corresponding timestamp in the audio track.

Through this bidirectional architecture, the minimap decouples audio navigation from playback, giving users an intuitive way to scrub, pan, and maintain context across long audio files.
