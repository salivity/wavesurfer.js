Reset Zoom to Fit Container in Wavesurfer.js

This guide explains how to reset the zoom level in Wavesurfer.js so the entire waveform fits neatly within its parent container. You will learn the exact method call required to reset the view, how the zooming mechanism works under the hood, and how to handle responsive resizing when audio extends beyond the viewport.

The Solution: Call zoom(0)

The fastest and most reliable way to reset the zoom level to fit the container width in modern Wavesurfer.js (version 7 and newer) is to pass 0 to the zoom method:

wavesurfer.zoom(0);

When you pass 0 as the parameter, Wavesurfer.js disables horizontal scrolling and scales the waveform so the full duration of the audio spans the exact width of the container element.

Implementation Example

Below is a complete implementation demonstrating how to zoom in and reset back to the default container width using a control button:

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#10B981',
  url: '/audio/sample.mp3',
  minPxPerSec: 0, // Default setting fits to container
});

// 2. Zoom in (e.g., 50 pixels per second)
document.getElementById('zoom-in-btn').addEventListener('click', () => {
  wavesurfer.zoom(50);
});

// 3. Reset zoom back to container width
document.getElementById('reset-zoom-btn').addEventListener('click', () => {
  wavesurfer.zoom(0);
});

How It Works

The zoom(minPxPerSec) function controls the horizontal scale of the waveform by setting the minimum number of pixels rendered per second of audio:

  • Values greater than 0: Force the waveform to expand horizontally. If the calculated width exceeds the container width, horizontal scrollbars appear (provided the container or wrapper allows overflow).
  • Value of 0: Tells Wavesurfer.js to clear any fixed pixel-per-second constraints. The player dynamically recalculates the scale using the formula containerWidth / audioDuration, ensuring the waveform fits edge-to-edge.

Handling Window and Container Resizing

If your waveform container changes dimensions dynamically (for example, when resizing a browser window or toggling a sidebar), Wavesurfer.js automatically recalculates the layout if the zoom is set to 0.

If you notice rendering artifacts after container changes, you can ensure a clean redraw by calling zoom(0) directly inside a resize listener:

window.addEventListener('resize', () => {
  wavesurfer.zoom(0);
});
