How to Listen for the Ready Event in Wavesurfer.js

This guide explains how to detect when an audio file has finished loading and rendering in Wavesurfer.js by utilizing the ready event listener. You will learn the correct syntax for subscribing to this event in modern Wavesurfer.js (v7+), how to execute code immediately after the waveform is prepared, and best practices for managing player states.

Using the ready Event Listener

Wavesurfer.js emits a ready event once the audio file is fully decoded, the waveform graphic is rendered in the DOM, and playback is safe to initiate.

To subscribe to this event, use the .on() method on your WaveSurfer instance:

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize the WaveSurfer instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

// 2. Attach the 'ready' event listener
wavesurfer.on('ready', () => {
  console.log('Waveform is ready to play!');
});

Running the Callback Only Once with .once()

If you only need to run setup logic the first time the audio loads—such as hiding a loading spinner or enabling an interface button—use .once() instead of .on(). This automatically removes the event listener after its first execution:

wavesurfer.once('ready', () => {
  const playButton = document.querySelector('#play-btn');
  playButton.removeAttribute('disabled');
  
  // Display total track duration
  const totalDuration = wavesurfer.getDuration();
  console.log(`Track duration: ${totalDuration.toFixed(2)} seconds`);
});

Listening for ready with Dynamic Audio Sources

If your application dynamically loads new audio tracks into an existing WaveSurfer instance using wavesurfer.load(url), the ready event will fire every time a new track finishes loading and decoding.

wavesurfer.on('ready', () => {
  // Updates UI elements whenever a new track finishes rendering
  document.getElementById('status').textContent = 'Audio ready';
});

// Loading a new track triggers the 'ready' event again
wavesurfer.load('/path/to/another-track.mp3');

Removing the Event Listener

If you need to manually stop listening to the ready event to prevent memory leaks in component-based frameworks (like React or Vue), pass the callback function reference to .un():

const onReady = () => {
  console.log('Waveform rendered');
};

// Add listener
wavesurfer.on('ready', onReady);

// Remove listener when cleaning up
wavesurfer.un('ready', onReady);
