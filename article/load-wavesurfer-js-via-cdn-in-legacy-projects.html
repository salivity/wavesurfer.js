Load Wavesurfer.js via CDN in Legacy Projects

Integrating audio visualization into legacy web applications can be challenging without modern build tools, module bundlers, or package managers. This guide explains how to quickly load and implement Wavesurfer.js using traditional Content Delivery Network (CDN) script tags, configure an interactive waveform container, and control audio playback directly using vanilla JavaScript.

Adding the CDN Script Tag

In legacy environments lacking tools like Webpack, Vite, or npm, you can load Wavesurfer.js by placing a standard <script> tag inside your HTML document. Using a CDN such as unpkg or cdnjs exposes the library as a global variable attached to the browser's window object.

Place the following script tag in the <head> or just before the closing </body> tag of your HTML:

<script src="https://unpkg.com/wavesurfer.js@7"></script>

(Note: If your legacy application must support deprecated browsers like Internet Explorer, use version 6 by specifying https://unpkg.com/wavesurfer.js@6 instead.)

Creating the HTML Container

Wavesurfer.js requires a DOM element to render the waveform canvas. Add a container <div> inside your page along with basic playback controls:

<div id="waveform"></div>
<button id="playPauseBtn">Play / Pause</button>

Initializing the Player

Once the script has loaded, instantiate the player by calling WaveSurfer.create() and passing the necessary configuration options. Ensure this script runs after the DOM element is rendered.

<script>
  document.addEventListener('DOMContentLoaded', function () {
    // Initialize Wavesurfer
    var wavesurfer = WaveSurfer.create({
      container: '#waveform',
      waveColor: '#violet',
      progressColor: '#purple',
      url: 'https://example.com/audio/sample.mp3'
    });

    // Wire up playback controls
    var playPauseBtn = document.getElementById('playPauseBtn');
    playPauseBtn.addEventListener('click', function () {
      wavesurfer.playPause();
    });

    // Handle ready event
    wavesurfer.on('ready', function () {
      console.log('Waveform is ready for playback.');
    });
  });
</script>

Key Considerations for Legacy Implementations

  • Cross-Origin Resource Sharing (CORS): If your audio files are hosted on a different domain or CDN than your application, the hosting server must supply proper Access-Control-Allow-Origin headers. Without CORS headers, the Web Audio API cannot decode the audio data to draw the waveform.
  • Loading Order: Ensure the CDN <script> tag finishes executing before any custom scripts call the global WaveSurfer object to prevent undefined reference errors.
  • Memory Management: In single-page legacy applications where views are swapped via AJAX or jQuery, always call wavesurfer.destroy() before removing the container element to clear audio contexts and avoid memory leaks.
