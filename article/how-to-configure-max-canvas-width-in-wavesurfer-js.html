How to Configure maxCanvasWidth in Wavesurfer.js

This guide explains how to properly configure the maxCanvasWidth property in Wavesurfer.js to maintain smooth waveform rendering for long audio files. You will learn what maxCanvasWidth does, why it is essential for avoiding browser canvas size limitations, and how to implement it within your initialization settings.

What Is maxCanvasWidth?

HTML5 <canvas> elements have maximum dimension limitations enforced by web browsers. When rendering long audio tracks or highly zoomed-in waveforms, a single canvas can exceed these limits (frequently between 4,096 and 16,384 pixels depending on the device and browser), causing the waveform to crash or fail to render.

The maxCanvasWidth parameter defines the maximum width in pixels of an individual canvas context. When the total waveform width exceeds this threshold, Wavesurfer.js automatically splits the visual rendering across multiple sequential canvas elements seamlessly.

The default value is typically 4000 pixels.

Configuring maxCanvasWidth

You set maxCanvasWidth directly inside the configuration object passed to WaveSurfer.create().

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  maxCanvasWidth: 4000, // Maximum width of a single canvas tile in pixels
});

wavesurfer.load('path/to/audio/file.mp3');

Recommended Values and Usage Tips

  • Default (4000px): Works reliably across nearly all modern desktop and mobile browsers.
  • Lowering the Value (e.g., 1000px–2000px): Recommended if you are developing for memory-constrained environments, such as older mobile devices, to prevent mobile Safari or Chrome memory exhaustion.
  • Raising the Value (e.g., 8000px): Can reduce the overall number of DOM elements on high-end desktop environments, but increases the risk of rendering errors on devices with strict hardware canvas limits.
  • Zooming: When using the zoom(pxPerSec) method, total waveform width expands rapidly. Setting an explicit maxCanvasWidth ensures the waveform continues to render into tiled segments as users zoom in.
