How to Get Audio Duration in Wavesurfer.js

This guide explains how to retrieve the total duration of a loaded audio track using Wavesurfer.js. You will learn the specific method used to access the audio length, how to handle the asynchronous loading process to avoid errors, and see practical JavaScript examples for modern implementations.

The getDuration() Method

In Wavesurfer.js, the method used to return the total duration of the loaded audio is getDuration().

When called on an active Wavesurfer instance, this method returns a floating-point number representing the total length of the audio file in seconds.

const duration = wavesurfer.getDuration();
console.log(`Audio duration: ${duration} seconds`);

Timing and Event Handling

Calling wavesurfer.getDuration() immediately after calling wavesurfer.load() will return 0 or NaN because the audio file has not yet been fetched and decoded by the browser.

To ensure the duration is available, you must listen for the ready or decode event before calling the method:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

// Wait for the audio to be decoded and ready to play
wavesurfer.on('ready', () => {
  const totalDuration = wavesurfer.getDuration();
  console.log(`Total duration: ${totalDuration.toFixed(2)} seconds`);
});

Formatting the Duration

Because getDuration() returns raw seconds, you often need to format the value into a standard MM:SS (minutes and seconds) format for user interfaces. You can achieve this with a simple helper function:

function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const remainingSeconds = Math.floor(seconds % 60);
  const paddedSeconds = remainingSeconds.toString().padStart(2, '0');
  return `${minutes}:${paddedSeconds}`;
}

wavesurfer.on('ready', () => {
  const durationInSeconds = wavesurfer.getDuration();
  const formattedTime = formatTime(durationInSeconds);
  document.getElementById('duration-display').textContent = formattedTime;
});

Using wavesurfer.getDuration() inside the ready event listener ensures accurate time tracking for track displays, progress bars, and custom playback controls.
