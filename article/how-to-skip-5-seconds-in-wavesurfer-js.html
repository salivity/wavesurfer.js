How to Skip 5 Seconds in Wavesurfer.js

This guide explains how to skip forward 5 seconds during audio playback in Wavesurfer.js. You will learn the primary built-in method for skipping audio, an alternative approach using current playback time, and how to attach this functionality to a user interaction like a button click.

The Direct Method: skip()

The cleanest and most straightforward way to skip ahead 5 seconds in Wavesurfer.js is using the built-in skip() method:

wavesurfer.skip(5);

Passing a positive number moves the playback position forward by that number of seconds. If you ever need to rewind, you can pass a negative number (e.g., -5).

Alternative Method: setTime()

If you are using Wavesurfer.js v7 and prefer explicitly calculating the new playback timestamp, use getCurrentTime() combined with setTime():

wavesurfer.setTime(wavesurfer.getCurrentTime() + 5);

In versions prior to v7, the equivalent approach uses seekTo() with a normalized duration value (from 0 to 1):

const newTime = wavesurfer.getCurrentTime() + 5;
const duration = wavesurfer.getDuration();
wavesurfer.seekTo(Math.min(newTime / duration, 1));

Complete Example with a Button

Here is a practical implementation connecting the 5-second skip action to an HTML button:

<button id="forward-btn">Forward 5s</button>

<script>
  const forwardBtn = document.querySelector('#forward-btn');

  forwardBtn.addEventListener('click', () => {
    wavesurfer.skip(5);
  });
</script>
