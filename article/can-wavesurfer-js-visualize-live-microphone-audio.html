Can Wavesurfer.js Visualize Live Microphone Audio?

Wavesurfer.js can visualize live microphone audio input in real time. Although it is primarily known for rendering waveforms from pre-recorded audio files, it natively supports live audio streams through dedicated plugins. By leveraging the browser's MediaStreams and the Web Audio API, developers can capture microphone input and generate an interactive, real-time waveform display directly in a web application.

How It Works

Wavesurfer.js relies on the browser's navigator.mediaDevices.getUserMedia() API to access the user's microphone. The captured audio stream is piped through the Web Audio API (AudioContext and AnalyserNode), which extracts real-time frequency and time-domain data. Wavesurfer.js then renders this data dynamically onto an HTML5 canvas element as a continuous, scrolling waveform.

Implementing Live Audio with the Record Plugin

In the modern versions of Wavesurfer.js (v7 and newer), live input visualization is handled by the official Record Plugin.

To implement live visualization:

  1. Initialize Wavesurfer: Create the primary Wavesurfer instance defining the container, dimensions, and visual styling (such as wave color and progress color).
  2. Register the Record Plugin: Attach the RecordPlugin to the instance. This plugin handles device selection, stream management, and the visual rendering of the incoming stream.
  3. Request Microphone Access: Call the plugin's stream activation method, which prompts the user for microphone permissions.
  4. Render the Stream: Once permission is granted, the plugin begins piping the stream directly to the waveform canvas, displaying live amplitude changes as the user speaks.
import WaveSurfer from 'wavesurfer.js'
import RecordPlugin from 'wavesurfer.js/dist/plugins/record.esm.js'

// 1. Create the instance
const wavesurfer = WaveSurfer.create({
  container: '#mic-container',
  waveColor: '#4F46E5',
  height: 100,
})

// 2. Initialize the Record plugin
const record = wavesurfer.registerPlugin(
  RecordPlugin.create({
    scrollingWaveform: true,
    renderRecordedAudio: false,
  })
)

// 3. Start the live visualizer
record.startMic()

Key Capabilities and Features

  • Scrolling Waveform: The visualizer can either render a static canvas that refreshes periodically or a scrolling waveform that moves horizontally as new audio data arrives.
  • Seamless Recording: In addition to visualization, the plugin can simultaneously record the input into a Blob (typically WebM or WAV format) and immediately display the recorded file for playback and editing once recording stops.
  • Device Selection: Developers can enumerate connected audio input devices and route specific microphones to the visualizer using standard browser APIs.

Important Technical Considerations

  • Secure Context Required: Browsers restrict microphone access to secure contexts. The application must be served over https:// or localhost for getUserMedia to function.
  • Resource Management: Live visualization requires continuous canvas repaints. Ensure streams and audio contexts are properly destroyed or disconnected when the component unmounts to prevent memory leaks and unnecessary CPU usage.
