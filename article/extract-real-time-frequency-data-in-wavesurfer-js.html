Extract Real-Time Frequency Data in Wavesurfer.js

Extracting real-time frequency data during playback in Wavesurfer.js requires tapping into the browser's Web Audio API using an AnalyserNode. Because modern versions of Wavesurfer.js (v7+) utilize an HTML5 MediaElement by default, you can pipe the audio element into an audio context graph, route it through an analyzer, and extract Fast Fourier Transform (FFT) byte data on each animation frame during active playback.

1. Initialize Wavesurfer and Obtain the Audio Element

Create your Wavesurfer instance normally. Once the instance is mounted and the audio is loaded, retrieve the underlying media element using the getMediaElement() method.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
});

2. Configure the Web Audio API AnalyserNode

Create an AudioContext and instantiate an AnalyserNode. Using createMediaElementSource(), capture the media element provided by Wavesurfer and connect it to your analyzer, then pipe the analyzer output to the destination speakers so sound remains audible.

let audioContext;
let analyser;
let dataArray;
let sourceNode;

wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();

  // Initialize AudioContext on user interaction/ready
  audioContext = new (window.AudioContext || window.webkitAudioContext)();
  analyser = audioContext.createAnalyser();

  // Configure FFT size (determines frequency bin count: fftSize / 2)
  analyser.fftSize = 128;
  const bufferLength = analyser.frequencyBinCount;
  dataArray = new Uint8Array(bufferLength);

  // Connect source -> analyser -> destination
  sourceNode = audioContext.createMediaElementSource(mediaElement);
  sourceNode.connect(analyser);
  analyser.connect(audioContext.destination);
});

3. Capture Frequency Data in Real Time

Use requestAnimationFrame to poll the analyzer continuously while playback is active. Calling analyser.getByteFrequencyData(dataArray) populates the array with values ranging from 0 to 255 across the defined frequency spectrum.

function getFrequencyData() {
  if (!wavesurfer.isPlaying()) return;

  // Populate dataArray with current frequency values
  analyser.getByteFrequencyData(dataArray);

  // Example: dataArray now contains amplitude across frequency bands
  // You can pass this data to a custom canvas, visualizer, or reactive UI element
  console.log(dataArray);

  requestAnimationFrame(getFrequencyData);
}

// Start polling on play and resume AudioContext if suspended
wavesurfer.on('play', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
  getFrequencyData();
});

Summary of Best Practices

  • AudioContext Suspension: Browsers block audio playback until user interaction occurs. Always verify and call audioContext.resume() inside the play event handler.
  • CORS Headers: If loading audio files from an external domain, ensure the server returns appropriate Access-Control-Allow-Origin headers; otherwise, the createMediaElementSource node will produce silence to prevent data leakage.
  • FFT Resolution: Adjust analyser.fftSize (must be a power of two between 32 and 32768) depending on your needs. A size of 128 or 256 is optimal for lightweight visualizers, while larger sizes provide higher frequency resolution for audio analysis.
