Sync Subtitles with Wavesurfer.js

Synchronizing captions or subtitles with Wavesurfer.js is primarily accomplished by combining the official Regions plugin with timed text formats (such as WebVTT or SRT), or by utilizing Wavesurfer’s playback events alongside the native HTML5 TextTrack API. This article covers the most effective plugins and technical setups to accurately display synced subtitle captions across your audio waveform.

Method 1: The Regions Plugin

The most popular visual method uses the official @wavesurfer/regions plugin. This approach renders individual subtitle cues as visual blocks on the waveform and triggers active states during playback.

  1. Install and Register the Plugin: Import the Regions plugin alongside Wavesurfer:

    import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
});

const wsRegions = ws.registerPlugin(RegionsPlugin.create());

  2. Populate Regions with Subtitle Data: Parse your SRT or WebVTT file and add a region for each subtitle segment:

    const subtitles = [
  { start: 0, end: 2.5, text: "Welcome to the audio track." },
  { start: 2.8, end: 5.0, text: "Here is the second caption line." }
];

subtitles.forEach(cue => {
  wsRegions.addRegion({
    start: cue.start,
    end: cue.end,
    content: cue.text,
    color: 'rgba(0, 123, 255, 0.2)',
    drag: false,
    resize: false
  });
});

  3. Handle Caption Display: Listen to region events to update an external caption container dynamically:

    const captionBox = document.getElementById('caption-box');

wsRegions.on('region-in', (region) => {
  captionBox.textContent = region.content.textContent || region.content;
});

wsRegions.on('region-out', () => {
  captionBox.textContent = '';
});

Method 2: Native HTML5 Media Element and WebVTT

If you already use standard .vtt files and want native browser subtitle parsing without visually cluttering the waveform, connect Wavesurfer to an existing HTML5 audio or video element.

  1. Bind Wavesurfer to the Media Element:

    const audio = document.getElementById('my-audio');

const ws = WaveSurfer.create({
  container: '#waveform',
  media: audio,
});

  2. Attach a Track Element: In your HTML, associate your VTT file with the audio element:

    <audio id="my-audio" src="audio.mp3">
  <track id="caption-track" default kind="subtitles" srclang="en" src="captions.vtt">
</audio>
<div id="subtitle-display"></div>

  3. Listen to the TextTrack cuechange Event: The browser automatically handles timing, keeping text perfectly synced with Wavesurfer's playback:

    const track = document.getElementById('caption-track').track;
const display = document.getElementById('subtitle-display');

track.oncuechange = () => {
  const activeCue = track.activeCues[0];
  display.textContent = activeCue ? activeCue.text : '';
};

Method 3: Custom Playhead Sync via timeupdate

For external caption renderers (such as React state or Vue stores), use the core Wavesurfer timeupdate event.

  1. Parse your SRT or VTT file into an array of objects with start, end, and text properties using a lightweight parser.

  2. Track the current playhead position using the timeupdate event:

    ws.on('timeupdate', (currentTime) => {
  const activeCaption = subtitles.find(
    cue => currentTime >= cue.start && currentTime <= cue.end
  );
  document.getElementById('captions').innerText = activeCaption ? activeCaption.text : '';
});

This lightweight setup minimizes overhead by bypassing additional plugins while maintaining frame-accurate subtitle synchronization.
