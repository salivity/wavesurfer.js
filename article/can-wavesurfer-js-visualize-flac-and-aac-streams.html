Can Wavesurfer.js Visualize FLAC and AAC Streams?

Wavesurfer.js can visualize FLAC and AAC audio files without transcoding, provided the target browser natively supports decoding these formats and the delivery method aligns with Web Audio API constraints. Because Wavesurfer.js relies entirely on underlying browser capabilities for rendering waveforms, understanding the difference between static HTTP delivery and continuous live streaming is essential for implementing seamless playback and visualization.

Native Codec Support

Wavesurfer.js does not contain proprietary decoders for audio formats. Instead, it relies on the browser's native Web Audio API (AudioContext.decodeAudioData()) or the standard HTML5 <audio> element (MediaElement backend).

Modern browsers—including Google Chrome, Mozilla Firefox, Apple Safari, and Microsoft Edge—provide built-in support for both AAC and FLAC containers. Because the browser handles the decompression, you do not need to transcode your FLAC or AAC assets into uncompressed WAV or MP3 formats before passing them to the visualizer.

Static Files vs. Continuous Audio Streams

While static files work out of the box, the behavior changes depending on how the audio is served:

  • Static Audio Files: If the FLAC or AAC file is hosted as a complete static file, Wavesurfer.js fetches the entire audio file as an ArrayBuffer and passes it to decodeAudioData(). The browser decodes the full file into raw PCM audio data, from which Wavesurfer.js calculates the peak values and renders the waveform.
  • Continuous or Live Streams: The Web Audio API cannot natively process continuous, indefinite live streams (such as Icecast, HLS, or DASH) via decodeAudioData(), because that method expects a complete, finite buffer before decoding begins. Visualizing a live FLAC or AAC stream as it plays requires using an AnalyserNode in real time or generating waveform peaks on the server.

The Precomputed Peaks Alternative

Decoding high-resolution formats like FLAC or high-bitrate AAC directly in the client browser can consume significant CPU and memory, especially on mobile devices or with long recordings.

To visualize these files efficiently without transcoding the underlying audio, you can generate waveform peak data beforehand on the server. By passing a pre-generated array of peak values into the peaks configuration option of Wavesurfer.js, the library instantly draws the waveform without having to download the entire FLAC or AAC file upfront. When combined with the MediaElement backend, playback begins immediately via standard browser streaming mechanisms while the waveform remains fully interactive.
