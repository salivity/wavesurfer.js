Generate Wavesurfer.js Peaks with FFmpeg

Rendering audio waveforms dynamically in the browser can degrade performance and consume significant memory when processing large audio files. Wavesurfer.js solves this by allowing developers to supply pre-computed peak data directly through its peaks option or load method. Generating these peak arrays requires extracting audio amplitude values at a reduced sample rate using FFmpeg, normalizing those values, and saving them into a compatible JSON format.

Understanding Wavesurfer.js Peak Requirements

Wavesurfer.js expects peak data as an array of floating-point numbers typically normalized between -1.0 and 1.0 (or 0.0 to 1.0 for positive-only waveforms). For a standard two-channel stereo display, it can also accept an array of arrays representing min and max values or individual channels:

[0.023, 0.451, 0.892, 0.312, 0.054, -0.213, -0.654, ...]

The total number of samples corresponds to the visual resolution of the waveform. Usually, 800 to 2000 data points are sufficient to draw an accurate representation of a track on standard screen sizes.

Extracting Peak Samples Using FFmpeg

FFmpeg does not include a dedicated --export-wavesurfer-json flag, but it can downsample an audio track, extract raw Pulse-Code Modulation (PCM) amplitude data, or compute statistics frame-by-frame.

Method 1: Downsampling to Raw PCM

The most efficient method uses FFmpeg to convert the input audio to a single channel (mono), downsample the sample rate to match the desired number of visual points, and output raw 8-bit or 16-bit PCM data.

To generate roughly 1,000 peak points for a 100-second track, resample the audio to 10 Hz (10 samples per second):

ffmpeg -i input.mp3 -ac 1 -filter:a aresample=10 -f s16le -acodec pcm_s16le raw_peaks.pcm
  • -i input.mp3: Specifies the input audio file.
  • -ac 1: Mixes the audio down to a single channel.
  • -filter:a aresample=10: Sets the sampling rate so that total samples equal duration_in_seconds * sample_rate.
  • -f s16le -acodec pcm_s16le: Outputs raw, signed 16-bit little-endian binary samples.

Method 2: Extracting Peak Levels Directly with ffprobe

You can also use FFmpeg's astats audio filter coupled with ffprobe to directly export metadata in native JSON format:

ffprobe -v error -f lavfi -i "amovie=input.mp3,asetnsamples=n=44100,astats=metadata=1:reset=1" \
  -show_entries frame_tags=lavfi.astats.Overall.Peak_level \
  -of json > peaks_raw.json

This instructs FFmpeg to analyze the audio in windows defined by asetnsamples and output the peak amplitude for each frame directly into JSON formatting.

Converting PCM Data to the Final JSON Structure

When using the raw PCM downsampling method, convert the binary values to a normalized JSON array using a lightweight script.

In Node.js:

const fs = require('fs');

const buffer = fs.readFileSync('raw_peaks.pcm');
const peaks = [];

// Read 16-bit signed integers (values range from -32768 to 32767)
for (let i = 0; i < buffer.length; i += 2) {
  const sample = buffer.readInt16LE(i);
  // Normalize to -1.0 ... 1.0
  peaks.push(parseFloat((sample / 32768).toFixed(4)));
}

fs.writeFileSync('peaks.json', JSON.stringify(peaks));

In Python:

import struct
import json

with open("raw_peaks.pcm", "rb") as f:
    raw_data = f.read()

# Unpack 16-bit signed integers
samples = struct.unpack(f"<{len(raw_data) // 2}h", raw_data)

# Normalize between -1.0 and 1.0
peaks = [round(sample / 32768.0, 4) for sample in samples]

with open("peaks.json", "w") as f:
    json.dump(peaks, f)

Loading the Peak Data in Wavesurfer.js

Once peaks.json is generated, provide the data directly to Wavesurfer.js upon initialization or when calling the load method.

import WaveSurfer from 'wavesurfer.js';

async function initWaveform() {
  const response = await fetch('peaks.json');
  const peakData = await response.json();

  const wavesurfer = WaveSurfer.create({
    container: '#waveform',
    waveColor: '#4F4A85',
    progressColor: '#383351',
    peaks: [peakData] // Accepts array of peak arrays for channels
  });

  // Load the audio file using the pre-computed peaks
  wavesurfer.load('input.mp3', [peakData]);
}

initWaveform();

By passing the pre-computed array, Wavesurfer.js renders the waveform immediately without downloading the full audio file or decoding audio buffers in the client's browser thread.
