Build an Interactive Transcript with Wavesurfer.js

This article explains how to build an interactive media transcript player synchronized with audio using the Wavesurfer.js library. You will learn how to initialize the waveform visualizer, format timestamped transcript data, synchronize active text cues with audio playback, and enable click-to-seek functionality so users can navigate the media by clicking directly on words or phrases.

Prerequisites and Setup

To begin, include the Wavesurfer.js library via CDN in your HTML file along with a basic container for the waveform, the media element, and the transcript container.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Interactive Transcript Player</title>
  <script src="https://unpkg.com/wavesurfer.js@7"></script>
  <style>
    .transcript-line {
      cursor: pointer;
      padding: 4px 8px;
      margin-bottom: 4px;
      border-radius: 4px;
      transition: background-color 0.2s ease;
    }
    .transcript-line.active {
      background-color: #e0f2fe;
      color: #0284c7;
      font-weight: 600;
    }
  </style>
</head>
<body>
  <div id="waveform"></div>
  <div id="transcript"></div>
  <script src="app.js"></script>
</body>
</html>

Structuring Transcript Data

Store your transcript as an array of JSON objects. Each object needs a start time, an end time (in seconds), and the corresponding text.

const transcriptData = [
  { start: 0.0, end: 3.5, text: "Welcome to this interactive audio guide." },
  { start: 3.6, end: 7.2, text: "Clicking any text line will jump to that point in the audio." },
  { start: 7.3, end: 11.0, text: "The waveform and text stay perfectly in sync." }
];

Initializing Wavesurfer.js

Instantiate Wavesurfer by targeting the container element and providing your media source:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#cbd5e1',
  progressColor: '#0284c7',
  url: 'audio.mp3', // Path to your media file
});

Rendering and Interacting with the Transcript

Iterate over the transcript data to create DOM elements. Attach a click event listener to each element so that clicking a cue seeks the audio to that cue's start timestamp.

const transcriptContainer = document.getElementById('transcript');

transcriptData.forEach((item, index) => {
  const line = document.createElement('div');
  line.classList.add('transcript-line');
  line.dataset.start = item.start;
  line.dataset.end = item.end;
  line.id = `cue-${index}`;
  line.textContent = item.text;

  line.addEventListener('click', () => {
    wavesurfer.setTime(item.start);
    wavesurfer.play();
  });

  transcriptContainer.appendChild(line);
});

Synchronizing Active Cues During Playback

Use Wavesurfer's timeupdate event to check the current playback position against the transcript cue times. When a cue is active, apply the active styling class and scroll the text into view if necessary.

wavesurfer.on('timeupdate', (currentTime) => {
  transcriptData.forEach((item, index) => {
    const lineElement = document.getElementById(`cue-${index}`);
    const isActive = currentTime >= item.start && currentTime < item.end;

    if (isActive) {
      if (!lineElement.classList.contains('active')) {
        lineElement.classList.add('active');
        lineElement.scrollIntoView({ behavior: 'smooth', block: 'nearest' });
      }
    } else {
      lineElement.classList.remove('active');
    }
  });
});

Syncing with HTML5 Video

To pair this implementation with an HTML5 video element instead of standalone audio, bind Wavesurfer directly to the video element using the media configuration option:

const videoElement = document.querySelector('video');

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#cbd5e1',
  progressColor: '#0284c7',
  media: videoElement,
});

Using the media parameter ensures that play, pause, seek, and rate adjustments automatically propagate between the HTML5 video, the Wavesurfer timeline, and the transcript renderer.
