How to Render Continuous Line Peaks in Wavesurfer.js

In Wavesurfer.js, the visual presentation of audio peaks can be displayed either as segmented vertical bars or as smooth, continuous line paths. This article explains how the barWidth configuration parameter controls peak rendering behavior and demonstrates how to configure your player to display a continuous line path instead of discrete bars.

The barWidth Parameter

The rendering style of audio peaks in Wavesurfer.js is governed by the barWidth option passed during instance creation.

  • Discrete Bars: When barWidth is assigned a positive numerical value (such as 2 or 4), Wavesurfer.js renders the peak data as separated rectangular bars, with spacing defined by the barGap parameter.
  • Continuous Line Paths: When barWidth is omitted, set to null, or set to undefined, Wavesurfer.js switches its rendering mode to draw a continuous, connected path using canvas drawing methods (lineTo or curve interpolation) to connect the peak coordinates.

Configuring Continuous Line Paths

To render audio as a continuous waveform, omit barWidth entirely from your configuration object or set it explicitly to null.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  // Omit barWidth, or set it to null/undefined
  barWidth: null,
  // barGap and barRadius are ignored when barWidth is null
});

wavesurfer.load('path/to/audio.mp3');

Comparing Configurations

Bar Rendering Configuration

const barWaveform = WaveSurfer.create({
  container: '#waveform',
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
});

Continuous Line Path Configuration

const lineWaveform = WaveSurfer.create({
  container: '#waveform',
  barWidth: null, // Alters rendering back to continuous paths
});

When switching to continuous lines, complementary properties such as barGap, barRadius, and barAlign become inactive, as they only apply to discrete bar drawing routines. Visual customization for continuous paths is primarily handled through waveColor, progressColor, and container height settings.
