Real-Time Decibels in Wavesurfer.js

This guide explains how to calculate real-time decibel (dB) levels in Wavesurfer.js. While Wavesurfer.js does not feature a dedicated, out-of-the-box "decibel plugin," it exposes the Web Audio API nodes required to calculate volume and amplitude dynamically. Below is an explanation of the tools available, the standard formula used for decibel conversion, and a direct implementation guide.

The Built-In Options

Wavesurfer.js does not provide a standalone core plugin named strictly for decibel metering during playback. However, you can achieve real-time level tracking using two standard approaches:

  1. Custom Web Audio Integration (AnalyserNode): The primary and most accurate method for audio playback. You create a standard Web Audio API AnalyserNode, route Wavesurfer’s media stream through it, and sample the amplitude using a recurring animation frame.
  2. The Record Plugin (RecordPlugin): If tracking input levels (such as a microphone stream) rather than playback, the official Wavesurfer.js Record Plugin provides an integrated audio meter that can be queried for amplitude values.

Calculating Decibels from Amplitude

Decibels Relative to Full Scale (dBFS) are calculated using the Root Mean Square (RMS) of time-domain audio samples.

The formula for converting RMS amplitude to decibels is:

\[\text{dB} = 20 \times \log_{10}(\text{RMS})\]

An RMS value of 1.0 corresponds to 0 dBFS (maximum digital volume before clipping), while silence approaches negative infinity (conventionally clamped to -100 dBFS or -Infinity).

Implementation Guide

To track decibel levels during playback, initialize Wavesurfer, connect an AnalyserNode, and compute the level inside a requestAnimationFrame loop.

1. Setup the AnalyserNode

Connect an AnalyserNode to Wavesurfer’s audio output:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio.mp3',
});

let analyser;
let dataArray;

wavesurfer.on('ready', () => {
  const audioContext = new (window.AudioContext || window.webkitAudioContext)();
  const mediaElement = wavesurfer.getMediaElement();
  const source = audioContext.createMediaElementSource(mediaElement);

  analyser = audioContext.createAnalyser();
  analyser.fftSize = 256;

  source.connect(analyser);
  analyser.connect(audioContext.destination);

  dataArray = new Float32Array(analyser.fftSize);
});

2. Create the Real-Time Decibel Hook/Loop

Use requestAnimationFrame when playback is active to read time-domain data, calculate RMS, and convert to dBFS:

function getDecibelLevel() {
  if (!analyser || wavesurfer.isPaused()) return;

  analyser.getFloatTimeDomainData(dataArray);

  let sumSquares = 0.0;
  for (let i = 0; i < dataArray.length; i++) {
    sumSquares += dataArray[i] * dataArray[i];
  }

  const rms = Math.sqrt(sumSquares / dataArray.length);
  const decibels = rms > 0 ? 20 * Math.log10(rms) : -100;

  console.log(`Current Level: ${decibels.toFixed(2)} dBFS`);

  requestAnimationFrame(getDecibelLevel);
}

wavesurfer.on('play', () => {
  requestAnimationFrame(getDecibelLevel);
});

Summary

Wavesurfer.js relies on the native Web Audio API rather than a standalone decibel plugin for playback metering. By tapping the media element with an AnalyserNode and running an RMS calculation loop, you can extract precise, low-latency decibel levels suitable for VU meters and dynamic audio visualizations.
