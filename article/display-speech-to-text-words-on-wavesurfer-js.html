Display Speech-to-Text Words on Wavesurfer.js

This guide explains how to synchronize and render dynamic speech-to-text (STT) words directly over a Wavesurfer.js waveform. By combining word-level transcription timestamps with Wavesurfer’s Regions plugin and DOM event listeners, you can project synchronized, interactive text segments directly over audio visualizer peaks that dynamically highlight during playback.

1. Structure the Speech-to-Text Data

To place words accurately on a waveform timeline, your transcription service (such as Whisper, Deepgram, or Google Cloud Speech-to-Text) must provide word-level timestamps. Format the output into an array of objects containing the word text, start time, and end time in seconds:

const transcriptData = [
  { word: "Hello", start: 0.2, end: 0.6 },
  { word: "world,", start: 0.7, end: 1.1 },
  { word: "welcome", start: 1.2, end: 1.8 },
  { word: "to", start: 1.9, end: 2.1 },
  { word: "Wavesurfer.", start: 2.2, end: 2.9 }
];

2. Initialize Wavesurfer.js with the Regions Plugin

The most effective way to anchor text directly to the waveform canvas (so it scales, scrolls, and pans correctly with zoom levels) is using the official @wavesurfer/regions plugin.

Install and initialize Wavesurfer alongside the Regions plugin:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize the Regions plugin
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
  plugins: [wsRegions],
});

3. Add Words as Visual Regions

Once the audio is decoded, iterate through the speech-to-text array and add each word as a region. Ensure the regions are non-draggable and non-resizable if the goal is purely display.

wavesurfer.on('decode', () => {
  transcriptData.forEach((item, index) => {
    wsRegions.addRegion({
      id: `word-${index}`,
      start: item.start,
      end: item.end,
      content: item.word,
      drag: false,
      resize: false,
      color: 'rgba(0, 0, 0, 0)', // Transparent background
    });
  });
});

4. Style the Word Overlays

Customize the appearance of the text via CSS. Wavesurfer mounts regions inside the waveform wrapper, allowing you to position and style the inner label:

/* Container for each word region */
.wavesurfer-region {
  display: flex !important;
  align-items: center;
  justify-content: center;
  pointer-events: auto;
  cursor: pointer;
}

/* Region text styling */
.wavesurfer-region::after {
  content: attr(data-region-content);
  font-size: 13px;
  font-family: sans-serif;
  font-weight: 500;
  color: #ffffff;
  background: rgba(0, 0, 0, 0.65);
  padding: 2px 4px;
  border-radius: 3px;
  white-space: nowrap;
  transform: translateY(-50%);
}

/* Highlight state for active word */
.wavesurfer-region.active-word::after {
  background: #ffcc00;
  color: #000000;
  font-weight: bold;
}

5. Highlight Words Dynamically During Playback

Track playback progress using region events to trigger highlighting whenever the playhead enters and exits each word’s time boundary:

// Add highlight class when playhead enters a word boundary
wsRegions.on('region-in', (region) => {
  region.element.classList.add('active-word');
});

// Remove highlight class when playhead exits a word boundary
wsRegions.on('region-out', (region) => {
  region.element.classList.remove('active-word');
});

// Enable click-to-play functionality for each word
wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation();
  wavesurfer.setTime(region.start);
  wavesurfer.play();
});

This implementation keeps speech-to-text words structurally coupled to the audio canvas, perfectly aligned regardless of waveform resizing or zooming, and responsive to user interaction.
