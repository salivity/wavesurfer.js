How to Prevent Region Dragging in Wavesurfer.js

This article explains how to lock a region in Wavesurfer.js to prevent users from moving or repositioning it along the audio timeline. By configuring the Regions plugin parameters correctly, you can make visual audio annotations static and non-interactive.

To lock a region and prevent a user from dragging it across the waveform, set the drag parameter to false.

By default, the drag property in the Wavesurfer.js Regions plugin is set to true. When defining a region during creation, you can explicitly disable dragging by passing drag: false in the region's configuration object:

const wsRegions = wavesurfer.registerPlugin(WaveSurfer.Regions.create())

wsRegions.addRegion({
  start: 10,
  end: 25,
  color: 'rgba(255, 0, 0, 0.3)',
  drag: false, // Prevents the user from dragging the region
  resize: false // Optional: also prevents altering the start/end boundaries
})

If you also want to completely freeze the region in place so that the handles cannot be pulled to change its duration, pass resize: false alongside drag: false.

To lock an already existing region dynamically at runtime, you can call the setOptions method on the region instance:

region.setOptions({
  drag: false
})

Setting drag: false immediately disables user mouse and touch interactions for moving that specific segment, ensuring the region remains fixed at its assigned timestamps.
