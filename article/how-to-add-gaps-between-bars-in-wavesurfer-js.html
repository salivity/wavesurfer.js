How to Add Gaps Between Bars in Wavesurfer.js

Customizing audio visualizers often requires adding spacing between waveform bars to create a cleaner, modern user interface. This guide demonstrates how to configure the barGap and barWidth options in Wavesurfer.js to create distinct gaps between individual waveform bars, complete with a functional code example.

Using the barGap Option

By default, Wavesurfer.js renders a continuous waveform line. To display distinct bars separated by empty space, you must explicitly set both barWidth and barGap in the configuration object when initializing the instance.

  • barWidth: Defines the width of each individual bar in pixels.
  • barGap: Defines the horizontal spacing between consecutive bars in pixels.

Implementation Example

Pass these properties to the WaveSurfer.create() method:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
  
  // Bar styling
  barWidth: 3,       // Width of each bar in pixels
  barGap: 2,         // Gap between bars in pixels
  barRadius: 2       // Optional: adds rounded corners to bars
});

Important Considerations

  1. Both Properties Are Required: Setting barGap without setting barWidth will not produce gaps. If barWidth is omitted or set to null, Wavesurfer renders a continuous waveform where bar-spacing properties are ignored.
  2. Responsive Adjustments: If your container is narrow or the audio file is long, large values for barWidth and barGap may reduce the waveform's detail. Aim for a balanced ratio, such as a 2px to 4px bar width paired with a 1px to 3px gap.
  3. Rounded Bars: You can pair barGap with barRadius to round the top and bottom edges of each bar, making the visual separation even more pronounced.
