Map MediaSession API to Wavesurfer.js

This article explains how to connect the browser’s Media Session API with Wavesurfer.js to control audio playback through hardware keys, notification widgets, and lock screens. It outlines the specific Media Session action handlers that map directly to the play, pause, and seek methods in Wavesurfer.js, providing practical code examples for seamless integration.

Core Action Handler Mappings

The navigator.mediaSession.setActionHandler method listens for user input from the operating system or browser UI. To control a Wavesurfer.js instance, register the standard media action names and call the corresponding Wavesurfer methods inside the callbacks.

1. Play (play)

The play action triggers when the user presses a hardware play button, clicks play on a notification, or interacts with a media remote control.

  • MediaSession Action: 'play'
  • Wavesurfer Method: wavesurfer.play()
navigator.mediaSession.setActionHandler('play', () => {
  wavesurfer.play();
});

2. Pause (pause)

The pause action captures pause commands from the interface or external devices.

  • MediaSession Action: 'pause'
  • Wavesurfer Method: wavesurfer.pause()
navigator.mediaSession.setActionHandler('pause', () => {
  wavesurfer.pause();
});

3. Absolute Seeking (seekto)

The seekto action fires when a user drags the progress scrubber on a lock screen or system media card. The callback receives a details object containing seekTime (in seconds).

  • MediaSession Action: 'seekto'
  • Wavesurfer Method: wavesurfer.setTime(details.seekTime) (Wavesurfer v7+)
navigator.mediaSession.setActionHandler('seekto', (details) => {
  if (details.seekTime !== undefined) {
    wavesurfer.setTime(details.seekTime);
  }
});

(Note: In Wavesurfer v6 and earlier, absolute seeking is performed using a normalized value from 0 to 1: wavesurfer.seekTo(details.seekTime / wavesurfer.getDuration()).)

4. Relative Seeking (seekbackward and seekforward)

These actions fire when users click native "skip back" or "skip forward" interval buttons. The details object may supply a seekOffset (in seconds), but typically defaults to 10 seconds if undefined.

  • MediaSession Actions: 'seekbackward', 'seekforward'
  • Wavesurfer Method: wavesurfer.skip(seconds)
const defaultSkipTime = 10;

navigator.mediaSession.setActionHandler('seekbackward', (details) => {
  const skipTime = details.seekOffset || defaultSkipTime;
  wavesurfer.skip(-skipTime);
});

navigator.mediaSession.setActionHandler('seekforward', (details) => {
  const skipTime = details.seekOffset || defaultSkipTime;
  wavesurfer.skip(skipTime);
});

Synchronizing Position State

To ensure the system UI correctly displays the playhead and scrub bar, update the Media Session position state whenever Wavesurfer changes position or playback state:

function updatePositionState() {
  if ('setPositionState' in navigator.mediaSession) {
    navigator.mediaSession.setPositionState({
      duration: wavesurfer.getDuration() || 0,
      playbackRate: wavesurfer.getPlaybackRate() || 1,
      position: wavesurfer.getCurrentTime() || 0,
    });
  }
}

wavesurfer.on('play', () => {
  navigator.mediaSession.playbackState = 'playing';
  updatePositionState();
});

wavesurfer.on('pause', () => {
  navigator.mediaSession.playbackState = 'paused';
  updatePositionState();
});

wavesurfer.on('timeupdate', updatePositionState);
