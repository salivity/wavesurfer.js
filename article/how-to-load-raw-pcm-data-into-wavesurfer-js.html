How to Load Raw PCM Data into Wavesurfer.js

Loading raw PCM (Pulse Code Modulation) array data into Wavesurfer.js requires converting the uncompressed samples into a format the browser can decode or directly rendering them through the Web Audio API. Because raw PCM lacks file headers specifying sample rate, bit depth, and channel count, you must supply these parameters manually. This guide explains how to convert raw PCM arrays into an AudioBuffer or a minimal WAV container so Wavesurfer.js can visualize and play the audio seamlessly.

Understanding the PCM Format Requirement

Wavesurfer.js primarily relies on the browser's native decoding capabilities or the Web Audio API. Raw PCM data is typically represented as an Int16Array (16-bit signed integers) or a Float32Array (32-bit floating-point samples normalized between -1.0 and 1.0). To render and play this data, you have two primary approaches:

  1. Packaging PCM into a WAV Blob: Recommended for full playback and waveform visualization using standard HTML5 Audio.
  2. Creating an AudioBuffer: Ideal when using the Web Audio API directly to feed channel data into Wavesurfer.js.

Method 1: Wrapping PCM Data in a WAV Header (Recommended)

Because the default backend in Wavesurfer.js v7 uses an HTML5 <audio> element for playback, wrapping raw PCM data in an in-memory WAV container is the most reliable approach for both visualization and audio playback.

Step 1: Create the WAV Container Helper

Use the following function to prepend a 44-byte RIFF/WAV header to your raw PCM array:

function pcmToWav(pcmData, sampleRate = 44100, numChannels = 1, bitDepth = 16) {
  const bytesPerSample = bitDepth / 8;
  const blockAlign = numChannels * bytesPerSample;
  const byteRate = sampleRate * blockAlign;
  const dataSize = pcmData.length * bytesPerSample;
  const buffer = new ArrayBuffer(44 + dataSize);
  const view = new DataView(buffer);

  // RIFF Chunk Descriptor
  writeString(view, 0, 'RIFF');
  view.setUint32(4, 36 + dataSize, true);
  writeString(view, 8, 'WAVE');

  // "fmt " Sub-chunk
  writeString(view, 12, 'fmt ');
  view.setUint32(16, 16, true); // Subchunk1Size (16 for PCM)
  view.setUint16(20, 1, true);  // AudioFormat (1 = PCM)
  view.setUint16(22, numChannels, true);
  view.setUint32(24, sampleRate, true);
  view.setUint32(28, byteRate, true);
  view.setUint16(32, blockAlign, true);
  view.setUint16(34, bitDepth, true);

  // "data" Sub-chunk
  writeString(view, 36, 'data');
  view.setUint32(40, dataSize, true);

  // Write PCM Samples
  if (bitDepth === 16) {
    let offset = 44;
    for (let i = 0; i < pcmData.length; i++, offset += 2) {
      view.setInt16(offset, pcmData[i], true);
    }
  } else if (bitDepth === 32) {
    let offset = 44;
    for (let i = 0; i < pcmData.length; i++, offset += 4) {
      view.setFloat32(offset, pcmData[i], true);
    }
  }

  return new Blob([buffer], { type: 'audio/wav' });
}

function writeString(view, offset, string) {
  for (let i = 0; i < string.length; i++) {
    view.setUint8(offset + i, string.charCodeAt(i));
  }
}

Step 2: Load the Blob into Wavesurfer.js

Pass the resulting Blob directly to your Wavesurfer instance using loadBlob:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
});

// Example: Int16Array PCM data
const rawPcm = new Int16Array([...]); 
const sampleRate = 16000;
const channels = 1;

const wavBlob = pcmToWav(rawPcm, sampleRate, channels, 16);
wavesurfer.loadBlob(wavBlob);

Method 2: Populating an AudioBuffer via Web Audio API

If your PCM data is already in a Float32Array format (normalized from -1.0 to 1.0), you can construct an AudioBuffer and pass it directly to Wavesurfer.

Step 1: Normalize Int16 to Float32 (If Applicable)

If your data is stored as signed 16-bit integers, convert it to 32-bit floats:

function int16ToFloat32(int16Array) {
  const float32Array = new Float32Array(int16Array.length);
  for (let i = 0; i < int16Array.length; i++) {
    // Divide by 32768 to scale values between -1.0 and 1.0
    float32Array[i] = int16Array[i] < 0 ? int16Array[i] / 32768 : int16Array[i] / 32767;
  }
  return float32Array;
}

Step 2: Create the Buffer and Load Channel Data

Use the browser's AudioContext to construct the buffer and load it into Wavesurfer:

import WaveSurfer from 'wavesurfer.js';

const sampleRate = 44100;
const numChannels = 1;

const audioContext = new (window.AudioContext || window.webkitAudioContext)({
  sampleRate: sampleRate,
});

const float32Data = int16ToFloat32(rawPcmInt16);

// Create an empty AudioBuffer
const audioBuffer = audioContext.createBuffer(
  numChannels,
  float32Data.length,
  sampleRate
);

// Copy raw data into channel 0 (Left/Mono)
audioBuffer.copyToChannel(float32Data, 0);

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#10B981',
  progressColor: '#059669',
});

// Render the waveform directly from channel data
wavesurfer.load('', [audioBuffer.getChannelData(0)], audioBuffer.duration);

When using load('', [channelData], duration), Wavesurfer renders the waveform peaks immediately. If audio playback is required without a media container, you must manage playback through an AudioBufferSourceNode routed via the Web Audio API.
