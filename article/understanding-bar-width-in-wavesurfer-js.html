Understanding barWidth in Wavesurfer.js

The barWidth option in Wavesurfer.js is a rendering configuration that converts a standard continuous audio waveform into a series of distinct vertical bars. This article explains the primary function of barWidth, how it alters the visual representation of audio data, and how it interacts with other styling properties to create modern, customized audio players.

By default, Wavesurfer.js draws audio data as a continuous, filled path that mimics traditional analog sound waves. When you define the barWidth property in your configuration object, the library switches its rendering mode to draw individual vertical rectangles instead of an unbroken wave. The value assigned to barWidth represents the width of each bar measured in pixels.

Setting a numeric value for barWidth is essential for creating the segmented audio visualizer aesthetic popularized by platforms like SoundCloud and Spotify. Rather than rendering every single audio sample as connected lines, the canvas is divided into evenly spaced columns corresponding to the specified pixel width.

To achieve an optimal visual design, barWidth is typically paired with two complementary properties:

  • barGap: Sets the spacing in pixels between each consecutive bar. Without adjusting this, bars may appear crowded or bleed together depending on the resolution.
  • barRadius: Controls the corner rounding of the bars, smoothing the tops and bottoms of each column for a modern interface design.

A standard implementation looks like this:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
});

Using barWidth also improves performance on complex or long audio files. Because the browser renders distinct blocks instead of a dense, multi-point continuous path, it reduces the overall canvas drawing overhead, resulting in smoother scrolling and playback visualization.
