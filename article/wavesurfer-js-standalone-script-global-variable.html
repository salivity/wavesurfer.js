Wavesurfer.js Standalone Script Global Variable

When integrating the Wavesurfer.js audio visualization library into a web project without a module bundler, you must interact with the object it exposes to the browser environment. This article identifies the exact global variable exported by Wavesurfer.js when included via a standalone <script> tag, explains how to access it, and demonstrates its basic implementation.

The Global Variable: WaveSurfer

When loaded via a standard HTML <script> tag (such as from a CDN), Wavesurfer.js attaches a single global variable to the browser's window object: WaveSurfer.

The variable is case-sensitive, featuring a capital W and a capital S. You can reference it directly as WaveSurfer or explicitly through the window object as window.WaveSurfer.

Basic Implementation

To use Wavesurfer.js via a standalone script, include the library and reference the WaveSurfer object in your JavaScript code:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Wavesurfer Example</title>
  <!-- Load the standalone Wavesurfer.js script -->
  <script src="https://unpkg.com/wavesurfer.js@7"></script>
</head>
<body>
  <div id="waveform"></div>

  <script>
    // Access the global WaveSurfer object
    const wavesurfer = WaveSurfer.create({
      container: '#waveform',
      waveColor: '#4F4A85',
      progressColor: '#383351',
      url: '/path/to/audio.mp3',
    });

    wavesurfer.on('ready', () => {
      console.log('WaveSurfer is ready to play');
    });
  </script>
</body>
</html>

Accessing Plugins in Standalone Mode

If you load official Wavesurfer.js plugins using standalone script tags, they do not overwrite the main object. Instead, depending on the version, plugins typically register themselves under the WaveSurfer namespace (such as WaveSurfer.Regions) or as independent global objects prefixed with WaveSurfer (such as WaveSurferRegions). Always verify that the main WaveSurfer script is loaded before any supplementary plugin scripts.
