Align Multiple Timelines in Stacked Wavesurfer.js

Aligning multiple timeline plugins across stacked Wavesurfer.js instances requires ensuring identical horizontal scaling, synchronized scroll offsets, and consistent container geometry. When building multi-track audio editors or stacked waveform visualizers, disparities in audio duration, padding, or zoom levels can cause timelines to fall out of sync. This guide details how to configure timeline options, synchronize zoom and scroll events, and implement architectural strategies to keep multiple Wavesurfer.js timelines perfectly aligned.

1. Ensure Identical Container Dimensions and CSS Box Models

Misalignment frequently occurs due to subtle CSS differences across track containers. Every stacked track must share the exact same width, borders, margins, and padding.

  • Set box-sizing: border-box on all track wrapper elements.
  • If track controls (e.g., mute, solo, track labels) sit beside the waveforms, ensure these sidebars have a fixed, identical width across all rows.
  • Do not apply horizontal padding or borders directly to the div assigned as the Wavesurfer container. Apply styling to an outer parent element instead.

2. Standardize Zoom and Audio Durations

Wavesurfer timelines calculate tick positions based on the ratio of pixels to audio duration. If the stacked audio files have different lengths, their default timelines will not align visually.

Normalize Audio Duration

To keep ticks aligned across files of unequal lengths, determine the maximum duration among all tracks and pad shorter audio clips, or manually set the primary track's duration across all timeline calculations:

const maxDuration = Math.max(...tracks.map(t => t.duration));

Lock minPxPerSec Across Instances

When initializing Wavesurfer and the Timeline plugin, pass the identical minPxPerSec (pixels per second) value to each instance:

import WaveSurfer from 'wavesurfer.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';

const commonPxPerSec = 50;

const ws1 = WaveSurfer.create({
  container: '#waveform-1',
  minPxPerSec: commonPxPerSec,
  plugins: [
    TimelinePlugin.create({
      container: '#timeline-1',
      primaryLabelInterval: 5,
      secondaryLabelInterval: 1,
    }),
  ],
});

const ws2 = WaveSurfer.create({
  container: '#waveform-2',
  minPxPerSec: commonPxPerSec,
  plugins: [
    TimelinePlugin.create({
      container: '#timeline-2',
      primaryLabelInterval: 5,
      secondaryLabelInterval: 1,
    }),
  ],
});

3. Synchronize Zoom Events

When users zoom in or out, every Wavesurfer instance must receive the new minPxPerSec value simultaneously to maintain alignment.

function zoomAll(pxPerSec) {
  instances.forEach((ws) => {
    ws.zoom(pxPerSec);
  });
}

4. Synchronize Horizontal Scrolling

When waveforms overflow their containers and enable horizontal scrolling, scrolling one waveform must scroll all other stacked waveforms and their corresponding timelines.

Listen to the scroll event on the wrapper or the scroll container of one instance and propagate the scrollLeft position to the others:

const scrollContainer1 = ws1.getWrapper().parentElement;
const scrollContainer2 = ws2.getWrapper().parentElement;

let isSyncing = false;

function syncScroll(source, target) {
  source.addEventListener('scroll', () => {
    if (!isSyncing) {
      isSyncing = true;
      target.scrollLeft = source.scrollLeft;
      isSyncing = false;
    }
  });
}

syncScroll(scrollContainer1, scrollContainer2);
syncScroll(scrollContainer2, scrollContainer1);

5. Architectural Alternative: Use a Single Master Timeline

Rendering separate Timeline plugins for every stacked track increases DOM overhead and the likelihood of visual drift. In most professional audio interfaces, a single "master" timeline is placed at the top or bottom of the stack.

  1. Instantiate the TimelinePlugin on only the primary (or longest) track.
  2. Render the timeline in a dedicated sticky header above the waveforms.
  3. Synchronize the scrolling and zooming of all stacked waveforms to this master timeline.

This pattern eliminates the need to calculate and draw redundant timeline canvases while ensuring the playhead and time intervals remain uniform across all tracks.
