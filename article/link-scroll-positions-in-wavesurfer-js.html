Link Scroll Positions in Wavesurfer.js

This guide explains how to synchronize horizontal scroll positions between two separate audio tracks in Wavesurfer.js. When building multi-track audio editors or comparison tools, linking viewports ensures that navigating through one track instantly mirrors the position on the second track. Below is a direct, robust implementation using Wavesurfer.js DOM elements and event handlers to prevent recursive scroll loops.

1. Ensure Equal Zoom Levels

For scroll positions to align accurately in time, both instances must have the same duration or share the same horizontal scale. Ensure both instances use the same minPxPerSec configuration or adjust their zoom levels simultaneously:

const wsA = WaveSurfer.create({
  container: '#waveform-a',
  waveColor: 'violet',
  progressColor: 'purple',
  minPxPerSec: 100, // Keep this identical
  autoScroll: true,
});

const wsB = WaveSurfer.create({
  container: '#waveform-b',
  waveColor: 'teal',
  progressColor: 'darkcyan',
  minPxPerSec: 100, // Keep this identical
  autoScroll: true,
});

2. Access the Scroll Containers

In Wavesurfer.js (v7+), the scrollable element is located on the renderer via renderer.scrollContainer. In earlier versions (v6 and below), the container is accessed via drawer.wrapper.

Wait for both tracks to finish rendering before setting up listeners:

Promise.all([
  new Promise((resolve) => wsA.once('ready', resolve)),
  new Promise((resolve) => wsB.once('ready', resolve)),
]).then(() => {
  linkScroll(wsA, wsB);
});

3. Bidirectional Sync with an Infinite-Loop Guard

When trackA scrolls, it updates the scroll position of trackB. This programmatic change triggers trackB's scroll event, which can lead to an infinite feedback loop and UI stutter. Use an active sync flag to decouple the events:

function linkScroll(instanceA, instanceB) {
  // Wavesurfer v7 scroll containers
  const containerA = instanceA.renderer.scrollContainer;
  const containerB = instanceB.renderer.scrollContainer;

  let isSyncing = false;

  containerA.addEventListener('scroll', () => {
    if (!isSyncing) {
      isSyncing = true;
      containerB.scrollLeft = containerA.scrollLeft;
      requestAnimationFrame(() => {
        isSyncing = false;
      });
    }
  });

  containerB.addEventListener('scroll', () => {
    if (!isSyncing) {
      isSyncing = true;
      containerA.scrollLeft = containerB.scrollLeft;
      requestAnimationFrame(() => {
        isSyncing = false;
      });
    }
  });
}

4. Synchronizing Zoom Events

If users can dynamically zoom into either track, synchronize the zoom action so the linked scroll positions remain proportional:

function syncZoom(level) {
  wsA.zoom(level);
  wsB.zoom(level);
}

By binding the native scroll events directly to the renderer's scroll container and wrapping the state update with requestAnimationFrame, you achieve smooth, low-overhead scroll mirroring across both tracks.
