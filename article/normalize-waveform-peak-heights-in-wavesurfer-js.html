Normalize Waveform Peak Heights in Wavesurfer.js

This article explains how to normalize the peak visual heights in a Wavesurfer.js waveform using the built-in normalize configuration option. By enabling this setting, audio tracks with low recording levels are rendered with full-height peaks, ensuring consistent and readable visual representations across different tracks regardless of their original recording volume.

The normalize Option

To normalize the peak visual heights of a waveform in Wavesurfer.js, set the normalize parameter to true within the player's initialization options.

By default, normalize is set to false. When disabled, the rendered heights reflect the raw amplitude of the audio data relative to the maximum possible digital ceiling, which often causes quiet audio files to render as flat, nearly invisible lines.

Implementation Example

Pass normalize: true directly to the WaveSurfer.create() method:

import WaveSurfer from 'wavesurfer.js'

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
  normalize: true,
})

How It Works

When normalize is set to true, Wavesurfer.js scans the audio buffer to find the absolute maximum peak value. It then calculates a scaling factor based on that peak and scales all visual data points proportionally.

This ensures that:

  • The loudest point in the audio file reaches the full vertical boundary of the waveform canvas.
  • All quieter parts scale relative to the highest peak, preserving the dynamic contrast of the track.
  • The actual audio playback volume remains untouched; only the visual canvas rendering is modified.

Dynamically Toggling Normalization

You can also adjust the normalization behavior after initialization using the setOptions method:

// Enable normalization dynamically
wavesurfer.setOptions({ normalize: true })

// Disable normalization dynamically
wavesurfer.setOptions({ normalize: false })

Calling setOptions triggers an automatic redraw of the waveform with the updated scale.
