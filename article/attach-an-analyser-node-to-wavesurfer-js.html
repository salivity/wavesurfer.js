Attach an AnalyserNode to Wavesurfer.js

This guide explains how to connect a custom Web Audio API AnalyserNode to a Wavesurfer.js instance. By routing the underlying media element through an audio context and an analyser node, you can extract real-time frequency and time-domain data for visualizers, meters, and custom signal processing alongside your waveform display.

1. Initialize Wavesurfer.js

First, initialize your standard Wavesurfer instance. In modern versions (v7+), Wavesurfer relies on an underlying HTML5 <audio> element for playback.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/your-audio.mp3',
});

2. Create the AudioContext and AnalyserNode

Set up the Web Audio API context and create the AnalyserNode. Configure properties such as fftSize to match your analysis resolution requirements.

const audioContext = new (window.AudioContext || window.webkitAudioContext)();
const analyser = audioContext.createAnalyser();

analyser.fftSize = 256; // Defines frequency bin count (fftSize / 2)

3. Route Wavesurfer’s Media Element

To direct audio data through the analyser, extract the media element from the Wavesurfer instance using getMediaElement(), create a MediaElementAudioSourceNode, and link it into the Web Audio graph.

Because audio contexts require a user interaction to start, hook the connection logic to Wavesurfer's play event or ensure the context is resumed when playback starts.

let isConnected = false;

wavesurfer.on('play', async () => {
  if (audioContext.state === 'suspended') {
    await audioContext.resume();
  }

  if (!isConnected) {
    const mediaElement = wavesurfer.getMediaElement();
    const sourceNode = audioContext.createMediaElementSource(mediaElement);

    // Route: Source -> Analyser -> Output Destination
    sourceNode.connect(analyser);
    analyser.connect(audioContext.destination);

    isConnected = true;
  }
});

Note: A single HTMLMediaElement can only be connected to a MediaElementAudioSourceNode once. Using a boolean flag prevents duplicate connection errors on subsequent play events.

4. Read Real-Time Audio Data

Once connected, create a typed array corresponding to the analyser’s frequency bin count and read data using an animation loop:

const bufferLength = analyser.frequencyBinCount;
const dataArray = new Uint8Array(bufferLength);

function renderVisualizer() {
  requestAnimationFrame(renderVisualizer);

  // Populate dataArray with real-time frequency values (0 - 255)
  analyser.getByteFrequencyData(dataArray);

  // Use dataArray to render custom canvas visuals, meters, or effects
}

renderVisualizer();

To capture waveform/time-domain data rather than frequencies, replace getByteFrequencyData with analyser.getByteTimeDomainData(dataArray).
