Custom Right-Click Context Menu in Wavesurfer.js

This guide explains how to intercept the default browser context menu on a Wavesurfer.js waveform and display a custom context menu instead. By listening to native DOM events on the Wavesurfer container, preventing default browser behavior, and calculating audio timestamps relative to the click position, you can easily implement custom contextual actions such as adding markers, splitting audio, or seeking to specific playback positions.

1. Set Up the HTML Structure

Create a container for the waveform and a hidden HTML element that will serve as the custom context menu.

<!-- Wavesurfer Container -->
<div id="waveform"></div>

<!-- Custom Context Menu -->
<ul id="custom-context-menu" class="context-menu">
  <li id="menu-play-pause">Play / Pause</li>
  <li id="menu-seek-here">Seek Here</li>
  <li id="menu-add-marker">Add Marker</li>
</ul>

2. Apply Basic CSS

Style the custom menu to remain hidden by default and position it absolutely relative to the viewport or a parent container.

.context-menu {
  display: none;
  position: absolute;
  z-index: 1000;
  width: 150px;
  background-color: #ffffff;
  border: 1px solid #cccccc;
  box-shadow: 2px 2px 6px rgba(0, 0, 0, 0.2);
  list-style: none;
  padding: 5px 0;
  margin: 0;
}

.context-menu li {
  padding: 8px 12px;
  cursor: pointer;
}

.context-menu li:hover {
  background-color: #f0f0f0;
}

3. Attach the Event Listener

Target the Wavesurfer wrapper element and listen for the contextmenu event. Use preventDefault() to suppress the browser's default menu, display the custom menu at the mouse coordinates, and compute the corresponding audio timestamp.

import WaveSurfer from 'wavesurfer.js';

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: 'path/to/audio.mp3',
});

const menu = document.getElementById('custom-context-menu');
let targetAudioTime = 0;

// Wait for audio to be ready to calculate durations
wavesurfer.on('ready', () => {
  const wrapper = wavesurfer.getWrapper();

  wrapper.addEventListener('contextmenu', (event) => {
    event.preventDefault();

    // Calculate click position relative to the waveform width
    const rect = wrapper.getBoundingClientRect();
    const relativeX = event.clientX - rect.left;
    const progress = Math.max(0, Math.min(1, relativeX / rect.width));
    targetAudioTime = progress * wavesurfer.getDuration();

    // Position and display the custom context menu
    menu.style.top = `${event.pageY}px`;
    menu.style.left = `${event.pageX}px`;
    menu.style.display = 'block';
  });
});

// Hide menu on outside click
window.addEventListener('click', (event) => {
  if (!menu.contains(event.target)) {
    menu.style.display = 'none';
  }
});

4. Bind Menu Actions

Attach click handlers to the menu items to trigger Wavesurfer methods using the calculated targetAudioTime.

document.getElementById('menu-play-pause').addEventListener('click', () => {
  wavesurfer.playPause();
  menu.style.display = 'none';
});

document.getElementById('menu-seek-here').addEventListener('click', () => {
  wavesurfer.setTime(targetAudioTime);
  menu.style.display = 'none';
});

document.getElementById('menu-add-marker').addEventListener('click', () => {
  console.log(`Marker placed at: ${targetAudioTime.toFixed(2)}s`);
  // Insert custom marker/region logic here
  menu.style.display = 'none';
});
