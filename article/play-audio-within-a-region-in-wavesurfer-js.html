Play Audio Within a Region in Wavesurfer.js

This article explains how to restrict audio playback to specific start and end boundaries in Wavesurfer.js. You will learn the exact method provided by the Wavesurfer.js Regions plugin to play strictly within a designated segment, how it functions under the hood, and how to implement it directly in your code.

To play audio strictly between a defined start and end time, use the play() method on an individual Region instance created via the Regions plugin (regions.addRegion()). Calling region.play() automatically seeks the playhead to the region's start time, begins playback, and pauses the audio when the playhead reaches the region's end time.

Implementation with the Regions Plugin

To use this feature, initialize the Regions plugin, add a region to your Wavesurfer instance, and invoke play() on the resulting region object:

import WaveSurfer from 'wavesurfer.js'
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js'

// Initialize Wavesurfer with the Regions plugin
const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/audio.mp3',
})

const wsRegions = ws.registerPlugin(RegionsPlugin.create())

ws.on('ready', () => {
  // Define a region with start and end times in seconds
  const myRegion = wsRegions.addRegion({
    start: 10,
    end: 20,
    color: 'rgba(0, 255, 0, 0.1)',
  })

  // Plays audio strictly from second 10 to second 20
  myRegion.play()
})

Core Mechanism and Manual Alternative

When region.play() is invoked, the plugin sets the audio current time to region.start, calls the underlying media element's play() function, and registers an internal listener on time updates. Once the playback time is greater than or equal to region.end, the plugin automatically halts playback.

If you are not using the Regions plugin and want to achieve the same strict boundary behavior using core Wavesurfer.js methods, monitor the timeupdate event manually:

function playSegment(wavesurfer, startTime, endTime) {
  wavesurfer.setTime(startTime)
  wavesurfer.play()

  const onTimeUpdate = (currentTime) => {
    if (currentTime >= endTime) {
      wavesurfer.pause()
      wavesurfer.un('timeupdate', onTimeUpdate)
    }
  }

  wavesurfer.on('timeupdate', onTimeUpdate)
}

Using region.play() remains the standard and most reliable method because the Regions plugin automatically manages cleanup, boundary checks, and loop behaviors for designated audio sections.
