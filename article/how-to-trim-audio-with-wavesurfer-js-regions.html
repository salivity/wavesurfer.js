How to Trim Audio with Wavesurfer.js Regions

This guide explains how to implement client-side audio trimming using Wavesurfer.js and its Regions plugin. You will learn how to initialize the waveform viewer, configure an interactive selection region, extract start and end timestamps, and slice the underlying Web Audio API buffer to export or play the trimmed audio segment.

1. Prerequisites and Installation

To implement audio trimming, you need the core wavesurfer.js package and the @wavesurfer/regions plugin.

Install them via npm:

npm install wavesurfer.js

Or load them via CDN in your HTML:

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/plugins/regions.min.js"></script>

2. Initialize Wavesurfer with the Regions Plugin

Set up the Wavesurfer instance and register the Regions plugin. The Regions plugin handles the visual selection overlay that users drag and resize to select the cut range.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Create Regions plugin instance
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
  plugins: [wsRegions],
});

3. Add an Interactive Trimming Region

Once the audio decodes and loads, create a single region representing the portion of the audio to keep. Set drag and resize to true to allow user adjustments.

let activeRegion = null;

wavesurfer.on('decode', () => {
  // Clear any existing regions to allow only one trim selection
  wsRegions.clearRegions();

  // Create an initial region spanning the first 10 seconds (or desired defaults)
  activeRegion = wsRegions.addRegion({
    start: 0,
    end: Math.min(10, wavesurfer.getDuration()),
    color: 'rgba(0, 255, 0, 0.2)',
    drag: true,
    resize: true,
  });
});

// Update the active region reference whenever it changes
wsRegions.on('region-updated', (region) => {
  activeRegion = region;
});

4. Slice the Audio Buffer

Wavesurfer visually defines the boundaries, but cutting the actual audio requires manipulating the underlying AudioBuffer. Use the browser's Web Audio API to copy the PCM audio samples between region.start and region.end.

function trimAudio(audioBuffer, start, end) {
  const sampleRate = audioBuffer.sampleRate;
  const numberOfChannels = audioBuffer.numberOfChannels;
  
  const startSample = Math.floor(start * sampleRate);
  const endSample = Math.floor(end * sampleRate);
  const frameCount = endSample - startSample;

  const audioContext = new (window.AudioContext || window.webkitAudioContext)();
  const trimmedBuffer = audioContext.createBuffer(numberOfChannels, frameCount, sampleRate);

  for (let channel = 0; channel < numberOfChannels; channel++) {
    const originalData = audioBuffer.getChannelData(channel);
    const trimmedData = trimmedBuffer.getChannelData(channel);

    for (let i = 0; i < frameCount; i++) {
      trimmedData[i] = originalData[startSample + i];
    }
  }

  return trimmedBuffer;
}

5. Execute the Trim and Handle the Output

Connect the process to a button. Retrieve the decoded audio data directly from Wavesurfer, run the trim function, and load the new buffer back into Wavesurfer or prepare it for download.

document.getElementById('trim-btn').addEventListener('click', () => {
  if (!activeRegion) return;

  const originalBuffer = wavesurfer.getDecodedData();
  if (!originalBuffer) return;

  const startTime = activeRegion.start;
  const endTime = activeRegion.end;

  // Generate the trimmed buffer
  const trimmedAudioBuffer = trimAudio(originalBuffer, startTime, endTime);

  // Clear regions after trimming
  wsRegions.clearRegions();

  // Load the newly trimmed buffer directly back into Wavesurfer
  wavesurfer.loadAudioBuffer(trimmedAudioBuffer);
});

6. Export to Downloadable Audio (Optional)

To allow users to download the trimmed section as a .wav file, convert the trimmedAudioBuffer to a Blob using standard PCM encoding techniques, create an object URL, and trigger a programmatic download link.
