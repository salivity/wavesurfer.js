Customize Wavesurfer.js Waveform with Gradients

Customizing the visual appearance of audio waveforms using gradients can elevate the design of any web-based audio player. Wavesurfer.js allows developers to replace standard solid colors with smooth, dynamic linear gradients for both unplayed and played states. This guide walks through how to create HTML5 canvas gradients and apply them to the waveColor and progressColor options in Wavesurfer.js.

Understanding Canvas Gradients in Wavesurfer.js

Wavesurfer.js renders waveforms onto an HTML5 <canvas> element. Because the waveColor and progressColor configuration properties accept native CanvasGradient objects in addition to CSS color strings, you can generate a custom gradient using the Canvas 2D API and pass it directly into your Wavesurfer configuration.

Step 1: Create a Canvas Gradient

Before initializing Wavesurfer, instantiate an offscreen canvas context to generate your gradient. Use createLinearGradient() to define the gradient's direction and dimensions.

// Create an offscreen canvas to generate the gradient
const canvas = document.createElement('canvas');
const ctx = canvas.getContext('2d');

// Define a vertical gradient (x0, y0, x1, y1)
// Match the y1 value to the height of your waveform container
const waveGradient = ctx.createLinearGradient(0, 0, 0, 128);
waveGradient.addColorStop(0, '#ff5e62');   // Top color
waveGradient.addColorStop(1, '#ff9966');   // Bottom color

// Define a separate gradient for the playback progress
const progressGradient = ctx.createLinearGradient(0, 0, 0, 128);
progressGradient.addColorStop(0, '#6a11cb');
progressGradient.addColorStop(1, '#2575fc');

Step 2: Pass Gradients to Wavesurfer Configuration

Assign your newly created gradient objects directly to waveColor and progressColor when initializing the player.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: waveGradient,
  progressColor: progressGradient,
  height: 128,
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
});

wavesurfer.load('path/to/audio-file.mp3');

Controlling Gradient Direction

The direction of your gradient is determined by the coordinates passed to ctx.createLinearGradient(x0, y0, x1, y1):

  • Vertical Gradient (Top to Bottom): Set x0 and x1 to 0, and set y1 to the height of the waveform.

    const vertical = ctx.createLinearGradient(0, 0, 0, height);

  • Horizontal Gradient (Left to Right): Set y0 and y1 to 0, and set x1 to the approximate width of the container.

    const horizontal = ctx.createLinearGradient(0, 0, width, 0);

Adding Multiple Color Stops

You can add as many color stops as needed using addColorStop(offset, color), where offset is a float between 0 (start) and 1 (end):

const multiStopGradient = ctx.createLinearGradient(0, 0, 0, 128);
multiStopGradient.addColorStop(0, '#00c6ff');
multiStopGradient.addColorStop(0.5, '#0072ff');
multiStopGradient.addColorStop(1, '#000b76');

Passing these customized canvas gradients gives you complete control over the depth, contrast, and theme integration of your audio visualization.
