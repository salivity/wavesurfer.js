Enable Smooth Waveform Scrolling in Wavesurfer.js

This guide explains how to enable smooth waveform scrolling during audio playback in Wavesurfer.js. You will learn the exact configuration properties required to activate continuous scrolling, how to center the playhead, and how to set the necessary zoom levels so the waveform overflows its container and animates smoothly.

The autoScroll Option

In modern versions of Wavesurfer.js (v7 and newer), smooth waveform scrolling animation is controlled by the autoScroll option. When set to true, Wavesurfer.js automatically animates the scroll position of the waveform container during playback to keep the current playhead position in view.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  minPxPerSec: 100,
  autoScroll: true,
  autoCenter: true,
});

Essential Companion Options

For autoScroll to operate visibly and smoothly, two additional settings are typically required:

1. minPxPerSec

Scrolling can only occur if the rendered waveform is wider than its parent HTML container. The minPxPerSec option sets the horizontal zoom level (the number of pixels rendered per second of audio). Increase this value until the audio length exceeds the container width, forcing a horizontal scrollbar.

2. autoCenter

Setting autoCenter: true ensures that the playhead remains centered inside the viewport as the waveform scrolls past, rather than only scrolling when the playhead approaches the edges of the visible area. This creates a continuous, smooth scrolling timeline animation similar to professional digital audio workstations (DAWs).
