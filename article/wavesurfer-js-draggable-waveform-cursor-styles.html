Wavesurfer.js Draggable Waveform Cursor Styles

This article outlines the standard CSS cursor styles used in Wavesurfer.js to visually indicate draggable states across audio waveforms and interactable plugins. Understanding these cursor types ensures clear user feedback during operations like waveform panning, timeline scrubbing, and region boundary adjustments.

Core Cursor Styles for Draggable States

In Wavesurfer.js, cursor cues communicate whether an element can be panned, repositioned, or resized along the audio timeline.

1. grab

The grab cursor (represented visually as an open hand) indicates that the waveform container or an element within it can be picked up and dragged. It is typically applied to:

  • The primary waveform container when drag-to-scroll or panning features are enabled.
  • Unclicked draggable regions created by the Regions plugin.

2. grabbing

The grabbing cursor (represented as a closed fist) indicates an active drag operation. It replaces grab the moment the user clicks and holds the mouse button down, remaining active until the mouse button is released.

3. ew-resize (or col-resize)

The ew-resize (east-west resize) cursor displays horizontal double-ended arrows. In Wavesurfer.js, it specifically indicates that the left or right edges of an audio segment can be dragged horizontally to expand or trim playback boundaries. This style is applied to:

  • The start and end handles of defined timeline regions.
  • Loop boundary adjustment points.

4. move

The move cursor (represented as a four-way arrow) serves as an alternative to grab to show that a highlighted segment or region can be translated along the timeline without changing its duration.

Implementing and Customizing Cursors

Wavesurfer.js relies primarily on standard CSS applied to its generated DOM elements. You can set or override draggable cursor behaviors through direct CSS targeting or initialization parameters:

  • Container Dragging: When enabling drag-to-scroll via the dragToSeek option or custom scroll handlers, apply cursor: grab; to the waveform wrapper, toggling to cursor: grabbing; on the mousedown and mouseup events.
  • Regions Plugin: Region handles are generated with custom classes (such as wavesurfer-handle), allowing you to override resize cursors using standard stylesheet declarations:
/* Style for region resize handles */
.wavesurfer-handle {
  cursor: ew-resize !important;
}

/* Style for entire draggable regions */
.wavesurfer-region {
  cursor: grab;
}

.wavesurfer-region:active {
  cursor: grabbing;
}
