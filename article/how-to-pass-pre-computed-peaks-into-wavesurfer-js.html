How to Pass Pre-Computed Peaks into Wavesurfer.js

This article explains how to pass pre-computed audio peaks directly into a Wavesurfer.js configuration to bypass client-side audio decoding. Using pre-computed peaks allows waveforms to render instantly, dramatically reducing CPU load and data consumption for users, especially when handling long audio files.

Why Use Pre-Computed Peaks?

By default, Wavesurfer.js downloads the entire audio file and decodes it via the Web Audio API to calculate waveform peaks. By generating peak data on the server beforehand using tools like audiowaveform or ffmpeg, you can supply this data directly during initialization.

Passing Peaks in Wavesurfer.js v7+

In modern versions of Wavesurfer.js (v7 and newer), the peaks parameter can be passed directly inside the initial configuration object passed to WaveSurfer.create(), alongside the audio url and duration.

import WaveSurfer from 'wavesurfer.js';

// Pre-computed peaks array (mono or multi-channel)
const precomputedPeaks = [
  [0.02, 0.45, 0.89, 0.12, -0.34, -0.78, 0.05, 0.62] // Channel 1
];

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/audio/track.mp3',
  peaks: precomputedPeaks,
  duration: 184 // Provide duration in seconds for accurate rendering
});

Passing Peaks via the .load() Method

If you create the instance first and fetch data asynchronously, you can alternatively supply peaks via the load method:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
});

// Load takes: url, peaks, and duration
wavesurfer.load('/audio/track.mp3', precomputedPeaks, 184);

Peak Data Format Requirements

Wavesurfer expects peaks to be provided as normalized floating-point numbers between -1 and 1 (or 0 to 1 depending on absolute vs. relative peak generation):

  • Mono Audio: A 1D array of floats [0.1, -0.2, 0.5, ...] or a single-element 2D array [[0.1, -0.2, 0.5, ...]].
  • Stereo Audio: A 2D array with two sub-arrays representing the left and right channels: [[...leftPeaks], [...rightPeaks]].

Always provide the duration property in seconds when providing pre-computed peaks, as this ensures the timeline and progress animations match the audio length before the media file is fully buffered.
