Disable Click to Seek in Wavesurfer.js

This guide explains how to prevent users from clicking or dragging on a Wavesurfer.js waveform to change the playback position. You will learn how to disable interaction at initialization, how to toggle the behavior dynamically at runtime, and how to achieve the same result using a pure CSS workaround.

Method 1: Using the interact Option

The cleanest way to disable clicking to seek is through Wavesurfer's built-in interact configuration property. Setting this option to false disables all mouse and touch interactions on the waveform, preventing the user from clicking or dragging to seek while still allowing you to control playback programmatically.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  interact: false // Disables click-to-seek and drag-to-seek
});

Method 2: Toggling Interaction Dynamically

If you need to enable or disable seeking conditionally (for example, preventing user seeking only during certain states), update the options dynamically using the setOptions method:

// Disable seeking
wavesurfer.setOptions({ interact: false });

// Re-enable seeking
wavesurfer.setOptions({ interact: true });

Method 3: Disabling Interaction via CSS

If you prefer to control user interaction through your stylesheet or UI state, use the CSS pointer-events property on the waveform container. This prevents all mouse click and touch events from reaching the underlying canvas elements.

/* Disable interaction via CSS */
#waveform {
  pointer-events: none;
}

You can toggle this in JavaScript by adding or removing a CSS class:

const container = document.querySelector('#waveform');

// Disable click-to-seek
container.classList.add('no-seek');

// Re-enable click-to-seek
container.classList.remove('no-seek');
.no-seek {
  pointer-events: none;
}
