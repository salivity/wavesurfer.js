How to Create Playable Regions in Wavesurfer.js

This guide explains how to define, configure, and play specific audio segments using the Wavesurfer.js Regions plugin. You will learn how to initialize the plugin alongside an audio waveform, add an interactive region with specified boundaries, and implement playback functionality so the selected region plays seamlessly on command.

1. Install and Import Wavesurfer.js and the Regions Plugin

To begin, ensure you have the core Wavesurfer.js package and its plugins available. If you are using a package manager like npm, install it via:

npm install wavesurfer.js

Then, import the main WaveSurfer class and the RegionsPlugin module into your project:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

If you are using HTML script tags via a CDN:

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/plugins/regions.min.js"></script>

2. Initialize WaveSurfer and Register the Plugin

Create your WaveSurfer instance and attach the Regions plugin using the registerPlugin method.

// 1. Initialize the Regions plugin
const wsRegions = RegionsPlugin.create();

// 2. Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: 'path/to/your/audio.mp3',
  plugins: [wsRegions],
});

3. Create a Playable Region

Once the audio file is ready, you can create a region by calling wsRegions.addRegion(). Define the start and end times in seconds, along with any styling or interaction properties.

wavesurfer.on('ready', () => {
  const region = wsRegions.addRegion({
    start: 5,               // Start time in seconds
    end: 15,                // End time in seconds
    content: 'Play Me',     // Optional label
    color: 'rgba(0, 123, 255, 0.2)', // Semi-transparent overlay
    drag: true,             // Allow users to move the region
    resize: true,           // Allow users to resize boundaries
  });

  // Play the region when clicked
  region.on('click', () => {
    region.play();
  });
});

4. Advanced Playback Controls

Play Region Programmatically

You can trigger playback from an external button by referencing the created region:

const playButton = document.getElementById('play-region-btn');

playButton.addEventListener('click', () => {
  region.play();
});

Loop a Region

To continuously loop the region during playback, listen to the region's playback events or pass the loop option directly depending on your implementation:

let loop = true;

// Replay the region once playback exits its boundary
region.on('out', () => {
  if (loop) {
    region.play();
  }
});

Stop at the End of a Region

By default, region.play() stops when the playback head hits the region's end boundary. If you are playing the audio manually via wavesurfer.play(start, end), ensure you stop the audio when it reaches the boundary:

wavesurfer.on('timeupdate', (currentTime) => {
  if (currentTime >= region.end) {
    wavesurfer.pause();
  }
});
