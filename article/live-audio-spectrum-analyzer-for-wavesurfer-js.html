Live Audio Spectrum Analyzer for Wavesurfer.js

Integrating a live audio spectrum analyzer adjacent to Wavesurfer.js requires tapping into the HTML5 Web Audio API, extracting real-time frequency data, and drawing the visual frames onto an adjacent HTML <canvas> element. This guide covers setting up the layout, hooking an AnalyserNode directly into Wavesurfer’s media source, and running an optimized rendering loop to animate the spectrum alongside playback.

1. Set Up the Layout

Create a container that houses both the Wavesurfer instance and an HTML5 canvas. You can use CSS Flexbox to align them horizontally (side-by-side) or vertically (stacked).

<div class="audio-visualizer-container">
  <!-- Wavesurfer target container -->
  <div id="waveform"></div>
  
  <!-- Canvas for frequency spectrum -->
  <canvas id="spectrum-canvas" width="400" height="128"></canvas>
</div>

<style>
  .audio-visualizer-container {
    display: flex;
    flex-direction: column; /* Use 'row' for side-by-side alignment */
    gap: 12px;
    width: 100%;
    max-width: 800px;
  }
  #waveform {
    width: 100%;
  }
  #spectrum-canvas {
    width: 100%;
    background-color: #121212;
    border-radius: 4px;
  }
</style>

2. Initialize Wavesurfer and Web Audio Nodes

Instantiate Wavesurfer, then capture its underlying media element to create an AudioContext pipeline with an AnalyserNode.

import WaveSurfer from 'wavesurfer.js';

const canvas = document.getElementById('spectrum-canvas');
const canvasCtx = canvas.getContext('2d');

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/your-audio.mp3',
});

let audioCtx;
let analyser;
let dataArray;
let animationId;

wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();

  // Create an AudioContext and connect it to the media element
  audioCtx = new (window.AudioContext || window.webkitAudioContext)();
  const source = audioCtx.createMediaElementSource(mediaElement);

  // Configure the AnalyserNode
  analyser = audioCtx.createAnalyser();
  analyser.fftSize = 256; // Controls frequency resolution (must be a power of 2)

  // Route: Source -> Analyser -> Output
  source.connect(analyser);
  analyser.connect(audioCtx.destination);

  // Initialize buffer for frequency values
  const bufferLength = analyser.frequencyBinCount;
  dataArray = new Uint8Array(bufferLength);
});

3. Build the Spectrum Drawing Function

Use requestAnimationFrame to continuously fetch byte frequency data from the analyser and draw bars onto the adjacent canvas.

function drawSpectrum() {
  animationId = requestAnimationFrame(drawSpectrum);

  analyser.getByteFrequencyData(dataArray);

  // Clear canvas for next frame
  canvasCtx.clearRect(0, 0, canvas.width, canvas.height);

  const barWidth = (canvas.width / dataArray.length) * 2;
  let x = 0;

  for (let i = 0; i < dataArray.length; i++) {
    const barHeight = (dataArray[i] / 255) * canvas.height;

    // Optional gradient or uniform color
    canvasCtx.fillStyle = `rgb(${barHeight + 50}, 100, 255)`;
    canvasCtx.fillRect(x, canvas.height - barHeight, barWidth, barHeight);

    x += barWidth + 1;
  }
}

4. Sync Visuals with Wavesurfer Playback

Trigger the rendering loop only while audio is actively playing to conserve system resources. Resume the AudioContext on user interaction to handle browser autoplay policies.

wavesurfer.on('play', () => {
  if (audioCtx.state === 'suspended') {
    audioCtx.resume();
  }
  drawSpectrum();
});

wavesurfer.on('pause', () => {
  cancelAnimationFrame(animationId);
});

wavesurfer.on('finish', () => {
  cancelAnimationFrame(animationId);
  canvasCtx.clearRect(0, 0, canvas.width, canvas.height);
});

wavesurfer.on('destroy', () => {
  cancelAnimationFrame(animationId);
  if (audioCtx) {
    audioCtx.close();
  }
});
