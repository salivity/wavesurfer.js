Jump Forward and Back Buttons in Wavesurfer.js

This article explains how to implement skip forward and skip backward functionality in an audio player using Wavesurfer.js. You will learn the required HTML markup and JavaScript methods needed to advance or rewind audio playback by a specified number of seconds.

The skip() Method

Wavesurfer.js provides a built-in skip() method on the player instance. Passing a positive number of seconds moves playback forward, while passing a negative number moves playback backward.

// Jump forward 10 seconds
wavesurfer.skip(10);

// Jump back 10 seconds
wavesurfer.skip(-10);

HTML Structure

Create the container element for the waveform and two button elements for the skip controls:

<div id="waveform"></div>

<button id="btn-back">Jump Back 10s</button>
<button id="btn-forward">Jump Forward 10s</button>

Complete JavaScript Implementation

Initialize the Wavesurfer instance and attach click event listeners to the buttons.

import WaveSurfer from 'wavesurfer.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

// Configure skip duration in seconds
const SKIP_TIME = 10;

// Grab button elements
const backButton = document.getElementById('btn-back');
const forwardButton = document.getElementById('btn-forward');

// Attach event listeners
backButton.addEventListener('click', () => {
  wavesurfer.skip(-SKIP_TIME);
});

forwardButton.addEventListener('click', () => {
  wavesurfer.skip(SKIP_TIME);
});

Alternative Method: setTime()

If you need explicit bounds checking or are working with absolute time values, you can achieve the same behavior using getCurrentTime(), getDuration(), and setTime():

// Jump back
backButton.addEventListener('click', () => {
  const newTime = Math.max(0, wavesurfer.getCurrentTime() - SKIP_TIME);
  wavesurfer.setTime(newTime);
});

// Jump forward
forwardButton.addEventListener('click', () => {
  const newTime = Math.min(wavesurfer.getDuration(), wavesurfer.getCurrentTime() + SKIP_TIME);
  wavesurfer.setTime(newTime);
});

Using wavesurfer.skip() is recommended for most use cases because it natively handles clamping values so playback does not exceed the start or end of the audio track.
