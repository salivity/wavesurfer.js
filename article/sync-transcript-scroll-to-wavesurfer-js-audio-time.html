Sync Transcript Scroll to Wavesurfer.js Audio Time

This guide explains how to automatically synchronize an external transcript's scroll position with the current playback time in Wavesurfer.js. By attaching timestamp metadata to transcript elements, listening to Wavesurfer's audio progress events, and utilizing native DOM scrolling methods, you can build a smooth, synchronized audio-to-text experience.

Step 1: Structure the Transcript HTML

Each transcript segment needs data attributes to store its start and end times in seconds. Wrap the transcript in a container with a fixed height and overflow scrolling enabled.

<div id="waveform"></div>

<div id="transcript-container" style="height: 300px; overflow-y: auto;">
  <p class="transcript-line" data-start="0.0" data-end="3.5">
    Welcome to this audio demonstration.
  </p>
  <p class="transcript-line" data-start="3.6" data-end="7.2">
    In this section, we discuss how text syncs with audio.
  </p>
  <p class="transcript-line" data-start="7.3" data-end="12.0">
    Wavesurfer emits events that make updating scroll positions easy.
  </p>
</div>

Step 2: Initialize Wavesurfer.js

Set up your Wavesurfer instance to load the audio file.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

Step 3: Listen for Playback Events

Use Wavesurfer's timeupdate event (or audioprocess in older versions) to detect the current playback timestamp. Iterate through the transcript items or use binary search to locate the active segment.

To maintain performance and prevent jittery scrolling, only trigger a scroll action when the active line changes.

const lines = Array.from(document.querySelectorAll('.transcript-line'));
let activeLine = null;

wavesurfer.on('timeupdate', (currentTime) => {
  // Find the line that matches the current time
  const currentLine = lines.find((line) => {
    const start = parseFloat(line.dataset.start);
    const end = parseFloat(line.dataset.end);
    return currentTime >= start && currentTime <= end;
  });

  // Only update if the active line has changed
  if (currentLine && currentLine !== activeLine) {
    if (activeLine) {
      activeLine.classList.remove('active');
    }

    currentLine.classList.add('active');
    activeLine = currentLine;

    // Scroll the transcript container to the active line
    currentLine.scrollIntoView({
      behavior: 'smooth',
      block: 'center', // Keeps the line centered within the container
    });
  }
});

Step 4: Handle User Clicks to Seek Audio (Optional)

To enable bidirectional interaction, allow users to click on transcript lines to jump the audio directly to that timestamp.

lines.forEach((line) => {
  line.addEventListener('click', () => {
    const start = parseFloat(line.dataset.start);
    const duration = wavesurfer.getDuration();
    
    // Seek to the line's start position (percentage between 0 and 1)
    wavesurfer.seekTo(start / duration);
  });
});

Performance Considerations

  • scrollIntoView settings: Using block: 'center' provides the best reading experience because the active phrase stays near the middle of the viewport rather than snapping to the top edge.
  • Scroll throttling: Storing activeLine prevents scrollIntoView from being called on every animation frame, saving CPU cycles and preventing native smooth-scrolling animations from conflicting with each other.
