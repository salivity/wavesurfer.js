Display Frames or Samples in Wavesurfer.js Timeline

Displaying secondary time units like video frames or raw audio samples in Wavesurfer.js allows for precise synchronization, video editing workflows, and audio engineering tasks. While the standard Timeline plugin defaults to hours, minutes, and seconds, you can output frames or sample counts by customizing the label formatting callback or by running concurrent timeline instances configured for secondary metrics.

Method 1: Customizing formatTimeCallback

The most direct way to show frames or samples is by modifying the Timeline plugin's formatTimeCallback function. This callback intercepts the raw time in seconds and lets you convert it into your desired unit before rendering the text label.

Displaying Video Frames (e.g., 30 FPS)

Multiply the current timestamp in seconds by your target frame rate (e.g., 24, 29.97, or 30 fps) to compute the frame index:

import WaveSurfer from 'wavesurfer.js'
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js'

const FRAME_RATE = 30

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  plugins: [
    TimelinePlugin.create({
      container: '#timeline',
      formatTimeCallback: (seconds) => {
        const totalFrames = Math.floor(seconds * FRAME_RATE)
        const frameRemainder = totalFrames % FRAME_RATE
        const mins = Math.floor(seconds / 60)
        const secs = Math.floor(seconds % 60)

        // Formats as MM:SS:FF (Frames)
        return `${String(mins).padStart(2, '0')}:${String(secs).padStart(2, '0')}:${String(frameRemainder).padStart(2, '0')}`
      },
    }),
  ],
})

Displaying Raw Audio Samples

To show raw sample counts, multiply the seconds by the audio buffer's sample rate (such as 44,100 Hz or 48,000 Hz):

const SAMPLE_RATE = 44100

TimelinePlugin.create({
  container: '#timeline',
  formatTimeCallback: (seconds) => {
    const samples = Math.floor(seconds * SAMPLE_RATE)
    return `${samples.toLocaleString()} spl`
  },
})

Method 2: Stacking Dual Timelines

If you need to show standard wall-clock time alongside frames or samples simultaneously, attach two separate instances of TimelinePlugin to your WaveSurfer instance, each rendering into its own HTML container.

HTML Structure

<div id="waveform"></div>
<div id="timeline-standard"></div>
<div id="timeline-frames"></div>

JavaScript Implementation

import WaveSurfer from 'wavesurfer.js'
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js'

const FRAME_RATE = 24

// 1. Primary timeline: Standard Time (MM:SS)
const standardTimeline = TimelinePlugin.create({
  container: '#timeline-standard',
  height: 20,
  timeInterval: 1,
  primaryLabelInterval: 5,
  style: {
    fontSize: '11px',
    color: '#6B7280',
  },
})

// 2. Secondary timeline: Frame Indices
const frameTimeline = TimelinePlugin.create({
  container: '#timeline-frames',
  height: 20,
  timeInterval: 1,
  primaryLabelInterval: 5,
  formatTimeCallback: (seconds) => {
    return `f: ${Math.floor(seconds * FRAME_RATE)}`
  },
  style: {
    fontSize: '11px',
    color: '#10B981',
  },
})

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  plugins: [standardTimeline, frameTimeline],
})

Adjusting Tick Density for Frame Accuracies

When zooming in closely to inspect individual frames or high sample counts, adjust the timeInterval and primaryLabelInterval parameters to prevent text overlaps:

  • timeInterval: Controls the interval (in seconds) between each minor notch.
  • primaryLabelInterval: Controls the frequency of major intervals displaying text labels.
  • wavesurfer.zoom(pxPerSec): Increase the zoom factor so that high-frequency units have adequate physical space on the canvas to display legibly.
