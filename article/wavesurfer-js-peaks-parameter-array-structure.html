Wavesurfer.js Peaks Parameter Array Structure

This guide outlines the expected array structure for the peaks parameter in Wavesurfer.js, detailing the exact data formats, channel representations, and value normalization required to render pre-computed waveforms efficiently.

Primary Array Format: Multi-Channel 2D Array

The standard format expected by Wavesurfer.js for the peaks parameter is a two-dimensional array (or an array of Float32Array objects). Each top-level element corresponds to an audio channel:

[
  [channel_0_peaks], // Left or Mono channel
  [channel_1_peaks]  // Right channel (optional)
]

Mono and Single-Channel Audio

For mono audio, you should wrap the peak data in an outer array representing a single channel:

const peaks = [
  [-0.5, 0.5, -0.8, 0.8, -0.2, 0.3]
];

wavesurfer.load('audio.mp3', peaks);

While some versions of Wavesurfer.js accept a flat 1D array ([peak1, peak2, ...]) for mono tracks, providing a 2D array ([ [peak1, peak2, ...] ]) guarantees compatibility across versions.

Stereo and Multi-Channel Audio

For multi-channel or stereo tracks, pass separate arrays for each channel inside the parent array:

const stereoPeaks = [
  [-0.6, 0.7, -0.4, 0.5], // Channel 0 (Left)
  [-0.5, 0.6, -0.3, 0.4]  // Channel 1 (Right)
];

wavesurfer.load('audio.mp3', stereoPeaks);

Value Normalization and Ranges

The numbers inside each channel array must be normalized floating-point numbers:

  • Range: Values must fall strictly between -1.0 and 1.0.
  • Min/Max Pairs: If generating peaks from tools like audiowaveform or FFmpeg, peak sequences typically alternate between minimum and maximum amplitudes (e.g., [-0.45, 0.52, -0.30, 0.35]). Wavesurfer uses these pairs to draw the top and bottom bounds of the waveform.
  • Positive-Only (Absolute) Peaks: You may also provide non-negative floats (between 0.0 and 1.0). Wavesurfer will mirror these values across the center line to create a symmetrical waveform.
