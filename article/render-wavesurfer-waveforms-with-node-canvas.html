Render Wavesurfer Waveforms with Node-Canvas

Generating server-side waveform images that match client-side Wavesurfer.js visualizations requires synchronizing audio peak extraction and canvas rendering parameters between the browser and Node.js. By configuring node-canvas with matching dimensions, pixel density, bar geometry, and normalization mathematics, you can export static PNG files that are visually indistinguishable from live Wavesurfer.js components.

1. Match Canvas Dimensions and Pixel Ratio

Wavesurfer.js scales the HTML5 canvas based on the browser's device pixel ratio (window.devicePixelRatio) to prevent blurriness on high-DPI displays. In node-canvas, you must explicitly account for this scaling:

const { createCanvas } = require('canvas');

const width = 800; // Desired CSS width
const height = 128; // Desired CSS height
const pixelRatio = 1; // Set to 1 for standard 1:1 matching, or 2 for Retina

const canvas = createCanvas(width * pixelRatio, height * pixelRatio);
const ctx = canvas.getContext('2d');
ctx.scale(pixelRatio, pixelRatio);

If your frontend configuration sets pixelRatio: 1 or explicitly defines renderOptions, match that value on the server. Otherwise, default frontend renders will produce images scaled by the client screen's DPI.

2. Synchronize Peak Decimation

Wavesurfer does not render raw PCM samples directly; it decodes audio into min and max floating-point amplitudes grouped into "peaks" based on the total width or number of bars.

To match Wavesurfer's peak generation:

  • Split your decoded linear PCM data (from a 32-bit float array) into buckets.
  • The number of buckets should equal the render width in pixels, or if using bars, Math.floor(width / (barWidth + barGap)).
  • For each bucket, calculate the maximum positive value and minimum negative value (between -1.0 and 1.0).

3. Replicate Drawing Parameters and Math

Wavesurfer.js offers continuous line rendering and discrete bar rendering. The discrete bar style (barWidth > 0) is the most common. Configure node-canvas to iterate over the calculated peaks using identical geometry rules:

  • Bar Placement: Each bar is positioned horizontally at i * (barWidth + barGap).
  • Bar Alignment: Peaks are mirrored vertically around the vertical center (height / 2). A peak value of 1.0 extends to 0 (top), and -1.0 extends to height (bottom).
  • Bar Radius: If Wavesurfer's barRadius option is set, use ctx.roundRect() or arc drawing methods to round the bar ends.
function drawWaveform(ctx, peaks, options) {
  const { width, height, barWidth = 2, barGap = 1, barRadius = 0, waveColor = '#4F46E5' } = options;
  const halfHeight = height / 2;

  ctx.fillStyle = waveColor;

  for (let i = 0; i < peaks.length; i += 2) {
    const min = peaks[i];     // e.g., -0.8
    const max = peaks[i + 1]; // e.g., 0.8

    const barX = (i / 2) * (barWidth + barGap);
    const topY = halfHeight - (max * halfHeight);
    const barHeight = Math.max(1, (max - min) * halfHeight);

    if (barRadius > 0 && typeof ctx.roundRect === 'function') {
      ctx.beginPath();
      ctx.roundRect(barX, topY, barWidth, barHeight, barRadius);
      ctx.fill();
    } else {
      ctx.fillRect(barX, topY, barWidth, barHeight);
    }
  }
}

4. Color, Normalization, and Anti-Aliasing

  • Color: Pass identical hex, RGB, or canvas gradient values to ctx.fillStyle.
  • Normalization: Wavesurfer normalizes waveforms by default (normalize: true), scaling the peak values so the highest absolute peak reaches 1.0. Divide all peak values by the absolute maximum peak in the file before drawing.
  • Anti-Aliasing: node-canvas applies anti-aliasing by default. To match standard browser rendering, leave ctx.imageSmoothingEnabled = true and ensure bar coordinates do not shift into subpixel boundaries by applying Math.round() to horizontal coordinates if barGap is an integer.

5. Exporting the Buffer

Once drawn, extract the raw PNG buffer directly to disk or an API response:

const fs = require('fs');
const buffer = canvas.toBuffer('image/png');
fs.writeFileSync('waveform.png', buffer);

Using these shared calculations ensures the resulting PNG matches the vector output generated by Wavesurfer.js in the browser.
