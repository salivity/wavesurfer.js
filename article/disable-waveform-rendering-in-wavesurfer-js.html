Disable Waveform Rendering in Wavesurfer.js

This article explains how to run Wavesurfer.js purely as an audio player without rendering canvas waveforms to the screen. By utilizing off-DOM elements, overriding the render function, or suppressing the container styling, you can preserve all audio playback controls, event listeners, and API methods while eliminating the performance overhead of visual rendering.

Method 1: Use a Detached DOM Element (Recommended)

The cleanest approach to run Wavesurfer.js in a "headless" mode is to initialize it with an HTML element that is never appended to the document body. Wavesurfer requires a DOM node for its container option, but that node does not have to be visible or attached to the page.

import WaveSurfer from 'wavesurfer.js';

// Create a detached container that is not added to the DOM
const hiddenContainer = document.createElement('div');

const wavesurfer = WaveSurfer.create({
  container: hiddenContainer,
  url: '/path/to/audio.mp3',
});

// Audio controls function normally
wavesurfer.on('ready', () => {
  wavesurfer.play();
});

wavesurfer.on('audioprocess', (currentTime) => {
  console.log('Current time:', currentTime);
});

Because the container is not in the active DOM tree, the browser does not calculate layout or paint the canvas pixels to the screen, while the underlying HTML5 Audio or Web Audio engine continues to handle decoding, playback, and timing events.

Method 2: Override the Render Function (Wavesurfer.js v7+)

Wavesurfer.js version 7 introduces a renderFunction option that determines how peaks are drawn onto the canvas. By passing an empty function, you completely disable the waveform drawing routines.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  url: '/path/to/audio.mp3',
  height: 0,
  renderFunction: () => {
    // Return empty callback to prevent canvas drawing
  },
});

Setting height: 0 alongside an empty renderFunction ensures that no canvas elements occupy vertical space in your layout.

Method 3: Hide the Container via CSS

If you need to dynamically toggle waveform visibility without destroying and re-instantiating the player instance, hide the parent element using CSS:

<div id="waveform" style="display: none;"></div>
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  url: '/path/to/audio.mp3',
});

// Control playback programmatically
document.getElementById('play-btn').addEventListener('click', () => {
  wavesurfer.playPause();
});

Note: While display: none stops visual presentation, Wavesurfer may still attempt to compute waveform peaks in memory when the audio file loads. If peak computation causes performance bottlenecks on low-end devices, prefer Method 1.
