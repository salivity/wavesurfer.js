Scrub Audio with Arrow Keys in Wavesurfer.js

Wavesurfer.js does not include keyboard-based scrubbing out of the box, but you can easily implement fine-grained backward and forward audio navigation using native DOM keyboard event listeners. By binding a keydown listener to the document or a focused container, you can capture ArrowLeft and ArrowRight keystrokes and control the playback position using Wavesurfer's built-in navigation methods.

Setting Up Arrow Key Listeners

To enable scrubbing, add a keydown event listener to window or document. Within the handler, evaluate event.key for ArrowLeft and ArrowRight, prevent the default browser scrolling behavior, and adjust the audio position using the skip() method.

// Define the step size in seconds (e.g., 0.1 for fine-grained scrubbing)
const STEP = 0.1;

window.addEventListener('keydown', (event) => {
  // Ignore keystrokes when the user is typing in form inputs
  if (['INPUT', 'TEXTAREA'].includes(document.activeElement.tagName)) {
    return;
  }

  if (event.key === 'ArrowLeft') {
    event.preventDefault();
    wavesurfer.skip(-STEP);
  } else if (event.key === 'ArrowRight') {
    event.preventDefault();
    wavesurfer.skip(STEP);
  }
});

Implementing Multi-Speed Scrubbing with Modifiers

For precise audio editing, transcription, or waveform inspection, you can combine arrow keys with modifier keys (such as Shift or Alt) to toggle between micro-adjustments and standard scrubbing steps:

window.addEventListener('keydown', (event) => {
  if (['INPUT', 'TEXTAREA'].includes(document.activeElement.tagName)) {
    return;
  }

  // Use 0.05s for fine control with Shift, or 0.5s for standard scrubbing
  const step = event.shiftKey ? 0.05 : 0.5;

  if (event.key === 'ArrowLeft') {
    event.preventDefault();
    wavesurfer.skip(-step);
  } else if (event.key === 'ArrowRight') {
    event.preventDefault();
    wavesurfer.skip(step);
  }
});

Alternative: Using setTime

In modern versions of Wavesurfer.js (v7+), wavesurfer.skip() is the primary shortcut for relative jumps. However, you can also manipulate the timeline directly using wavesurfer.getCurrentTime() and wavesurfer.setTime():

const step = 0.25;
const currentTime = wavesurfer.getCurrentTime();

if (event.key === 'ArrowLeft') {
  event.preventDefault();
  wavesurfer.setTime(Math.max(0, currentTime - step));
} else if (event.key === 'ArrowRight') {
  event.preventDefault();
  wavesurfer.setTime(Math.min(wavesurfer.getDuration(), currentTime + step));
}

Cleanup

When unmounting your player or destroying the Wavesurfer instance, remove the listener using window.removeEventListener('keydown', handler) to prevent memory leaks and unexpected audio calls on destroyed instances.
