How to Add Zoom Buttons in Wavesurfer.js

This article explains how to implement custom zoom-in and zoom-out buttons for an audio waveform using Wavesurfer.js. You will learn how to initialize the player, track the zoom level, and use the built-in zoom method to adjust the visual scale of the audio track dynamically.

1. Set Up the HTML Structure

Create a container for the waveform and two simple button elements for the zoom controls:

<div id="waveform"></div>

<div class="controls">
  <button id="zoom-out">- Zoom Out</button>
  <button id="zoom-in">+ Zoom In</button>
</div>

2. Initialize Wavesurfer.js

Import or include Wavesurfer.js (version 7+) and instantiate it with your target container and audio source:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: 'audio-file.mp3',
  minPxPerSec: 50, // Initial zoom level (pixels per second)
});

3. Implement the Zoom Logic

The wavesurfer.zoom(pxPerSec) method changes the horizontal resolution of the waveform by setting the minimum number of pixels rendered per second of audio.

Define a current zoom state, set a step value, and attach event listeners to your buttons:

// Reference the buttons
const zoomInBtn = document.getElementById('zoom-in');
const zoomOutBtn = document.getElementById('zoom-out');

// Configuration
let currentZoom = 50; // Must match initial minPxPerSec
const zoomStep = 20;  // Pixels per second to add or subtract
const minZoom = 10;   // Lowest allowed zoom level
const maxZoom = 500;  // Highest allowed zoom level

// Zoom In Handler
zoomInBtn.addEventListener('click', () => {
  if (currentZoom < maxZoom) {
    currentZoom = Math.min(currentZoom + zoomStep, maxZoom);
    wavesurfer.zoom(currentZoom);
  }
});

// Zoom Out Handler
zoomOutBtn.addEventListener('click', () => {
  if (currentZoom > minZoom) {
    currentZoom = Math.max(currentZoom - zoomStep, minZoom);
    wavesurfer.zoom(currentZoom);
  }
});

4. Handling Boundaries and Edge Cases

  • Minimum Bound (minZoom): Setting the zoom level too low can break the layout or prevent the waveform from fitting the screen properly. A safe lower limit is usually between 0 and 20.
  • Maximum Bound (maxZoom): Setting the value too high can degrade rendering performance on long audio files, as thousands of canvas elements may need to be drawn.
  • Scroll Behavior: Ensure the parent container of #waveform has overflow-x: auto; in your CSS so users can scroll horizontally across the expanded waveform when zoomed in.
