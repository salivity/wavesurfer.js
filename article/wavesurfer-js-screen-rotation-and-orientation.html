Wavesurfer.js Screen Rotation and Orientation

Handling screen rotation and orientation changes in Wavesurfer.js requires adapting canvas-based audio waveforms to dynamic viewport dimensions on mobile devices. Because orientation transitions cause rapid changes in container widths and screen pixel ratios, waveforms can appear stretched, cropped, or misaligned if not properly redrawn. This guide explains why these rendering issues occur and demonstrates how to handle orientation shifts cleanly without interrupting audio playback or degrading performance.

Why Orientation Changes Affect Wavesurfer.js

Wavesurfer.js renders visual audio data using HTML5 <canvas> elements. Unlike standard HTML layout elements that reflow automatically via CSS, canvas dimensions are fixed in physical pixels. When a mobile device rotates between portrait and landscape modes:

  1. The parent container width changes instantly or animates via CSS.
  2. The initial canvas keeps its previous width and height, causing visual distortion.
  3. Mobile browsers often fire orientation events before the DOM completes its layout recalculation, leading to inaccurate width measurements if redrawn too early.

The Modern Built-in Handling (Wavesurfer.js v7+)

Recent versions of Wavesurfer.js automatically observe the waveform's container element using the ResizeObserver API. In standard browser resizing scenarios, this redraws the waveform automatically.

However, during a mobile device orientation change, mobile operating systems (such as iOS Safari and Android Chrome) often update container dimensions asynchronously after the orientationchange event fires. This timing gap can cause ResizeObserver to read stale dimensions or trigger multiple expensive canvas redraws during the screen rotation animation.

Reliable Orientation Handling Pattern

To ensure clean recalculation, combine a ResizeObserver with a debounced fallback specifically targeting orientation changes. This ensures the canvas redraw occurs only after the viewport has stabilized.

Implementation Example

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/audio/track.mp3',
  // Setting height to a percentage or responsive value can help adapt to landscape
  height: 100, 
});

// 2. Debounce helper to prevent excessive rendering
function debounce(func, wait) {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
}

// 3. Define the refresh logic
const handleOrientationRefresh = debounce(() => {
  if (!wavesurfer) return;

  // Preserve the current playback position
  const currentTime = wavesurfer.getCurrentTime();
  const isPlaying = wavesurfer.isPlaying();

  // Force Wavesurfer to re-evaluate the container dimensions
  wavesurfer.renderer.recenter(currentTime / wavesurfer.getDuration());

  // Alternatively, redraw the buffer directly if using custom zoom levels
  wavesurfer.zoom(wavesurfer.options.minPxPerSec || 0);

  // Maintain playback state if necessary
  if (isPlaying) {
    wavesurfer.play();
  }
}, 150);

// 4. Attach event listeners
window.addEventListener('orientationchange', () => {
  // Wait slightly for mobile browsers to finish the rotation animation
  handleOrientationRefresh();
});

// Screen Orientation API alternative
if (screen.orientation) {
  screen.orientation.addEventListener('change', handleOrientationRefresh);
}

Key Considerations for Stable Rotation

1. Wait for Viewport Stabilization

Never trigger a redraw immediately inside the orientationchange callback. Always introduce a delay (typically 100ms to 200ms) or use requestAnimationFrame to ensure the browser has recalculated document.documentElement.clientWidth.

2. Adjust Waveform Height in Landscape

Landscape mode drastically reduces vertical screen space on mobile devices. Adjust the waveform height dynamically during orientation changes to prevent the waveform from pushing playback controls offscreen:

const updateWaveformHeight = () => {
  const isLandscape = window.matchMedia("(orientation: landscape)").matches;
  wavesurfer.setOptions({
    height: isLandscape ? 50 : 100
  });
};

window.addEventListener('orientationchange', () => {
  setTimeout(updateWaveformHeight, 150);
});

3. Maintain Scroll and Zoom States

If your implementation uses zooming (minPxPerSec > 0) or enables horizontal scrolling, recalculate the scroll offset post-rotation. Access wavesurfer.renderer.recenter() passing the normalized playback progress (currentTime / duration) to ensure the playback cursor stays within the user's field of view when changing orientations.
