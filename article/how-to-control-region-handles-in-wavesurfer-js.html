How to Control Region Handles in Wavesurfer.js

This guide explains how to control and customize the visual resize handles on regions created with the Wavesurfer.js Regions plugin. You will learn which configuration properties toggle the display of these handles and how to modify their appearance across different versions of the library.

In Wavesurfer.js, the presence and behavior of the visual handles on a region are primarily controlled by the resize option. When you define or add a region using the Regions plugin, setting resize determines whether boundary handles are rendered and functional.

Toggling Handle Visibility with resize

When creating a region with the addRegion method, set the resize boolean property:

wsRegions.addRegion({
  start: 10,
  end: 20,
  color: 'rgba(0, 255, 0, 0.1)',
  resize: false, // Disables resizing and removes the visual handles
  drag: true
});
  • resize: true (default): Displays interactive handles on the left and right borders of the region, allowing users to drag and adjust the start and end points.
  • resize: false: Completely disables resizing and hides the visual edge handles from the region.

Customizing Handle Appearance

If you want the handles to remain active but change how they look, the method depends on your version of Wavesurfer.js.

Wavesurfer.js v7+

In modern versions of Wavesurfer.js, region handles are DOM elements appended inside the region wrapper. You control their visual presentation using standard CSS targeting the handle elements:

/* Style both left and right resize handles */
::part(region-handle) {
  width: 4px;
  background-color: #3b82f6;
}

/* Or target via class names if shadow DOM is not used */
.wavesurfer-handle {
  width: 6px;
  opacity: 0.8;
  background-color: #ffffff;
  border-left: 1px solid #333;
}

Wavesurfer.js v6 and Earlier

In legacy versions, visual handles were controlled directly via the handleStyle configuration object passed into the region settings:

wavesurfer.addRegion({
  start: 2,
  end: 6,
  resize: true,
  handleStyle: {
    left: {
      backgroundColor: '#ff0000',
      width: '4px'
    },
    right: {
      backgroundColor: '#ff0000',
      width: '4px'
    }
  }
});

Using resize allows you to toggle handle functionality and presence, while CSS rules (v7+) or the handleStyle property (v6 and below) give you direct control over their visual appearance.
