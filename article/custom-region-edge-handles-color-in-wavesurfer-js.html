Custom Region Edge Handles Color in Wavesurfer.js

This article explains how to customize the color of region edge handles in Wavesurfer.js using both CSS and JavaScript. By default, the Regions plugin generates subtle, generic handles for resizing audio selections, but you can alter their appearance to match your application's design system or make them more accessible to users.

Method 1: Styling via CSS (Recommended)

The most direct way to change handle colors is by targeting the handle elements rendered into the DOM by the Wavesurfer Regions plugin.

In Wavesurfer.js v7, region handles use data-resize attributes. You can target both handles globally or customize the left and right handles individually:

/* Style both edge handles */
[data-resize="left"],
[data-resize="right"] {
  background-color: #ff5722 !important;
  width: 4px !important; /* Optional: adjust handle thickness */
  opacity: 0.9;
}

/* Optional: distinct color on hover */
[data-resize="left"]:hover,
[data-resize="right"]:hover {
  background-color: #e64a19 !important;
}

If you are using Wavesurfer.js v6 or older, the handles are rendered using class names instead of data attributes:

/* For Wavesurfer.js v6 and below */
.wavesurfer-handle {
  background-color: #4caf50 !important;
}

.wavesurfer-handle-start {
  background-color: #2196f3 !important; /* Left handle */
}

.wavesurfer-handle-end {
  background-color: #f44336 !important; /* Right handle */
}

Method 2: Dynamic Styling with JavaScript

If you need unique handle colors for different regions or want to apply colors dynamically at runtime, you can modify the handle elements directly through the region instance.

In Wavesurfer.js v7

After initializing the region, access its DOM element and apply styles to the resize handles:

import WaveSurfer from 'wavesurfer.js'
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js'

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
})

const wsRegions = ws.registerPlugin(RegionsPlugin.create())

ws.on('ready', () => {
  const region = wsRegions.addRegion({
    start: 2,
    end: 6,
    color: 'rgba(0, 123, 255, 0.2)',
  })

  // Target handle elements inside the region container
  const handles = region.element.querySelectorAll('[data-resize]')
  handles.forEach((handle) => {
    handle.style.backgroundColor = '#ff0055'
  })
})

In Wavesurfer.js v6

Wavesurfer v6 supports the handleStyle configuration property directly inside the addRegion options:

wavesurfer.addRegion({
  start: 1,
  end: 4,
  color: 'rgba(255, 193, 7, 0.2)',
  handleStyle: {
    left: {
      backgroundColor: '#00bcd4',
      width: '3px',
    },
    right: {
      backgroundColor: '#00bcd4',
      width: '3px',
    },
  },
})

Using CSS is ideal for global application themes, while the JavaScript approach allows you to color-code handles per region dynamically based on user interaction or metadata.
