Audio Crossfading in Wavesurfer.js

Wavesurfer.js does not provide an official, standalone "crossfade" plugin out of the box for handling transitions between dual track instances. Instead, crossfading between two simultaneous Wavesurfer instances is achieved either by leveraging the official Envelope plugin for automated volume curves or by directly manipulating the Web Audio API's GainNode instances connected to each track. This article explains how dual-instance audio crossfading is implemented in Wavesurfer.js and outlines the standard approaches for achieving smooth transitions.

The Dual-Instance Architecture

Because Wavesurfer.js is primarily designed to render and control a single audio buffer per canvas, handling two overlapping tracks requires instantiating two distinct Wavesurfer objects:

const trackA = WaveSurfer.create({
  container: '#track-a',
  url: '/audio/track1.mp3',
});

const trackB = WaveSurfer.create({
  container: '#track-b',
  url: '/audio/track2.mp3',
});

To crossfade between trackA and trackB, volume attenuation must be synchronized so that as one instance fades out, the other fades in.

Method 1: Web Audio API Gain Nodes

The most robust and click-free method for crossfading is routing each Wavesurfer instance through dedicated Web Audio API GainNode elements. This bypasses JavaScript timing delays and utilizes hardware-level audio scheduling.

  1. Access or Assign an AudioContext: Wavesurfer allows you to supply an existing AudioContext or access its internal context.
  2. Create Gain Nodes: Connect each track instance to its own GainNode.
  3. Automate the Transition: Use linearRampToValueAtTime or exponentialRampToValueAtTime to execute the fade over a defined duration.
function crossfade(fromTrack, toTrack, duration = 3) {
  const ctx = fromTrack.backend.ac || new AudioContext();
  const currentTime = ctx.currentTime;

  // Ensure target track is playing
  toTrack.play();

  // Schedule gain values
  fromTrack.backend.gainNode.gain.setValueAtTime(1, currentTime);
  fromTrack.backend.gainNode.gain.linearRampToValueAtTime(0, currentTime + duration);

  toTrack.backend.gainNode.gain.setValueAtTime(0, currentTime);
  toTrack.backend.gainNode.gain.linearRampToValueAtTime(1, currentTime + duration);

  // Pause the faded-out track once transition finishes
  setTimeout(() => {
    fromTrack.pause();
  }, duration * 1000);
}

Method 2: The Envelope Plugin

In Wavesurfer v7, the official Envelope plugin (wavesurfer.js/dist/plugins/envelope.esm.js) provides visual and interactive control over volume automation via draggable control points.

While the Envelope plugin is designed to operate within a single instance to create fade-ins, fade-outs, and volume ducking, running two instances concurrently with complementary envelope curves allows you to create visual crossfades. By setting the tail of Track A to drop to zero volume and the head of Track B to rise from zero to full volume, users gain precise, visible control over the crossfade slope.

Method 3: Programmatic Volume Interpolation

If low-level Web Audio API access is unavailable or you are using HTML5 Audio element fallbacks, you can implement a software-driven crossfade using setVolume() inside an interval or requestAnimationFrame loop.

function stepCrossfade(fadeOutInstance, fadeInInstance, durationMs = 2000) {
  const steps = 50;
  const interval = durationMs / steps;
  let step = 0;

  fadeInInstance.setVolume(0);
  fadeInInstance.play();

  const fadeTimer = setInterval(() => {
    step++;
    const progress = step / steps;

    fadeOutInstance.setVolume(1 - progress);
    fadeInInstance.setVolume(progress);

    if (step >= steps) {
      clearInterval(fadeTimer);
      fadeOutInstance.pause();
    }
  }, interval);
}

Summary

There is no dedicated third-party or official "crossfade plugin" for dual tracks in the Wavesurfer.js ecosystem. The standard, production-ready solution is using the Web Audio API GainNode parameters directly on two separate Wavesurfer instances, or utilizing the Envelope plugin when user-facing visual curve controls are required.
