Unbind Event Listeners in Wavesurfer.js

Managing event listeners in Wavesurfer.js is essential for preventing memory leaks and avoiding unintended behavior in dynamic web applications. The method used to unbind specific event listeners depends on the version of Wavesurfer.js your project utilizes. In modern Wavesurfer.js (version 7 and above), calling the .on() method returns an unsubscribe function, whereas legacy versions (version 6 and below) rely on the dedicated .un() method.

Unbinding Event Listeners in Wavesurfer.js v7+

In modern releases of Wavesurfer.js, the library handles event subscriptions by returning a cleanup function directly from the .on() method. To unbind a specific listener, execute the returned function:

// Register the event listener and capture the unsubscribe function
const unsubscribe = wavesurfer.on('ready', () => {
    console.log('Waveform is ready');
});

// Call the function to unbind the listener
unsubscribe();

This pattern provides a clean, functional approach that eliminates the need to pass matching callback references back into the library.

Unbinding Event Listeners in Wavesurfer.js v6 and Earlier

In older versions of Wavesurfer.js, the specific method used to unbind an event listener is .un(). This method requires both the event name and the exact function reference that was originally passed to .on():

// Define a named handler
const onReadyHandler = () => {
    console.log('Waveform is ready');
};

// Bind the event listener
wavesurfer.on('ready', onReadyHandler);

// Unbind the specific event listener
wavesurfer.un('ready', onReadyHandler);

Using anonymous functions with .un() will not work because the library must compare the reference of the handler function to identify which listener to remove.

Removing All Listeners

If your goal is to tear down all registered listeners for a specific event or across the entire instance:

  • In v6 and earlier: You can use wavesurfer.unAll() to detach all bound listeners simultaneously.
  • In v7+: Calling wavesurfer.destroy() removes all internal listeners and completely tears down the audio context and visual canvas elements.
