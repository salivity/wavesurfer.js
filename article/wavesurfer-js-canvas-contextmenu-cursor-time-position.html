Wavesurfer.js Canvas Contextmenu Cursor Time Position

When capturing a contextmenu event on a Wavesurfer.js canvas, the triggering event object is a standard native DOM MouseEvent (or PointerEvent). Because standard DOM events do not possess built-in audio playback metadata, the event object does not contain a direct time property; instead, the cursor's time position must be derived from the event object's coordinate properties—specifically clientX or offsetX—relative to the waveform container and the audio file's total duration.

The Underlying Event Object

When attaching a contextmenu listener directly to the Wavesurfer canvas or wrapper element, the browser provides a standard MouseEvent.

const wrapper = wavesurfer.getWrapper();

wrapper.addEventListener('contextmenu', (event) => {
    event.preventDefault(); // Prevents default browser context menu
    // 'event' is a native MouseEvent
});

Because this is a native browser event, it lacks direct audio context information. However, the MouseEvent holds critical spatial coordinates required to calculate the exact cursor time:

  • event.clientX: The horizontal coordinate within the application's viewport.
  • event.offsetX: The horizontal coordinate relative to the target element's padding edge.

Calculating Cursor Time Position

To convert the cursor position from the MouseEvent into audio time in seconds, calculate the horizontal click ratio across the waveform container and multiply it by the total duration of the track.

const wrapper = wavesurfer.getWrapper();

wrapper.addEventListener('contextmenu', (event) => {
    event.preventDefault();

    // Get waveform container bounds
    const rect = wrapper.getBoundingClientRect();

    // Calculate cursor position relative to the waveform width (0 to 1)
    const relativeX = (event.clientX - rect.left) / rect.width;
    const clampedProgress = Math.max(0, Math.min(relativeX, 1));

    // Calculate time position in seconds
    const duration = wavesurfer.getDuration();
    const cursorTime = clampedProgress * duration;

    console.log(`Cursor time on right-click: ${cursorTime.toFixed(2)} seconds`);
});

Handling Scroll and Zoom

If Wavesurfer.js is configured with zoom or horizontal scrolling (minPxPerSec set to a high value or autoCenter enabled with overflow), using clientX against the visible bounding box alone can introduce an offset. Account for the horizontal scroll position of the wrapper container:

wrapper.addEventListener('contextmenu', (event) => {
    event.preventDefault();

    const rect = wrapper.getBoundingClientRect();
    const scrollLeft = wrapper.scrollLeft || 0;
    const totalWidth = wrapper.scrollWidth;

    const absoluteX = (event.clientX - rect.left) + scrollLeft;
    const progress = Math.max(0, Math.min(absoluteX / totalWidth, 1));

    const cursorTime = progress * wavesurfer.getDuration();

    console.log(`Accurate scrolled cursor time: ${cursorTime.toFixed(2)}s`);
});

By extracting the coordinates from the MouseEvent and mapping them against the container width and audio duration, you can accurately determine the exact cursor time position during any canvas right-click interaction.
