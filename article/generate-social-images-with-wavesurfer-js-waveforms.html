Generate Social Images with Wavesurfer.js Waveforms

Generating dynamic social share images (Open Graph images) featuring audio waveforms increases engagement when sharing podcasts, music, or audio snippets across social media platforms. This article provides a straightforward guide on how to render audio waveforms using the Wavesurfer.js library, combine them with branding and metadata, and export the final visual as a static image suitable for social sharing cards.

The Generation Workflow

To turn an audio file into a static social card, you need three core steps:

  1. Decode and Render: Load the audio source into Wavesurfer.js to decode the audio buffer and render the waveform onto an HTML <canvas> element.
  2. Composite the Graphics: Draw the waveform canvas, background colors, titles, and branding onto a master canvas sized for social platforms (typically 1200x630 pixels).
  3. Export the Image: Convert the composite canvas into a standard image format (PNG or JPEG) and save or serve it.

This workflow can be executed entirely client-side (for user downloads or uploads) or server-side using a headless browser like Puppeteer.

Step 1: Initialize Wavesurfer.js on a Hidden Canvas

First, initialize a hidden container where Wavesurfer.js can draw the waveform. Keep the dimensions proportional to your final layout design.

<div id="waveform-container" style="display: none; width: 1000px; height: 300px;"></div>
import WaveSurfer from 'wavesurfer.js';

async function generateWaveformCanvas(audioUrl) {
  const container = document.getElementById('waveform-container');

  const wavesurfer = WaveSurfer.create({
    container: container,
    waveColor: '#4F46E5',
    progressColor: '#4F46E5',
    height: 300,
    barWidth: 4,
    barGap: 3,
    barRadius: 2,
    normalize: true,
    interact: false
  });

  await wavesurfer.load(audioUrl);

  return new Promise((resolve) => {
    wavesurfer.on('ready', () => {
      // Extract the canvas element rendered by Wavesurfer.js
      const waveCanvas = container.querySelector('canvas');
      resolve({ waveCanvas, wavesurfer });
    });
  });
}

Step 2: Composite onto a Master Social Share Canvas

Standard Open Graph images should be 1200 pixels wide by 630 pixels high. Create an off-screen <canvas> with these exact dimensions, render the background, add your text metadata, and paste the waveform canvas directly onto it.

async function createSocialCard({ audioUrl, title, author }) {
  const { waveCanvas, wavesurfer } = await generateWaveformCanvas(audioUrl);

  const canvas = document.createElement('canvas');
  canvas.width = 1200;
  canvas.height = 630;
  const ctx = canvas.getContext('2d');

  // 1. Draw Background
  ctx.fillStyle = '#0F172A'; // Dark slate background
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  // 2. Draw Text Details
  ctx.fillStyle = '#FFFFFF';
  ctx.font = 'bold 48px sans-serif';
  ctx.fillText(title, 100, 150);

  ctx.fillStyle = '#94A3B8';
  ctx.font = '32px sans-serif';
  ctx.fillText(author, 100, 210);

  // 3. Draw the Waveform Canvas
  // Positioning: x: 100, y: 260, width: 1000, height: 250
  ctx.drawImage(waveCanvas, 100, 260, 1000, 250);

  // Clean up the Wavesurfer instance
  wavesurfer.destroy();

  // 4. Export as Data URL or Blob
  return canvas.toDataURL('image/png');
}

Step 3: Implement Server-Side for Dynamic OG Tags

Social media crawlers (like Twitterbot or LinkedInBot) do not execute client-side JavaScript. To generate these preview cards dynamically on the server:

  1. Use Puppeteer: Run a lightweight Node.js script with Puppeteer or Playwright that opens an HTML page containing the client-side code above.
  2. Pass Parameters via Query String: Load a template page with parameters, for example: https://example.com/og-generator?title=My+Track&audio=track.mp3.
  3. Capture the Canvas: Wait for the ready event from Wavesurfer.js, then take a screenshot of the master canvas or capture its toDataURL() output.
  4. Cache the Result: Store the generated PNG in a cloud storage bucket or cache it at the edge using a CDN to avoid re-rendering on subsequent requests.

Using precomputed waveform JSON peaks rather than full audio files in your script will significantly speed up server-side rendering, as Wavesurfer.js supports passing pre-decoded peak data via the backend: 'MediaElement' and peaks options.
