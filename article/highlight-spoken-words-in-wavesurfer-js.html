Highlight Spoken Words in Wavesurfer.js

Real-time word highlighting over Wavesurfer.js audio is achieved by synchronizing time-stamped transcription data with the audio player’s playback events. This article explains how combining word-level timestamps from speech recognition with Wavesurfer.js event listeners creates a dynamic, karaoke-style transcript where each word is visually highlighted precisely as it is spoken.

1. Generating Word-Level Timestamps

The foundation of real-time word highlighting is time-aligned transcript data. Traditional transcripts only provide full sentences or paragraphs, but word-level synchronization requires exact start and end times for every individual token.

This data is generated using automatic speech recognition (ASR) engines (such as OpenAI's Whisper) or forced alignment tools (such as Gentle or Montreal Forced Aligner). The resulting output is typically a JSON structure containing an array of word objects:

[
  { "word": "Welcome", "start": 0.12, "end": 0.54 },
  { "word": "to", "start": 0.56, "end": 0.72 },
  { "word": "the", "start": 0.74, "end": 0.88 },
  { "word": "audio", "start": 0.90, "end": 1.35 }
]

2. Rendering the Interactive Transcript

Each word from the alignment data is rendered into the DOM as an individual inline element (such as a <span>). Data attributes are attached to each element to store its start and end times:

<p id="transcript">
  <span class="word" data-start="0.12" data-end="0.54">Welcome</span>
  <span class="word" data-start="0.56" data-end="0.72">to</span>
  <span class="word" data-start="0.74" data-end="0.88">the</span>
  <span class="word" data-start="0.90" data-end="1.35">audio</span>
</p>

3. Syncing with Wavesurfer.js Playback Events

Wavesurfer.js emits events as the audio playhead advances. To update the transcript in real time, listen to the timeupdate event (or audioprocess in older versions of Wavesurfer.js).

Inside the event handler:

  1. Retrieve the current playback time using wavesurfer.getCurrentTime().
  2. Locate the word element whose data-start is less than or equal to the current time, and whose data-end is greater than or equal to the current time.
  3. Apply an active CSS highlighting class to that word while removing it from previously active words.
wavesurfer.on('timeupdate', (currentTime) => {
  const words = document.querySelectorAll('.word');
  
  words.forEach((word) => {
    const start = parseFloat(word.dataset.start);
    const end = parseFloat(word.dataset.end);

    if (currentTime >= start && currentTime <= end) {
      word.classList.add('highlighted');
    } else {
      word.classList.remove('highlighted');
    }
  });
});

For performance optimization on long transcripts, binary search or an index pointer can be used instead of iterating over every DOM element during each tick.

4. Waveform Highlighting with the Regions Plugin

If the goal is to highlight the spoken word directly on the visual waveform rather than in text, the official Wavesurfer.js Regions Plugin is used.

When a word starts, a dynamic region can be created or updated to match the active word's boundary:

// Example using Regions Plugin
const activeRegion = wsRegions.addRegion({
  start: currentWord.start,
  end: currentWord.end,
  color: 'rgba(255, 220, 0, 0.4)',
  drag: false,
  resize: false
});

Combining text-based DOM updates with the Regions plugin provides full two-way synchronization: spoken words highlight dynamically on the page, the waveform visually flags the active audio segment, and clicking any word allows the user to seek to that exact moment in the audio.
