How to Change Cursor Color in Wavesurfer.js

This guide explains how to customize the cursor color on an audio waveform using Wavesurfer.js. You will learn the exact configuration option required to style the playback cursor, along with a practical code snippet demonstrating how to implement it during player initialization.

The option that sets the cursor color on the waveform in Wavesurfer.js is cursorColor.

When initializing a new Wavesurfer instance using the WaveSurfer.create() method, you can pass cursorColor as a property within the configuration options object. It accepts standard CSS color values, such as HEX codes, RGB, RGBA, or standard color names.

Here is a basic example:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  cursorColor: '#FF5733', // Sets the cursor color
  cursorWidth: 2          // Optional: Sets the cursor width in pixels
});

wavesurfer.load('path/to/audio/file.mp3');

In this example, cursorColor: '#FF5733' renders the vertical playhead line as an orange-red bar. You can also pair it with cursorWidth to adjust the thickness of the indicator, or set cursorWidth: 0 if you want to hide the cursor entirely.
