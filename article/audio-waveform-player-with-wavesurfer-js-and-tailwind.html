Audio Waveform Player with Wavesurfer.js and Tailwind

This guide demonstrates how to build a responsive, modern audio waveform player component using Wavesurfer.js and Tailwind CSS. You will learn how to set up the player interface, customize waveform aesthetics with Tailwind's color palette, and implement interactive playback controls, including play/pause toggling, time tracking, and mute functions.

1. Project Setup and Dependencies

To build a standalone component, include the Tailwind CSS CDN and the modern Wavesurfer.js (v7) module script.

Create an index.html file and add the required scripts to your <head> tag:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Waveform Audio Player</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-900 flex items-center justify-center min-h-screen p-6">
  <!-- Player markup goes here -->
</body>
</html>

3. WaveSurfer.js Initialization and Logic

Use ES modules to load Wavesurfer.js, configure the visual waveform, and bind the player controls to event listeners.

Add the following <script> block before the closing </body> tag:

<script type="module">
  import WaveSurfer from 'https://unpkg.com/wavesurfer.js@7/dist/wavesurfer.esm.js';

  // Format seconds into MM:SS
  const formatTime = (seconds) => {
    const mins = Math.floor(seconds / 60);
    const secs = Math.floor(seconds % 60);
    return `${String(mins).padStart(2, '0')}:${String(secs).padStart(2, '0')}`;
  };

  // Initialize WaveSurfer
  const wavesurfer = WaveSurfer.create({
    container: '#waveform',
    waveColor: '#475569',       // Slate 600
    progressColor: '#6366f1',   // Indigo 500
    cursorColor: '#818cf8',     // Indigo 400
    cursorWidth: 2,
    barWidth: 3,
    barGap: 3,
    barRadius: 3,
    height: 64,
    url: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3'
  });

  // DOM Elements
  const playBtn = document.getElementById('playBtn');
  const playIcon = document.getElementById('playIcon');
  const pauseIcon = document.getElementById('pauseIcon');
  const currentTimeEl = document.getElementById('currentTime');
  const durationEl = document.getElementById('duration');
  const muteBtn = document.getElementById('muteBtn');

  // Toggle Play / Pause
  playBtn.addEventListener('click', () => {
    wavesurfer.playPause();
  });

  wavesurfer.on('play', () => {
    playIcon.classList.add('hidden');
    pauseIcon.classList.remove('hidden');
  });

  wavesurfer.on('pause', () => {
    playIcon.classList.remove('hidden');
    pauseIcon.classList.add('hidden');
  });

  // Track Duration and Current Time
  wavesurfer.on('ready', (duration) => {
    durationEl.textContent = formatTime(duration);
  });

  wavesurfer.on('timeupdate', (currentTime) => {
    currentTimeEl.textContent = formatTime(currentTime);
  });

  wavesurfer.on('finish', () => {
    playIcon.classList.remove('hidden');
    pauseIcon.classList.add('hidden');
  });

  // Mute / Unmute
  muteBtn.addEventListener('click', () => {
    const isMuted = wavesurfer.getMuted();
    wavesurfer.setMuted(!isMuted);
    muteBtn.classList.toggle('text-indigo-400', !isMuted);
    muteBtn.classList.toggle('text-slate-400', isMuted);
  });
</script>

4. Key Configuration Options

Wavesurfer.js exposes several properties to match your application's design:

  • barWidth and barGap: Creates the rounded modern bar styling rather than a solid waveform block.
  • progressColor and waveColor: Matches your Tailwind color tokens directly via hexadecimal values.
  • height: Controls the pixel height of the waveform canvas, allowing the player to fit compact or expanded layouts.
