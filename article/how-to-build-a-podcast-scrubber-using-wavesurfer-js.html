How to Build a Podcast Scrubber Using Wavesurfer.js

Building an interactive podcast scrubber allows listeners to navigate seamlessly through long-form audio using a visual waveform representation. This tutorial covers the step-by-step implementation of an interactive audio scrubber using the Wavesurfer.js library, including setting up the audio container, generating the waveform, and integrating custom controls for playback and visual scrubbing.

1. Set Up the HTML Structure

To get started, create an HTML container where the waveform will render, along with standard playback controls such as a play/pause button and timestamps.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Podcast Scrubber</title>
</head>
<body>
  <div id="podcast-player">
    <div id="waveform"></div>
    <div class="controls">
      <button id="play-btn">Play</button>
      <span id="current-time">0:00</span> / <span id="total-duration">0:00</span>
    </div>
  </div>

  <!-- Import Wavesurfer.js via CDN -->
  <script src="https://unpkg.com/wavesurfer.js@7"></script>
  <script src="app.js"></script>
</body>
</html>

2. Initialize Wavesurfer.js

In your JavaScript file (app.js), instantiate the WaveSurfer object. You can configure properties such as the target container, waveform colors, bar width, and the audio source.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',
  progressColor: '#3b82f6',
  cursorColor: '#1d4ed8',
  barWidth: 3,
  barRadius: 3,
  barGap: 2,
  height: 100,
  responsive: true,
  url: 'path/to/your-podcast-episode.mp3',
});

By setting barWidth, barRadius, and barGap, the waveform takes on a modern, discrete bar appearance typical of podcast platforms.

3. Add Playback and Timeline Controls

Wavesurfer.js provides built-in event listeners to manage playback state and track progress. Attach event listeners to update the play/pause button and display accurate time values as the audio plays.

const playBtn = document.getElementById('play-btn');
const currentTimeEl = document.getElementById('current-time');
const totalDurationEl = document.getElementById('total-duration');

// Helper to format seconds into mm:ss
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const remainingSeconds = Math.floor(seconds % 60);
  return `${minutes}:${remainingSeconds < 10 ? '0' : ''}${remainingSeconds}`;
}

// Toggle Play/Pause
playBtn.addEventListener('click', () => {
  wavesurfer.playPause();
});

wavesurfer.on('play', () => {
  playBtn.textContent = 'Pause';
});

wavesurfer.on('pause', () => {
  playBtn.textContent = 'Play';
});

// Set total duration when audio is ready
wavesurfer.on('ready', () => {
  totalDurationEl.textContent = formatTime(wavesurfer.getDuration());
});

// Update current timestamp while scrubbing or playing
wavesurfer.on('audioprocess', () => {
  currentTimeEl.textContent = formatTime(wavesurfer.getCurrentTime());
});

wavesurfer.on('seeking', () => {
  currentTimeEl.textContent = formatTime(wavesurfer.getCurrentTime());
});

4. Enable Visual Scrubbing with Hover Feedback

Wavesurfer.js natively supports clicking or dragging along the canvas to seek through the track. To enhance the scrubber for podcast episodes, install the Hover plugin to display the exact timestamp a user is hovering over before they click.

import Hover from 'https://unpkg.com/wavesurfer.js@7/dist/plugins/hover.esm.js';

wavesurfer.registerPlugin(
  Hover.create({
    lineColor: '#ff0000',
    lineWidth: 2,
    labelBackground: '#1f2937',
    labelColor: '#ffffff',
    labelSize: '11px',
  })
);

5. Add Forward and Rewind Skipping

Podcasts benefit significantly from quick skip buttons (e.g., jump forward or backward 15 seconds). You can implement this using Wavesurfer's setTime() method.

function skip(seconds) {
  const newTime = Math.min(
    Math.max(wavesurfer.getCurrentTime() + seconds, 0),
    wavesurfer.getDuration()
  );
  wavesurfer.setTime(newTime);
}

// Example usage:
// skip(-15); // Rewind 15 seconds
// skip(30);  // Skip forward 30 seconds

With these components assembled, you have a fully functional, responsive podcast episode scrubber that visualizes audio data and provides intuitive navigation.
