Wavesurfer.js Auto Scroll During Playback

Wavesurfer.js is a widely used audio visualization library that renders interactive waveforms in the browser. When dealing with long audio files or zoomed-in waveforms, keeping the playhead visible as the track progresses is essential for a good user experience. This article explains the configuration option required to force auto-scrolling during playback in Wavesurfer.js and covers the accompanying parameters needed to make it function correctly.

The Auto-Scroll Option

In modern versions of Wavesurfer.js (v7 and above), the option that forces the waveform to follow the playhead during playback is autoScroll.

Setting autoScroll: true ensures that the container scrolls automatically to keep the current playback position visible on the screen.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#10B981',
  autoScroll: true,
  minPxPerSec: 100
});

Essential Companion Settings

For auto-scrolling to take effect, the waveform must physically exceed the width of its parent container. If the waveform fits entirely inside the container, scrolling will not trigger.

  • minPxPerSec: Defines the minimum number of horizontal pixels rendered per second of audio. Increasing this value zooms into the waveform, forcing horizontal overflow and enabling scroll behavior.
  • autoCenter: When set to true, this option automatically centers the playhead within the viewable area as it scrolls, rather than letting it hit the right boundary before advancing.
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  autoScroll: true,
  autoCenter: true,
  minPxPerSec: 150
});

Legacy Versions (Wavesurfer.js v6 and Older)

If you are maintaining an older installation running Wavesurfer.js v6 or earlier, the configuration differs:

  • Use scrollParent: true to enable horizontal container scrolling.
  • Use autoCenter: true to force the view to center around the playback cursor dynamically during playback.
