Sync Transcription Text with Audio in Wavesurfer.js

Synchronizing transcription text with audio timestamps in Wavesurfer.js requires pairing time-coded text data with Wavesurfer's playback events. This process involves rendering your transcript into HTML elements embedded with timestamp attributes, listening to Wavesurfer's playback progress events, and dynamically highlighting the active segment while allowing users to click text to jump directly to specific audio cues.

1. Format the Transcription Data

To align text with audio, you need a structured format containing start times, end times, and the corresponding text. JSON is the most flexible format for this:

const transcriptData = [
  { start: 0.0, end: 2.5, text: "Welcome to this tutorial." },
  { start: 2.6, end: 5.0, text: "Today we are syncing audio with text." },
  { start: 5.1, end: 8.4, text: "Wavesurfer makes this process straightforward." }
];

2. Render the Transcript into the DOM

Render the JSON items into HTML container elements (such as <span> or <p>) and store the timing information using data-* attributes.

const transcriptContainer = document.getElementById("transcript");

transcriptData.forEach((item, index) => {
  const span = document.createElement("span");
  span.id = `segment-${index}`;
  span.className = "transcript-segment";
  span.dataset.start = item.start;
  span.dataset.end = item.end;
  span.textContent = item.text + " ";
  transcriptContainer.appendChild(span);
});

Add CSS to visually distinguish the active word or sentence:

.transcript-segment {
  cursor: pointer;
  padding: 2px 4px;
  transition: background-color 0.2s ease;
}

.transcript-segment.active {
  background-color: #ffe066;
  border-radius: 4px;
}

3. Initialize Wavesurfer.js

Create the Wavesurfer instance and load the audio track.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',
  progressColor: '#3b82f6',
  url: '/path/to/audio.mp3'
});

4. Listen to Playback and Highlight Text

In modern versions of Wavesurfer.js (v7+), the timeupdate event fires continuously as the audio plays. Use this event to retrieve the current playback time using wavesurfer.getCurrentTime() and update the UI accordingly.

wavesurfer.on('timeupdate', (currentTime) => {
  const segments = document.querySelectorAll('.transcript-segment');

  segments.forEach((segment) => {
    const start = parseFloat(segment.dataset.start);
    const end = parseFloat(segment.dataset.end);

    if (currentTime >= start && currentTime <= end) {
      if (!segment.classList.contains('active')) {
        segment.classList.add('active');
        segment.scrollIntoView({ behavior: 'smooth', block: 'center' });
      }
    } else {
      segment.classList.remove('active');
    }
  });
});

5. Add Click-to-Seek Functionality

To make the transcript interactive, add a click event listener to each segment so that selecting a phrase automatically seeks the audio to that position.

document.querySelectorAll('.transcript-segment').forEach((segment) => {
  segment.addEventListener('click', () => {
    const startTime = parseFloat(segment.dataset.start);
    wavesurfer.setTime(startTime);
    wavesurfer.play();
  });
});

Alternative: Using the Regions Plugin

For advanced use cases—such as visual text labeling overlaid directly onto the waveform—you can use the official RegionsPlugin. By calling regions.addRegion() with the start and end times, you can set event listeners like region-in and region-out to toggle the transcript highlight state instead of manually querying the DOM on every time update.
