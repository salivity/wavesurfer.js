How to Change Wavesurfer.js Auto-Scroll Behavior

This guide explains how to customize and control the auto-scroll behavior during audio playback in Wavesurfer.js. When working with zoomed-in waveforms, Wavesurfer.js automatically scrolls the container to keep the playhead visible. By configuring built-in initialization options and dynamically updating player settings, you can toggle auto-scrolling, alter how the playhead is centered, or implement custom scrolling logic.

Controlling Auto-Scroll with Initialization Options

When initializing Wavesurfer.js (version 7+), two primary configuration properties dictate how the viewport tracks audio playback: autoScroll and autoCenter.

  • autoScroll (boolean, defaults to true): Determines whether the waveform container automatically scrolls to follow the playback cursor when the waveform exceeds the width of its container (such as when using minPxPerSec to zoom in).
  • autoCenter (boolean, defaults to true): Controls whether the current playback position is centered within the visible container during auto-scroll, or whether it only scrolls once the cursor hits the edge of the screen.

Here is an example configuring these properties during instance creation:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
  minPxPerSec: 100, // Zoomed in to enable horizontal overflow
  autoScroll: true, // Enables auto-scrolling
  autoCenter: false // Keeps continuous scrolling without snapping to center
});

Updating Auto-Scroll Dynamically

You can enable or disable auto-scroll at runtime using the setOptions method. This is useful if you want to pause auto-scrolling when a user manually interacts with the scrollbar.

// Disable auto-scroll during playback
wavesurfer.setOptions({
  autoScroll: false
});

// Re-enable auto-scroll
wavesurfer.setOptions({
  autoScroll: true
});

Disabling Auto-Scroll on Manual User Interaction

A common requirement is pausing auto-scroll if the user manually scrolls the waveform container, and resuming it once playback resumes or when a dedicated button is clicked.

const container = document.querySelector('#waveform');

// Detect user scrolling within the container
container.addEventListener('scroll', () => {
  if (wavesurfer.isPlaying()) {
    wavesurfer.setOptions({ autoScroll: false });
  }
});

// Re-enable auto-scroll when playback starts or restarts
wavesurfer.on('play', () => {
  wavesurfer.setOptions({ autoScroll: true });
});

Custom Scroll Logic Using Events

If the default scrolling behavior does not fit your application needs, set autoScroll: false and handle the scroll behavior manually using the timeupdate event.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  url: '/path/to/audio.mp3',
  minPxPerSec: 100,
  autoScroll: false // Disable built-in scrolling
});

const scrollContainer = document.querySelector('#waveform');

wavesurfer.on('timeupdate', (currentTime) => {
  const duration = wavesurfer.getDuration();
  if (!duration) return;

  const progress = currentTime / duration;
  const maxScroll = scrollContainer.scrollWidth - scrollContainer.clientWidth;

  // Smoothly scroll the container based on custom progress calculations
  scrollContainer.scrollTo({
    left: progress * maxScroll,
    behavior: 'smooth'
  });
});
