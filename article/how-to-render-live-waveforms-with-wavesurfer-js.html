How to Render Live Waveforms with Wavesurfer.js

Rendering a real-time audio waveform during recording provides essential visual feedback for users speaking into a microphone. This guide explains how to capture live microphone input and display an animated, scrolling waveform using Wavesurfer.js and its official Record plugin. You will learn the necessary HTML markup, JavaScript initialization, and key configuration options required to capture and visualize audio streams effectively.

1. Install and Import Wavesurfer.js

To capture and visualize live audio, you need both the core wavesurfer.js library and its RecordPlugin.

Using npm:

npm install wavesurfer.js

In your JavaScript file:

import WaveSurfer from 'wavesurfer.js';
import RecordPlugin from 'wavesurfer.js/dist/plugins/record.esm.js';

If using a CDN, include the main library and the plugin scripts directly in your HTML:

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/plugins/record.min.js"></script>

2. Set Up the HTML Structure

Create a container element for the waveform along with control buttons to manage recording states:

<div id="waveform"></div>
<button id="record-btn">Record</button>
<button id="pause-btn" disabled>Pause</button>

3. Initialize Wavesurfer and the Record Plugin

Initialize the main WaveSurfer instance, register the Record plugin, and configure the real-time visualization settings:

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4f46e5',
  progressColor: '#818cf8',
  cursorWidth: 0,
});

// Initialize the Record plugin
const record = wavesurfer.registerPlugin(
  RecordPlugin.create({
    scrollingWaveform: true, // Enables continuous scrolling during recording
    renderRecordedAudio: false, // Prevents full audio redraw until recording stops
  })
);

4. Manage Recording and User Input

Attach event listeners to the buttons to request microphone access, start recording, pause, and stop. The plugin handles the browser's navigator.mediaDevices.getUserMedia internally.

const recordBtn = document.getElementById('record-btn');
const pauseBtn = document.getElementById('pause-btn');

// Start or stop recording
recordBtn.addEventListener('click', async () => {
  if (record.isRecording() || record.isPaused()) {
    record.stopRecording();
    recordBtn.textContent = 'Record';
    pauseBtn.disabled = true;
    return;
  }

  recordBtn.disabled = true;

  // Start recording from the default microphone device
  await record.startRecording();

  recordBtn.textContent = 'Stop';
  recordBtn.disabled = false;
  pauseBtn.disabled = false;
});

// Pause or resume recording
pauseBtn.addEventListener('click', () => {
  if (record.isPaused()) {
    record.resumeRecording();
    pauseBtn.textContent = 'Pause';
  } else {
    record.pauseRecording();
    pauseBtn.textContent = 'Resume';
  }
});

5. Handle the Recorded Output

Once recording completes, the record-end event fires, providing the recorded audio as a Blob. You can load this directly into Wavesurfer for playback or send it to a server:

record.on('record-end', (blob) => {
  // Render the final recorded waveform for playback
  wavesurfer.load(URL.createObjectURL(blob));
});

Key Configuration Options

  • scrollingWaveform (boolean): Set to true to keep the waveform moving dynamically across the screen as sound is detected. If set to false, the waveform will compress horizontally to fit the container.
  • renderRecordedAudio (boolean): Set to false during live visualization to minimize browser reflows and ensure smooth animation on low-power devices.
  • continuousWaveform (boolean): Ensures that silent periods during the recording do not introduce visual gaps or distortions in the scrolling buffer.
