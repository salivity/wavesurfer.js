How to Set Playback Speed in Wavesurfer.js

This guide explains how to control and adjust audio playback speed in Wavesurfer.js using its native API methods. You will learn the exact method used to modify the rate, how to handle pitch preservation, and how to implement dynamic speed controls using HTML and JavaScript.

The setPlaybackRate Method

Wavesurfer.js provides a built-in method called setPlaybackRate() to alter the speed of an audio track.

Syntax

wavesurfer.setPlaybackRate(rate, preservePitch);

Parameters

  • rate (number): The target playback speed. A value of 1 represents normal speed, 0.5 plays the audio at half speed, and 2 doubles the speed.
  • preservePitch (boolean, optional): Determines whether the audio maintains its original pitch when the speed changes. The default value is true. Set this to false if you want the classic vinyl slowdown/chipmunk effect.

Basic Implementation

After initializing your Wavesurfer instance, call setPlaybackRate() at any time during audio playback or while paused:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

// Set playback speed to 1.5x with pitch preserved
wavesurfer.on('ready', () => {
  wavesurfer.setPlaybackRate(1.5);
});

Creating an Interactive Speed Selector

To let users dynamically change the playback speed, bind the method to an HTML <select> dropdown or range slider:

HTML

<label for="speed-select">Playback Speed:</label>
<select id="speed-select">
  <option value="0.5">0.5x</option>
  <option value="1" selected>1.0x (Normal)</option>
  <option value="1.25">1.25x</option>
  <option value="1.5">1.5x</option>
  <option value="2">2.0x</option>
</select>

JavaScript

const speedSelect = document.getElementById('speed-select');

speedSelect.addEventListener('change', (event) => {
  const newRate = parseFloat(event.target.value);
  wavesurfer.setPlaybackRate(newRate, true);
});

Checking the Current Playback Rate

To read the current playback speed of the audio element, call the getPlaybackRate() method:

const currentSpeed = wavesurfer.getPlaybackRate();
console.log(`Current speed is: ${currentSpeed}`);
