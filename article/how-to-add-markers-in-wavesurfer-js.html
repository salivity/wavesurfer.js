How to Add Markers in Wavesurfer.js

This article provides a practical guide on implementing marker points on an audio waveform using Wavesurfer.js. You will learn how to set up the player, load the required plugin, add custom visual points along the audio timeline, and listen to user interaction events such as clicks and dragging.

Step 1: Include Wavesurfer.js and the Regions Plugin

In modern versions of Wavesurfer.js (version 7 and later), point markers are primarily created using the official Regions plugin. You can install both packages via npm or import them using a content delivery network (CDN).

<div id="waveform"></div>

<script type="module">
  import WaveSurfer from 'https://unpkg.com/wavesurfer.js@7/dist/wavesurfer.esm.js';
  import RegionsPlugin from 'https://unpkg.com/wavesurfer.js@7/dist/plugins/regions.esm.js';
</script>

Step 2: Initialize Wavesurfer and Register the Plugin

Create your main Wavesurfer instance, register an instance of RegionsPlugin, and load your audio file.

// Initialize the Regions plugin
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/your/audio.mp3',
  plugins: [wsRegions],
});

Step 3: Add Marker Points to the Waveform

Wait for the audio to be decoded or ready, then use the addRegion method provided by the Regions plugin. To create a precise point marker instead of a spanned duration, set start and end to the same timestamp value.

wavesurfer.on('ready', () => {
  // Add a single point marker at 5 seconds
  wsRegions.addRegion({
    start: 5,
    end: 5,
    content: 'Marker 1',
    color: 'rgba(255, 0, 0, 0.7)',
    drag: true, // Allow user to reposition the marker
    resize: false, // Prevent extending into a range
  });

  // Add another marker at 12 seconds
  wsRegions.addRegion({
    start: 12,
    end: 12,
    content: 'Chorus Start',
    color: 'rgba(0, 128, 255, 0.7)',
    drag: false,
    resize: false,
  });
});

Step 4: Style the Marker Elements

By default, zero-length regions generate a thin line. You can customize the marker appearance using CSS to make them stand out visually, such as turning the content label into a custom badge or pin.

/* Custom styling for the marker line */
.wavesurfer-region {
  border-left: 2px solid #ff4444;
}

/* Custom styling for the marker label */
.wavesurfer-region > div {
  background: #222;
  color: #fff;
  font-size: 11px;
  padding: 2px 6px;
  border-radius: 4px;
  transform: translateY(-100%);
  white-space: nowrap;
}

Step 5: Handle Interaction Events

The Regions plugin exposes events to interact with markers. You can listen for clicks to jump the playhead directly to a marker's position or capture update events when a marker is dragged.

// Seek to marker when clicked
wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation(); // Prevent toggling play/pause on the waveform
  wavesurfer.setTime(region.start);
});

// Detect when a marker has finished being moved
wsRegions.on('region-updated', (region) => {
  console.log(`Marker "${region.content.innerText}" moved to: ${region.start}s`);
});
