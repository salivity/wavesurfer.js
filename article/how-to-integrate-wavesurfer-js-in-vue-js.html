How to Integrate Wavesurfer.js in Vue.js

This guide explains how to integrate Wavesurfer.js into a Vue.js 3 application using the Composition API. You will learn how to install the required package, set up a reactive container element, initialize the waveform instance, handle audio playback, and properly clean up audio resources on component unmount.

Step 1: Install Wavesurfer.js

First, install the latest version of Wavesurfer.js via npm or yarn:

npm install wavesurfer.js

Step 2: Build the Audio Waveform Component

Create a dedicated Vue component (for example, AudioPlayer.vue). This component creates a DOM reference for the waveform container, initializes the WaveSurfer instance inside the onMounted hook, and destroys it inside onBeforeUnmount to prevent memory leaks.

<template>
  <div class="audio-player">
    <div ref="waveformRef" class="waveform-container"></div>
    
    <div class="controls">
      <button @click="togglePlay">
        {{ isPlaying ? 'Pause' : 'Play' }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted, onBeforeUnmount } from 'vue'
import WaveSurfer from 'wavesurfer.js'

const props = defineProps({
  audioUrl: {
    type: String,
    required: true
  }
})

const waveformRef = ref(null)
let wavesurfer = null
const isPlaying = ref(false)

onMounted(() => {
  if (!waveformRef.value) return

  wavesurfer = WaveSurfer.create({
    container: waveformRef.value,
    waveColor: '#cbd5e1',
    progressColor: '#3b82f6',
    cursorColor: '#1d4ed8',
    barWidth: 2,
    barGap: 1,
    barRadius: 2,
    height: 100,
    url: props.audioUrl
  })

  wavesurfer.on('play', () => {
    isPlaying.value = true
  })

  wavesurfer.on('pause', () => {
    isPlaying.value = false
  })

  wavesurfer.on('finish', () => {
    isPlaying.value = false
  })
})

const togglePlay = () => {
  if (wavesurfer) {
    wavesurfer.playPause()
  }
}

onBeforeUnmount(() => {
  if (wavesurfer) {
    wavesurfer.destroy()
  }
})
</script>

<style scoped>
.audio-player {
  width: 100%;
  max-width: 600px;
  margin: 0 auto;
}

.waveform-container {
  width: 100%;
  background: #f8fafc;
  border-radius: 8px;
  overflow: hidden;
}

.controls {
  margin-top: 1rem;
  display: flex;
  justify-content: center;
}

button {
  padding: 0.5rem 1.5rem;
  font-size: 1rem;
  cursor: pointer;
}
</style>

Step 3: Use the Component in Your Application

Import and use the AudioPlayer component inside any parent view, passing the path or URL to your audio file via the audioUrl prop:

<template>
  <main>
    <h1>Audio Preview</h1>
    <AudioPlayer audioUrl="/path/to/audio.mp3" />
  </main>
</template>

<script setup>
import AudioPlayer from './components/AudioPlayer.vue'
</script>

Key Considerations

  • Lifecycle Management: Wavesurfer creates active Web Audio API contexts and event listeners. Always call wavesurfer.destroy() inside onBeforeUnmount (or beforeUnmount in the Options API) to avoid memory leaks.
  • Dynamic Sources: To switch tracks dynamically, watch the audioUrl prop using Vue's watch function and call wavesurfer.load(newUrl) when the source changes.
  • Plugins: Wavesurfer.js offers official plugins such as Timeline, Regions, and Minimap. These are imported from submodules (e.g., wavesurfer.js/dist/plugins/timeline.esm.js) and registered within the WaveSurfer.create() configuration array under the plugins key.
