Wavesurfer.js Markers Plugin Replacement Guide

In modern releases of Wavesurfer.js, specifically version 7 and newer, the legacy standalone Markers plugin was retired and superseded by the Regions plugin. This article details the transition from the old marker system, explains how the unified Regions plugin fulfills marker functionality, and outlines how to implement discrete point markers in current Wavesurfer.js projects.

The Evolution from Markers to Regions

In Wavesurfer.js versions 4 through 6, developers relied on wavesurfer.markers.js to place specific points in time on audio waveforms. When Wavesurfer.js was rewritten from the ground up for version 7—focusing on a lighter footprint, native TypeScript support, and a streamlined plugin ecosystem—the dedicated Markers plugin was eliminated.

Instead of maintaining two overlapping tools for spatial audio cues, the core development team consolidated marker capabilities into the Regions plugin (wavesurfer.js/dist/plugins/regions.esm.js).

How the Regions Plugin Handles Markers

The Regions plugin is traditionally used to highlight audio segments spanning from a start time to an end time. However, it also natively functions as a marker tool when applied to a single point in time.

To create a marker using the modern Regions plugin, you define a region where the duration is zero:

  • Identical Start and End Points: Set both start and end to the exact same second value (or simply omit end in supported configurations).
  • Custom Labels and Content: Use the content property to inject plain text or custom HTML elements to visually represent a marker pin, label, or flag.
  • Interactivity: You can toggle dragging via the drag property, enabling markers to be repositioned along the timeline just as they were in older versions.

Example Implementation

To use regions as markers in Wavesurfer.js v7+:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize Wavesurfer with the Regions plugin
const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/audio.mp3',
});

const wsRegions = ws.registerPlugin(RegionsPlugin.create());

// Add a point marker once audio is ready
ws.on('ready', () => {
  wsRegions.addRegion({
    start: 15.5,
    end: 15.5,
    content: 'Verse 1',
    color: 'rgba(255, 0, 0, 0.7)',
    drag: true,
  });
});

Advantages of the Unified Plugin

Consolidating markers into the Regions plugin provides several improvements:

  1. Reduced Bundle Size: Eliminates duplicate logic for coordinate calculations, rendering, and drag events.
  2. Consistent Event Handling: A single set of events (such as region-created, region-clicked, and region-updated) governs both segments and discrete point markers.
  3. Enhanced Customization: Modern regions render cleanly via custom CSS, making it straightforward to style vertical marker lines, icons, and tooltips using standard CSS rules.
