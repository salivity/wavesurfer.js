Global Volume Control for Multiple Wavesurfer.js Instances

Managing a unified volume level across several Wavesurfer.js audio instances requires centralizing your player instances in an accessible array or state manager and binding a single event listener to an input control. This guide walks through instantiating multiple waveform players, maintaining their references, and synchronizing their audio levels in real time using an HTML range input.

Centralizing Player Instances

To manage multiple players simultaneously, store each initialized Wavesurfer instance in an array. This creates a single registry that can be iterated over whenever a global adjustment occurs.

import WaveSurfer from 'wavesurfer.js';

// Registry to hold all active instances
const wavesurferInstances = [];

// Initialize instances and push them to the registry
const player1 = WaveSurfer.create({
  container: '#waveform-1',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio/track1.mp3',
});

const player2 = WaveSurfer.create({
  container: '#waveform-2',
  waveColor: '#00A86B',
  progressColor: '#006644',
  url: '/audio/track2.mp3',
});

wavesurferInstances.push(player1, player2);

Implementing the Global Slider

Define an HTML <input> element with a range type. Wavesurfer's setVolume method accepts float values between 0 (silent) and 1 (full volume). Configure the slider's min, max, and step attributes to match this scale.

<label for="global-volume">Master Volume</label>
<input 
  type="range" 
  id="global-volume" 
  min="0" 
  max="1" 
  step="0.01" 
  value="1" 
/>

Binding the Slider Event

Attach an input event listener to the slider. Using input ensures that the audio updates continuously as the user drags the slider, rather than waiting for the change event when the mouse is released.

const volumeSlider = document.getElementById('global-volume');

volumeSlider.addEventListener('input', (event) => {
  const targetVolume = parseFloat(event.target.value);

  wavesurferInstances.forEach((instance) => {
    instance.setVolume(targetVolume);
  });
});

Handling Relative Volumes

If individual tracks require different base volume levels (for example, in a multi-track mixing interface), you should scale each track's individual volume proportionally to the master slider rather than applying an absolute value.

To do this, store a baseline gain property with each instance:

const tracks = [
  { instance: player1, baseGain: 0.8 },
  { instance: player2, baseGain: 0.5 },
];

volumeSlider.addEventListener('input', (event) => {
  const masterVolume = parseFloat(event.target.value);

  tracks.forEach(({ instance, baseGain }) => {
    // Calculate proportional volume bounded between 0 and 1
    const finalVolume = Math.min(1, Math.max(0, masterVolume * baseGain));
    instance.setVolume(finalVolume);
  });
});

Dynamic Instances and Cleanup

When adding or removing players dynamically:

  1. Additions: Set the new instance's volume to the slider's current value immediately upon creation so it matches existing players.
  2. Removals: When calling instance.destroy(), remove that instance from your array to avoid memory leaks and prevent errors from attempting to update destroyed audio nodes.
