How to Apply Audio Fades in Wavesurfer.js

Applying smooth fade-in and fade-out envelopes in Wavesurfer.js prevents abrupt audio clicks and creates a professional listening experience. This guide demonstrates how to build sample-accurate volume envelopes using the Web Audio API’s GainNode alongside Wavesurfer.js, as well as how to implement a lightweight script-based alternative using standard playback events.

Method 1: Native Web Audio API Envelopes (Recommended)

The most reliable way to create click-free, sample-accurate volume fades is by inserting an AudioContext GainNode between the audio source and the destination.

1. Initialize Wavesurfer and Create the Audio Graph

Configure Wavesurfer.js to create or use an external AudioContext.

import WaveSurfer from 'wavesurfer.js';

const audioContext = new (window.AudioContext || window.webkitAudioContext)();
const gainNode = audioContext.createGain();

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
});

// Connect the media element to the GainNode once audio is ready
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const source = audioContext.createMediaElementSource(mediaElement);

  source.connect(gainNode);
  gainNode.connect(audioContext.destination);
});

2. Schedule Linear or Exponential Ramps

Use linearRampToValueAtTime or exponentialRampToValueAtTime on the gainNode.gain parameter. Exponential ramps sound more natural to the human ear, but require a starting value greater than zero (e.g., 0.0001).

const FADE_DURATION = 2.0; // duration in seconds

function applyFades() {
  const duration = wavesurfer.getDuration();
  const currentTime = audioContext.currentTime;
  const gain = gainNode.gain;

  // Reset and cancel previous automation
  gain.cancelScheduledValues(currentTime);

  // Fade In: from 0.0001 to 1.0 over FADE_DURATION
  gain.setValueAtTime(0.0001, currentTime);
  gain.exponentialRampToValueAtTime(1.0, currentTime + FADE_DURATION);

  // Fade Out: ramp down to 0.0001 before the track finishes
  const fadeOutStart = currentTime + Math.max(0, duration - FADE_DURATION);
  gain.setValueAtTime(1.0, fadeOutStart);
  gain.exponentialRampToValueAtTime(0.0001, currentTime + duration);
}

// Trigger automation when playback begins
wavesurfer.on('play', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
  applyFades();
});

Method 2: Dynamic Volume via Playback Events

If direct Web Audio graph manipulation is not an option, you can dynamically adjust volume using the timeupdate event and the built-in setVolume() method.

const FADE_DURATION = 2; // Duration in seconds

wavesurfer.on('timeupdate', (currentTime) => {
  const totalDuration = wavesurfer.getDuration();

  // Fade In
  if (currentTime < FADE_DURATION) {
    const volume = currentTime / FADE_DURATION;
    wavesurfer.setVolume(Math.min(1, Math.max(0, volume)));
  }
  // Fade Out
  else if (currentTime > totalDuration - FADE_DURATION) {
    const remainingTime = totalDuration - currentTime;
    const volume = remainingTime / FADE_DURATION;
    wavesurfer.setVolume(Math.min(1, Math.max(0, volume)));
  }
  // Full Volume
  else {
    wavesurfer.setVolume(1);
  }
});

Best Practices

  • Handle Seeking: Always reset or recalculate envelope parameters on the seeking or seek event to prevent sudden volume spikes when users jump across the timeline.
  • Avoid Zero in Exponential Ramps: The Web Audio API throws an error if exponentialRampToValueAtTime attempts to ramp to or from an exact value of 0. Always use a near-zero floor such as 0.0001.
