Style Wavesurfer.js Markers as Pill Badges

This guide explains how to transform default Wavesurfer.js timeline markers into interactive, modern pill badges using pure CSS. By overriding standard marker elements, adjusting pointer behaviors, creating pill geometry with rounded borders, and adding dynamic hover states, you can build visually distinct, clickable controls aligned precisely to your audio timestamps.

Target the Marker DOM Elements

Wavesurfer.js injects marker elements directly into the waveform container. Depending on whether you are using the Markers plugin or Regions plugin, markers typically consist of a wrapper div containing a label and an optional marker line. To style these as badges, target the marker wrapper and its inner text label:

/* Container for the marker */
.wavesurfer-marker {
  position: absolute;
  top: 10px !important; /* Force to the top of the canvas */
  transform: translateX(-50%); /* Center the badge horizontally on the timestamp */
  z-index: 10;
  display: flex;
  flex-direction: column;
  align-items: center;
}

Create the Pill Badge Geometry

To achieve the pill shape, use an oversized border-radius, horizontal padding, and a compact typography style. Hide or repurpose any default marker lines to isolate the badge appearance.

/* The pill label */
.wavesurfer-marker-label {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  padding: 4px 12px;
  border-radius: 9999px; /* Creates the full pill shape */
  background-color: #1e293b;
  color: #f8fafc;
  font-family: system-ui, -apple-system, sans-serif;
  font-size: 11px;
  font-weight: 600;
  letter-spacing: 0.025em;
  white-space: nowrap;
  box-shadow: 0 2px 6px rgba(0, 0, 0, 0.15), 
              0 0 0 1px rgba(255, 255, 255, 0.1);
  user-select: none;
}

Manage Pointer Events for Clickability

By default, some waveform layers capture mouse events, which can prevent clicks from triggering marker events. Ensure the pill responds properly to interactions while allowing the waveform beneath to remain accessible outside the badge footprint:

.wavesurfer-marker {
  pointer-events: none; /* Let clicks fall through around the badge */
}

.wavesurfer-marker-label {
  pointer-events: auto; /* Re-enable clicks strictly on the pill */
  cursor: pointer;
}

Add Interactive Hover and Active States

Pill badges need visual feedback to indicate they are clickable. Micro-interactions such as subtle scale transforms, background changes, and elevation adjustments provide clear visual cues:

.wavesurfer-marker-label {
  transition: transform 0.15s ease, 
              background-color 0.15s ease, 
              box-shadow 0.15s ease;
}

.wavesurfer-marker-label:hover {
  background-color: #3b82f6; /* Highlight color */
  transform: translateY(-2px); /* Slight lift */
  box-shadow: 0 4px 10px rgba(59, 130, 246, 0.35);
}

.wavesurfer-marker-label:active {
  transform: translateY(0) scale(0.96);
}

Add a Timestamp Anchor Stem

To show the exact point in the audio that the pill represents, add a subtle pointer tip underneath the pill using the ::after pseudo-element:

.wavesurfer-marker-label::after {
  content: "";
  position: absolute;
  bottom: -4px;
  left: 50%;
  transform: translateX(-50%);
  width: 0;
  height: 0;
  border-left: 4px solid transparent;
  border-right: 4px solid transparent;
  border-top: 4px solid #1e293b;
  transition: border-top-color 0.15s ease;
}

.wavesurfer-marker-label:hover::after {
  border-top-color: #3b82f6;
}

This configuration converts raw timestamp indicators into polished, actionable pill components that align with modern UI standards while maintaining native Wavesurfer.js event listeners.
