Calculate RMS Amplitude from Wavesurfer.js Peaks

This article explains the mathematical formula and computational process required to derive Root Mean Square (RMS) amplitude visualization from Wavesurfer.js peak arrays. While Wavesurfer.js by default renders waveforms using linear peak values (minima and maxima), transforming these peaks into RMS values provides an accurate representation of perceived loudness and energy. Below, you will find the exact formula, how to adapt it to peak arrays, and how to compute it for custom waveform visualization.

The Standard RMS Formula

The Root Mean Square (\(X_{\text{RMS}}\)) of a discrete set of \(N\) values is defined mathematically as:

\[X_{\text{RMS}} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2}\]

Where:

  • \(N\) is the total number of audio samples or peak data points in a given window.
  • \(x_i\) represents the amplitude of an individual sample at index \(i\).
  • \(\sum_{i=1}^{N} x_i^2\) is the sum of the squared values across the window.

Adapting the Formula for Wavesurfer.js Peak Arrays

Wavesurfer.js generates peak arrays in two primary formats depending on configuration:

  1. A single interleaved array: [min_0, max_0, min_1, max_1, ..., min_k, max_k]
  2. Two separate parallel arrays: one for min values and one for max values.

Because peak arrays already downsample the original PCM buffer into pairs representing the negative and positive limits of time slices, the formula must treat both bounds as discrete amplitude observations.

Formula for Interleaved Peak Arrays

For an interleaved slice containing \(M\) peak pairs (total \(N = 2M\) points):

\[\text{RMS}_{\text{window}} = \sqrt{\frac{1}{2M} \sum_{j=1}^{M} \left( (\text{min}_j)^2 + (\text{max}_j)^2 \right)}\]

If you are calculating RMS across the entire peak array to normalize rendering:

\[\text{RMS}_{\text{total}} = \sqrt{\frac{1}{L} \sum_{k=0}^{L-1} p_k^2}\]

Where \(L\) is the total length of the peaks array and \(p_k\) is the peak value at index \(k\).

Step-by-Step Implementation

  1. Normalize Peak Values: Ensure values fall within a normalized range of \([-1.0, 1.0]\). If Wavesurfer.js outputs 8-bit integers ([-128, 127]), divide each value by 128 before calculation.
  2. Define Window Size: Group the peaks into discrete windows (e.g., chunks of 10 to 50 values) depending on the desired visual smoothing.
  3. Square and Accumulate: Square every peak value in the target window and add them together.
  4. Divide by Sample Count: Divide the accumulated sum by the number of peak values evaluated in that window.
  5. Square Root: Take the square root of the quotient to yield the window's RMS value.

Decibel Conversion for Dynamic Range Display

Linear RMS values can be converted to decibels full scale (dBFS) to map visual height to human auditory perception:

\[\text{dBFS} = 20 \log_{10}(\text{RMS})\]

Values can then be clamped between a defined floor (such as \(-60\text{ dB}\)) and \(0\text{ dB}\) to render a smoothed, perceptually balanced energy envelope in your Wavesurfer.js canvas or custom visualizer.
