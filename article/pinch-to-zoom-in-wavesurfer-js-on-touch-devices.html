Pinch to Zoom in Wavesurfer.js on Touch Devices

This article demonstrates how to implement intuitive pinch-to-zoom functionality for Wavesurfer.js on mobile and touch-enabled devices. By capturing standard multi-touch DOM events, calculating touch distance variations, and dynamically passing the calculated scale to the Wavesurfer zoom API, you can provide users with a smooth, native-feeling waveform manipulation experience on touchscreens.

Understanding Wavesurfer.js Zoom

Wavesurfer.js controls waveform magnification using the zoom(minPxPerSec) method. The parameter specifies the minimum number of horizontal pixels allocated per second of audio. To support pinch gestures, you must intercept two-pointer touch events on the waveform container, compute the geometric distance between two fingers, and adjust the minPxPerSec value proportionally.

Preparing the Container

To prevent native browser zoom and scroll gestures from interfering with your custom pinch handling, apply the touch-action CSS property to the Wavesurfer container:

#waveform {
  touch-action: pan-x; /* or 'none' if you want complete gesture control */
  user-select: none;
  -webkit-user-select: none;
}

Implementing Touch Event Listeners

To calculate pinch scale, monitor touchstart, touchmove, and touchend events.

  1. touchstart: Detect when two touches are present, record the initial distance between them, and store the baseline zoom level.
  2. touchmove: When two touches are active, calculate the new distance. Determine the ratio between the new distance and the starting distance, scale the zoom level accordingly, and call wavesurfer.zoom().
  3. touchend: Reset the active tracking state once fingers leave the surface.

Complete Implementation Example

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
  minPxPerSec: 50,
});

const container = document.querySelector('#waveform');

// 2. Gesture State Variables
let initialDistance = 0;
let initialZoom = 50;
let currentZoom = 50;
const MIN_ZOOM = 20;
const MAX_ZOOM = 500;

// Helper to calculate Euclidean distance between two touch points
function getDistance(touch1, touch2) {
  const dx = touch1.clientX - touch2.clientX;
  const dy = touch1.clientY - touch2.clientY;
  return Math.hypot(dx, dy);
}

// 3. Touch Start Handler
container.addEventListener('touchstart', (e) => {
  if (e.touches.length === 2) {
    e.preventDefault();
    initialDistance = getDistance(e.touches[0], e.touches[1]);
    initialZoom = currentZoom;
  }
}, { passive: false });

// 4. Touch Move Handler
container.addEventListener('touchmove', (e) => {
  if (e.touches.length === 2 && initialDistance > 0) {
    e.preventDefault();

    const currentDistance = getDistance(e.touches[0], e.touches[1]);
    const scale = currentDistance / initialDistance;
    
    // Calculate new zoom and clamp within bounds
    let newZoom = initialZoom * scale;
    newZoom = Math.max(MIN_ZOOM, Math.min(MAX_ZOOM, newZoom));

    currentZoom = newZoom;
    wavesurfer.zoom(currentZoom);
  }
}, { passive: false });

// 5. Touch End / Cancel Handler
function handleTouchEnd(e) {
  if (e.touches.length < 2) {
    initialDistance = 0;
  }
}

container.addEventListener('touchend', handleTouchEnd);
container.addEventListener('touchcancel', handleTouchEnd);

Key Considerations

  • Passive Listeners: Use { passive: false } inside your addEventListener options so that e.preventDefault() can effectively block the default viewport pinch-zooming behavior of mobile browsers.
  • Performance: Wavesurfer.js handles canvas redraws during zoom() quickly, but applying bounds (MIN_ZOOM and MAX_ZOOM) ensures the renderer does not freeze when exceeding browser canvas limits.
  • Scroll Sync: When the waveform extends beyond the container width, Wavesurfer handles horizontal scrolling automatically if autoCenter or fillParent: false configurations are enabled.
