Change Spectrogram Color Map in Wavesurfer.js

Customizing the visual representation of audio frequencies in Wavesurfer.js is achieved through the Spectrogram plugin's colorMap configuration option. This guide explains how to define and apply custom color palettes to a spectrogram in Wavesurfer.js, enabling you to replace the default color scheme with custom multi-color gradients or specialized data visualization palettes.

Understanding the colorMap Property

The Spectrogram plugin uses an array of 256 color values to map frequency intensity from quietest (index 0) to loudest (index 255). Each element in the array represents a color in RGBA format, formatted as an array of four numbers [r, g, b, a] where red, green, and blue range from 0 to 255, and alpha ranges from 0 to 1 (or 0 to 255 depending on the version).

Generating a Custom Color Map

To create a smooth gradient, you can write a helper function using an HTML5 Canvas to interpolate colors across 256 points.

function createColorMap(colorStops) {
  const canvas = document.createElement('canvas');
  canvas.width = 256;
  canvas.height = 1;
  const ctx = canvas.getContext('2d');

  const gradient = ctx.createLinearGradient(0, 0, 256, 0);
  colorStops.forEach(stop => {
    gradient.addColorStop(stop.offset, stop.color);
  });

  ctx.fillStyle = gradient;
  ctx.fillRect(0, 0, 256, 1);

  const imgData = ctx.getImageData(0, 0, 256, 1).data;
  const colorMap = [];

  for (let i = 0; i < 256; i++) {
    const offset = i * 4;
    colorMap.push([
      imgData[offset] / 255,     // Red (0 to 1)
      imgData[offset + 1] / 255, // Green (0 to 1)
      imgData[offset + 2] / 255, // Blue (0 to 1)
      imgData[offset + 3] / 255  // Alpha (0 to 1)
    ]);
  }

  return colorMap;
}

Applying the Color Map to the Plugin

Once the 256-element array is generated, pass it directly into the colorMap option when initializing the Spectrogram plugin.

import WaveSurfer from 'wavesurfer.js';
import Spectrogram from 'wavesurfer.js/dist/plugins/spectrogram.esm.js';

// Define the gradient stops from low intensity to high intensity
const customPalette = createColorMap([
  { offset: 0.0, color: '#000004' }, // Dark purple / black
  { offset: 0.25, color: '#51127c' }, // Purple
  { offset: 0.5, color: '#b73779' }, // Magenta
  { offset: 0.75, color: '#fc8961' }, // Orange
  { offset: 1.0, color: '#fcfdbf' }  // Pale yellow
]);

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  plugins: [
    Spectrogram.create({
      container: '#spectrogram',
      labels: true,
      colorMap: customPalette,
      height: 200
    })
  ]
});

wavesurfer.load('path/to/audio.mp3');

Using Predefined Colormap Libraries

If you prefer not to generate your own array manually, you can use third-party libraries such as colormap:

npm install colormap

Then configure the plugin with a preset like viridis, inferno, or magma:

import colormap from 'colormap';

const viridisMap = colormap({
  colormap: 'viridis',
  nshades: 256,
  format: 'rgba',
  alpha: 1
}).map(color => [
  color[0] / 255,
  color[1] / 255,
  color[2] / 255,
  color[3]
]);

Spectrogram.create({
  container: '#spectrogram',
  colorMap: viridisMap
});
