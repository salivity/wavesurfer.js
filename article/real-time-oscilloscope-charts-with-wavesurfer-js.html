Real-Time Oscilloscope Charts with Wavesurfer.js

This guide explains how to extract real-time audio output data from Wavesurfer.js and visualize it as an oscilloscope waveform. By routing the audio playback through the Web Audio API's AnalyserNode, you can capture raw time-domain data during playback and render a continuously updating line chart onto an HTML5 <canvas> element using requestAnimationFrame.

1. Initialize Wavesurfer and Web Audio Nodes

Wavesurfer.js handles audio decoding and standard playback. To intercept the audio stream for real-time visualization, you must connect the underlying HTML5 audio element to an AudioContext and an AnalyserNode.

import WaveSurfer from 'wavesurfer.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-your-audio.mp3',
});

// Set up Web Audio API nodes
const audioContext = new (window.AudioContext || window.webkitAudioContext)();
const analyser = audioContext.createAnalyser();
analyser.fftSize = 2048; // Determines waveform resolution

// Connect audio element once ready
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const source = audioContext.createMediaElementSource(mediaElement);

  source.connect(analyser);
  analyser.connect(audioContext.destination);
});

Note: Browsers restrict audio contexts from running until user interaction occurs. Ensure audioContext.resume() is called when the user initiates playback.

2. Prepare the Canvas

Set up a standard HTML5 <canvas> element where the oscilloscope waveform will be drawn.

<canvas id="oscilloscope" width="800" height="200"></canvas>
const canvas = document.getElementById('oscilloscope');
const canvasCtx = canvas.getContext('2d');

3. Extract Time-Domain Data

The AnalyserNode provides getByteTimeDomainData(), which populates an array with values ranging from 0 to 255, where 128 represents the zero-crossing baseline of the audio signal.

const bufferLength = analyser.frequencyBinCount;
const dataArray = new Uint8Array(bufferLength);

4. Implement the Render Loop

Create an animation loop using requestAnimationFrame. In each frame, clear the canvas, fetch the current time-domain data, map the array values to canvas coordinates, and stroke the path.

let isVisualizing = false;

function drawOscilloscope() {
  if (!isVisualizing) return;

  requestAnimationFrame(drawOscilloscope);

  analyser.getByteTimeDomainData(dataArray);

  // Clear previous frame
  canvasCtx.fillStyle = '#1e1e1e';
  canvasCtx.fillRect(0, 0, canvas.width, canvas.height);

  // Configure line style
  canvasCtx.lineWidth = 2;
  canvasCtx.strokeStyle = '#00ffcc';
  canvasCtx.beginPath();

  const sliceWidth = canvas.width / bufferLength;
  let x = 0;

  for (let i = 0; i < bufferLength; i++) {
    // Normalize value from 0-255 to 0.0-1.0
    const v = dataArray[i] / 128.0;
    // Map to canvas Y-coordinate
    const y = (v * canvas.height) / 2;

    if (i === 0) {
      canvasCtx.moveTo(x, y);
    } else {
      canvasCtx.lineTo(x, y);
    }

    x += sliceWidth;
  }

  canvasCtx.lineTo(canvas.width, canvas.height / 2);
  canvasCtx.stroke();
}

5. Synchronize with Wavesurfer Events

Trigger the rendering loop only while audio is actively playing to conserve CPU and GPU resources.

wavesurfer.on('play', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
  isVisualizing = true;
  drawOscilloscope();
});

wavesurfer.on('pause', () => {
  isVisualizing = false;
});

wavesurfer.on('finish', () => {
  isVisualizing = false;
  // Draw baseline zero state
  canvasCtx.fillRect(0, 0, canvas.width, canvas.height);
  canvasCtx.beginPath();
  canvasCtx.moveTo(0, canvas.height / 2);
  canvasCtx.lineTo(canvas.width, canvas.height / 2);
  canvasCtx.stroke();
});

This implementation directly links the media source loaded by Wavesurfer.js to an oscilloscope chart, ensuring that seeking, playing, and pausing are mirrored precisely in real time on the canvas.
