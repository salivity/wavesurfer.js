Dynamic Regions on Scroll in Wavesurfer.js

Rendering thousands of audio regions simultaneously in Wavesurfer.js can degrade DOM performance, cause UI stutter, and increase memory usage. This article explains how to subscribe to horizontal scroll events to dynamically render only the regions currently visible within the container's viewport, cleaning up out-of-view elements to maintain smooth performance during playback and scrubbing.

1. Identify the Scroll Container and Event

In Wavesurfer.js v7, horizontal scrolling occurs when the waveform width exceeds the container width (typically configured via the minPxPerSec setting). Wavesurfer exposes a native scroll event directly on the instance, or you can attach a native DOM listener to the wrapper element returned by wavesurfer.getWrapper().

Using the built-in scroll event provides the most reliable trigger across different zoom levels and platform scrollbars.

2. Calculate the Visible Time Window

To determine which regions must be rendered, calculate the visible start and end times using the scroll offset, container width, total scrollable width, and audio duration:

function getVisibleTimeRange(wavesurfer) {
  const wrapper = wavesurfer.getWrapper();
  const scrollLeft = wrapper.scrollLeft;
  const clientWidth = wrapper.clientWidth;
  const scrollWidth = wrapper.scrollWidth;
  const duration = wavesurfer.getDuration();

  const startTime = (scrollLeft / scrollWidth) * duration;
  const endTime = ((scrollLeft + clientWidth) / scrollWidth) * duration;

  return { startTime, endTime };
}

3. Implement Dynamic Region Management

Keep your complete region dataset in a plain JavaScript array or spatial index outside the DOM. When the scroll event fires, filter the dataset to find items that intersect with the current visible time window (optionally adding a buffer on each side to prevent popping during fast scrolling) and sync them with the Wavesurfer Regions plugin.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize Wavesurfer and Regions plugin
const wsRegions = RegionsPlugin.create();
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  minPxPerSec: 100, // Enables horizontal scrolling
  plugins: [wsRegions],
});

// Full dataset stored in memory
const allRegionsData = [
  { id: '1', start: 2, end: 5, content: 'Intro' },
  { id: '2', start: 120, end: 125, content: 'Chorus' },
  // ... thousands of region definitions
];

// Map to track currently rendered regions
const activeRegions = new Map();

function updateVisibleRegions() {
  const { startTime, endTime } = getVisibleTimeRange(wavesurfer);
  const buffer = 2; // Render 2 seconds beyond each viewport edge
  const visibleStart = Math.max(0, startTime - buffer);
  const visibleEnd = endTime + buffer;

  // Identify regions that belong in the current viewport
  const visibleData = allRegionsData.filter(
    (r) => r.end >= visibleStart && r.start <= visibleEnd
  );
  const visibleIds = new Set(visibleData.map((r) => r.id));

  // Remove regions that left the viewport
  activeRegions.forEach((regionInstance, id) => {
    if (!visibleIds.has(id)) {
      regionInstance.remove();
      activeRegions.delete(id);
    }
  });

  // Add new regions that entered the viewport
  visibleData.forEach((data) => {
    if (!activeRegions.has(data.id)) {
      const region = wsRegions.addRegion({
        id: data.id,
        start: data.start,
        end: data.end,
        content: data.content,
      });
      activeRegions.set(data.id, region);
    }
  });
}

4. Optimize Scroll Event Handling

Horizontal scroll events fire at high frequencies. Executing array filtering and DOM manipulations on every single event will cause thread contention. Wrap the update function using requestAnimationFrame or a debounce/throttle utility to match the display refresh rate:

let isTicking = false;

wavesurfer.on('scroll', () => {
  if (!isTicking) {
    window.requestAnimationFrame(() => {
      updateVisibleRegions();
      isTicking = false;
    });
    isTicking = true;
  }
});

// Initial render once the audio is ready
wavesurfer.on('ready', () => {
  updateVisibleRegions();
});

// Update regions when zooming alters the horizontal layout
wavesurfer.on('zoom', () => {
  updateVisibleRegions();
});

Using this approach keeps the active DOM footprint capped to only what the user can see, maintaining stable 60 FPS scrolling regardless of how many thousands of regions exist in your audio file.
