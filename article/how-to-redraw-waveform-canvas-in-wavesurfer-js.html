How to Redraw Waveform Canvas in Wavesurfer.js

When developing dynamic web applications with Wavesurfer.js, modifying container dimensions, switching visual themes, or updating audio settings often requires a manual redraw of the waveform. Depending on whether you are using Wavesurfer.js version 7 or legacy versions (v6 and below), different methods are used to refresh and re-render the canvas elements efficiently without reloading the audio file.

For Wavesurfer.js v6 and Below: drawBuffer()

In Wavesurfer.js version 6 and earlier, the dedicated method to force a canvas redraw is drawBuffer(). This method recalculates the peaks and redraws the canvas using the existing decoded audio data stored in memory.

// Redraw the waveform on demand
wavesurfer.drawBuffer();

A common use case involves redrawing the canvas during a window or container resize event:

window.addEventListener('resize', () => {
    wavesurfer.drawBuffer();
});

Calling drawBuffer() updates the waveform to fit new container dimensions instantly without making redundant network requests or re-decoding the audio file.

For Wavesurfer.js v7 and Newer: renderer.render() and setOptions()

In Wavesurfer.js version 7, the rendering pipeline was completely rewritten. By default, Wavesurfer v7 employs a built-in ResizeObserver, meaning manual redraws upon container resizing are often handled automatically.

However, if you need to manually force a redraw—such as after modifying audio peaks or canvas rendering properties—you invoke the render method on the renderer instance:

// Manually redraw the canvas using the current decoded audio data
wavesurfer.renderer.render(wavesurfer.getDecodedData());

Alternatively, if your redraw is triggered by changes to visual options (such as waveColor, progressColor, or barWidth), you can use setOptions(), which applies the updates and automatically triggers a re-render:

wavesurfer.setOptions({
    waveColor: '#ff0000',
    progressColor: '#00ff00'
});

If you only need to adjust the horizontal scaling or pixel density, using the zoom method also recalculates and repaints the canvas:

wavesurfer.zoom(wavesurfer.options.minPxPerSec);
