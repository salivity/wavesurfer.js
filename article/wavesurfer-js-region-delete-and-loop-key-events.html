Wavesurfer.js Region Delete and Loop Key Events

This article explains how keyboard events handle region deletion and loop toggling in Wavesurfer.js. While the library does not ship with built-in, pre-configured keyboard shortcuts for these actions, developers can implement standard DOM keyboard events—most commonly keydown using the Delete, Backspace, and custom shortcut keys—to trigger the corresponding programmatic methods on active region instances.

Default Keyboard Behavior in Wavesurfer.js

The Wavesurfer.js Regions plugin does not automatically bind keyboard events to DOM elements for deleting regions or toggling loops. This design choice prevents interference with host application shortcuts, form inputs, and custom audio player interfaces.

To enable keyboard-driven region controls, you must track the active or selected region and register custom DOM keyboard listeners.

Triggering Region Deletion

Region deletion is typically mapped to the Delete or Backspace keys. To implement this:

  1. Track the Active Region: Listen for the region-clicked or region-in event emitted by the Regions plugin to store a reference to the currently focused region.
  2. Listen for Keyboard Events: Attach a keydown listener to the window, document, or a focusable wrapper element containing the waveform.
  3. Invoke the Removal Method: When event.key === 'Delete' or event.key === 'Backspace', call region.remove() on the selected region instance.
let activeRegion = null;

// Track selection
regionsPlugin.on('region-clicked', (region, e) => {
  e.stopPropagation();
  activeRegion = region;
});

// Deselect when clicking outside
window.addEventListener('click', () => {
  activeRegion = null;
});

// Handle deletion key events
window.addEventListener('keydown', (event) => {
  if (!activeRegion) return;

  if (event.key === 'Delete' || event.key === 'Backspace') {
    event.preventDefault();
    activeRegion.remove();
    activeRegion = null;
  }
});

Triggering Loop Toggles

Loop toggling is commonly bound to keys such as L, Space, or modifier combinations (such as Shift + Space). In Wavesurfer.js, looping a region is controlled programmatically rather than via a native plugin toggle flag.

  1. Handle the Key Event: Capture the desired key (e.g., event.key.toLowerCase() === 'l') inside the keydown listener.
  2. Execute the Loop Logic: If using Wavesurfer.js v7, invoke region.play() and manage repetition by listening to the region's boundary events (region-out), or call activeRegion.playLoop() if available in your version:
let isLooping = false;

window.addEventListener('keydown', (event) => {
  if (!activeRegion) return;

  if (event.key.toLowerCase() === 'l') {
    event.preventDefault();
    isLooping = !isLooping;

    if (isLooping) {
      activeRegion.play();
    }
  }
});

// Ensure playback seeks back to the region start upon exiting the region
regionsPlugin.on('region-out', (region) => {
  if (isLooping && activeRegion === region) {
    region.play();
  }
});

Best Practices

  • Scope Event Listeners: Ensure key events only fire when the audio player container has focus or when text input fields (<input>, <textarea>) are not actively focused.
  • State Clean-Up: Always set your active region reference to null when a region is removed or when a user clicks empty space on the waveform.
