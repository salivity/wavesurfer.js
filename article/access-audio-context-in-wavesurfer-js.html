Access AudioContext in Wavesurfer.js

Accessing the Web Audio API AudioContext in Wavesurfer.js allows developers to build custom digital signal processing (DSP) pipelines, attach analytical nodes, and apply audio effects such as equalizers and spatial audio. This guide explains how to access or initialize the AudioContext in both the modern Wavesurfer.js architecture (v7+) and legacy versions (v6 and below).

Modern Wavesurfer.js (Version 7+)

Starting with version 7, Wavesurfer.js switched from the Web Audio API to HTML5 HTMLMediaElement by default to improve memory usage, decoding performance, and streaming capabilities. As a result, an AudioContext is not automatically initialized unless required.

Method 1: Injecting an AudioContext via Initialization

If you need Wavesurfer.js to share an AudioContext with your application, you can instantiate one and pass it directly into the configuration options:

import WaveSurfer from 'wavesurfer.js';

// 1. Create your AudioContext
const audioContext = new (window.AudioContext || window.webkitAudioContext)();

// 2. Pass it to the Wavesurfer instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'violet',
  progressColor: 'purple',
  url: '/path/to/audio.mp3',
  audioContext: audioContext,
});

// 3. Access it later via options
console.log(wavesurfer.options.audioContext);

Method 2: Connecting the Media Element to a Web Audio Graph

If you do not pass an audioContext during initialization, you can attach an AudioContext to Wavesurfer's internal media element using createMediaElementSource:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  url: '/path/to/audio.mp3',
});

wavesurfer.on('ready', () => {
  const audioContext = new (window.AudioContext || window.webkitAudioContext)();
  const mediaElement = wavesurfer.getMediaElement();
  
  // Create a MediaElementAudioSourceNode
  const sourceNode = audioContext.createMediaElementSource(mediaElement);

  // Example: Insert a GainNode or AnalyzerNode
  const gainNode = audioContext.createGain();
  sourceNode.connect(gainNode);
  gainNode.connect(audioContext.destination);
});

Note: Browsers restrict AudioContext playback until a user interaction occurs. Ensure audioContext.resume() is called within a user-triggered event like a click.

Legacy Wavesurfer.js (Version 6 and Earlier)

In Wavesurfer.js v6 and older, the default playback engine relied directly on the Web Audio API backend (WebAudio).

You can retrieve the AudioContext directly through the backend property:

// Access the AudioContext directly
const audioContext = wavesurfer.backend.ac;

// Or use the backend getter method
const audioContextFromGetter = wavesurfer.backend.getAudioContext();

In these legacy versions, you can also directly insert Web Audio nodes into the built-in signal chain using:

const filter = wavesurfer.backend.ac.createBiquadFilter();
filter.type = 'lowpass';
filter.frequency.value = 1000;

// Connect into Wavesurfer's existing backend graph
wavesurfer.backend.setFilter(filter);
