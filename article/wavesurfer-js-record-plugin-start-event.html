Wavesurfer.js Record Plugin Start Event

This guide covers the specific event triggered when an audio recording begins using the Wavesurfer.js Record plugin. You will learn the exact event name to listen for in your application, see practical JavaScript code examples of how to implement the event listener, and understand how it integrates into the overall recording lifecycle.

The Recording Start Event: record-start

In Wavesurfer.js (version 7 and later), the Record plugin emits the record-start event as soon as the recording process successfully initiates.

When you call the plugin's startRecording() method and the user grants microphone permissions, the audio stream activates and the record-start event fires.

How to Listen for the Event

To capture this event, attach a listener to the instance of the Record plugin using the .on() method.

import WaveSurfer from 'wavesurfer.js'
import RecordPlugin from 'wavesurfer.js/dist/plugins/record.esm.js'

// 1. Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
})

// 2. Initialize the Record plugin
const record = wavesurfer.registerPlugin(
  RecordPlugin.create({
    scrollingWaveform: true,
    renderRecordedAudio: false,
  })
)

// 3. Listen for the 'record-start' event
record.on('record-start', () => {
  console.log('Recording has officially started.')
  // Update UI elements, disable the start button, or start a timer
})

// 4. Trigger recording
const startButton = document.querySelector('#start-btn')
startButton.addEventListener('click', () => {
  record.startRecording()
})

Related Lifecycle Events

For managing complete recording workflows, the Record plugin also provides corresponding lifecycle events:

  • record-start: Triggered immediately when recording begins.
  • record-pause: Triggered when the recording is temporarily paused.
  • record-resume: Triggered when recording resumes after being paused.
  • record-end: Triggered when recording stops and the final audio blob is created.
  • record-progress: Emitted continuously during recording to report the elapsed time.
