Wavesurfer.js Equalizer Bar Width and Gap Settings

Achieving a retro or vintage graphic equalizer aesthetic in Wavesurfer.js depends primarily on balancing the barWidth and barGap properties alongside structural styling like barRadius. By shifting away from standard continuous waveforms toward distinct, blocky vertical pillars, you can transform standard audio data into displays reminiscent of 1980s rackmount units, studio spectrum analyzers, and modern digital meters.

Understanding the Equalizer Proportions

A standard waveform uses continuous, thin lines with minimal spacing, whereas a graphic equalizer utilizes wider vertical bars separated by distinct gaps that mimic hardware LED columns. To achieve this look, the ratio between barWidth and barGap generally needs to stay between 1:1 and 3:1, coupled with a squared or slightly rounded edge profile.

1. The Vintage Stereo Rack (LED Segment Look)

This profile replicates the chunky, rectangular look of physical LED meters found on 1980s and 1990s stereo receivers.

  • barWidth: 6
  • barGap: 3
  • barRadius: 0

The 2:1 width-to-gap ratio provides sufficient separation to make each bar read as a standalone indicator, while flat tops (barRadius: 0) ensure an authentic, unrounded hardware appearance.

2. The High-Density Studio Spectrum

For an equalizer look that mimics digital mastering software or multi-band parametric equalizers, smaller elements packed closely together yield a sharper, more technical display.

  • barWidth: 2
  • barGap: 1
  • barRadius: 0

This tight layout fits dozens of visible channels across medium-width containers, maintaining distinct vertical columns without blurring into a solid wave.

3. The Modern Neo-Retro Equalizer

If you prefer an equalizer style with softer modern UI aesthetics (similar to mobile music visualizers), use wider bars with subtle rounding.

  • barWidth: 4
  • barGap: 2
  • barRadius: 2

The slight border radius softens the harsh edges of the blocks while preserving the distinct separation necessary for an equalizer feel.

4. The Chunky Boombox Analyzer

For lower-resolution, arcade-like displays or dashboard visualizers, maximize the width and spacing.

  • barWidth: 8
  • barGap: 4
  • barRadius: 0

This layout reduces the total number of bars rendered across the container, giving the visual appearance of a fixed 10-band or 12-band graphic equalizer rather than a continuous audio signal.

Implementation Example

To apply these settings, initialize your Wavesurfer instance with the selected values along with complementary equalizer properties:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4ade80',
  progressColor: '#22c55e',
  barWidth: 6,
  barGap: 3,
  barRadius: 0,
  barHeight: 1,
  normalize: true,
  minPxPerSec: 50,
});

Critical Complementary Settings

  • barRadius: Setting this to 0 is essential for classic hardware realism. Softening the corners beyond 2 quickly shifts the design from a technical equalizer to a standard audio pill visualizer.
  • normalize: true: An authentic equalizer utilizes the entire vertical display. Normalizing scales the peaks to touch the container edges, mirroring peak audio meter behavior.
  • Canvas Gradients: Real graphic equalizers often shift from green at the bottom to yellow in the mid-range and red at the top. You can pass an HTML5 Canvas gradient into waveColor and progressColor to match this classic tri-color LED meter look.
