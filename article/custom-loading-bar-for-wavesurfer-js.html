Custom Loading Bar for Wavesurfer.js

Displaying a custom loading bar in Wavesurfer.js allows you to provide clear visual feedback to users while large audio files download and decode. This guide demonstrates how to set up the HTML markup, style a progress indicator, and hook into Wavesurfer.js lifecycle events to dynamically update and hide the progress bar.

HTML Structure

Create a container for the waveform and a separate element to act as the loading bar wrapper and progress indicator.

<div id="waveform-container">
  <div id="waveform"></div>
  
  <!-- Loading Bar Container -->
  <div id="loading-bar-wrapper">
    <div id="loading-bar"></div>
  </div>
</div>

CSS Styling

Style the progress bar to overlay the waveform or sit directly beneath it. The inner bar width will start at 0% and expand as the audio loads.

#waveform-container {
  position: relative;
  width: 100%;
}

#loading-bar-wrapper {
  width: 100%;
  height: 8px;
  background-color: #e0e0e0;
  border-radius: 4px;
  overflow: hidden;
  margin-top: 10px;
}

#loading-bar {
  width: 0%;
  height: 100%;
  background-color: #007bff;
  transition: width 0.1s ease;
}

JavaScript Implementation

Wavesurfer.js emits a loading event that provides the download and decoding progress as a percentage value (from 0 to 100). Use this event to update the CSS width property of your loading bar, and use the ready event to hide the loading bar once playback is ready.

import WaveSurfer from 'wavesurfer.js';

const loadingBar = document.getElementById('loading-bar');
const loadingBarWrapper = document.getElementById('loading-bar-wrapper');

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#38335C',
  url: '/path/to/audio-file.mp3',
});

// Update progress bar width on loading event
wavesurfer.on('loading', (percent) => {
  loadingBar.style.width = `${percent}%`;
});

// Hide the loading bar when audio is decoded and ready
wavesurfer.on('ready', () => {
  loadingBarWrapper.style.display = 'none';
});

Handling Errors

To prevent the loading bar from remaining indefinitely if the audio fails to fetch or decode, add a listener for the error event:

wavesurfer.on('error', (err) => {
  console.error('WaveSurfer error:', err);
  loadingBarWrapper.style.display = 'none';
});
