Extract ID3 Tags and Load Audio in Wavesurfer.js

This guide demonstrates how to build a client-side audio player that simultaneously visualizes audio using Wavesurfer.js and extracts embedded ID3 metadata (such as artist, title, album, and artwork) from locally selected audio files. By combining the HTML5 File API, the jsmediatags library for tag parsing, and Wavesurfer.js for audio processing, you can render waveforms and display track information instantly without uploading files to a server.

Required Dependencies

To achieve this in the browser, you need two client-side libraries: Wavesurfer.js for rendering the waveform and jsmediatags for reading the ID3 binary frames.

You can include them via CDN:

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/jsmediatags/3.9.5/jsmediatags.min.js"></script>

HTML Structure

Create an input element for file selection, a container for the waveform, and placeholders to display the extracted metadata.

<input type="file" id="audio-input" accept="audio/*" />

<div id="metadata-display">
  <h3 id="track-title">Title: -</h3>
  <p id="track-artist">Artist: -</p>
  <p id="track-album">Album: -</p>
  <img id="track-artwork" alt="Album Art" style="max-width: 150px; display: none;" />
</div>

<div id="waveform"></div>
<button id="play-btn">Play / Pause</button>

Initializing Wavesurfer.js

Initialize your Wavesurfer instance targeting your container element:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  height: 100,
});

document.getElementById('play-btn').addEventListener('click', () => {
  wavesurfer.playPause();
});

Reading Local Files and Parsing ID3 Tags

When a user selects a file via the <input type="file"> element, you receive a standard File object. You can pass this single object to both Wavesurfer.js and jsmediatags simultaneously.

const fileInput = document.getElementById('audio-input');

fileInput.addEventListener('change', (event) => {
  const file = event.target.files[0];
  if (!file) return;

  // 1. Load the file into Wavesurfer.js
  wavesurfer.loadBlob(file);

  // 2. Extract ID3 metadata using jsmediatags
  window.jsmediatags.read(file, {
    onSuccess: (tag) => {
      const tags = tag.tags;

      // Update text fields
      document.getElementById('track-title').textContent = `Title: ${tags.title || 'Unknown'}`;
      document.getElementById('track-artist').textContent = `Artist: ${tags.artist || 'Unknown'}`;
      document.getElementById('track-album').textContent = `Album: ${tags.album || 'Unknown'}`;

      // Handle embedded cover art
      const artworkElement = document.getElementById('track-artwork');
      const image = tags.picture;

      if (image) {
        let base64String = '';
        for (let i = 0; i < image.data.length; i++) {
          base64String += String.fromCharCode(image.data[i]);
        }
        const base64 = window.btoa(base64String);
        artworkElement.src = `data:${image.format};base64,${base64}`;
        artworkElement.style.display = 'block';
      } else {
        artworkElement.style.display = 'none';
      }
    },
    onError: (error) => {
      console.warn('ID3 metadata extraction failed:', error.type, error.info);
      document.getElementById('track-title').textContent = `Title: ${file.name}`;
      document.getElementById('track-artist').textContent = 'Artist: Unknown';
      document.getElementById('track-album').textContent = 'Album: Unknown';
    }
  });
});

How the Process Works

  1. Blob Loading: wavesurfer.loadBlob(file) takes the raw browser File object, decodes the audio data using the Web Audio API, and renders the visual waveform peaks.
  2. Binary Slicing: The jsmediatags.read() method uses binary chunk reading on the local File object without reading the entire file into memory, specifically targeting the ID3v1 or ID3v2 header and APIC frames.
  3. Cover Art Decoding: The binary image array stored inside tag.tags.picture.data is converted into a Base64 string and assigned directly to the src attribute of an HTML image tag as a Data URI.
