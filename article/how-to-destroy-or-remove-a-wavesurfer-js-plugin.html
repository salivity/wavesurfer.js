How to Destroy or Remove a Wavesurfer.js Plugin

Managing plugins properly in Wavesurfer.js is essential for maintaining application performance and preventing memory leaks when dynamically toggling audio features. This guide explains how to cleanly destroy and unregister plugins in both modern Wavesurfer.js (v7+) and legacy releases (v6 and older), covering direct instance teardown and full player cleanup.

Destroying Plugins in Wavesurfer.js v7+

In Wavesurfer.js version 7, plugins are modular classes instantiated either during the initialization of the main player or via the registerPlugin() method.

To destroy a plugin, call the destroy() method directly on the plugin instance. This removes all associated event listeners, clears custom DOM elements, and unhooks the plugin from the Wavesurfer instance.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// 1. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'violet',
  progressColor: 'purple'
});

// 2. Register the plugin and store the instance
const regions = wavesurfer.registerPlugin(RegionsPlugin.create());

// 3. Destroy and remove the plugin when it is no longer needed
regions.destroy();

Once destroy() is executed on the plugin reference, it is completely removed from the Wavesurfer lifecycle. If you need to restore the plugin's functionality later, you must create and register a new instance.

Destroying Plugins in Wavesurfer.js v6 and Earlier

In older versions of Wavesurfer.js, plugins were managed through internal registries using string identifiers. You can remove a plugin using the built-in destroyPlugin() method on the main WaveSurfer instance:

// Remove and destroy a plugin using its registered name
wavesurfer.destroyPlugin('regions');

Alternatively, if you maintained a reference to the plugin instance returned during initialization, calling destroy() directly on that instance produces the same result:

const regions = wavesurfer.addPlugin(WaveSurfer.regions.create());

// Destroy directly via instance
regions.destroy();

Automatic Plugin Destruction

If your goal is to tear down the entire audio player rather than a single feature, you do not need to destroy each plugin manually. Calling wavesurfer.destroy() on the primary player instance automatically iterates over all registered plugins and invokes their respective destroy() methods before clearing the audio context and canvas elements.
