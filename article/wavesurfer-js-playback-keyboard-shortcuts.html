Wavesurfer.js Playback Keyboard Shortcuts

This article outlines how to implement keyboard shortcuts to control audio playback in Wavesurfer.js. While the library does not bundle default keyboard controls, developers can capture native browser keyboard events using JavaScript to trigger essential playback methods. Below is a guide to the most common shortcuts to map, the core API methods used, and practical implementation code.

Essential Playback Shortcuts to Map

You can map any key event to Wavesurfer.js instance methods. The most intuitive shortcuts mirror standard media player conventions:

  • Spacebar (Space): Toggle Play / Pause. Triggers wavesurfer.playPause().
  • Left Arrow (ArrowLeft): Seek backward (e.g., 5 seconds). Triggers wavesurfer.skip(-5).
  • Right Arrow (ArrowRight): Seek forward (e.g., 5 seconds). Triggers wavesurfer.skip(5).
  • Up Arrow (ArrowUp): Increase volume by an increment. Uses wavesurfer.setVolume(currentVolume + 0.1).
  • Down Arrow (ArrowDown): Decrease volume by an increment. Uses wavesurfer.setVolume(currentVolume - 0.1).
  • Key M (KeyM): Toggle mute. Uses wavesurfer.setMuted(!wavesurfer.getMuted()).
  • Key 0 or Home (Digit0 / Home): Reset to the beginning of the track. Triggers wavesurfer.seekTo(0).
  • Bracket Keys ([ / ]): Decrease or increase playback rate. Uses wavesurfer.setPlaybackRate(rate).

Implementation Example

To implement these controls, attach a keydown event listener to the window or a dedicated container. Ensure event.preventDefault() is used on keys like the spacebar and arrow keys to avoid unwanted page scrolling.

window.addEventListener('keydown', (event) => {
  // Prevent shortcuts when user is typing in an input field
  const targetTag = event.target.tagName.toLowerCase();
  if (targetTag === 'input' || targetTag === 'textarea') {
    return;
  }

  switch (event.code) {
    case 'Space':
      event.preventDefault();
      wavesurfer.playPause();
      break;

    case 'ArrowLeft':
      event.preventDefault();
      wavesurfer.skip(-5);
      break;

    case 'ArrowRight':
      event.preventDefault();
      wavesurfer.skip(5);
      break;

    case 'ArrowUp':
      event.preventDefault();
      const currentVolUp = wavesurfer.getVolume();
      wavesurfer.setVolume(Math.min(1, currentVolUp + 0.05));
      break;

    case 'ArrowDown':
      event.preventDefault();
      const currentVolDown = wavesurfer.getVolume();
      wavesurfer.setVolume(Math.max(0, currentVolDown - 0.05));
      break;

    case 'KeyM':
      wavesurfer.setMuted(!wavesurfer.getMuted());
      break;

    case 'Home':
    case 'Digit0':
      event.preventDefault();
      wavesurfer.seekTo(0);
      break;
  }
});

Best Practices

  • Input Focus Checks: Always verify that the active element is not a text field, dropdown, or editable element before executing playback commands.
  • Accessibility: Ensure the container element has a tabindex="0" attribute and suitable aria-label tags if you are scoping the shortcuts to a specific component rather than the global window object.
  • Modifier Keys: Use combinations like Shift + ArrowLeft or Shift + ArrowRight to enable larger jump intervals (such as 30 seconds) for faster timeline navigation.
