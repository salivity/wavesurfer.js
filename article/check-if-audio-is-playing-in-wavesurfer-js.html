Check if Audio is Playing in Wavesurfer.js

Managing playback state is a common requirement when building custom audio interfaces with Wavesurfer.js. This article explains how to determine whether an audio track is currently playing using the built-in isPlaying() method, demonstrates its practical implementation in JavaScript, and covers state-tracking alternatives using Wavesurfer event listeners.

The isPlaying() Method

To check if audio is actively playing in Wavesurfer.js, call the isPlaying() method on your initialized Wavesurfer instance. This method returns a boolean value: true if the audio is currently playing, and false if the audio is paused, stopped, or has finished playing.

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/path/to/audio.mp3'
});

// Check playback status
if (wavesurfer.isPlaying()) {
  console.log('Audio is currently playing.');
} else {
  console.log('Audio is paused or stopped.');
}

Using isPlaying() in a Custom Play/Pause Toggle

The most frequent use case for isPlaying() is toggling the playback state and updating the UI accordingly. While Wavesurfer provides a native playPause() method, you can also use isPlaying() for manual conditional logic:

const playButton = document.getElementById('play-btn');

playButton.addEventListener('click', () => {
  if (wavesurfer.isPlaying()) {
    wavesurfer.pause();
    playButton.textContent = 'Play';
  } else {
    wavesurfer.play();
    playButton.textContent = 'Pause';
  }
});

Listening to Playback Events

Instead of polling isPlaying() repeatedly, it is often more efficient to track playback state reactively using Wavesurfer.js lifecycle events. You can subscribe to the play, pause, and finish events to synchronize your UI:

wavesurfer.on('play', () => {
  console.log('Audio started playing');
});

wavesurfer.on('pause', () => {
  console.log('Audio was paused');
});

wavesurfer.on('finish', () => {
  console.log('Audio reached the end');
});

Using wavesurfer.isPlaying() provides an immediate synchronous snapshot of playback, while event listeners ensure your application stays updated across asynchronous audio state changes.
