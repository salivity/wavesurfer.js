Build a Multi-Track Audio Editor with Wavesurfer.js

This guide provides an end-to-end walkthrough for creating an in-browser multi-track audio editor using Wavesurfer.js and its official Multitrack plugin. You will learn how to set up the environment, load and render multiple synchronized audio tracks, implement playback and mixing controls, and render the final composite audio using the Web Audio API.

1. Project Setup and Installation

Wavesurfer.js provides an official package designed specifically for multi-track arrangements. Install both the core library and the multitrack extension via npm, or include them using a modern CDN.

npm install wavesurfer.js @wavesurfer/multitrack

In your HTML, define a container element where the waveforms and track headers will be rendered:

<div id="controls">
  <button id="playPauseBtn">Play</button>
  <button id="addTrackBtn">Add Track</button>
</div>
<div id="multitrack-container"></div>

2. Initializing the Multitrack Instance

The @wavesurfer/multitrack package handles the rendering, dragging, and synchronized playback of multiple audio clips across separate horizontal lanes.

import Multitrack from '@wavesurfer/multitrack'

const container = document.querySelector('#multitrack-container')

const multitrack = Multitrack.create(
  [
    {
      id: 0,
      draggable: true,
      startPosition: 0,
      url: '/audio/drums.mp3',
      volume: 0.8,
      options: {
        waveColor: '#4f46e5',
        progressColor: '#312e81',
      },
    },
    {
      id: 1,
      draggable: true,
      startPosition: 2.5, // Start 2.5 seconds in
      url: '/audio/bass.mp3',
      volume: 0.6,
      options: {
        waveColor: '#06b6d4',
        progressColor: '#0e7490',
      },
    },
  ],
  {
    container: container,
    minPxPerSec: 50,
    rightButtonDrag: false,
    cursorWidth: 2,
    cursorColor: '#ef4444',
  }
)

3. Managing Transport Controls

Global playback must control all tracks simultaneously. Use the multitrack API to handle global play, pause, and seeking.

const playPauseBtn = document.querySelector('#playPauseBtn')

playPauseBtn.addEventListener('click', () => {
  if (multitrack.isPlaying()) {
    multitrack.pause()
    playPauseBtn.textContent = 'Play'
  } else {
    multitrack.play()
    playPauseBtn.textContent = 'Pause'
  }
})

// Listen to time updates across tracks
multitrack.on('timeupdate', (currentTime) => {
  console.log(`Current position: ${currentTime.toFixed(2)}s`)
})

4. Track Controls: Volume, Mute, and Solo

To provide mixer functionality, create custom UI controls that interface with individual track nodes within the multitrack instance:

// Change volume for a specific track
function setTrackVolume(trackId, volume) {
  multitrack.setTrackVolume(trackId, volume) // volume between 0 and 1
}

// Mute a specific track
function muteTrack(trackId) {
  multitrack.setTrackVolume(trackId, 0)
}

// Solo a specific track
function soloTrack(targetTrackId) {
  multitrack.tracks.forEach((track) => {
    if (track.id === targetTrackId) {
      multitrack.setTrackVolume(track.id, 1)
    } else {
      multitrack.setTrackVolume(track.id, 0)
    }
  })
}

5. Adding and Manipulating Tracks Dynamically

You can add new audio clips dynamically when users record or upload new files. Use the addTrack method:

function loadUserFile(file) {
  const url = URL.createObjectURL(file)

  multitrack.addTrack({
    id: Date.now(),
    draggable: true,
    startPosition: 0,
    url: url,
    options: {
      waveColor: '#10b981',
      progressColor: '#065f46',
    },
  })
}

Track drag events allow users to reposition audio along the timeline. You can listen for positional changes to persist state:

multitrack.on('drop', ({ id, startPosition }) => {
  console.log(`Track ${id} relocated to ${startPosition} seconds`)
})

6. Rendering and Exporting the Final Mixdown

Wavesurfer handles browser playback, but exporting the combined tracks to an audio file requires the Web Audio API's OfflineAudioContext.

async function exportAudio(tracks, totalDurationInSeconds) {
  const sampleRate = 44100
  const offlineCtx = new OfflineAudioContext(
    2, // Stereo
    sampleRate * totalDurationInSeconds,
    sampleRate
  )

  for (const track of tracks) {
    const response = await fetch(track.url)
    const arrayBuffer = await response.arrayBuffer()
    const audioBuffer = await offlineCtx.decodeAudioData(arrayBuffer)

    const source = offlineCtx.createBufferSource()
    const gainNode = offlineCtx.createGain()

    source.buffer = audioBuffer
    gainNode.gain.value = track.volume ?? 1

    source.connect(gainNode)
    gainNode.connect(offlineCtx.destination)

    // Schedule playback at the track's configured start position
    source.start(track.startPosition)
  }

  const renderedBuffer = await offlineCtx.startRendering()
  return renderedBuffer
}

The resulting AudioBuffer can then be converted to a WAV or MP3 blob for downloading or server-side storage.
