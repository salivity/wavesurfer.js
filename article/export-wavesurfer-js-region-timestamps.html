Export Wavesurfer.js Region Timestamps

Exporting audio segment timestamps from Wavesurfer.js allows developers to save annotations, build transcripts, or process audio slices on a backend server. In Wavesurfer.js, the primary method used to retrieve these segments is the getRegions() function provided by the Regions plugin. This article explains how to access getRegions() to extract start and end timestamps and export them into standard data formats like JSON.

The Primary Function: getRegions()

Wavesurfer.js does not have a single built-in file export button; instead, it provides programmatic access to segment data via the getRegions() method on your RegionsPlugin instance.

Calling getRegions() returns an array containing all currently active region objects on the waveform. Each region object in this array contains properties that store the necessary segment data, specifically start (the beginning of the segment in seconds) and end (the conclusion of the segment in seconds), along with an optional unique id and data payload.

Extracting Timestamp Data

To convert the raw region instances into a clean data structure, you can iterate over the output of getRegions() using JavaScript's .map() method:

// Initialize the regions plugin instance
const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

// Function to export region timestamps
function exportRegionTimestamps() {
  const regions = wsRegions.getRegions();

  const timestampData = regions.map((region) => {
    return {
      id: region.id,
      start: region.start,
      end: region.end,
      duration: region.end - region.start,
      data: region.data || {}
    };
  });

  return timestampData;
}

Exporting Timestamps to a JSON File

Once you extract the start and end properties, you can serialize the data to JSON and trigger a browser download:

function downloadTimestampsAsJSON() {
  const timestamps = exportRegionTimestamps();
  const jsonString = JSON.stringify(timestamps, null, 2);
  const blob = new Blob([jsonString], { type: "application/json" });
  const url = URL.createObjectURL(blob);

  const downloadLink = document.createElement("a");
  downloadLink.href = url;
  downloadLink.download = "audio-regions.json";
  downloadLink.click();

  URL.revokeObjectURL(url);
}

Listening for Real-Time Timestamp Updates

If your application needs to capture timestamps as soon as a user finishes creating or adjusting a segment, listen to the region-specific lifecycle events on the RegionsPlugin instance:

  • region-created: Fires when a region is drawn or instantiated.
  • region-updated: Fires continuously or when the user finishes dragging the region boundaries.
  • region-removed: Fires when a segment is deleted.

By combining getRegions() with these event listeners, you ensure that any exported timestamp data reflects the exact boundaries set on the audio timeline.
