FFmpeg Waveform Peaks for Wavesurfer.js

Pre-generating waveform data with FFmpeg eliminates client-side audio decoding bottlenecks, drastically speeding up waveform rendering in Wavesurfer.js. This guide provides the exact FFmpeg command-line flags required to extract raw amplitude peak data for both mono and multi-channel audio for direct consumption by Wavesurfer.js.

The Standard FFmpeg Command

Wavesurfer.js can ingest precomputed waveform peaks via an array of floating-point numbers or by reading raw pulse-code modulation (PCM) data. To export raw amplitude values, use the following FFmpeg command:

ffmpeg -i input.mp3 -ac 1 -ar 8000 -f f32le -acodec pcm_f32le output.raw

Breakdown of Essential Command Line Flags

  • -i <input_file>: Specifies the path to the input audio or video file.
  • -ac <number>: Sets the number of audio channels.
    • Use -ac 1 to downmix audio into a single mono channel, ideal for standard single-line waveforms.
    • Use -ac 2 to preserve stereo channels for multi-channel waveform rendering.
  • -ar <frequency>: Audio sample rate. Raw full-resolution audio (e.g., 44.1kHz or 48kHz) yields far more data points than a browser canvas needs. Lowering the rate (such as 8000 or lower) downsamples the stream to a manageable size for quick parsing.
  • -acodec pcm_f32le: Selects the raw uncompressed 32-bit floating-point Little-Endian PCM audio codec. This format maps amplitude values directly to 32-bit floats ranging between -1.0 and 1.0, matching the internal representation used by the Web Audio API.
  • -f f32le: Forces the output container format to raw 32-bit Little-Endian data (headerless stream).

Extracting Separate Stereo Amplitude Channels

If Wavesurfer.js needs to display distinct left and right amplitude waveforms, extract each channel separately using the -map_channel flag or audio filters:

Left Channel:

ffmpeg -i input.mp3 -map_channel 0.0.0 -ar 8000 -f f32le -acodec pcm_f32le left.raw

Right Channel:

ffmpeg -i input.mp3 -map_channel 0.0.1 -ar 8000 -f f32le -acodec pcm_f32le right.raw

Alternatively, use -filter_complex to split the stereo channels in a single pass:

ffmpeg -i input.mp3 -filter_complex "[0:a]channelsplit=channel_layout=stereo[left][right]" \
  -map "[left]" -ar 8000 -f f32le left.raw \
  -map "[right]" -ar 8000 -f f32le right.raw

Integrating Output with Wavesurfer.js

The generated .raw file can be fetched as an ArrayBuffer in JavaScript and read directly into a Float32Array:

fetch('output.raw')
  .then(response => response.arrayBuffer())
  .then(buffer => {
    const float32Array = new Float32Array(buffer);
    
    const wavesurfer = WaveSurfer.create({
      container: '#waveform',
      waveColor: '#4F4A85',
      progressColor: '#383351',
      peaks: [float32Array],
      duration: audioDurationInSeconds
    });
  });

When passing pre-extracted peaks, ensure the audio element's total duration is explicitly declared in Wavesurfer's configuration, as raw amplitude streams do not contain container duration metadata.
