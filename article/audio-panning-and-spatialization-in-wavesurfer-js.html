Audio Panning and Spatialization in Wavesurfer.js

This article explains how to implement audio panning and spatialization in Wavesurfer.js. While Wavesurfer.js includes official plugins for features like regions, timelines, and minimaps, it does not feature a dedicated, standalone spatialization plugin. Instead, stereo panning and 3D audio spatialization are handled directly through native Web Audio API integration using nodes such as StereoPannerNode and PannerNode. Below, you will learn how these nodes connect to Wavesurfer.js and how to implement both 2D panning and 3D spatial audio in your project.

Understanding the Web Audio API Integration

Wavesurfer.js is built on modern web standards and interfaces seamlessly with the browser's Web Audio API. Rather than relying on a third-party plugin for panning, developers route Wavesurfer’s audio output through native audio nodes.

To use custom audio nodes, Wavesurfer must be configured to utilize an AudioContext and connect custom processing nodes before routing the signal to audioContext.destination.

Implementing Stereo Panning (2D)

For basic left-to-right stereo panning, the StereoPannerNode provides a lightweight and efficient solution.

  1. Initialize Wavesurfer: Create your Wavesurfer instance as usual.
  2. Create the Panner Node: Instantiate a StereoPannerNode using the active AudioContext.
  3. Route the Audio: Insert the panner node between the media source and the destination.
  4. Update the Pan Value: Control the pan property between -1 (full left) and 1 (full right).
import WaveSurfer from 'wavesurfer.js';

// 1. Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
});

// 2. Set up Web Audio nodes once ready
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const audioContext = new (window.AudioContext || window.webkitAudioContext)();
  
  const source = audioContext.createMediaElementSource(mediaElement);
  const panner = audioContext.createStereoPanner();

  // Connect source -> panner -> destination
  source.connect(panner);
  panner.connect(audioContext.destination);

  // Set pan: -1 (left), 0 (center), 1 (right)
  panner.pan.setValueAtTime(0.5, audioContext.currentTime);
});

Implementing 3D Spatial Audio

For complete 3D spatialization (positioning audio in an X, Y, Z coordinate space), use the Web Audio API's PannerNode alongside the AudioListener.

The PannerNode supports complex spatial parameters, including:

  • Positioning: positionX, positionY, positionZ coordinates.
  • Orientation: Directivity cones for directional sound sources.
  • Distance Models: Linear, inverse, or exponential rolloff as the listener moves away from the source.
const audioContext = new AudioContext();
const panner3D = audioContext.createPanner();

// Configure 3D properties
panner3D.panningModel = 'HRTF'; // Realistic spatial rendering
panner3D.distanceModel = 'inverse';
panner3D.refDistance = 1;
panner3D.maxDistance = 10000;
panner3D.rolloffFactor = 1;

// Position the sound source in 3D space
panner3D.positionX.setValueAtTime(2, audioContext.currentTime);
panner3D.positionY.setValueAtTime(0, audioContext.currentTime);
panner3D.positionZ.setValueAtTime(-1, audioContext.currentTime);

// Route through Wavesurfer's media source
const source = audioContext.createMediaElementSource(wavesurfer.getMediaElement());
source.connect(panner3D);
panner3D.connect(audioContext.destination);

Key Considerations

  • Single Audio Source: An HTML media element can only be bound to a single createMediaElementSource call. Ensure your routing logic initializes once to prevent DOM exceptions.
  • Autoplay Policies: Audio contexts typically begin in a suspended state until user interaction occurs. Call audioContext.resume() on user input if audio output does not start automatically.
