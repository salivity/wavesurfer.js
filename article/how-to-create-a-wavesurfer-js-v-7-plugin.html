How to Create a Wavesurfer.js v7 Plugin

This guide provides a comprehensive overview of building a custom plugin for Wavesurfer.js v7 using modern JavaScript. You will learn the core architecture of the plugin system, how to extend the standard base class, implement required lifecycle hooks, and register your custom functionality with an active audio waveform instance.

Understanding the Plugin Architecture in v7

In Wavesurfer.js v7, plugins are modular classes that extend the core BasePlugin class. Unlike older versions, v7 provides a more decoupled design where plugins must handle their own initialization, event listening, and DOM cleanup through standard lifecycle methods.

The Boilerplate Plugin Class

To create a plugin, extend BasePlugin and implement the static create factory method along with onInit and destroy.

import BasePlugin from 'wavesurfer.js/dist/base-plugin.js';

// Define default options
const defaultOptions = {
  customProperty: true,
};

export class MyCustomPlugin extends BasePlugin {
  /**
   * Static factory method to instantiate the plugin.
   * This aligns with standard Wavesurfer.js v7 conventions.
   */
  static create(options) {
    return new MyCustomPlugin(options);
  }

  constructor(options) {
    // Merge provided options with defaults and pass to BasePlugin
    super({ ...defaultOptions, ...options });
  }

  /**
   * Called automatically when the plugin is registered with Wavesurfer.
   */
  onInit() {
    if (!this.wavesurfer) {
      throw new Error('Wavesurfer instance not found.');
    }

    // Access the WaveSurfer instance
    const ws = this.wavesurfer;

    // Set up listeners or DOM elements
    this.subscriptions.push(
      ws.on('ready', () => {
        this.handleWaveformReady();
      })
    );
  }

  handleWaveformReady() {
    // Custom feature logic here
    console.log('Waveform is ready inside MyCustomPlugin');
  }

  /**
   * Cleanup method to remove listeners and DOM nodes.
   */
  destroy() {
    // Custom cleanup logic here

    // Call super.destroy() to clean up subscriptions tracked by BasePlugin
    super.destroy();
  }
}

export default MyCustomPlugin;

Core Components Explained

1. The BasePlugin Inheritance

The BasePlugin class provides default storage for options and the this.wavesurfer reference. It also manages an internal array called this.subscriptions, which tracks event listeners so they can be disposed of automatically.

2. The static create() Method

Wavesurfer plugins typically use a static factory method named create(). This allows users to instantiate the plugin cleanly inside the plugins array during Wavesurfer initialization.

3. The onInit() Lifecycle Hook

The onInit method executes as soon as the plugin binds to the Wavesurfer instance. This is where you access this.wavesurfer, query container elements, and bind events.

4. Event Subscriptions

When attaching events via this.wavesurfer.on(), push the returned unsubscribe function into this.subscriptions:

this.subscriptions.push(
  this.wavesurfer.on('play', () => {
    // React to play event
  })
);

5. The destroy() Method

When the Wavesurfer instance is destroyed, it triggers destroy() on all registered plugins. Use this method to remove any injected HTML elements or third-party listeners, then execute super.destroy() to flush all registered event listeners.

Using the Custom Plugin

Register your custom plugin using either the plugins array during initial configuration or the registerPlugin method at runtime.

Method 1: On Initialization

import WaveSurfer from 'wavesurfer.js';
import MyCustomPlugin from './MyCustomPlugin.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio.mp3',
  plugins: [
    MyCustomPlugin.create({
      customProperty: false,
    }),
  ],
});

Method 2: At Runtime

import WaveSurfer from 'wavesurfer.js';
import MyCustomPlugin from './MyCustomPlugin.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  url: '/audio.mp3',
});

const myPlugin = wavesurfer.registerPlugin(
  MyCustomPlugin.create({ customProperty: true })
);
