Styling Wavesurfer.js UI Controls With CSS Variables

This article provides an overview of how CSS variables interact with Wavesurfer.js and its interface components. Because Wavesurfer.js renders audio waveforms primarily on an HTML5 <canvas>, direct styling of the wave itself via CSS requires passing computed values to the library's initialization options. Meanwhile, external DOM elements—including plugin overlays, interactive regions, timeline markers, and playback controls—can be customized and themed directly using CSS custom properties.

Understanding Wavesurfer.js DOM vs. Canvas Architecture

To style Wavesurfer.js controls effectively, it is essential to distinguish between what is rendered on the canvas and what exists as HTML DOM nodes:

  1. Canvas Elements (Waveform and Progress): The main waveform, progress fill, and default playhead cursor are drawn inside an HTML5 <canvas>. The Canvas 2D API does not read CSS stylesheets directly.
  2. DOM Elements (Containers, Plugins, and Player UI): Elements such as the wrapper container, Regions plugin overlays, Hover plugin tooltips, Timeline plugin markers, and custom play/pause/volume controls are standard HTML elements that fully support CSS classes and CSS custom properties (variables).

Passing CSS Variables to Wavesurfer.js Waveform Properties

To use CSS variables for the waveform itself, define the custom properties on your audio player container in CSS, then read their values in JavaScript using getComputedStyle() during initialization:

:root {
  --wavesurfer-wave-color: #cbd5e1;
  --wavesurfer-progress-color: #3b82f6;
  --wavesurfer-cursor-color: #1d4ed8;
  --wavesurfer-cursor-width: 2px;
  --wavesurfer-bar-width: 2px;
  --wavesurfer-bar-gap: 1px;
  --wavesurfer-bar-radius: 2px;
}

.waveform-container {
  width: 100%;
  height: 128px;
  background-color: var(--wavesurfer-bg, #ffffff);
}
const container = document.querySelector('.waveform-container');
const styles = getComputedStyle(container);

const wavesurfer = WaveSurfer.create({
  container: container,
  waveColor: styles.getPropertyValue('--wavesurfer-wave-color').trim(),
  progressColor: styles.getPropertyValue('--wavesurfer-progress-color').trim(),
  cursorColor: styles.getPropertyValue('--wavesurfer-cursor-color').trim(),
  cursorWidth: parseInt(styles.getPropertyValue('--wavesurfer-cursor-width')) || 1,
  barWidth: parseInt(styles.getPropertyValue('--wavesurfer-bar-width')) || undefined,
  barGap: parseInt(styles.getPropertyValue('--wavesurfer-bar-gap')) || undefined,
  barRadius: parseInt(styles.getPropertyValue('--wavesurfer-bar-radius')) || 0,
});

Styling Built-in Plugins With CSS Custom Properties

Wavesurfer.js plugins generate standard HTML elements that can be styled directly in stylesheets using custom CSS variables.

1. Regions Plugin

The Regions plugin inserts elements with the class .wavesurfer-region. You can define custom variables to override colors, opacity, and resize handle styles:

:root {
  --region-bg: rgba(59, 130, 246, 0.2);
  --region-border: #2563eb;
  --region-handle-color: #1d4ed8;
}

.wavesurfer-region {
  background-color: var(--region-bg) !important;
  border-left: 2px solid var(--region-border);
  border-right: 2px solid var(--region-border);
}

.wavesurfer-region [data-resize="left"],
.wavesurfer-region [data-resize="right"] {
  background-color: var(--region-handle-color);
  width: 4px;
}

2. Hover Plugin

The Hover plugin displays a vertical guide line and timestamp tooltip on pointer hover:

:root {
  --hover-line-color: rgba(0, 0, 0, 0.4);
  --hover-label-bg: #1f2937;
  --hover-label-color: #f9fafb;
}

/* Hover line overlay */
.wavesurfer-hover {
  border-left: 1px dashed var(--hover-line-color) !important;
}

/* Hover time label */
.wavesurfer-hover-label {
  background-color: var(--hover-label-bg);
  color: var(--hover-label-color);
  font-size: 0.75rem;
  padding: 2px 6px;
  border-radius: 4px;
}

3. Timeline Plugin

The Timeline plugin creates DOM elements for primary and secondary tick notches and text labels:

:root {
  --timeline-border-color: #e5e7eb;
  --timeline-text-color: #6b7280;
  --timeline-font-size: 10px;
}

.wavesurfer-timeline {
  border-top: 1px solid var(--timeline-border-color);
  color: var(--timeline-text-color);
  font-size: var(--timeline-font-size);
}

CSS Variables for Default Player Controls

Because Wavesurfer.js does not render an embedded HTML5 transport toolbar by default, player controls (such as play/pause buttons, time displays, and volume sliders) are constructed in user HTML. A recommended standard architecture uses the following custom properties:

:root {
  --player-btn-size: 40px;
  --player-btn-bg: #3b82f6;
  --player-btn-hover: #2563eb;
  --player-btn-color: #ffffff;
  --player-slider-track: #e2e8f0;
  --player-slider-thumb: #3b82f6;
}

.player-controls {
  display: flex;
  align-items: center;
  gap: 12px;
}

.player-btn {
  width: var(--player-btn-size);
  height: var(--player-btn-size);
  background-color: var(--player-btn-bg);
  color: var(--player-btn-color);
  border: none;
  border-radius: 50%;
  cursor: pointer;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  transition: background-color 0.2s ease;
}

.player-btn:hover {
  background-color: var(--player-btn-hover);
}

.volume-slider {
  accent-color: var(--player-slider-thumb);
  background-color: var(--player-slider-track);
}

Dynamic Theme Switching

When using CSS variables to theme the entire player interface, dynamic themes (such as dark mode) can be applied by updating CSS classes on a parent element and calling wavesurfer.setOptions() with the refreshed computed values:

function applyTheme() {
  const styles = getComputedStyle(container);
  wavesurfer.setOptions({
    waveColor: styles.getPropertyValue('--wavesurfer-wave-color').trim(),
    progressColor: styles.getPropertyValue('--wavesurfer-progress-color').trim(),
    cursorColor: styles.getPropertyValue('--wavesurfer-cursor-color').trim(),
  });
}

// Example: Trigger update after toggling a dark theme class
document.body.classList.toggle('dark-theme');
applyTheme();
