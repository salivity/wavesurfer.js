Set Cursor Border Color in Wavesurfer.js

This guide explains how to customize the cursor line and border color in Wavesurfer.js. You will learn which configuration parameters define the cursor's appearance during playback and hover states, along with practical code examples for standard and plugin-based implementations.

The cursorColor Option

In Wavesurfer.js, the primary option used to set the cursor's color is cursorColor.

Because Wavesurfer.js historically renders the playback cursor line as an HTML element styled using CSS borders (typically border-right), setting the cursorColor parameter directly controls this border color.

Basic Usage

You pass cursorColor into the options object when initializing the WaveSurfer instance:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  cursorColor: '#FF5733', // Sets the cursor line / border color
  cursorWidth: 2,          // Specifies the thickness of the cursor line in pixels
});

Options Overview

  • cursorColor (string, default: #333): Accepts any valid CSS color string (hex, RGB, HSL, or named colors). This defines the color of the vertical playback marker.
  • cursorWidth (number, default: 1): Controls the width of the cursor marker in pixels, corresponding to the border thickness.

Cursor Plugin and Hover Styling

If you are using the Cursor Plugin or Hover Plugin to display an interactive indicator that follows the mouse pointer, the styling is handled slightly differently depending on your version.

Using the Cursor Plugin

When using the dedicated CursorPlugin, you configure the cursor color directly inside the plugin configuration:

import WaveSurfer from 'wavesurfer.js';
import CursorPlugin from 'wavesurfer.js/dist/plugins/cursor.esm.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#ddd',
  progressColor: '#555',
  plugins: [
    CursorPlugin.create({
      showTime: true,
      opacity: 1,
      customStyle: {
        'border-right': '2px solid #00AAFF', // Explicitly overrides the border styling
      },
    }),
  ],
});

Using the customStyle property allows you to explicitly assign standard CSS border properties such as border-left, border-right, or border-color if you require complex styling like dashed lines or dual-colored borders.

Styling via CSS

You can also target the cursor element directly through CSS stylesheets. Wavesurfer generates a cursor element inside the waveform container:

/* Target the built-in cursor element */
wave cursor {
  border-right-color: #00ff00 !important;
}

/* Target the cursor plugin element */
.wavesurfer-cursor {
  border-right: 2px dashed #ff0000 !important;
}

Applying CSS directly provides full control over border-radius, outline styles, and border effects without modifying your JavaScript configuration.
