Map X-Coordinates to Audio Time in Wavesurfer.js

Mapping pixel x-coordinates to audio timestamps in Wavesurfer.js requires calculating the relative horizontal position of a click or mouse event within the waveform container and scaling that ratio against the total duration of the audio. This guide covers the mathematical formula, modern Wavesurfer.js v7 implementations for static containers, and how to account for scroll offsets when zooming is enabled.

The Core Formula

The relationship between the visual width of a waveform and the audio duration is linear. The basic calculation is:

Timestamp (seconds) = (X-Offset / Total Waveform Width) * Audio Duration

Basic Implementation: Non-Scrollable Waveform

When the waveform fits entirely inside its parent container without horizontal scrolling, use getBoundingClientRect() to determine the click position relative to the left edge of the waveform element.

const waveformContainer = document.querySelector('#waveform');

waveformContainer.addEventListener('click', (event) => {
  const rect = waveformContainer.getBoundingClientRect();
  const duration = wavesurfer.getDuration();

  // Calculate the click's X position relative to the container
  const x = event.clientX - rect.left;

  // Calculate the ratio across the container (clamped between 0 and 1)
  const progress = Math.max(0, Math.min(x / rect.width, 1));

  // Derive the timestamp in seconds
  const timestamp = progress * duration;

  console.log(`Clicked timestamp: ${timestamp.toFixed(2)}s`);
});

Advanced Implementation: Zoomed and Scrollable Waveforms

When horizontal zoom (wavesurfer.zoom(pxPerSec)) is applied, the waveform overflows the visible container, creating a scrollable area. In this scenario, client-space coordinates must account for the wrapper's scrollLeft property, and the width must reference the total scrollable content (scrollWidth), not just the visible viewport.

// Wavesurfer v7 stores the rendering wrapper internally
const wrapper = wavesurfer.getWrapper();

wrapper.addEventListener('click', (event) => {
  const rect = wrapper.getBoundingClientRect();
  const duration = wavesurfer.getDuration();

  // Add scrollLeft to account for horizontal scroll position
  const x = (event.clientX - rect.left) + wrapper.scrollLeft;
  const totalWidth = wrapper.scrollWidth;

  // Calculate normalized position
  const progress = Math.max(0, Math.min(x / totalWidth, 1));
  const timestamp = progress * duration;

  console.log(`Timestamp with scroll: ${timestamp.toFixed(2)}s`);
});

Alternative: Using Pixels-Per-Second

If you configure your waveform using the minPxPerSec parameter during initialization or dynamically via wavesurfer.zoom(pxPerSec), the mapping becomes direct without needing the total duration:

const pxPerSec = wavesurfer.options.minPxPerSec;

wrapper.addEventListener('click', (event) => {
  const rect = wrapper.getBoundingClientRect();
  const absoluteX = (event.clientX - rect.left) + wrapper.scrollLeft;

  // Direct calculation based on pixel density
  const timestamp = absoluteX / pxPerSec;

  // Clamp to valid audio bounds
  const clampedTimestamp = Math.max(0, Math.min(timestamp, wavesurfer.getDuration()));

  console.log(`Timestamp: ${clampedTimestamp.toFixed(2)}s`);
});

Key Considerations

  • Ensure Audio Is Decoded: wavesurfer.getDuration() returns 0 or NaN until the ready or decode event has fired. Always verify audio is loaded before performing calculations.
  • Bounding Clamps: Always use Math.max(0, Math.min(time, duration)) to prevent negative timestamps or values exceeding the audio track length caused by padding or click events slightly outside the bounds.
