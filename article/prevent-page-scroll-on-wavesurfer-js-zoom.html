Prevent Page Scroll on Wavesurfer.js Zoom

When implementing interactive waveform zooming with Wavesurfer.js via the mouse wheel, the browser will simultaneously scroll the entire web page by default. This article explains how to target the wheel event listener and call preventDefault()—using a non-passive listener configuration—to suppress the default window scroll behavior while keeping audio zooming smooth and responsive.

The Required Event Listener: wheel

The standard event listener used to stop the window or parent container from scrolling during a Wavesurfer.js zoom operation is the wheel event.

Because modern browsers optimize scrolling performance by making touch and wheel listeners passive by default, simply calling e.preventDefault() inside a standard listener will often fail or trigger a browser console warning. To ensure the browser cancels the native scroll, you must explicitly set { passive: false } in the listener options.

Implementation

To handle zooming via mouse wheel on the waveform container while preventing native scrolling, attach the wheel listener to the waveform's DOM element:

const container = document.querySelector('#waveform');

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: container,
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path-to-audio.mp3',
});

let currentZoom = 0;
const minZoom = 0;
const maxZoom = 200;

// Listen for the wheel event on the container
container.addEventListener(
  'wheel',
  (event) => {
    // Stop the browser from scrolling the web page
    event.preventDefault();

    // Determine scroll direction
    if (event.deltaY < 0) {
      // Zoom in
      currentZoom = Math.min(currentZoom + 10, maxZoom);
    } else {
      // Zoom out
      currentZoom = Math.max(currentZoom - 10, minZoom);
    }

    // Apply the zoom level to Wavesurfer
    wavesurfer.zoom(currentZoom);
  },
  { passive: false } // Required to allow preventDefault()
);

Why { passive: false } is Necessary

Modern browser engines run scrolling on a separate compositor thread to eliminate jank. When an event listener is marked as passive, the browser assumes it will never cancel the event, allowing immediate scrolling. Explicitly defining { passive: false } forces the browser to wait for the JavaScript execution to complete, thereby honoring the event.preventDefault() instruction and freezing the viewport in place while adjusting the waveform scale.
