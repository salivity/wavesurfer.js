How to Loop a Region in Wavesurfer.js

Looping audio within a specific segment in Wavesurfer.js is achieved by combining the core library with its official Regions plugin. By creating a designated region on the waveform and listening to boundary playback events, you can automatically seek playback back to the region's start time whenever the playhead exits the specified end point.

1. Set Up Wavesurfer and the Regions Plugin

First, import and initialize the core WaveSurfer library alongside the RegionsPlugin. The Regions plugin provides the methods needed to create, style, and monitor specific audio slices.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d9dcff',
  progressColor: '#4353ff',
  url: '/path-to-your-audio.mp3',
});

// Initialize the Regions plugin
const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

2. Define the Region

Once your audio is ready, create the region by defining start and end times (in seconds). Enable resizing and dragging if you want users to adjust the loop interactively.

wavesurfer.on('ready', () => {
  const loopRegion = wsRegions.addRegion({
    start: 5,
    end: 12,
    color: 'rgba(0, 255, 0, 0.2)',
    drag: true,
    resize: true,
  });

  enableLooping(loopRegion);
});

3. Implement the Loop Logic

To loop continuously inside the region, use the region-out event provided by the Regions plugin. When the playhead crosses the region's boundary, command the region to play from the beginning.

function enableLooping(region) {
  let isLooping = true;

  // Listen for when playback leaves the region
  wsRegions.on('region-out', (reg) => {
    if (reg === region && isLooping) {
      reg.play();
    }
  });

  // Start playback from the region's start point
  region.play();
}

Alternative: Using the timeupdate Event

If you prefer higher precision or need custom controls without relying on region-out, use the core timeupdate event to verify the current playback timestamp manually:

wavesurfer.on('timeupdate', (currentTime) => {
  if (currentTime >= region.end) {
    wavesurfer.setTime(region.start);
    wavesurfer.play();
  }
});

Using region.play() via the region-out listener remains the most standard and efficient method for continuous region playback in Wavesurfer.js.
