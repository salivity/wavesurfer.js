Change Wavesurfer.js Cursor Line to Dashed

Customizing the playhead cursor in Wavesurfer.js allows you to alter the default solid line into a dashed visual marker for a more tailored audio player design. Although the library's initialization options provide properties for cursor width and color, they do not include a dedicated line-style parameter. You can easily achieve a dashed cursor line by directly modifying the cursor DOM element via JavaScript after initialization or by applying targeted CSS styles to the player's markup.

Method 1: Modify the Cursor Element via JavaScript (Wavesurfer.js v7)

In modern versions of Wavesurfer.js (v7 and newer), the cursor element is rendered internally and managed by the renderer. You can target this element directly using the wavesurfer.renderer.cursor reference once the instance is ready.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#A8DBA8',
  progressColor: '#3B8686',
  cursorColor: '#FF5722',
  cursorWidth: 2, // Ensure width is at least 1px or 2px so dashes are visible
});

wavesurfer.on('ready', () => {
  // Access the rendered cursor element and apply the dashed style
  if (wavesurfer.renderer && wavesurfer.renderer.cursor) {
    wavesurfer.renderer.cursor.style.borderRightStyle = 'dashed';
  }
});

Because Wavesurfer implements the cursor line using the element's border-right CSS property, setting borderRightStyle to 'dashed' immediately converts the solid line into dashes.

Method 2: Styling the Cursor Element via Shadow DOM

Wavesurfer.js v7 encapsulates its internal HTML inside a Shadow Root attached to a wrapper element. If you prefer to set the style dynamically through DOM queries, locate the Shadow Root inside your container and update the cursor element directly:

wavesurfer.on('ready', () => {
  const container = document.querySelector('#waveform');
  const shadowRoot = container.querySelector('div')?.shadowRoot;
  
  if (shadowRoot) {
    // Locate the cursor element inside the shadow root
    const cursorEl = shadowRoot.querySelector('div[style*="border-right"]');
    if (cursorEl) {
      cursorEl.style.borderRightStyle = 'dashed';
    }
  }
});

Method 3: CSS Override for Wavesurfer.js v6 and Earlier

If your project runs on Wavesurfer.js v6 or older, the player structure does not rely on Shadow DOM encapsulation. You can override the playhead line style globally using standard CSS:

/* Target the playhead line in Wavesurfer.js v6 */
#waveform wave > wave {
  border-right-style: dashed !important;
}

Changing the Hover Cursor Line to Dashed

If you are using the official Cursor/Hover plugin to display a secondary line where the user points their mouse, you can configure dashed styles directly within the plugin's customStyle options:

import WaveSurfer from 'wavesurfer.js';
import Hover from 'wavesurfer.js/dist/plugins/hover.esm.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#ddd',
  progressColor: '#555',
  plugins: [
    Hover.create({
      lineColor: '#ff0000',
      lineWidth: '2px',
      labelBackground: '#555',
      labelColor: '#fff',
      labelSize: '11px',
    }),
  ],
});

wavesurfer.on('ready', () => {
  // Find hover plugin cursor line and change to dashed
  const container = document.querySelector('#waveform');
  const hoverLine = container.querySelector('.spec-hover-line');
  if (hoverLine) {
    hoverLine.style.borderRightStyle = 'dashed';
  }
});
