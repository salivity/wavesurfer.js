Extract Audio Peaks for Wavesurfer.js Using Python

Pre-rendering audio waveform data on the server drastically reduces client-side decoding overhead and accelerates page load times when working with Wavesurfer.js. This article explains how to write Python scripts that parse audio files, split them into discrete channels, calculate downsampled peak arrays, and export the resulting channel data into JSON formats tailored directly for the Wavesurfer.js peaks parameter.

Understanding the Wavesurfer.js Data Format

Wavesurfer.js accepts precomputed peaks via its peaks configuration option. For multi-channel audio, it expects an array of arrays containing floating-point numbers typically normalized between -1.0 and 1.0:

[
  [0.02, -0.05, 0.45, -0.62, ...], // Channel 0 peaks
  [0.01, -0.04, 0.40, -0.58, ...]  // Channel 1 peaks
]

To achieve this in Python, the audio must be decoded into raw NumPy arrays, sliced into uniform frames based on the desired sample count, and reduced to minimum and maximum amplitude pairs or absolute maximums.

Method 1: Extraction Using soundfile and numpy

The combination of soundfile and numpy is fast, lightweight, and preserves distinct audio channels without unnecessary resampling.

Installation

pip install soundfile numpy

Python Script

import json
import numpy as np
import soundfile as sf

def extract_peaks_soundfile(audio_path, output_json, target_length=1000):
    """
    Extracts min/max peak arrays for each channel of an audio file.
    
    :param audio_path: Path to the audio file.
    :param output_json: Path to save the extracted peaks.
    :param target_length: Number of peak points per channel.
    """
    # Read audio data: data shape will be (samples, channels) or (samples,)
    data, sample_rate = sf.read(audio_path, dtype='float32')

    # Handle mono audio by expanding dimensions
    if data.ndim == 1:
        data = data[:, np.newaxis]

    total_samples, channels = data.shape
    samples_per_pixel = max(1, total_samples // target_length)

    channel_peaks = []

    for c in range(channels):
        channel_data = data[:, c]
        
        # Truncate to make chunking exact
        usable_samples = (total_samples // samples_per_pixel) * samples_per_pixel
        truncated_data = channel_data[:usable_samples]
        
        # Reshape into chunks
        chunks = truncated_data.reshape(-1, samples_per_pixel)
        
        # Calculate min and max for alternating peak visualization
        mins = chunks.min(axis=1)
        maxs = chunks.max(axis=1)
        
        # Interleave mins and maxs to create high-resolution waveform data
        peaks = np.empty((mins.size + maxs.size,), dtype=np.float32)
        peaks[0::2] = maxs
        peaks[1::2] = mins
        
        # Convert to list and round for smaller payload size
        channel_peaks.append(np.round(peaks, 4).tolist())

    # Write output structure
    output_data = {
        "sample_rate": sample_rate,
        "samples_per_pixel": samples_per_pixel,
        "length": target_length * 2,
        "data": channel_peaks
    }

    with open(output_json, 'w') as f:
        json.dump(output_data, f)

if __name__ == "__main__":
    extract_peaks_soundfile("input.wav", "peaks.json", target_length=1200)

Method 2: Extraction Using librosa for Broad Format Support

librosa relies on audioread and soundfile under the hood, making it capable of handling various formats (MP3, WAV, FLAC, OGG). By default, librosa loads mono audio, so you must explicitly specify mono=False to preserve stereo channels.

Installation

pip install librosa numpy

Python Script

import json
import librosa
import numpy as np

def extract_peaks_librosa(audio_path, output_json, num_peaks=1000):
    """
    Extracts audio channel arrays using librosa.
    """
    # Load audio preserving native sample rate and all channels
    # Librosa returns shape (channels, samples) or (samples,)
    audio, sr = librosa.load(audio_path, sr=None, mono=False)

    if audio.ndim == 1:
        audio = audio[np.newaxis, :]

    channels, total_samples = audio.shape
    step = max(1, total_samples // num_peaks)

    all_channel_peaks = []

    for c in range(channels):
        channel_data = audio[c]
        limit = (total_samples // step) * step
        reshaped = channel_data[:limit].reshape(-1, step)

        # Extract absolute peaks normalized between -1.0 and 1.0
        max_peaks = reshaped.max(axis=1)
        min_peaks = reshaped.min(axis=1)

        # Alternating max and min representation
        combined = np.empty((max_peaks.size * 2,), dtype=np.float32)
        combined[0::2] = max_peaks
        combined[1::2] = min_peaks

        all_channel_peaks.append(np.round(combined, 4).tolist())

    output_payload = {
        "version": 2,
        "channels": channels,
        "sample_rate": sr,
        "data": all_channel_peaks
    }

    with open(output_json, "w") as f:
        json.dump(output_payload, f)

if __name__ == "__main__":
    extract_peaks_librosa("audio.mp3", "peaks.json", num_peaks=1000)

Integrating Output with Wavesurfer.js

Once the JSON file is generated, provide the data directly into your Wavesurfer.js instance. Fetch the JSON payload and pass the extracted array of channel peaks to the initialization options or the load method:

fetch('peaks.json')
  .then(response => response.json())
  .then(peaksData => {
    const wavesurfer = WaveSurfer.create({
      container: '#waveform',
      waveColor: '#4F46E5',
      progressColor: '#818CF8',
      splitChannels: true, // Render separate canvases if stereo
      backend: 'MediaElement'
    });

    // Pass the multi-channel array to the load method
    wavesurfer.load('audio.mp3', peaksData.data);
  });

Using these extraction routines ensures that the browser bypasses AudioContext decoding entirely, rendering the waveform instantaneously even on long audio files.
