Extract Average Audio Volume in Wavesurfer.js

Extracting average volume levels across audio channels in Wavesurfer.js involves accessing the decoded audio buffer, iterating through the raw PCM samples of each channel, and computing the Root Mean Square (RMS). This guide explains how to retrieve the underlying AudioBuffer using Wavesurfer.js v7 and calculate both a normalized average volume and a decibel level (dBFS) across multi-channel audio.

1. Access the AudioBuffer

Wavesurfer.js decodes audio files using the Web Audio API. Once an audio file is decoded, you can access the underlying AudioBuffer instance using the getDecodedData() method. To ensure the audio is ready, attach this logic to the decode or ready event listener.

wavesurfer.on('decode', () => {
  const audioBuffer = wavesurfer.getDecodedData();
  if (audioBuffer) {
    const averageVolume = calculateAverageVolume(audioBuffer);
    console.log(`Average Volume (RMS): ${averageVolume.rms}`);
    console.log(`Average Volume (dB): ${averageVolume.decibels} dB`);
  }
});

2. Calculate Root Mean Square (RMS) Across Channels

Volume in digital audio is best represented by Root Mean Square (RMS) rather than a simple arithmetic mean, as audio waveforms oscillate between positive and negative values.

To calculate the overall average volume across all channels:

  1. Loop through each channel using audioBuffer.numberOfChannels.
  2. Extract the Float32Array containing the channel samples via audioBuffer.getChannelData(channelIndex).
  3. Square each sample, sum them together, divide by the total number of samples across all channels, and take the square root.
function calculateAverageVolume(audioBuffer) {
  const numberOfChannels = audioBuffer.numberOfChannels;
  let totalSquaredSum = 0;
  let totalSampleCount = 0;

  for (let channel = 0; channel < numberOfChannels; channel++) {
    const channelData = audioBuffer.getChannelData(channel);
    const length = channelData.length;
    let channelSquaredSum = 0;

    for (let i = 0; i < length; i++) {
      channelSquaredSum += channelData[i] * channelData[i];
    }

    totalSquaredSum += channelSquaredSum;
    totalSampleCount += length;
  }

  // Calculate overall RMS
  const rms = Math.sqrt(totalSquaredSum / totalSampleCount);

  // Convert RMS to Decibels Full Scale (dBFS)
  // 20 * log10(rms). When silent, return -Infinity.
  const decibels = rms > 0 ? 20 * Math.log10(rms) : -Infinity;

  return {
    rms: rms,            // Value between 0.0 (silent) and 1.0 (peak)
    decibels: decibels   // Value typically between -Infinity and 0 dBFS
  };
}

3. Calculating Channel-Specific Averages

If you need the average level separated per channel (e.g., Left and Right in stereo audio), perform the RMS calculation per channel array without combining the totals:

function getPerChannelAverages(audioBuffer) {
  const results = [];

  for (let channel = 0; channel < audioBuffer.numberOfChannels; channel++) {
    const data = audioBuffer.getChannelData(channel);
    let sum = 0;

    for (let i = 0; i < data.length; i++) {
      sum += data[i] * data[i];
    }

    const rms = Math.sqrt(sum / data.length);
    const db = rms > 0 ? 20 * Math.log10(rms) : -Infinity;

    results.push({
      channel: channel,
      rms: rms,
      decibels: db
    });
  }

  return results;
}

4. Implementation Considerations

  • Performance: Processing very long audio files (e.g., audiobooks or hour-long podcasts) in a single loop on the main thread may cause a brief UI freeze. For large files, consider subsampling the data (evaluating every nth sample) or running the calculation inside a Web Worker.
  • Peak vs. RMS: Peak measurement captures the highest single sample point in the file, whereas RMS measures continuous perceived loudness over time. Always use RMS when calculating average perceived volume.
