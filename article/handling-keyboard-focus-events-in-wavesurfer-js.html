Handling Keyboard Focus Events in Wavesurfer.js

This article explains how to detect keyboard focus and trigger actions within Wavesurfer.js elements. Because Wavesurfer.js does not provide a custom internal event specifically named for keyboard focus, triggering actions requires capturing native DOM focus (or focusin) and keydown events on the waveform container or its internal wrapper element. Below, you will learn how to make your waveform focusable, capture focus events, and bind keyboard shortcuts for playback and navigation.

Making Wavesurfer.js Keyboard-Focusable

By default, the HTML elements generated by Wavesurfer.js (such as <canvas> or <div> wrapper nodes) are not focusable via the keyboard unless explicitly configured. To allow users to navigate to the waveform using the Tab key, you must assign a tabindex attribute to the container element or the generated wrapper.

You can set the tabindex on your host container directly in the HTML or dynamically via JavaScript:

const container = document.querySelector('#waveform');
container.setAttribute('tabindex', '0');

Alternatively, you can apply it to the internal wrapper generated by Wavesurfer using the getWrapper() method:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
});

wavesurfer.on('ready', () => {
  const wrapper = wavesurfer.getWrapper();
  wrapper.setAttribute('tabindex', '0');
});

Listening for the Focus Event

Once the element is focusable, the standard DOM focus or focusin event enables you to detect when a user highlights the waveform using keyboard navigation. You can listen directly on the wrapper element:

wavesurfer.on('ready', () => {
  const wrapper = wavesurfer.getWrapper();

  wrapper.addEventListener('focus', (event) => {
    // Actions triggered when the waveform receives keyboard focus
    wrapper.style.outline = '2px solid #4F46E5';
    console.log('Waveform is focused via keyboard');
  });

  wrapper.addEventListener('blur', (event) => {
    // Clean up or remove active indicators
    wrapper.style.outline = 'none';
  });
});

Triggering Actions via Keyboard Controls

After capturing focus, listening for the keydown event on the same focused element allows you to execute specific playback controls without interfering with the rest of the web page.

wavesurfer.on('ready', () => {
  const wrapper = wavesurfer.getWrapper();

  wrapper.addEventListener('keydown', (event) => {
    switch (event.key) {
      case ' ':
      case 'Spacebar':
        event.preventDefault();
        wavesurfer.playPause();
        break;

      case 'ArrowLeft':
        event.preventDefault();
        wavesurfer.skip(-5);
        break;

      case 'ArrowRight':
        event.preventDefault();
        wavesurfer.skip(5);
        break;
    }
  });
});

By pairing tabindex="0" with the native DOM focus and keydown events on the Wavesurfer wrapper element, you ensure full keyboard accessibility and seamless control over audio actions.
