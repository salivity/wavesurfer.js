Configure Wavesurfer.js Silence Detection Threshold

This article explains how to configure and implement silence detection thresholds to automatically generate audio regions in Wavesurfer.js. By analyzing decoded audio buffer data against a predefined amplitude threshold and minimum duration parameters, developers can detect active audio segments, filter out background noise, and automatically map regions across the timeline using the Wavesurfer.js Regions plugin.

Understanding Silence Detection in Wavesurfer.js

Wavesurfer.js does not include an automatic silence detection algorithm in its core library out of the box, but it exposes the underlying Web Audio API AudioBuffer once a file is decoded. To generate regions based on sound activity, you extract the raw channel data, determine an amplitude threshold, and programmatically feed the calculated boundaries into the RegionsPlugin.

The silence detection process relies on three primary variables:

  • Threshold: The linear amplitude limit (ranging from 0.0 to 1.0) below which audio samples are considered silent.
  • Minimum Silence Duration: The minimum duration (in seconds) of continuous silence required to trigger the end of an active sound region.
  • Minimum Region Duration: The minimum length (in seconds) required for an active sound segment to be registered as a valid region, filtering out brief transient clicks or noise.

Step-by-Step Implementation

1. Initialize Wavesurfer and the Regions Plugin

First, set up your Wavesurfer instance with the Regions plugin imported and registered.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#A8DBA8',
  progressColor: '#3B8686',
});

const wsRegions = ws.registerPlugin(RegionsPlugin.create());
ws.load('/path/to/audio.mp3');

2. Extract Channel Data and Detect Regions

Listen for the ready event to ensure the audio buffer is completely decoded. Once ready, access the PCM data using ws.getDecodedData().

ws.on('ready', () => {
  const decodedData = ws.getDecodedData();
  if (!decodedData) return;

  // Configuration parameters
  const threshold = 0.02; // Linear amplitude threshold (e.g., ~ -34 dB)
  const minSilenceDuration = 0.4; // Seconds of silence required to split
  const minRegionDuration = 0.2; // Ignore audio bursts shorter than this

  const detectedRegions = extractAudioRegions(
    decodedData,
    threshold,
    minSilenceDuration,
    minRegionDuration
  );

  // Add the detected regions to the waveform
  detectedRegions.forEach((region) => {
    wsRegions.addRegion({
      start: region.start,
      end: region.end,
      color: 'rgba(0, 123, 255, 0.2)',
    });
  });
});

3. Write the Detection Function

The detection algorithm iterates through the channel data to identify transitions between silent and non-silent states.

function extractAudioRegions(audioBuffer, threshold, minSilenceDuration, minRegionDuration) {
  const channelData = audioBuffer.getChannelData(0); // Primary channel
  const sampleRate = audioBuffer.sampleRate;
  
  const minSilenceSamples = minSilenceDuration * sampleRate;
  const minRegionSamples = minRegionDuration * sampleRate;
  
  const regions = [];
  let isSound = false;
  let regionStart = 0;
  let silenceCounter = 0;

  for (let i = 0; i < channelData.length; i++) {
    const amplitude = Math.abs(channelData[i]);

    if (amplitude >= threshold) {
      if (!isSound) {
        isSound = true;
        regionStart = i;
      }
      silenceCounter = 0;
    } else {
      if (isSound) {
        silenceCounter++;
        if (silenceCounter >= minSilenceSamples) {
          const regionEnd = i - silenceCounter;
          if (regionEnd - regionStart >= minRegionSamples) {
            regions.push({
              start: regionStart / sampleRate,
              end: regionEnd / sampleRate,
            });
          }
          isSound = false;
          silenceCounter = 0;
        }
      }
    }
  }

  // Handle a trailing region that reaches the end of the audio
  if (isSound) {
    const regionEnd = channelData.length;
    if (regionEnd - regionStart >= minRegionSamples) {
      regions.push({
        start: regionStart / sampleRate,
        end: regionEnd / sampleRate,
      });
    }
  }

  return regions;
}

Calibrating the Threshold

Converting decibels (dB) to linear amplitude helps set intuitive configuration controls for users:

\[\text{Amplitude} = 10^{\frac{\text{dB}}{20}}\]

  • Clean Voice Recording: Use a threshold between -40 dB (0.01) and -30 dB (0.0316).
  • Noisy Audio: Increase the threshold to -26 dB (0.05) or higher to prevent ambient room noise from registering as active speech.
  • Fine-Tuning: If words are getting cut off prematurely, increase the minSilenceDuration to bridge small natural pauses between words. If regions encompass too much dead air, lower the minSilenceDuration and raise the linear threshold.
