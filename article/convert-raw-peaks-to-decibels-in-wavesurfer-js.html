Convert Raw Peaks to Decibels in Wavesurfer.js

Converting linear audio peak amplitudes into a logarithmic decibel (dB) scale is essential for accurate audio visualization, dynamic metering, and realistic waveform rendering in Wavesurfer.js. This article explains the standard mathematical formula used to transform raw floating-point amplitude peaks into decibels relative to full scale (dBFS), addresses edge cases such as digital silence, and provides a direct JavaScript implementation for processing Wavesurfer.js peak data.

The Decibel Conversion Formula

Audio samples in Web Audio API and Wavesurfer.js are represented as linear amplitudes normalized between -1.0 and 1.0. The human auditory system perceives loudness logarithmically rather than linearly. To convert a linear peak amplitude to decibels, use the 20-log rule:

\[\text{dB} = 20 \times \log_{10}(\text{amplitude})\]

Where:

  • \(\text{amplitude}\) is the absolute value of the raw audio peak (\(|x|\)), ranging from 0.0 (silence) to 1.0 (0 dBFS, peak digital ceiling).
  • \(\log_{10}\) is the base-10 logarithm.
  • \(20\) is the multiplier used for field quantities (sound pressure or voltage/sample amplitude).

Handling Complete Silence

The mathematical limit of \(\log_{10}(0)\) approaches negative infinity (\(-\infty\text{ dB}\)). In digital signal processing and browser-based rendering, feeding 0 directly into Math.log10() returns -Infinity, which breaks UI rendering calculations.

To prevent errors, establish a noise floor (typically between -60 dB and -100 dB). Any absolute peak value below a microscopic threshold (such as 1e-5) should be clamped directly to this minimum decibel level.

JavaScript Implementation for Wavesurfer.js

When extracting peaks via Wavesurfer.js (using decoded audio buffer data or exported waveform peaks), map each value through the conversion function:

function peakToDecibels(peak, minDb = -60) {
  const amplitude = Math.abs(peak);
  
  // Prevent Math.log10(0) returning -Infinity
  if (amplitude <= 0) {
    return minDb;
  }

  const db = 20 * Math.log10(amplitude);
  
  // Clamp to defined dynamic floor
  return Math.max(db, minDb);
}

Normalizing Decibels for Waveform Heights

If you are customizing peak heights in Wavesurfer.js or drawing custom canvas bars, you must map the decibel value back to a normalized UI range of 0.0 to 1.0:

function getDecibelHeightRatio(peak, minDb = -60, maxDb = 0) {
  const db = peakToDecibels(peak, minDb);
  
  // Scale dB linearly between 0 (silence) and 1 (full scale)
  return (db - minDb) / (maxDb - minDb);
}

Using this logarithmic transformation ensures that subtle background sounds remain visible while loud audio transients do not disproportionately dominate the visual display.
