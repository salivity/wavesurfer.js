Minimum Pixels Per Second in Wavesurfer.js

This article explains how to control horizontal scaling and zoom levels in Wavesurfer.js using the minPxPerSec parameter. You will learn what this configuration does, how to declare it during instance initialization, and how to update it dynamically at runtime using the built-in zoom API.

In Wavesurfer.js, the parameter that specifies the minimum pixels per second when rendering or zooming an audio waveform is minPxPerSec.

This parameter controls the horizontal resolution of the rendered audio track. By defining how many horizontal pixels correspond to one second of audio data, minPxPerSec directly dictates how stretched out or compressed the waveform appears on the screen.

Setting minPxPerSec on Initialization

You can set an initial zoom level when creating the Wavesurfer instance by passing minPxPerSec into the options object:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  minPxPerSec: 50, // Minimum number of pixels per second of audio
});

If the calculated width (duration * minPxPerSec) exceeds the width of the container, the waveform container becomes scrollable, provided your container element allows horizontal scrolling or the default scroll behavior is enabled.

Changing Zoom Dynamically

To zoom in and out interactively after the waveform has loaded—such as in response to a slider or button—call the zoom() method. The zoom method accepts the new minPxPerSec numeric value as its argument:

// Zoom in to 100 pixels per second
wavesurfer.zoom(100);

// Zoom out to 20 pixels per second
wavesurfer.zoom(20);

Behavior and Defaults

  • Default Value: In recent versions of Wavesurfer.js, minPxPerSec defaults to 0. When set to 0, the waveform automatically fits the entire width of its parent container.
  • Higher Values: Increasing minPxPerSec increases horizontal stretching, revealing finer details in the audio waveform and typically enabling horizontal scrolling.
  • Lower Values: Decreasing the value condenses the waveform horizontally, making larger sections of the track visible at once.
