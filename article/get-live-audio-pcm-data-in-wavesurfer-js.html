Get Live Audio PCM Data in Wavesurfer.js

This guide explains how to access live pulse-code modulation (PCM) audio data in Wavesurfer.js. While developers often expect a built-in Wavesurfer.js event to emit raw audio buffers during live capture, Wavesurfer.js relies on the Web Audio API under the hood. You will learn the difference between Wavesurfer's internal events, how the Web Audio audioprocess event provides live PCM data, and how to extract channel buffers when using the Wavesurfer.js Record plugin.

The Role of the audioprocess Event

In the Web Audio API, the audioprocess event—dispatched by a ScriptProcessorNode—is the primary event that provides access to live, raw PCM audio data. The event object (AudioProcessingEvent) exposes an inputBuffer property. Calling inputBuffer.getChannelData(channelIndex) yields a Float32Array containing the raw PCM samples for that frame. Modern implementations may also use an AudioWorkletNode, which posts PCM data to the main thread using standard message events.

Wavesurfer.js Core vs. Live Audio Capture

It is crucial to distinguish between Wavesurfer’s built-in event and the Web Audio event:

  • Wavesurfer Core audioprocess: Wavesurfer.js has its own event named audioprocess. However, this event fires continuously during playback to emit the current playback time in seconds (a number), not the raw audio PCM buffer.
  • Decoded PCM (Pre-recorded Audio): For static audio files, PCM data is not streamed live through an event. Instead, you listen to the ready or decode event and call wavesurfer.getDecodedData().getChannelData(channelNumber) to obtain the complete PCM Float32Array.

Capturing Live PCM with the Record Plugin

To capture live microphone input in modern Wavesurfer.js (v7+), you use the official RecordPlugin. The plugin captures the audio stream via the browser's MediaStreams API.

While the plugin exposes events like record-progress (reporting elapsed recording time) and record-end (delivering the final audio Blob), raw live PCM streaming requires intercepting the stream using a custom Web Audio node.

Here is how you can hook into live PCM data alongside Wavesurfer.js:

import WaveSurfer from 'wavesurfer.js';
import RecordPlugin from 'wavesurfer.js/dist/plugins/record.esm.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
});

// Initialize the Record plugin
const record = wavesurfer.registerPlugin(RecordPlugin.create());

// Get available audio input devices and start recording
record.startMic().then(() => {
  // Access the live MediaStream from the plugin
  const stream = record.stream;
  
  const audioContext = new (window.AudioContext || window.webkitAudioContext)();
  const source = audioContext.createMediaStreamSource(stream);
  
  // Use a ScriptProcessorNode to capture live PCM buffers
  const processor = audioContext.createScriptProcessor(4096, 1, 1);

  processor.onaudioprocess = (event) => {
    // This provides the live PCM Float32Array
    const pcmData = event.inputBuffer.getChannelData(0);
    console.log('Live PCM samples:', pcmData);
  };

  source.connect(processor);
  processor.connect(audioContext.destination);
});

Summary

Wavesurfer.js does not have a native custom event that emits raw live PCM chunks directly. To access live PCM data, tap into the Web Audio API's audioprocess event via a ScriptProcessorNode (or an AudioWorkletNode) connected to the active microphone stream provided by the Wavesurfer Record plugin. For pre-recorded tracks, access the full PCM array using wavesurfer.getDecodedData() after the ready or decode event fires.
