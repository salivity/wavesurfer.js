Configure Wavesurfer.js Bar Height Multiplier

This guide explains how to adjust the visual scale of waveform bars using the bar height multiplier in Wavesurfer.js. By modifying this parameter, you can amplify quiet audio signals to make waveforms more visually striking or compress loud ones to prevent visual clipping. Below, you will find direct instructions on defining the multiplier during initialization and updating it dynamically in modern versions of the library.

Setting the Bar Height During Initialization

In Wavesurfer.js (version 7 and later), the bar height multiplier is controlled via the barHeight property within the configuration object passed to WaveSurfer.create(). This property accepts a positive number representing a multiplier relative to the canvas height:

  • A value of 1 (default) renders bars scaled to fit the full height of the container based on standard normalization.
  • A value greater than 1 (such as 1.5 or 2) amplifies the bar heights, making waveforms appear larger.
  • A value less than 1 (such as 0.5 or 0.8) scales down the peaks, leaving extra vertical padding.
import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
  barHeight: 1.5, // Scales the waveform peaks to 150% of default height
  url: '/path/to/audio.mp3',
});

Changing Bar Height Dynamically

To change the height multiplier after the waveform instance has already been created, use the setOptions method. Wavesurfer.js will automatically redraw the canvas with the updated multiplier.

// Scale up the bar heights on the fly
wavesurfer.setOptions({
  barHeight: 2.0,
});

Handling Visual Clipping

When setting barHeight to a value higher than 1, peaks may extend beyond the top and bottom bounds of the waveform canvas. If your design requires strict boundaries, ensure the parent container handles overflow properly or balance barHeight with the container's explicit height option to prevent visual artifacts.
