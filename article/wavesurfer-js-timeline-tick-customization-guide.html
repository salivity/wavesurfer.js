Wavesurfer.js Timeline Tick Customization Guide

This guide outlines the visual customization options available for timeline tick marks in Wavesurfer.js using the Timeline plugin. It covers the configuration parameters used to adjust tick spacing, height, and color across different versions of the library, as well as direct CSS techniques for styling notches and labels.

Built-in Configuration Properties

Wavesurfer.js exposes specific properties through the TimelinePlugin to alter how ticks are drawn. In modern releases (v7 and newer), the plugin generates DOM elements, whereas older versions (v6 and below) utilized HTML5 Canvas.

1. Tick Interval and Density

You can control the frequency and density of tick marks using time-interval settings:

  • timeInterval: Defines the numeric interval (in seconds) between primary tick marks based on zoom level.
  • primaryLabelInterval: Determines how frequently primary ticks and their corresponding text labels appear along the timeline.
  • secondaryLabelInterval: Controls the step frequency of smaller, intermediary tick marks between major markers.

2. Height and Dimensions

The vertical dimension of tick marks can be manipulated to create visual hierarchy:

  • height: Defines the total height of the timeline container.
  • notchPercentHeight (Legacy v5/v6): A percentage value (e.g., 50 or 90) specifying how tall the secondary ticks are relative to the overall timeline height, leaving primary ticks taller to distinguish major divisions.

3. Color and Typography

Visual identification relies on distinguishing major ticks from minor subdivisions:

  • primaryColor / secondaryColor (Legacy v5/v6): Accepts CSS color values (hex, RGB, or named colors) to set the stroke color for major and minor tick marks independently.
  • primaryFontColor / secondaryFontColor (Legacy v5/v6): Styles the numerical time labels rendered adjacent to primary and secondary notches.
  • fontSize & fontFamily: Adjusts the scale and typeface of labels aligned with the ticks.

CSS-Based Customization (Wavesurfer.js v7+)

In Wavesurfer.js v7+, timeline elements are rendered as standard DOM nodes, allowing full styling via CSS rules or the plugin's style configuration property:

  • Container Styling: The style option in TimelinePlugin.create() accepts a standard CSS style object to modify borders, backgrounds, and positions of the timeline track.
  • Class Targeting: CSS classes injected by the plugin can be targeted directly in your stylesheet to control tick visual properties:
    • Adjusting tick width using border-left-width or width.
    • Changing tick colors using border-color or background-color.
    • Adjusting tick heights using absolute values (px, rem) or percentages (%).
    • Modifying label offset via margin, padding, or absolute positioning rules.

Custom Time Formatting

The formatTimeCallback option allows functional customization of the tick mark text. While it primarily formats the time string (e.g., converting seconds to hh:mm:ss), it visually impacts tick spacing by dictating the width and layout of the rendered text labels over primary tick lines.
