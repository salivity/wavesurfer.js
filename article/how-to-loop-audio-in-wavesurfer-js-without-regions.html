How to Loop Audio in Wavesurfer.js Without Regions

Looping audio in Wavesurfer.js does not require the Regions plugin if your goal is to repeat the entire audio track or loop a specific timeframe programmatically. By leveraging Wavesurfer's access to the underlying HTML5 media element or attaching listeners to its native playback events, you can implement clean, lightweight audio loops directly in your application with minimal code.

Method 1: Using the Native Media Element (Full Track Loop)

Wavesurfer.js renders audio via an internal HTML5 <audio> or <video> element. The simplest way to continuously loop the entire audio file is to set the loop attribute on this underlying element to true.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

// Enable looping once the audio is ready
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  mediaElement.loop = true;
});

Using the browser's native loop attribute provides gapless, performance-optimized playback handled directly by the browser's media engine.

Method 2: Using the finish Event Listener

If you do not want to alter the DOM element directly, you can achieve the same full-track looping behavior by listening to Wavesurfer's built-in finish event and restarting playback.

wavesurfer.on('finish', () => {
  wavesurfer.play();
});

This method is useful if you want to execute custom logic between loops, such as counting iterations, updating UI elements, or adding a short delay before restarting.

Method 3: Programmatic A-B Looping (Time-Based)

To loop a specific section of an audio track without using the Regions plugin, track the playback position using the timeupdate event. When the current time reaches your designated endpoint, reset the position to the start point.

const loopStart = 2.5; // Start time in seconds
const loopEnd = 7.0;   // End time in seconds
let isLooping = true;

wavesurfer.on('timeupdate', (currentTime) => {
  if (isLooping && currentTime >= loopEnd) {
    wavesurfer.setTime(loopStart);
    wavesurfer.play();
  }
});

For Wavesurfer.js v6 and earlier, replace timeupdate with the audioprocess event, and use wavesurfer.setCurrentTime(loopStart) or wavesurfer.seekTo(loopStart / wavesurfer.getDuration()) to reset the playhead.
