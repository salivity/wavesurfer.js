How to Enable Dragging in Wavesurfer.js Regions

This article explains how to enable and configure draggable regions within an audio waveform using the Wavesurfer.js Regions plugin. By utilizing built-in configuration options and event listeners, you can allow users to freely reposition highlighted segments along the audio timeline.

Installing and Initializing the Regions Plugin

In modern versions of Wavesurfer.js (version 7 and above), regions are managed by the standalone RegionsPlugin. Before enabling drag capabilities, you must initialize the plugin and register it with your main Wavesurfer instance:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/path/to/audio.mp3',
});

// Initialize the Regions plugin
const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

Enabling the Drag Option on Regions

Dragging is controlled at the individual region level via the drag property. When creating a region using addRegion(), set the drag property to true to allow users to move the region along the timeline.

wsRegions.addRegion({
  start: 10,
  end: 20,
  content: 'Draggable Region',
  color: 'rgba(0, 255, 0, 0.3)',
  drag: true,    // Enables horizontal dragging
  resize: true,  // Optionally allows resizing the boundaries
});

By default, the drag parameter is set to true if omitted in standard configurations, but explicitly passing drag: true ensures the behavior is active regardless of version defaults or inherited settings. To disable dragging on a specific region, pass drag: false.

Enabling Dragging for User-Created Regions

If you allow users to draw new regions dynamically using click-and-drag interactions, you can ensure that newly created regions remain draggable by attaching to the enableDragSelection method:

wsRegions.enableDragSelection({
  color: 'rgba(255, 0, 0, 0.2)',
  drag: true,
  resize: true,
});

Any region drawn by the user will inherit the drag: true setting upon creation.

Updating Drag Properties Dynamically

You can toggle the draggable state of an existing region at runtime by modifying its properties directly:

// Toggle dragging off
region.setOptions({
  drag: false,
});

// Toggle dragging back on
region.setOptions({
  drag: true,
});

Capturing Drag Events

To detect when a user has moved a region, listen to the region lifecycle events. This is useful for saving updated timestamps to a database:

// Fires continuously while the region is being dragged
wsRegions.on('region-update', (region) => {
  console.log(`Region ${region.id} moving: start ${region.start}, end ${region.end}`);
});

// Fires once dragging has finished and the user releases the mouse
wsRegions.on('region-updated', (region) => {
  console.log(`Region ${region.id} finalized at: start ${region.start}, end ${region.end}`);
});
