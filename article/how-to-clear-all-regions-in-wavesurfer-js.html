How to Clear All Regions in Wavesurfer.js

The Wavesurfer.js Regions plugin allows developers to highlight, loop, and interact with specific segments of an audio waveform. Managing dynamic audio workflows often requires resetting these highlights programmatically. This article explains the exact method used to remove all active regions simultaneously from your waveform display and outlines how to implement it cleanly in your JavaScript application.

The primary method used to remove all regions created by the Wavesurfer.js Regions plugin is clearRegions().

Using clearRegions() in Wavesurfer.js v7

In the modern version of Wavesurfer.js (v7 and newer), the Regions plugin operates as an independent plugin instance. To clear all regions, you must call clearRegions() directly on the plugin instance itself rather than the core WaveSurfer instance:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize the plugin instance
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer with the plugin
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  plugins: [wsRegions],
});

// Remove every region currently rendered
wsRegions.clearRegions();

Using clearRegions() in Wavesurfer.js v6 and Earlier

In older versions of Wavesurfer.js (v6 and below), the regions functionality was typically exposed directly on the primary player instance once the plugin was registered. In these legacy setups, you can execute the command directly on the main instance:

wavesurfer.clearRegions();

Alternatively, if you retained a reference to the plugin instance during creation:

wavesurfer.plugins.regions.clearRegions();

What Happens When clearRegions() Is Executed

Calling this method iterates over every region tracked in the plugin's internal collection, removes the associated DOM overlays and handlers from the waveform, and empties the active region list. It does not alter, unload, or restart the underlying audio track, ensuring a smooth visual reset without interrupting playback.
