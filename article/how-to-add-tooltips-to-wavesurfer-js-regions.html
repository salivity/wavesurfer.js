How to Add Tooltips to Wavesurfer.js Regions

This guide explains how to render dynamic tooltips when users hover over regions in Wavesurfer.js. By leveraging the Wavesurfer.js Regions plugin, you can access region instances and their underlying DOM elements to attach mouse event listeners. With simple DOM manipulation or CSS, you can dynamically display contextual metadata, such as region labels, start times, and durations, whenever a pointer enters or moves across a region.

1. Initialize Wavesurfer and the Regions Plugin

First, set up your Wavesurfer instance alongside the Regions plugin (using Wavesurfer.js v7 syntax):

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio-file.mp3',
});

// Initialize the Regions plugin
const wsRegions = ws.registerPlugin(RegionsPlugin.create());

// Add a sample region once decoded
ws.on('decode', () => {
  wsRegions.addRegion({
    start: 2,
    end: 6,
    content: 'Intro Segment',
    color: 'rgba(0, 123, 255, 0.3)',
  });
});

2. Create the Tooltip Element

Add a generic tooltip element to your HTML or create one dynamically using JavaScript. Style it with absolute positioning so it can track mouse coordinates or position itself above the hovered region.

.wavesurfer-tooltip {
  position: absolute;
  display: none;
  background-color: #1e1e1e;
  color: #ffffff;
  padding: 4px 8px;
  border-radius: 4px;
  font-size: 12px;
  pointer-events: none; /* Prevents cursor interference */
  z-index: 1000;
  transform: translate(-50%, -100%);
  white-space: nowrap;
}
const tooltip = document.createElement('div');
tooltip.className = 'wavesurfer-tooltip';
document.body.appendChild(tooltip);

3. Attach Hover Listeners to Regions

Whenever a region is created, access its container element via region.element and attach mouseenter, mousemove, and mouseleave event listeners.

wsRegions.on('region-created', (region) => {
  const element = region.element;

  // Show tooltip on hover
  element.addEventListener('mouseenter', () => {
    tooltip.style.display = 'block';
    tooltip.textContent = `${region.content || 'Region'}: ${region.start.toFixed(2)}s - ${region.end.toFixed(2)}s`;
  });

  // Track cursor movement for dynamic positioning
  element.addEventListener('mousemove', (e) => {
    tooltip.style.left = `${e.pageX}px`;
    tooltip.style.top = `${e.pageY - 10}px`;
  });

  // Hide tooltip when moving out
  element.addEventListener('mouseleave', () => {
    tooltip.style.display = 'none';
  });
});

4. Handling Dynamic Region Updates

If your application allows users to resize or drag regions, ensure the tooltip updates in real time to reflect current timing data by tapping into the region-updated event:

wsRegions.on('region-updated', (region) => {
  if (tooltip.style.display === 'block') {
    tooltip.textContent = `${region.content || 'Region'}: ${region.start.toFixed(2)}s - ${region.end.toFixed(2)}s`;
  }
});

Alternative: Using Native HTML Tooltips

If advanced styling or continuous cursor-tracking is unnecessary, assign the text directly to the native title attribute of the region element:

wsRegions.on('region-created', (region) => {
  region.element.setAttribute(
    'title',
    `${region.content || 'Region'}: ${region.start.toFixed(2)}s - ${region.end.toFixed(2)}s`
  );
});

wsRegions.on('region-updated', (region) => {
  region.element.setAttribute(
    'title',
    `${region.content || 'Region'}: ${region.start.toFixed(2)}s - ${region.end.toFixed(2)}s`
  );
});
