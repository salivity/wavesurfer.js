Wavesurfer.js Plugins for Grid Lines and Beat Grids

Displaying visual grid lines or musical beat grids on a Wavesurfer.js waveform enhances audio analysis, editing, and DJ-style playback. While Wavesurfer.js does not feature an out-of-the-box plugin named explicitly "BeatGrid," developers achieve grid lines and beat-aligned grids using the official Timeline plugin, the Regions plugin, or by creating a lightweight custom canvas overlay plugin tailored to BPM calculations.

1. The Official Timeline Plugin

The primary tool for rendering standard grid lines across a waveform is the official Timeline plugin (wavesurfer.js/dist/plugins/timeline.esm.js).

Although typically positioned above or below the waveform to show seconds and minutes, the Timeline plugin can be styled and configured to project grid lines across the entire waveform container:

  • Time Notches and Secondary Lines: You can configure the timeInterval, primaryLabelInterval, and secondaryLabelInterval parameters to determine how frequently vertical markers appear.
  • Full-Height Grid Overlay: By adjusting CSS (such as setting the timeline's position to absolute, stretching its height to 100%, and styling notch elements with low-opacity borders), the timeline notches act as full-height vertical grid lines across the audio peaks.

While effective for fixed time intervals (e.g., every 1 second, 500 milliseconds), the standard Timeline plugin tracks absolute time rather than dynamic musical beats or tempo changes.

2. The Regions Plugin for Measure and Beat Markers

The official Regions plugin (wavesurfer.js/dist/plugins/regions.esm.js) allows you to programmatically draw non-interactive vertical markers or shaded zones across the waveform:

  • Beat and Bar Markers: By knowing an audio track's BPM (beats per minute) and start offset, you can loop through the duration and add thin, vertical regions (start equals end) at every beat or bar interval.
  • Custom Styling: Each line can be assigned custom CSS classes, allowing you to visually distinguish downbeats (the start of a measure) from regular beats using different colors or line thicknesses.
  • Interactivity: Unlike static canvas grids, markers created via the Regions plugin can be clicked, dragged, or updated dynamically if you need an editable beat grid.

3. Custom Canvas Overlays for True Beat Grids

For music applications, digital audio workstations (DAWs), or DJ software requiring true BPM-synchronized beat grids, developers typically write a custom plugin or use a secondary HTML5 <canvas> element.

Because musical intervals depend on tempo rather than round seconds, a BPM-based beat grid requires calculating beat intervals:

  1. Calculate Interval: Divide 60 by the track's BPM to determine the interval between beats in seconds (e.g., 120 BPM = 0.5 seconds per beat).
  2. Handle the Offset: Account for the first downbeat offset (transient detection or manual alignment).
  3. Render to Canvas: Listen to Wavesurfer's redraw and timeupdate events to project vertical lines onto a transparent canvas directly over the waveform.
  4. Zoom Support: A custom render loop ensures grid lines scale correctly when the user changes the waveform's zoom level (wavesurfer.zoom(pxPerSec)).
