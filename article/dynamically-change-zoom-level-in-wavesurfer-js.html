Dynamically Change Zoom Level in Wavesurfer.js

This article explains how to dynamically adjust the zoom level of an interactive waveform using Wavesurfer.js. You will learn how to use the built-in zoom method, connect it to user interface elements such as range sliders, and manage waveform scrolling to create an intuitive audio scrubbing experience.

The zoom() Method

Wavesurfer.js provides a native method called zoom(minPxPerSec) to control the horizontal scale of the waveform. The parameter minPxPerSec defines the minimum number of pixels rendered per second of audio.

  • Increasing this value stretches the waveform horizontally, zooming in to reveal finer audio details.
  • Decreasing this value compresses the waveform horizontally, zooming out for a broader overview.
  • Setting the value to 0 resets the waveform to fit the container width.

HTML Setup

To allow dynamic zooming, pair a container for the waveform with a standard HTML <input type="range"> element:

<div id="waveform"></div>

<div class="controls">
  <label for="zoom-slider">Zoom:</label>
  <input 
    type="range" 
    id="zoom-slider" 
    min="0" 
    max="200" 
    value="0" 
    step="1"
  />
</div>

JavaScript Implementation

Initialize Wavesurfer.js and attach an input event listener to the slider. Using the input event ensures real-time updates as the user drags the slider thumb.

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  minPxPerSec: 0, // Default zoom (fits container)
});

// 2. Select the zoom slider
const zoomSlider = document.querySelector('#zoom-slider');

// 3. Update zoom dynamically on slider input
zoomSlider.addEventListener('input', (e) => {
  const minPxPerSec = Number(e.target.value);
  wavesurfer.zoom(minPxPerSec);
});

Handling Scrolling When Zoomed

When zooming in, the waveform width typically exceeds the container width. Ensure your waveform container handles overflow properly by setting CSS overflow rules:

#waveform {
  width: 100%;
  overflow-x: auto;
}

In Wavesurfer.js v7, setting autoCenter: true or autoScroll: true in the initial configuration ensures that the playhead remains visible within the viewport while playing back a zoomed waveform.

Programmatic Zoom Controls

If you prefer discrete zoom buttons instead of a continuous slider, invoke wavesurfer.zoom() with incremented or decremented values:

let currentZoom = 0;
const step = 20;

document.querySelector('#zoom-in').addEventListener('click', () => {
  currentZoom += step;
  wavesurfer.zoom(currentZoom);
});

document.querySelector('#zoom-out').addEventListener('click', () => {
  currentZoom = Math.max(0, currentZoom - step);
  wavesurfer.zoom(currentZoom);
});

document.querySelector('#zoom-reset').addEventListener('click', () => {
  currentZoom = 0;
  wavesurfer.zoom(0);
});
