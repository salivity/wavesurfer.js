Generate Wavesurfer.js JSON Waveforms in PHP

Exporting pre-computed waveform data from a PHP backend dramatically improves client-side performance by allowing Wavesurfer.js to render audio visualizations without downloading and decoding complete audio files in the browser. This article covers the target JSON structure Wavesurfer.js expects, how to generate peak data using standard CLI tools like BBC’s audiowaveform and FFmpeg within PHP, and how to format and serve the resulting payload.

Understanding the Wavesurfer.js Data Format

Wavesurfer.js accepts an array of peak values via its peaks configuration option or through a standalone JSON file loaded via backend.load(url, peaks).

The peaks can be structured in two standard ways:

  1. Single-channel normalized floats: A one-dimensional array of values between -1.0 and 1.0 (or 0.0 and 1.0 for absolute amplitudes).
  2. Channel-separated peaks: An array containing separate arrays for each audio channel, alternating between negative (trough) and positive (crest) values, or stored under a standard JSON schema containing sample rate, length, and a data array.

A typical standard JSON payload generated for Wavesurfer.js looks like this:

{
  "version": 2,
  "channels": 1,
  "sample_rate": 44100,
  "samples_per_pixel": 256,
  "bits": 8,
  "length": 1200,
  "data": [-12, 14, -30, 28, -50, 48, -10, 12]
}

When passing raw arrays directly to Wavesurfer.js, a simple flat array of floating-point numbers (e.g., [0.12, 0.45, 0.89, 0.32]) is also fully supported.

Method 1: Using audiowaveform via PHP (Recommended)

The most efficient backend utility for generating compatible waveform data is the open-source C++ utility audiowaveform developed by the BBC. It natively exports JSON structures formatted specifically for web waveforms.

Implementation

You can invoke audiowaveform directly from PHP using proc_open or exec:

<?php

function generateWaveformJson(string $audioFilePath, string $outputJsonPath, int $pixelsPerSecond = 20): bool
{
    if (!file_exists($audioFilePath)) {
        throw new InvalidArgumentException("Audio file not found: {$audioFilePath}");
    }

    // Command options:
    // -i: input file
    // -o: output file
    // --pixels-per-second: zoom/resolution level
    // --bits: bit depth (8 or 16; 8 bits yields values between -128 and 127)
    $command = sprintf(
        'audiowaveform -i %s -o %s --pixels-per-second %d --bits 8 2>&1',
        escapeshellarg($audioFilePath),
        escapeshellarg($outputJsonPath),
        $pixelsPerSecond
    );

    exec($command, $output, $returnCode);

    if ($returnCode !== 0) {
        throw new RuntimeException("Error generating waveform: " . implode("\n", $output));
    }

    return true;
}

// Example usage
$audioFile = __DIR__ . '/audio/track.mp3';
$jsonFile = __DIR__ . '/waveforms/track.json';

generateWaveformJson($audioFile, $jsonFile);

Normalizing the Output for Wavesurfer.js

The standard audiowaveform tool outputs integers between -128 and 127 when using --bits 8. While Wavesurfer.js can read this format directly from its JSON structure, you can normalize the values in PHP to an array of positive floats (from 0.0 to 1.0) if preferred:

<?php

function getNormalizedPeaks(string $jsonFilePath): array
{
    $rawContent = file_get_contents($jsonFilePath);
    $decoded = json_decode($rawContent, true);

    if (!isset($decoded['data'])) {
        throw new RuntimeException("Invalid waveform JSON structure.");
    }

    $normalized = [];
    $data = $decoded['data'];

    // In 8-bit mode, values range from -128 to 127
    foreach ($data as $value) {
        $normalized[] = round(abs($value) / 128, 4);
    }

    return $normalized;
}

Method 2: Extracting Peaks Using FFmpeg in Pure PHP

If installing external specialized binaries like audiowaveform is not an option, you can use FFmpeg—which is standard on most media servers—to decode raw audio samples and calculate peaks directly in PHP.

<?php

function extractPeaksWithFfmpeg(string $audioPath, int $targetPeakCount = 800): array
{
    // Convert audio to raw 16-bit little-endian PCM mono stream at 8kHz
    $command = sprintf(
        'ffmpeg -v quiet -i %s -f s16le -ac 1 -ar 8000 - 2>&1',
        escapeshellarg($audioPath)
    );

    $process = popen($command, 'r');
    if (!is_resource($process)) {
        throw new RuntimeException("Failed to run FFmpeg process.");
    }

    $samples = [];
    while (!feof($process)) {
        $buffer = fread($process, 4096);
        if ($buffer === false || strlen($buffer) === 0) {
            continue;
        }

        // Unpack 16-bit signed integers
        $unpacked = unpack('s*', $buffer);
        foreach ($unpacked as $sample) {
            $samples[] = abs($sample);
        }
    }
    pclose($process);

    $totalSamples = count($samples);
    if ($totalSamples === 0) {
        return [];
    }

    // Downsample to target peak count
    $blockSize = (int) floor($totalSamples / $targetPeakCount);
    $peaks = [];

    for ($i = 0; $i < $targetPeakCount; $i++) {
        $start = $i * $blockSize;
        $chunk = array_slice($samples, $start, $blockSize);
        $max = !empty($chunk) ? max($chunk) : 0;
        
        // Normalize 16-bit values (range 0 - 32767) to a float (0.0 - 1.0)
        $peaks[] = round($max / 32767, 4);
    }

    return $peaks;
}

// Example usage and direct JSON output:
$peaks = extractPeaksWithFfmpeg('audio/track.mp3', 500);

header('Content-Type: application/json');
echo json_encode([
    'version' => 2,
    'channels' => 1,
    'data' => $peaks
]);

Client-Side Integration in Wavesurfer.js

Once the PHP backend exposes the JSON endpoint or outputs the generated JSON file, load the peaks directly into the client instance to avoid client-side decoding delays:

// Fetch the pre-computed JSON from your PHP backend
fetch('/waveforms/track.json')
  .then(response => response.json())
  .then(waveformData => {
    const wavesurfer = WaveSurfer.create({
      container: '#waveform',
      waveColor: '#4F46E5',
      progressColor: '#10B981',
      url: '/audio/track.mp3',
      // Pass the extracted peak array directly
      peaks: waveformData.data || waveformData
    });
  });

Using pre-computed peaks reduces the time-to-render from several seconds to milliseconds, especially on longer audio tracks or constrained mobile devices.
