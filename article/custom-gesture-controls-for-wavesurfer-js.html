Custom Gesture Controls for Wavesurfer.js

Integrating custom gesture controls into Wavesurfer.js allows users to navigate, zoom, and interact with audio waveforms using mobile touch gestures and trackpads. This guide covers how to bind custom gestures—such as pinch-to-zoom, two-finger panning, and double-tap actions—to a Wavesurfer.js instance using both the Hammer.js library and native browser Pointer Events.

Preparing the Container

Before attaching touch listeners, ensure the Wavesurfer wrapper element allows custom touch handling. By default, mobile browsers capture gestures for scrolling and zooming the entire page. Set the CSS touch-action property on your waveform container to prevent default behavior:

#waveform {
  touch-action: pan-y; /* Allows vertical page scroll while capturing horizontal gestures */
  user-select: none;
  overflow: hidden;
}

Method 1: Binding Gestures with Hammer.js

Hammer.js simplifies complex multi-touch recognition like pinches and directional pans.

1. Pinch-to-Zoom

To zoom in and out of the waveform, bind the pinch recognizer to modify Wavesurfer's zoom level based on the event scale.

const container = document.getElementById('waveform');
const ws = WaveSurfer.create({
  container: container,
  waveColor: '#4F4A85',
  progressColor: '#383351',
  minPxPerSec: 50,
});

const hammer = new Hammer.Manager(container);

// Enable Pinch recognizer
const pinch = new Hammer.Pinch();
hammer.add(pinch);

let initialZoom = 50;

hammer.on('pinchstart', () => {
  // Store the zoom level at the start of the gesture
  initialZoom = ws.options.minPxPerSec || 50;
});

hammer.on('pinchmove', (e) => {
  // Calculate new pixels per second using gesture scale
  const newZoom = Math.max(20, Math.min(1000, initialZoom * e.scale));
  ws.zoom(newZoom);
});

2. Pan (Horizontal Waveform Scrubbing / Scrolling)

When the waveform is zoomed in, use the pan event to smoothly scroll along the time axis.

const pan = new Hammer.Pan({ direction: Hammer.DIRECTION_HORIZONTAL, threshold: 10 });
hammer.add(pan);

// Ensure Pan and Pinch can be recognized simultaneously if needed
pinch.recognizeWith(pan);

let startScrollLeft = 0;

hammer.on('panstart', () => {
  const scrollContainer = ws.getWrapper();
  startScrollLeft = scrollContainer.scrollLeft;
});

hammer.on('panmove', (e) => {
  const scrollContainer = ws.getWrapper();
  // Dragging right moves the view to earlier in the track
  scrollContainer.scrollLeft = startScrollLeft - e.deltaX;
});

3. Double Tap to Play/Pause

Add a double-tap recognizer to toggle playback without interfering with single-click seeking:

const doubleTap = new Hammer.Tap({ event: 'doubletap', taps: 2 });
hammer.add(doubleTap);

hammer.on('doubletap', () => {
  ws.playPause();
});

Method 2: Implementing Native Pointer Events

If you prefer to avoid third-party dependencies, modern browsers support Pointer Events (pointerdown, pointermove, pointerup), which unify mouse, pen, and touch inputs.

Tracking Multi-Touch for Pinch-to-Zoom

Native pinch recognition requires tracking active pointers in a cache and calculating the Euclidean distance between two contact points.

const container = document.getElementById('waveform');
const activePointers = new Map();
let initialDistance = 0;
let initialZoom = 50;

function getDistance(p1, p2) {
  return Math.hypot(p1.clientX - p2.clientX, p1.clientY - p2.clientY);
}

container.addEventListener('pointerdown', (e) => {
  activePointers.set(e.pointerId, e);
  container.setPointerCapture(e.pointerId);

  if (activePointers.size === 2) {
    const [p1, p2] = Array.from(activePointers.values());
    initialDistance = getDistance(p1, p2);
    initialZoom = ws.options.minPxPerSec || 50;
  }
});

container.addEventListener('pointermove', (e) => {
  if (!activePointers.has(e.pointerId)) return;
  activePointers.set(e.pointerId, e);

  // Two fingers active: perform zoom
  if (activePointers.size === 2) {
    const [p1, p2] = Array.from(activePointers.values());
    const currentDistance = getDistance(p1, p2);
    
    if (initialDistance > 0) {
      const scale = currentDistance / initialDistance;
      const newZoom = Math.max(10, Math.min(500, initialZoom * scale));
      ws.zoom(newZoom);
    }
  }
});

const cleanupPointer = (e) => {
  activePointers.delete(e.pointerId);
  try {
    container.releasePointerCapture(e.pointerId);
  } catch (err) {
    // Pointer capture might have already been released
  }
  if (activePointers.size < 2) {
    initialDistance = 0;
  }
};

container.addEventListener('pointerup', cleanupPointer);
container.addEventListener('pointercancel', cleanupPointer);

Choosing Between Native Events and Hammer.js

  • Hammer.js is best suited for legacy application support or when complex multi-finger gestures (rotations, swipes with velocity thresholds, and multi-tap states) are required with minimal custom math.
  • Native Pointer Events are recommended for modern applications using Wavesurfer.js v7+. They reduce bundle size, eliminate external library synchronization issues, and offer native performance with the browser's hardware-accelerated event loop.
