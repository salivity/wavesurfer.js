Export Wavesurfer.js Regions to MP3

Exporting a selected region from Wavesurfer.js as a downloadable MP3 requires a combination of the Web Audio API and a client-side MP3 encoder, most notably lamejs. While Wavesurfer.js excels at waveform visualization and segment selection via its Regions plugin, it does not include a native MP3 encoding engine. By slicing the underlying decoded AudioBuffer between the selected region's start and end timestamps and processing it through lamejs, developers can encode raw PCM audio data into an MP3 file entirely within the browser.

The Primary Library: lamejs

The most common and lightweight library for converting audio buffers to MP3 in the browser is lamejs. It is a pure JavaScript port of the LAME MP3 encoder. When used with Wavesurfer.js, it converts raw audio samples directly into an MP3 bitstream without needing a backend server.

An alternative for high-performance or complex multi-format requirements is @ffmpeg/ffmpeg (FFmpeg WebAssembly), but lamejs remains the preferred, lightweight solution when only MP3 generation is needed.

Step-by-Step Conversion Workflow

1. Retrieve the Region Boundaries

When using the Wavesurfer.js Regions plugin, a region provides start and end values in seconds:

const region = wsRegions.getRegions()[0];
const startTime = region.start;
const endTime = region.end;

2. Slice the AudioBuffer

Wavesurfer stores the decoded audio in an AudioBuffer. Using the Web Audio API, create a new buffer that contains only the samples between startTime and endTime:

const originalBuffer = wavesurfer.getDecodedData();
const sampleRate = originalBuffer.sampleRate;
const numberOfChannels = originalBuffer.numberOfChannels;

const startOffset = Math.floor(startTime * sampleRate);
const endOffset = Math.floor(endTime * sampleRate);
const frameCount = endOffset - startOffset;

const audioContext = new AudioContext();
const slicedBuffer = audioContext.createBuffer(numberOfChannels, frameCount, sampleRate);

for (let channel = 0; channel < numberOfChannels; channel++) {
  const sourceData = originalBuffer.getChannelData(channel);
  const targetData = slicedBuffer.getChannelData(channel);
  for (let i = 0; i < frameCount; i++) {
    targetData[i] = sourceData[startOffset + i];
  }
}

3. Encode to MP3 with lamejs

Convert the float samples from the sliced buffer into 16-bit signed integers (PCM data), then encode them in chunks using lamejs.Mp3Encoder:

import lamejs from 'lamejs';

function bufferToMp3(buffer) {
  const channels = buffer.numberOfChannels;
  const sampleRate = buffer.sampleRate;
  const mp3encoder = new lamejs.Mp3Encoder(channels, sampleRate, 128); // 128 kbps
  const mp3Data = [];

  // Convert Float32Array to Int16Array
  const left = floatToInt16(buffer.getChannelData(0));
  const right = channels > 1 ? floatToInt16(buffer.getChannelData(1)) : left;

  const sampleBlockSize = 1152;
  for (let i = 0; i < left.length; i += sampleBlockSize) {
    const leftChunk = left.subarray(i, i + sampleBlockSize);
    const rightChunk = right.subarray(i, i + sampleBlockSize);
    const mp3buf = channels === 1 
      ? mp3encoder.encodeBuffer(leftChunk)
      : mp3encoder.encodeBuffer(leftChunk, rightChunk);

    if (mp3buf.length > 0) {
      mp3Data.push(mp3buf);
    }
  }

  const endBuf = mp3encoder.flush();
  if (endBuf.length > 0) {
    mp3Data.push(endBuf);
  }

  return new Blob(mp3Data, { type: 'audio/mp3' });
}

function floatToInt16(floatSamples) {
  const int16Array = new Int16Array(floatSamples.length);
  for (let i = 0; i < floatSamples.length; i++) {
    const s = Math.max(-1, Math.min(1, floatSamples[i]));
    int16Array[i] = s < 0 ? s * 0x8000 : s * 0x7FFF;
  }
  return int16Array;
}

4. Trigger the Download

Create a temporary anchor tag linked to the generated Blob to prompt a browser download:

const mp3Blob = bufferToMp3(slicedBuffer);
const url = URL.createObjectURL(mp3Blob);

const link = document.createElement('a');
link.href = url;
link.download = 'selected-region.mp3';
link.click();

URL.revokeObjectURL(url);

Using lamejs alongside the browser's native Web Audio API provides an efficient, serverless pipeline for trimming and downloading audio selections made within Wavesurfer.js.
