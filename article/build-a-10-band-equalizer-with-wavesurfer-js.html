Build a 10-Band Equalizer with Wavesurfer.js

This guide explains how to construct a functional 10-band graphic equalizer control panel integrated directly into Wavesurfer.js. By utilizing the native Web Audio API's BiquadFilterNode interface in conjunction with Wavesurfer's playback engine, you will learn how to create distinct frequency bands, chain them within the audio routing graph, and bind interactive HTML range inputs to manipulate audio output in real time.

1. HTML Markup

Create a container for the waveform and a control panel featuring 10 sliders corresponding to standard ISO graphic equalizer frequencies: 32Hz, 64Hz, 125Hz, 250Hz, 500Hz, 1kHz, 2kHz, 4kHz, 8kHz, and 16kHz.

<div id="waveform"></div>
<div id="equalizer-controls" class="eq-container">
  <!-- Sliders will be injected dynamically or defined statically -->
</div>
<button id="play-pause">Play/Pause</button>

2. Equalizer CSS

Basic styling facilitates standard vertical slider controls for a conventional equalizer appearance.

.eq-container {
  display: flex;
  gap: 15px;
  margin-top: 20px;
}

.eq-band {
  display: flex;
  flex-direction: column;
  align-items: center;
  font-family: sans-serif;
  font-size: 12px;
}

.eq-band input[type="range"] {
  writing-mode: vertical-lr;
  direction: rtl;
  height: 120px;
  margin-bottom: 8px;
}

3. Initialize Wavesurfer.js

Initialize Wavesurfer.js using an explicit AudioContext so that filter nodes can be inserted into the audio signal chain.

import WaveSurfer from 'wavesurfer.js';

const audioContext = new (window.AudioContext || window.webkitAudioContext)();

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  audioContext: audioContext
});

4. Create and Chain Biquad Filter Nodes

Define the 10 frequency centers. Iterate through them to generate BiquadFilterNode instances configured with a peaking filter type, then chain each node sequentially to process the audio signal.

const frequencies = [32, 64, 125, 250, 500, 1000, 2000, 4000, 8000, 16000];

// Create the filters
const filters = frequencies.map((freq) => {
  const filter = audioContext.createBiquadFilter();
  filter.type = 'peaking';
  filter.frequency.value = freq;
  filter.Q.value = 1.4; // Typical bandwidth for 1-octave spacing
  filter.gain.value = 0; // Default gain at 0 dB
  return filter;
});

// Chain the filters sequentially
for (let i = 0; i < filters.length - 1; i++) {
  filters[i].connect(filters[i + 1]);
}

5. Hook the Filter Chain into Wavesurfer.js

Intercept the audio stream from Wavesurfer once the audio is ready. Route the media element source into the first filter, and route the last filter into the destination.

wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const sourceNode = audioContext.createMediaElementSource(mediaElement);

  // Connect source -> first filter -> ... -> last filter -> audio context output
  sourceNode.connect(filters[0]);
  filters[filters.length - 1].connect(audioContext.destination);
});

6. Build UI and Bind Control Handlers

Generate the DOM sliders for each frequency band and attach input event listeners to modify the gain parameter of the corresponding filter node.

const eqContainer = document.getElementById('equalizer-controls');

frequencies.forEach((freq, index) => {
  const bandDiv = document.createElement('div');
  bandDiv.className = 'eq-band';

  const slider = document.createElement('input');
  slider.type = 'range';
  slider.min = '-12';
  slider.max = '12';
  slider.value = '0';
  slider.step = '0.5';

  slider.addEventListener('input', (e) => {
    filters[index].gain.value = parseFloat(e.target.value);
  });

  const label = document.createElement('span');
  label.textContent = freq >= 1000 ? `${freq / 1000}k` : `${freq}Hz`;

  bandDiv.appendChild(slider);
  bandDiv.appendChild(label);
  eqContainer.appendChild(bandDiv);
});

// Simple transport control
document.getElementById('play-pause').addEventListener('click', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
  wavesurfer.playPause();
});

Adjusting any slider updates its mapped BiquadFilterNode gain in real time, shifting the amplitude of that specific frequency band up to +12 dB or down to -12 dB without interrupting playback.
