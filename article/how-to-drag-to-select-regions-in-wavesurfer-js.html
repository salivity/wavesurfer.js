How to Drag to Select Regions in Wavesurfer.js

Modern versions of Wavesurfer.js (v7+) provide native support for drag-to-select regions via the official Regions plugin. By registering this plugin and invoking its built-in enableDragSelection method, developers can allow users to click and drag directly across an audio waveform to create, resize, and manage custom audio segments without manual DOM tracking or external libraries.

Installing and Importing the Plugin

In Wavesurfer.js v7 and above, regions are managed as a modular plugin. Ensure you have the core package installed, then import both WaveSurfer and RegionsPlugin.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

Initializing the WaveSurfer Instance

To implement drag-to-select behavior, initialize the WaveSurfer player and register an instance of the RegionsPlugin within the plugins configuration array.

// Create the regions plugin instance
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  plugins: [wsRegions],
});

Enabling Drag Selection

The modern Regions plugin features a native helper method called enableDragSelection. Calling this method binds internal mouse and touch listeners to the waveform container, enabling instantaneous bounding-box creation on drag.

Call enableDragSelection once the waveform is ready or directly after plugin instantiation:

wsRegions.enableDragSelection({
  color: 'rgba(0, 123, 255, 0.2)', // Semi-transparent overlay color
  drag: true,                      // Allow moving the region after creation
  resize: true,                    // Allow resizing the region edges
});

The options object passed to enableDragSelection accepts the same parameters as standard region objects in Wavesurfer.js, including custom styling, HTML content, and behavioral constraints.

Listening to Region Events

Once drag-to-select is enabled, you can respond to user interactions using region-specific event listeners attached to the plugin instance:

// Triggered when a new region is created by dragging
wsRegions.on('region-created', (region) => {
  console.log('Region created:', region.id, region.start, region.end);
});

// Triggered when resizing or moving finishes
wsRegions.on('region-updated', (region) => {
  console.log('Region updated:', region.start, region.end);
});

// Triggered when a user clicks on an existing region
wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation(); // Prevent playback trigger on region click
  region.play();
});

Disabling or Limiting Drag Selection

If your application requires limiting the user to a single active region, you can listen to region-created and remove prior regions using wsRegions.clearRegions() before adding the new one.

To disable the drag-to-select behavior conditionally, the enableDragSelection method returns an unsubscribe function:

// Enable drag-to-select and store the cleanup handler
const disableDrag = wsRegions.enableDragSelection({
  color: 'rgba(0, 255, 0, 0.15)',
});

// Disable drag selection when no longer needed
disableDrag();
