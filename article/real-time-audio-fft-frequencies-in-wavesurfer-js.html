Real-Time Audio FFT Frequencies in Wavesurfer.js

This guide demonstrates how to extract real-time Fast Fourier Transform (FFT) frequency data from audio playback using Wavesurfer.js and the Web Audio API. By attaching an AnalyserNode to Wavesurfer's underlying audio pipeline, you can capture frequency spectrum data on every animation frame to power custom visualizers, level meters, or real-time reactive audio features.

1. Initialize Wavesurfer with an AudioContext

To intercept frequency data, you must either provide an existing AudioContext to Wavesurfer or utilize the context Wavesurfer creates internally. Passing your own context provides full control over the audio graph routing.

import WaveSurfer from 'wavesurfer.js';

// 1. Create a custom AudioContext
const audioContext = new (window.AudioContext || window.webkitAudioContext)();

// 2. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  audioContext: audioContext,
});

2. Configure the AnalyserNode

An AnalyserNode provides real-time frequency and time-domain analysis. Create the node and insert it between the audio source and the audio context's destination.

// Create the AnalyserNode
const analyser = audioContext.createAnalyser();
analyser.fftSize = 512; // Must be a power of 2 (e.g., 32, 64, 128, 256, 512, 1024, 2048)

// Create an array to hold the frequency data
const bufferLength = analyser.frequencyBinCount; // Half of fftSize (256)
const frequencyData = new Uint8Array(bufferLength);

// Connect the media element to the AnalyserNode once audio is ready
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const sourceNode = audioContext.createMediaElementSource(mediaElement);

  // Route: Source -> Analyser -> Output
  sourceNode.connect(analyser);
  analyser.connect(audioContext.destination);
});

Note: In modern browsers, you must resume the AudioContext on user interaction (such as clicking play) if it starts in a suspended state.

wavesurfer.on('play', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
  renderFrame();
});

3. Capture Frequencies with requestAnimationFrame

Use an animation frame loop to extract the FFT values continuously while the audio plays. The getByteFrequencyData method populates the typed array with integers ranging from 0 to 255, representing signal strength across mapped frequency bins.

let animationId = null;

function renderFrame() {
  if (!wavesurfer.isPlaying()) {
    cancelAnimationFrame(animationId);
    return;
  }

  // Copy current frequency data into the Uint8Array
  analyser.getByteFrequencyData(frequencyData);

  // Example: frequencyData[0] is sub-bass, higher indices represent treble
  // Use frequencyData here to drive visualizers, canvas drawing, or UI changes

  animationId = requestAnimationFrame(renderFrame);
}

wavesurfer.on('pause', () => cancelAnimationFrame(animationId));
wavesurfer.on('finish', () => cancelAnimationFrame(animationId));

4. Key AnalyserNode Properties

  • fftSize: Determines the frequency resolution. A higher value yields more frequency bins (calculated as fftSize / 2), but increases processing latency. For visualizations, 256 or 512 offers a good balance between performance and detail.
  • smoothingTimeConstant: A value between 0 and 1 (default is 0.8). Higher values smooth the transition between frames, preventing jittery visual movements, while lower values offer a more instantaneous response.
