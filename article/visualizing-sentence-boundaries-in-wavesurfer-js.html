Visualizing Sentence Boundaries in Wavesurfer.js

This article explains how to visually render sentence boundary markers along an audio timeline using Wavesurfer.js. By utilizing the official Regions plugin, you can transform speech-to-text timestamps into visual segments directly on the waveform. The following guide covers installation, data preparation, marker creation, and styling configurations to achieve clean, readable sentence demarcation.

1. Initialize Wavesurfer with the Regions Plugin

Wavesurfer.js handles visual markers through its RegionsPlugin. First, import Wavesurfer and the plugin, then initialize your player instance with the plugin registered.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize the Regions plugin
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',
  progressColor: '#3b82f6',
  url: '/path/to/audio.mp3',
  plugins: [wsRegions],
});

2. Format Sentence Boundary Data

Sentence boundaries typically come from automated transcription engines or forced alignment tools (such as Whisper, gentle, or WebVTT files). Structure your data as an array of objects containing start times, end times, and optional textual labels.

const sentenceBoundaries = [
  { start: 0.0, end: 3.25, text: "Welcome to the presentation." },
  { start: 3.4, end: 7.10, text: "Today, we are discussing audio visualization." },
  { start: 7.3, end: 11.8, text: "Wavesurfer provides flexible plugin options." }
];

3. Render the Markers

Wait for the audio to decode (or register immediately after initialization) and loop through the boundary data to render each sentence. Use addRegion() to place markers across the timeline.

wavesurfer.on('decode', () => {
  sentenceBoundaries.forEach((sentence, index) => {
    wsRegions.addRegion({
      start: sentence.start,
      end: sentence.end,
      content: sentence.text,
      color: index % 2 === 0 ? 'rgba(59, 130, 246, 0.1)' : 'rgba(99, 102, 241, 0.1)',
      drag: false,
      resize: false,
    });
  });
});

Key options for sentence demarcation:

  • start & end: The start and end positions in seconds.
  • content: Inserts a DOM element or text string inside the region boundary.
  • color: Sets a semi-transparent background to distinguish alternating sentences.
  • drag & resize: Set both to false to ensure static display for playback.

4. Style Boundary Markers with CSS

Regions automatically receive the class .wavesurfer-region. You can use CSS to make the boundary lines crisp and place labels clearly along the timeline.

/* Style the full sentence block */
.wavesurfer-region {
  border-left: 2px solid #2563eb !important;
  border-right: 2px dashed #9333ea !important;
  box-sizing: border-box;
}

/* Style the text label inside the boundary */
.wavesurfer-region-content {
  font-size: 12px;
  color: #1f2937;
  padding: 4px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

5. Interaction and Playback Sync

To enhance user navigation, add an event listener so clicking a sentence marker plays that specific segment:

wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation(); // Prevents normal waveform click behavior
  region.play();
});

This configuration renders distinct, non-intrusive sentence boundaries that allow listeners to track and seek through spoken audio content with visual precision.
