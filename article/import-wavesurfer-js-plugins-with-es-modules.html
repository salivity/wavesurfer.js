Import Wavesurfer.js Plugins with ES Modules

Modern Wavesurfer.js (version 7 and above) uses a fully modular architecture where plugins are decoupled from the core library. This article explains how to properly install, import, and register official plugins—such as Regions, Timeline, and Minimap—into a modern ES module workflow using both npm-based bundlers and native browser <script type="module"> tags.

Installing Wavesurfer.js

To use official plugins in a project using Node.js and a bundler (such as Vite, Webpack, or Rollup), install the core library via npm:

npm install wavesurfer.js

Official plugins are bundled directly inside the wavesurfer.js package under subpaths, so no separate plugin packages are required.

Importing Official Plugins via a Bundler

In modern ES module environments, import the core WaveSurfer class and the specific plugin class directly from their designated subpaths in wavesurfer.js/dist/plugins/:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';

// Initialize plugins with their static .create() methods
const regions = RegionsPlugin.create();
const timeline = TimelinePlugin.create({
  container: '#wave-timeline',
});

// Pass plugins into the WaveSurfer instance
const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio.mp3',
  plugins: [regions, timeline],
});

Importing via CDN in Native Browser ES Modules

If you are using native ES modules directly in the browser without a bundler, import directly from an ES module CDN such as unpkg or jsDelivr using standard import syntax:

<script type="module">
  import WaveSurfer from 'https://unpkg.com/wavesurfer.js@7/dist/wavesurfer.esm.js';
  import RegionsPlugin from 'https://unpkg.com/wavesurfer.js@7/dist/plugins/regions.esm.js';

  const ws = WaveSurfer.create({
    container: '#waveform',
    waveColor: '#violet',
    progressColor: '#purple',
    url: '/audio.mp3',
    plugins: [
      RegionsPlugin.create(),
    ],
  });
</script>

Registering Plugins Dynamically

Plugins can also be initialized and attached after the WaveSurfer instance has already been created using the registerPlugin method:

import WaveSurfer from 'wavesurfer.js';
import HoverPlugin from 'wavesurfer.js/dist/plugins/hover.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  url: '/audio.mp3',
});

// Register after initialization
const hover = ws.registerPlugin(
  HoverPlugin.create({
    lineColor: '#ff0000',
    lineWidth: 2,
    labelBackground: '#555',
  })
);

// Destroy the plugin when it is no longer needed
hover.destroy();

Common Official Plugin Paths

The following official plugins can be imported using the same subpath pattern:

  • Regions: wavesurfer.js/dist/plugins/regions.esm.js
  • Timeline: wavesurfer.js/dist/plugins/timeline.esm.js
  • Minimap: wavesurfer.js/dist/plugins/minimap.esm.js
  • Spectrogram: wavesurfer.js/dist/plugins/spectrogram.esm.js
  • Hover: wavesurfer.js/dist/plugins/hover.esm.js
  • Record: wavesurfer.js/dist/plugins/record.esm.js
  • Envelope: wavesurfer.js/dist/plugins/envelope.esm.js
  • Zoom: wavesurfer.js/dist/plugins/zoom.esm.js
