Sync Canvas Particles with Wavesurfer.js Audio

Synchronizing an HTML5 Canvas particle system with audio intensity in Wavesurfer.js requires extracting real-time audio data through the Web Audio API and mapping those values to visual particle properties. By connecting an AnalyserNode to Wavesurfer's audio graph, developers can calculate the instantaneous volume or specific frequency band energy during playback. This data is then used inside a standard animation loop to modulate particle physics, such as velocity, size, count, and color, creating a responsive visualizer.

Connecting the Web Audio API AnalyserNode

Wavesurfer.js decodes and plays audio using the browser's native Web Audio API or HTML5 Media Elements. To capture real-time audio intensity, you must intercept the audio signal using an AnalyserNode.

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio.mp3'
});

// Create an AudioContext and AnalyserNode
const audioContext = new (window.AudioContext || window.webkitAudioContext)();
const analyser = audioContext.createAnalyser();
analyser.fftSize = 256;

// Connect Wavesurfer's media element to the AnalyserNode
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const source = audioContext.createMediaElementSource(mediaElement);
  source.connect(analyser);
  analyser.connect(audioContext.destination);
});

Extracting Audio Intensity

Audio intensity can be calculated using either time-domain data (waveform amplitude) or frequency-domain data (energy across specific pitch bands). For dynamic particle effects, frequency data focusing on bass and sub-bass frequencies (the lower indices of the frequency array) typically yields the most pronounced rhythmic response.

const bufferLength = analyser.frequencyBinCount;
const dataArray = new Uint8Array(bufferLength);

function getAudioIntensity() {
  analyser.getByteFrequencyData(dataArray);

  // Focus on low frequencies (bass kick)
  let sum = 0;
  const bassBinCount = Math.floor(bufferLength * 0.25);
  for (let i = 0; i < bassBinCount; i++) {
    sum += dataArray[i];
  }

  // Normalize intensity to a 0.0 - 1.0 range
  return sum / (bassBinCount * 255);
}

Driving Particle Physics on Canvas

In the canvas render loop, call getAudioIntensity() on each frame. This intensity factor acts as a multiplier against base particle parameters.

  1. Velocity and Spread: Multiply individual particle velocities by the intensity value to make particles explode outward on beat drops.
  2. Radius and Scale: Increase particle size dynamically when the intensity exceeds a designated threshold.
  3. Lifespan and Alpha: Fade particles faster during quiet intervals and increase opacity during high-amplitude peaks.
  4. Spawning Rates: Emit new particles only when intensity spikes past a sensitivity baseline.
const canvas = document.getElementById('particle-canvas');
const ctx = canvas.getContext('2d');

class Particle {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.baseRadius = Math.random() * 2 + 1;
    this.vx = (Math.random() - 0.5) * 2;
    this.vy = (Math.random() - 0.5) * 2;
  }

  update(intensity) {
    // Accelerate movement and expand size based on intensity
    this.x += this.vx * (1 + intensity * 5);
    this.y += this.vy * (1 + intensity * 5);
    this.currentRadius = this.baseRadius + (intensity * 6);
  }

  draw(ctx) {
    ctx.beginPath();
    ctx.arc(this.x, this.y, this.currentRadius, 0, Math.PI * 2);
    ctx.fillStyle = '#ffffff';
    ctx.fill();
  }
}

const particles = Array.from({ length: 100 }, () => new Particle(canvas.width / 2, canvas.height / 2));

function render() {
  requestAnimationFrame(render);
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  const intensity = wavesurfer.isPlaying() ? getAudioIntensity() : 0;

  particles.forEach(p => {
    p.update(intensity);
    p.draw(ctx);
  });
}

render();

By tapping into the raw frequency buffers via AnalyserNode and passing the computed amplitude directly into the canvas update phase, the particle system maintains low-latency, frame-accurate synchronization with the audio stream handled by Wavesurfer.js.
