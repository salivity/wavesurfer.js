How to Implement Audio Scrubbing in Wavesurfer.js

Audio scrubbing provides users with real-time auditory feedback as they drag the playhead across a waveform, mimicking the behavior of analog tape reels and modern digital audio workstations (DAWs). This guide demonstrates how to implement responsive audio scrubbing in Wavesurfer.js by capturing pointer drag interactions, throttling updates, and playing micro-bursts of audio corresponding to the scrubbed position.

The Core Concept

By default, Wavesurfer.js seeks silently when dragging across the waveform container. To create a scrub preview, you must:

  1. Detect when a user is actively dragging the playhead.
  2. Calculate the audio position based on pointer coordinates.
  3. Play a very short snippet (typically 30–80 milliseconds) of audio from that exact timestamp.
  4. Throttle the playback calls to prevent browser audio buffer underruns and severe stuttering.

Step-by-Step Implementation

1. Initialize Wavesurfer

Create your Wavesurfer instance as normal. Ensure the waveform container is accessible for attaching pointer listeners.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path-to-audio.mp3',
  dragToSeek: true, // Enables default visual seeking on drag
});

2. Implement the Scrubbing Playback Logic

The most reliable approach across modern browsers uses wavesurfer.play(start, end) to trigger a small fragment of audio. Wrap this in a throttle mechanism so rapid mouse movements do not overwhelm the Web Audio API context.

let isScrubbing = false;
let lastScrubTime = 0;
const SCRUB_THROTTLE_MS = 40; // Minimum time between audio triggers
const SNIPPET_DURATION = 0.05; // Duration of audio slice in seconds (50ms)

function playScrubSnippet(targetTime) {
  const now = performance.now();
  if (now - lastScrubTime < SCRUB_THROTTLE_MS) return;

  lastScrubTime = now;

  const duration = wavesurfer.getDuration();
  const startTime = Math.max(0, Math.min(targetTime, duration));
  const endTime = Math.min(startTime + SNIPPET_DURATION, duration);

  wavesurfer.play(startTime, endTime);
}

3. Bind Pointer and Drag Events

Attach pointer listeners to the waveform container. Calculate the relative position across the waveform width to derive the current audio timestamp during a drag.

const container = document.querySelector('#waveform');

container.addEventListener('pointerdown', (e) => {
  isScrubbing = true;
  triggerScrubFromEvent(e);
});

window.addEventListener('pointermove', (e) => {
  if (!isScrubbing) return;
  triggerScrubFromEvent(e);
});

window.addEventListener('pointerup', () => {
  if (isScrubbing) {
    isScrubbing = false;
    wavesurfer.pause();
  }
});

function triggerScrubFromEvent(e) {
  const rect = container.getBoundingClientRect();
  const relativeX = e.clientX - rect.left;
  const progress = Math.max(0, Math.min(relativeX / rect.width, 1));
  const targetTime = progress * wavesurfer.getDuration();

  playScrubSnippet(targetTime);
}

Performance and Audio Polish

To refine the scrub effect and avoid harsh audio artifacts:

  • Snippet Duration: Keep the snippet between 0.03 and 0.08 seconds. Values below 30ms produce mechanical clicks, while values above 100ms feel sluggish and disconnected from the cursor.
  • Volume Attenuation: Audio bursts during scrubbing can sound abrasive at normal levels. Lower the gain slightly during the drag event using wavesurfer.setVolume(0.7) and restore it to 1.0 on pointerup.
  • State Clean-up: Always ensure the pointerup listener is attached to window rather than the waveform container so the scrub state resets even if the user releases the pointer outside the waveform element.
