Set Min and Max Region Durations in Wavesurfer.js

Controlling the duration of user-created or edited regions is a common requirement in audio editing applications. In Wavesurfer.js, you can restrict how small or large an audio region can be stretched using the built-in properties of the Regions plugin, or by enforcing constraints manually using region event listeners. This guide demonstrates how to configure both approaches to guarantee regions stay within your desired time limits.

Using Built-in Plugin Properties

The most direct way to limit region boundaries is by defining minLength and maxLength when initializing a region. These properties accept numerical values in seconds and automatically prevent users from resizing a region beyond the designated thresholds.

First, initialize WaveSurfer along with the Regions plugin:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/path-to-audio.mp3',
});

// Initialize the Regions plugin
const wsRegions = ws.registerPlugin(RegionsPlugin.create());

Next, provide minLength and maxLength when creating a region:

ws.on('ready', () => {
  wsRegions.addRegion({
    start: 2,
    end: 8,
    content: 'Limited Region',
    color: 'rgba(0, 255, 0, 0.3)',
    minLength: 2, // Minimum duration: 2 seconds
    maxLength: 10, // Maximum duration: 10 seconds
    resize: true,
    drag: true,
  });
});

Once defined, the user cannot drag the region's start or end handles beyond a 10-second duration or closer than 2 seconds apart.

Restricting User-Drawn Regions

If you allow users to click and drag to draw new regions using wsRegions.enableDragSelection(), the Regions plugin allows you to supply default settings for dynamically created regions:

wsRegions.enableDragSelection({
  color: 'rgba(255, 0, 0, 0.3)',
  minLength: 1,  // Minimum drawn duration: 1 second
  maxLength: 5,  // Maximum drawn duration: 5 seconds
});

Manual Constraint via Event Listeners

If you require custom logic, dynamic limitations, or are using a configuration where native parameters do not apply, you can manually clamp region bounds by listening to the region-update event:

wsRegions.on('region-update', (region, side) => {
  const minDuration = 2; // seconds
  const maxDuration = 10; // seconds
  const currentDuration = region.end - region.start;

  if (currentDuration < minDuration) {
    if (side === 'start') {
      region.start = region.end - minDuration;
    } else {
      region.end = region.start + minDuration;
    }
  }

  if (currentDuration > maxDuration) {
    if (side === 'start') {
      region.start = region.end - maxDuration;
    } else {
      region.end = region.start + maxDuration;
    }
  }
});

Using minLength and maxLength ensures smooth, default resizing behavior, while the region-update listener provides an adaptable fallback for complex, state-dependent constraints.
