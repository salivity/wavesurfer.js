Converting Wavesurfer.js Regions to JSON Arrays

This article explores the serialization format used to convert Wavesurfer.js regions into structured JSON arrays. You will learn the exact data format required, the standard properties included in serialized region objects, and the straightforward JavaScript methods used to export and re-import region data for audio annotation and playback workflows.

The Serialization Format: Standard JSON

The format used to convert and store Wavesurfer.js regions as arrays is standard JavaScript Object Notation (JSON). Because Wavesurfer.js handles regions as runtime JavaScript class instances, converting them for storage or network transfer requires transforming these objects into a standard JSON array of plain JavaScript objects via JSON.stringify().

Structure of a Serialized Region Object

When serialized into a JSON array, each region is typically represented as a lightweight key-value object containing the spatial and visual boundaries of the audio segment. A standard serialized region contains the following properties:

  • id (string): A unique identifier for the region.
  • start (number): The start time of the region in seconds.
  • end (number): The end time of the region in seconds.
  • color (string, optional): An RGBA or hex color string defining the region overlay.
  • drag (boolean, optional): Indicates whether the region can be dragged across the timeline.
  • resize (boolean, optional): Indicates whether the boundaries can be resized.
  • data (object, optional): Custom metadata associated with the region, such as transcriptions, tags, or speaker labels.

Example of a serialized JSON array containing multiple regions:

[
  {
    "id": "region-1",
    "start": 1.5,
    "end": 4.2,
    "color": "rgba(0, 255, 0, 0.3)",
    "data": {
      "label": "Speaker 1"
    }
  },
  {
    "id": "region-2",
    "start": 5.0,
    "end": 8.75,
    "color": "rgba(255, 0, 0, 0.3)",
    "data": {
      "label": "Speaker 2"
    }
  }
]

How to Serialize Regions in Wavesurfer.js

To serialize active regions from the Wavesurfer.js Regions plugin into a JSON array, access the collection of regions, map each instance to its primitive properties, and convert the result with JSON.stringify():

// Access all active regions from the plugin instance
const activeRegions = wsRegions.getRegions();

// Map region instances to plain objects
const regionArray = activeRegions.map(region => ({
  id: region.id,
  start: region.start,
  end: region.end,
  color: region.color,
  drag: region.drag,
  resize: region.resize,
  data: region.data
}));

// Serialize the array to a JSON string
const jsonOutput = JSON.stringify(regionArray);

How to Deserialize and Load Regions

To restore serialized regions from a JSON array back into Wavesurfer.js, parse the JSON string and iterate over the elements using the addRegion method:

const savedRegions = JSON.parse(jsonOutput);

savedRegions.forEach(regionData => {
  wsRegions.addRegion(regionData);
});

Using a JSON array format ensures complete interoperability between frontend audio interfaces, persistent databases, and REST or GraphQL APIs.
