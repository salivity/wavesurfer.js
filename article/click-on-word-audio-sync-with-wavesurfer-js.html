Click-on-Word Audio Sync with Wavesurfer.js

This guide explains how to implement click-to-sync audio navigation using timestamped text and Wavesurfer.js. You will learn how to structure word-level transcription data, render it into interactive HTML elements, and use Wavesurfer.js seek methods—specifically setTime() in modern versions and seekTo() in legacy versions—to immediately jump audio playback to the exact timestamp of any clicked word.

1. Structure the Transcript Data

To link words to audio positions, you need structured data where each word or phrase has an associated start time (in seconds). This data typically comes from speech-to-text engines in JSON format:

const transcript = [
  { word: "Welcome", start: 0.0, end: 0.5 },
  { word: "to", start: 0.6, end: 0.8 },
  { word: "the", start: 0.9, end: 1.1 },
  { word: "audio", start: 1.2, end: 1.7 },
  { word: "player.", start: 1.8, end: 2.3 }
];

2. Initialize Wavesurfer.js

Initialize your Wavesurfer instance targeting a container element:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',
  progressColor: '#3b82f6',
  url: '/path/to/audio.mp3',
});

3. Render Interactive Words in HTML

Render the transcript into the DOM. Wrap each word in an inline element (such as a <span>) and store its start time in a data-start attribute:

const transcriptContainer = document.getElementById('transcript');

transcript.forEach((item) => {
  const span = document.createElement('span');
  span.textContent = item.word + ' ';
  span.dataset.start = item.start;
  span.className = 'clickable-word';
  transcriptContainer.appendChild(span);
});

4. Implement the Click-to-Seek Handler

Wavesurfer.js provides different methods for jumping to a specific timestamp depending on the version you are using.

Wavesurfer.js v7 (Modern)

In Wavesurfer.js v7, the primary method for jumping to an absolute timestamp in seconds is setTime():

transcriptContainer.addEventListener('click', (event) => {
  const target = event.target;
  if (target.classList.contains('clickable-word')) {
    const startTime = parseFloat(target.dataset.start);
    
    // Jump to the absolute time in seconds
    wavesurfer.setTime(startTime);
    wavesurfer.play();
  }
});

Wavesurfer.js v6 (Legacy)

In Wavesurfer.js v6, seekTo() accepts a normalized progress value between 0 and 1 (calculated as targetTime / totalDuration):

transcriptContainer.addEventListener('click', (event) => {
  const target = event.target;
  if (target.classList.contains('clickable-word')) {
    const startTime = parseFloat(target.dataset.start);
    const duration = wavesurfer.getDuration();
    
    if (duration > 0) {
      // Calculate normalized progress (0 to 1)
      const progress = startTime / duration;
      wavesurfer.seekTo(progress);
      wavesurfer.play();
    }
  }
});

5. Add Active Word Highlighting (Optional)

To sync the text back when the audio plays, listen to the timeupdate event and apply an active CSS class to the corresponding word:

wavesurfer.on('timeupdate', (currentTime) => {
  const words = transcriptContainer.querySelectorAll('.clickable-word');
  
  words.forEach((wordElement, index) => {
    const item = transcript[index];
    if (currentTime >= item.start && currentTime <= item.end) {
      wordElement.classList.add('active');
    } else {
      wordElement.classList.remove('active');
    }
  });
});
