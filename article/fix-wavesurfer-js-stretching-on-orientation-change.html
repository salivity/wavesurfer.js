Fix Wavesurfer.js Stretching on Orientation Change

When mobile devices switch between portrait and landscape modes, Wavesurfer.js waveforms often distort and stretch horizontally or vertically. This occurs because the rendered HTML5 <canvas> retains its pre-rotation pixel dimensions while its parent wrapper adapts immediately to the new screen width. Implementing the correct CSS container rules prevents these layout shifts and forces the waveform container to scale predictably during device orientation changes.

1. Apply min-width: 0 on Flexbox Parents

If your Wavesurfer container resides inside a CSS Flexbox layout, the default min-width: auto prevents the flex item from shrinking properly when rotating back from landscape to portrait. This causes the canvas to overflow and stretch the entire layout.

.waveform-flex-parent {
  display: flex;
  width: 100%;
}

.waveform-container {
  flex: 1;
  min-width: 0; /* Critical: allows container to shrink below content size */
}

2. Enforce Container Bounds and Hide Overflow

Restricting the container's bounding box prevents the canvas from breaking the layout while Wavesurfer recalculates its dimensions. Applying overflow: hidden clips visual distortion instantly during the rotation animation.

#waveform {
  width: 100%;
  position: relative;
  overflow: hidden;
  display: block;
}

3. Maintain Fixed or Defined Height

Wavesurfer.js calculates the canvas height based on the height parameter set during initialization. If the CSS container collapses or relies on dynamic viewport units (like vh) without a fallback, orientation shifts cause vertical aspect-ratio stretching. Set an explicit height on the container matching your Wavesurfer configuration.

#waveform {
  height: 128px; /* Match the 'height' option in your Wavesurfer config */
  max-height: 128px;
}

4. Normalize the Canvas Display via Deep Selectors

Wavesurfer generates nested wrappers and one or more <canvas> elements. By default, canvas elements behave as inline elements, introducing unwanted spacing and aspect-ratio skewing. Enforce block rendering and width constraints on the internal canvas elements:

#waveform ::part(wrapper),
#waveform > div {
  width: 100% !important;
  height: 100% !important;
}

#waveform canvas {
  display: block;
  max-width: 100%;
  height: 100% !important;
}

Complete Drop-In CSS Fix

Combine these rules to ensure the waveform container adapts cleanly across all screen sizes and orientations:

/* Container fix for orientation change distortion */
.audio-player-wrapper {
  display: flex;
  flex-direction: column;
  width: 100%;
  min-width: 0;
}

#waveform {
  width: 100%;
  height: 120px;
  min-width: 0;
  position: relative;
  overflow: hidden;
  box-sizing: border-box;
}

#waveform canvas {
  display: block;
  width: 100% !important;
  height: 100% !important;
  object-fit: fill;
}

These CSS rules visually lock the waveform dimensions during the orientation transition. Once the device finishes rotating, Wavesurfer's internal resize listeners will recalculate peaks and redraw the canvas cleanly at the exact new pixel ratio without layout jumps.
