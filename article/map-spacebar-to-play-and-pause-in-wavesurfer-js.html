Map Spacebar to Play and Pause in Wavesurfer.js

Integrating keyboard shortcuts into web audio applications significantly improves accessibility and user experience. This article explains how to capture spacebar presses using a standard JavaScript keydown event listener, prevent default browser scrolling behavior, ignore typing inside form fields, and map the key event directly to the Wavesurfer.js playback toggle method.

Setting Up the Keydown Listener

To control Wavesurfer.js playback with the keyboard, attach an event listener to the global window or document object that listens for the keydown event. When a key is pressed, the browser generates a KeyboardEvent object containing details about which key was pressed.

Identifying the Spacebar

The KeyboardEvent object provides two primary properties to identify keys: event.code and event.key. For mapping physical keyboard keys regardless of keyboard layout, event.code === 'Space' is the most reliable condition. Alternatively, checking event.key === ' ' or legacy event.keyCode === 32 works, but modern JavaScript standards favor event.code.

Preventing Default Page Scrolling

By default, pressing the spacebar in a web browser scrolls the viewport downward. To ensure the spacebar only affects audio playback, invoke event.preventDefault() immediately after confirming the spacebar was pressed.

Avoiding Conflicts with Form Elements

If a user is typing inside an <input>, <textarea>, or content-editable container, pressing the spacebar should register as a blank character rather than triggering audio playback. You can prevent this conflict by inspecting event.target.tagName.

Complete Implementation Example

Assuming an instance of Wavesurfer has already been initialized as wavesurfer, the mapping logic is implemented as follows:

// Initialize Wavesurfer instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/path/to/audio.mp3'
});

// Add the global keydown listener
window.addEventListener('keydown', (event) => {
  // Check if the pressed key is the spacebar
  if (event.code === 'Space') {
    // Ignore input if the user is typing in a form control
    const targetTag = event.target.tagName;
    if (targetTag === 'INPUT' || targetTag === 'TEXTAREA' || event.target.isContentEditable) {
      return;
    }

    // Stop default scrolling behavior
    event.preventDefault();

    // Toggle playback using the Wavesurfer API
    wavesurfer.playPause();
  }
});

How the Mapping Executes

When the user presses the spacebar:

  1. The keydown event fires on window.
  2. The conditional check verifies that the pressed key's code matches 'Space'.
  3. The event target check ensures focus is not inside an editable text area.
  4. event.preventDefault() suppresses the default scroll action.
  5. The wavesurfer.playPause() method is executed, which checks the internal playback state of the audio buffer and toggles between the playing and paused states.
