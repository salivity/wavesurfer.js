Monitor Horizontal Scroll in Wavesurfer.js

This guide explains how to track and respond to horizontal scroll position changes within the Wavesurfer.js audio visualization library. You will learn about the built-in event listener available in modern versions of the library, the data parameters it provides, and alternative methods for tracking scroll behavior in older implementations.

The scroll Event in Wavesurfer.js

In modern versions of Wavesurfer.js (version 7 and above), the primary event used to monitor horizontal scroll changes is the scroll event.

When a waveform overflows its container—typically configured via the minPxPerSec option or manual container styling—scrolling triggers this event. The event emits two floating-point numbers representing the visible range of the waveform as relative values between 0 and 1.

Implementation Example

You can attach an event listener directly to your Wavesurfer instance using the on method:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/audio-file.mp3',
  minPxPerSec: 100, // Enables horizontal scrolling for longer tracks
  autoScroll: true,
});

// Monitor horizontal scroll position changes
wavesurfer.on('scroll', (startPercent, endPercent) => {
  console.log(`Scroll Start: ${(startPercent * 100).toFixed(2)}%`);
  console.log(`Scroll End: ${(endPercent * 100).toFixed(2)}%`);
});

Event Parameters

  • startPercent: A number between 0 and 1 indicating the starting position of the currently visible viewport relative to the total audio length.
  • endPercent: A number between 0 and 1 indicating the ending position of the visible viewport.

Handling Scroll in Legacy Versions (v6 and Earlier)

In Wavesurfer.js v6 and earlier, a dedicated high-level scroll event was not part of the standard core instance. To monitor horizontal scrolling in legacy versions, you must attach a native DOM scroll listener directly to the scrollable wrapper element:

const wrapper = wavesurfer.drawer.wrapper;

wrapper.addEventListener('scroll', () => {
  const scrollLeft = wrapper.scrollLeft;
  const maxScroll = wrapper.scrollWidth - wrapper.clientWidth;
  const scrollProgress = scrollLeft / maxScroll;

  console.log(`Horizontal Scroll Position: ${scrollLeft}px`);
  console.log(`Progress: ${(scrollProgress * 100).toFixed(2)}%`);
});

Common Use Cases

  • Synchronizing Timelines: Aligning external UI elements, such as markers, minimaps, or lyric displays, with the currently visible segment of the audio track.
  • Lazy Loading: Loading peak data dynamically as the user scrolls through extremely long audio recordings.
  • UI Controls: Showing or hiding directional scroll indicator buttons when the user reaches the beginning or end of the waveform.
