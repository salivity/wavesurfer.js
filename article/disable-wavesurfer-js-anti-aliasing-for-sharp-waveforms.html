Disable Wavesurfer.js Anti-Aliasing for Sharp Waveforms

This guide explains how to disable canvas smoothing and anti-aliasing in Wavesurfer.js to achieve crisp, retro, pixelized waveform displays. By default, browsers apply anti-aliasing to HTML5 <canvas> elements, softening lines and peaks. You can override this behavior by combining Wavesurfer.js configuration options, canvas context properties, and CSS rules to produce a sharp, pixel-perfect visualization.

1. Adjust Wavesurfer.js Initialization Settings

Modern versions of Wavesurfer.js automatically scale the canvas to match the device's pixel ratio for smoother rendering. To create a raw, pixelated look, force a 1:1 pixel mapping and use clean integer values for bar widths and gaps:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  pixelRatio: 1, // Prevents automatic subpixel scaling
  barWidth: 2,   // Use integer pixel sizes
  barGap: 1,     // Consistent integer spacing
  barRadius: 0   // Disables rounded corners
});

Setting pixelRatio: 1 prevents subpixel interpolation, while setting barRadius: 0 ensures rectangular bars with sharp edges.

2. Apply CSS Image Rendering Properties

The most reliable way to force browsers to disable anti-aliasing across rendering engines is using CSS image-rendering rules on the generated <canvas> elements:

#waveform canvas {
  image-rendering: -moz-crisp-edges;         /* Firefox */
  image-rendering: -webkit-crisp-edges;      /* Webkit browsers */
  image-rendering: pixelated;                /* Standard Chrome, Edge, Safari */
  image-rendering: crisp-edges;              /* Modern standard */
}

Applying image-rendering: pixelated instructs the browser’s compositor to scale and render the canvas using nearest-neighbor interpolation rather than bilinear filtering, eliminating blurry edges.

3. Disable Context Smoothing in JavaScript

If you perform custom drawing or use plugins that redraw the canvas, disable image smoothing directly on the canvas's 2D rendering context:

wavesurfer.on('ready', () => {
  const container = document.querySelector('#waveform');
  const canvases = container.querySelectorAll('canvas');

  canvases.forEach((canvas) => {
    const ctx = canvas.getContext('2d');
    if (ctx) {
      ctx.imageSmoothingEnabled = false;
      ctx.webkitImageSmoothingEnabled = false;
      ctx.mozImageSmoothingEnabled = false;
      ctx.msImageSmoothingEnabled = false;
    }
  });
});

4. Align Coordinates to Whole Pixels

Subpixel values in bar dimensions or line widths can trigger anti-aliasing even when smoothing properties are disabled. Ensure any custom drawing logic or Wavesurfer styling coordinates fall directly on whole pixel increments (e.g., 1px, 2px) rather than fractional values (e.g., 1.5px) to prevent edge blurring.
