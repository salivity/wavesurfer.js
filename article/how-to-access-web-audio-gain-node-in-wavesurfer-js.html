How to Access Web Audio Gain Node in Wavesurfer.js

Accessing the Web Audio GainNode in Wavesurfer.js allows developers to manipulate volume, apply custom dynamic range adjustments, and route audio through custom processing graphs. In Wavesurfer.js, direct access to the native Web Audio GainNode is primarily achieved through the wavesurfer.backend.gainNode property when using the WebAudio backend, or by integrating a custom AudioContext with the media element in modern versions (v7+). This guide outlines the specific properties and implementation patterns required to access and control the gain node across different versions of the library.

Accessing the Gain Node in Wavesurfer.js (v6 and Earlier)

In Wavesurfer.js versions 6 and below, audio processing relies heavily on the built-in WebAudio backend. When an instance is initialized with this backend, the library creates and manages an internal Web Audio graph.

You access the gain node directly through the backend object:

// Access the native Web Audio GainNode
const gainNode = wavesurfer.backend.gainNode;

// Modify audio gain directly
gainNode.gain.setValueAtTime(0.5, wavesurfer.backend.ac.currentTime);

Key Components:

  • wavesurfer.backend: The internal controller managing audio playback and nodes.
  • wavesurfer.backend.gainNode: The instance of the browser's native GainNode used to scale the audio signal amplitude.
  • wavesurfer.backend.ac: The instance of AudioContext associated with the player.

Accessing the Gain Node in Wavesurfer.js v7+

Starting with Wavesurfer.js version 7, the architecture switched to standard HTML5 media elements (HTMLMediaElement) by default for performance and streaming efficiency. Because of this, a GainNode is not instantiated automatically unless you construct a Web Audio graph around the media element.

To access and control a GainNode in Wavesurfer.js v7+, use the getMediaElement() method to bridge the player into an AudioContext:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  url: '/audio.mp3',
});

wavesurfer.on('ready', () => {
  // Obtain the HTMLMediaElement from Wavesurfer
  const mediaElement = wavesurfer.getMediaElement();

  // Create an AudioContext and GainNode
  const audioContext = new (window.AudioContext || window.webkitAudioContext)();
  const sourceNode = audioContext.createMediaElementSource(mediaElement);
  const gainNode = audioContext.createGain();

  // Connect nodes to the destination output
  sourceNode.connect(gainNode);
  gainNode.connect(audioContext.destination);

  // Manipulate the gain node
  gainNode.gain.value = 1.5; // Boost volume
});

Standard Volume Control Alternatives

If low-level audio manipulation via AudioParam automation curves or custom node routing is not strictly required, Wavesurfer.js provides built-in methods to handle gain without referencing the underlying Web Audio node directly:

  • wavesurfer.setVolume(newVolume): Accepts a float between 0 (silent) and 1 (full volume) to scale output amplitude.
  • wavesurfer.getVolume(): Returns the current volume level of the instance.
