How to Install Wavesurfer.js via NPM

This guide explains how to install and configure Wavesurfer.js in modern web projects using Node Package Manager (NPM). You will learn the precise package name, the installation command, and the minimal code required to render an interactive, customizable audio waveform in your modern JavaScript or TypeScript applications.

The Official NPM Package

The official NPM package for Wavesurfer.js is simply named wavesurfer.js.

To add it to your project, run the following command in your terminal:

npm install wavesurfer.js

If you are using alternative package managers, use:

# Yarn
yarn add wavesurfer.js

# pnpm
pnpm add wavesurfer.js

Basic Implementation

In modern ES6+ projects, you import WaveSurfer directly from the package and mount it to an HTML container element.

HTML Setup

Create a container element in your HTML where the waveform will render:

<div id="waveform"></div>
<button id="playBtn">Play / Pause</button>

JavaScript Initialization

Import and initialize the library:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

const playButton = document.querySelector('#playBtn');
playButton.addEventListener('click', () => {
  wavesurfer.playPause();
});

Using Built-In Plugins

Starting with Wavesurfer.js version 7, official plugins are bundled directly inside the core wavesurfer.js package under the dist/plugins/ path. You do not need separate NPM packages for features like timelines or regions.

For example, to add a timeline:

import WaveSurfer from 'wavesurfer.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#A8DBA8',
  progressColor: '#3B8686',
  url: '/audio.mp3',
  plugins: [
    TimelinePlugin.create({
      container: '#waveform',
    }),
  ],
});

Using the official wavesurfer.js package ensures full compatibility with modern bundlers such as Vite, Webpack, and Rollup, as well as native TypeScript support.
