Add Custom Reverb to Wavesurfer.js with ConvolverNode

Integrating custom impulse response (IR) reverb into Wavesurfer.js requires connecting the Web Audio API's ConvolverNode directly into the audio rendering pipeline. This article outlines how to configure an AudioContext, load and decode a custom impulse response audio file, establish a parallel wet/dry routing graph, and bridge the entire setup to a Wavesurfer.js instance for real-time acoustic spatialization.

The ConvolverNode Routing Architecture

A standard reverb implementation requires splitting the dry audio signal from Wavesurfer.js into two parallel paths: one that remains unaffected (dry) and one processed through the convolution engine (wet).

The audio graph consists of:

  1. Source Node: The output audio generated or played by Wavesurfer.js.
  2. ConvolverNode: Processes the incoming signal using an impulse response AudioBuffer.
  3. GainNodes (Wet & Dry): Control the balance between the direct signal and the reverberated reflection.
  4. Destination: The final hardware audio output (audioContext.destination).
[Wavesurfer Source] ---> [Dry GainNode] --------------> [AudioContext Destination]
                   |                                       ^
                   ---> [ConvolverNode] ---> [Wet GainNode]-|

Step 1: Loading and Decoding the Impulse Response

The ConvolverNode requires an AudioBuffer containing the acoustic profile of a space. Fetch the impulse response file (typically a .wav file) as an ArrayBuffer and decode it using the active AudioContext.

async function loadImpulseResponse(audioContext, irUrl) {
  const response = await fetch(irUrl);
  const arrayBuffer = await response.arrayBuffer();
  return await audioContext.decodeAudioData(arrayBuffer);
}

Step 2: Configuring the Audio Graph

Create the processing nodes and assemble the parallel wet/dry mix architecture.

// Initialize a shared AudioContext
const audioContext = new (window.AudioContext || window.webkitAudioContext)();

// Create nodes
const convolver = audioContext.createConvolver();
const dryGain = audioContext.createGain();
const wetGain = audioContext.createGain();

// Set initial balance (e.g., 70% dry, 30% wet)
dryGain.gain.setValueAtTime(0.7, audioContext.currentTime);
wetGain.gain.setValueAtTime(0.3, audioContext.currentTime);

// Route wet path
convolver.connect(wetGain);
wetGain.connect(audioContext.destination);

// Route dry path
dryGain.connect(audioContext.destination);

// Load the IR buffer into the convolver
loadImpulseResponse(audioContext, '/path/to/impulse-response.wav')
  .then((buffer) => {
    convolver.buffer = buffer;
  });

Step 3: Connecting to Wavesurfer.js

Wavesurfer.js can be integrated by binding it to the custom AudioContext and routing its media element output through the created audio graph.

import WaveSurfer from 'wavesurfer.js';

// Initialize Wavesurfer with the shared AudioContext
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/track.mp3',
  audioContext: audioContext,
});

// Once ready, pipe the media element source into the nodes
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const source = audioContext.createMediaElementSource(mediaElement);

  // Split audio source into dry and wet paths
  source.connect(dryGain);
  source.connect(convolver);
});

Controlling Reverb Parameters

Dynamic adjustments during playback can be managed by updating the gain values:

  • Adjusting Reverb Depth: Change wetGain.gain.value between 0 (no reverb) and 1 (full reverb).
  • Adjusting Direct Volume: Change dryGain.gain.value between 0 and 1.
  • Switching Spaces: Replace the impulse response on the fly by decoding a new audio file and assigning the new AudioBuffer directly to convolver.buffer.
