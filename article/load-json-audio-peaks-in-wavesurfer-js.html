Load JSON Audio Peaks in Wavesurfer.js

Precomputing audio peaks and loading them via JSON significantly reduces browser CPU usage and bandwidth, allowing waveforms to render instantly without waiting for the full audio file to decode. This guide explains how to fetch precomputed peak data stored in a JSON file and pass it directly into a Wavesurfer.js instance for optimal rendering performance.

1. Understanding Peak Data Structure

Audio peak data is typically stored as a flat array of floating-point numbers representing amplitude values, or as a nested array for multi-channel audio.

A standard single-channel JSON file (peaks.json) looks like this:

{
  "version": 2,
  "channels": 1,
  "sample_rate": 44100,
  "samples_per_pixel": 512,
  "bits": 8,
  "length": 1200,
  "data": [0.01, -0.02, 0.45, -0.42, 0.89, -0.85, 0.12, -0.15]
}

Wavesurfer.js expects the peak data to be passed as an array of numbers (or an array of arrays for stereo) normalized between -1 and 1.

2. Loading Peaks into Wavesurfer.js

In modern versions of Wavesurfer.js (v7+), the load method accepts peak data and the audio duration as optional parameters. Providing the duration along with peaks is strongly recommended so the waveform correctly scales before the audio buffer finishes downloading.

Here is the complete implementation using standard JavaScript:

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize the Wavesurfer instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  cursorColor: '#312E81',
  barWidth: 2,
  barGap: 1,
  barRadius: 2,
});

async function loadAudioWithPeaks() {
  try {
    // 2. Fetch the JSON file containing precomputed peaks
    const response = await fetch('/path/to/peaks.json');
    const peakData = await response.json();

    // 3. Extract the array of peaks
    // Adapt this line depending on your JSON structure (e.g., peakData.data or just peakData)
    const peaks = peakData.data;

    // 4. Load the audio file along with the peaks and total duration (in seconds)
    const audioUrl = '/path/to/audio.mp3';
    const duration = 180; // Optional, but recommended for accurate scaling

    wavesurfer.load(audioUrl, peaks, duration);
  } catch (error) {
    console.error('Failed to load audio peaks:', error);
  }
}

loadAudioWithPeaks();

3. Using Peaks via Initialization Options

Alternatively, if you already have the peak array available when instantiating Wavesurfer, you can define the peaks directly in the configuration object:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',

  duration: 180,
