Double Tap to Seek in Wavesurfer.js on Mobile

Implementing touch gestures like double-tap in a custom Wavesurfer.js audio player enables mobile users to skip forward or backward efficiently, mirroring popular media streaming interfaces. This guide details how to intercept native mobile touch events, distinguish double-taps from standard interactions, determine the seek direction, and programmatically adjust playback positions using the Wavesurfer.js API.

The Mechanism Behind Gesture-Based Seeking

Wavesurfer.js handles standard pointer interactions such as dragging and tapping on the waveform to reposition playback. However, it does not include native multi-tap gesture detection. To implement double-tap seeking, developers overlay a transparent gesture layer on top of the waveform or listen directly to touch events on the player container.

The process involves four key steps:

  1. Capturing touchstart or touchend events.
  2. Tracking the time interval and spatial distance between consecutive taps.
  3. Evaluating the horizontal position of the tap to determine whether to skip backward or forward.
  4. Calling Wavesurfer.js methods to shift playback by a fixed time offset.

Capturing and Identifying Double-Taps

Mobile browsers do not provide a native doubletap event, requiring detection through manual state tracking. An effective implementation monitors the timestamp and coordinates of touch events:

  • Time threshold: Two taps occurring within roughly 250 to 300 milliseconds represent a double-tap.
  • Distance threshold: The distance between tap coordinates should remain within a small radius (typically 20 to 30 pixels) to avoid mistaking swipes or scrolling for double-taps.
let lastTapTime = 0;
let lastTapX = 0;
const TAP_DELAY = 300;
const TAP_MAX_DISTANCE = 30;

const gestureContainer = document.getElementById('waveform-container');

gestureContainer.addEventListener('touchend', (e) => {
  const currentTime = new Date().getTime();
  const tapLength = currentTime - lastTapTime;
  const touch = e.changedTouches[0];
  const currentX = touch.clientX;
  const distance = Math.abs(currentX - lastTapX);

  if (tapLength < TAP_DELAY && tapLength > 0 && distance < TAP_MAX_DISTANCE) {
    // Double-tap detected
    handleDoubleTap(touch, gestureContainer);
    e.preventDefault(); // Prevent default zoom or synthetic click actions
  }

  lastTapTime = currentTime;
  lastTapX = currentX;
});

Determining Seek Direction

Once a double-tap is verified, the player must decide whether to jump backward or forward. This is achieved by comparing the touch's horizontal screen coordinate against the bounding box of the player container:

function handleDoubleTap(touch, container) {
  const rect = container.getBoundingClientRect();
  const tapOffset = touch.clientX - rect.left;
  const containerWidth = rect.width;

  // Split container into left and right zones
  if (tapOffset < containerWidth / 2) {
    seekRelative(-10); // Rewind 10 seconds
  } else {
    seekRelative(10);  // Skip forward 10 seconds
  }
}

Applying the Seek in Wavesurfer.js

Depending on the version of Wavesurfer.js in use, the method to update the audio position varies:

  • Wavesurfer.js v7+: Use wavesurfer.setTime(seconds).
  • Wavesurfer.js v6 and earlier: Use wavesurfer.seekTo(progress), where progress is a normalized value between 0 and 1.

In modern Wavesurfer.js implementations, relative seeking is computed using getCurrentTime() and getDuration():

function seekRelative(seconds) {
  const currentTime = wavesurfer.getCurrentTime();
  const duration = wavesurfer.getDuration();
  
  // Calculate new time clamped between 0 and track duration
  const targetTime = Math.min(Math.max(currentTime + seconds, 0), duration);
  
  wavesurfer.setTime(targetTime);
}

Resolving Interaction Conflicts

A primary challenge with custom touch gestures is preventing conflicts with Wavesurfer’s built-in click-to-seek functionality:

  1. Dedicated Gesture Overlays: Placing a dedicated touch layer over the player allows complete isolation of touch events. Single taps can be held in a timer buffer (e.g., 250ms) to verify that a second tap does not follow before passing a single-seek or play/pause command to Wavesurfer.
  2. Disabling Built-in Interactivity: Setting interact: false in the Wavesurfer configuration completely disables default waveform click-and-drag listeners. This gives the custom gesture handler total control over all seeking, scrubbing, and tapping behaviors.
