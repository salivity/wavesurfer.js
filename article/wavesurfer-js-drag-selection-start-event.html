Wavesurfer.js Drag Selection Start Event

When implementing click-and-drag functionality to select an audio segment in Wavesurfer.js using the Regions plugin, the primary event that fires at the beginning of the selection is region-created. This article explains how this event operates, how it integrates with the enableDragSelection feature, and how to track the subsequent updates as dragging continues.

The Event: region-created

In Wavesurfer.js (version 7 and above), user drag-selection is managed via the Regions plugin (wavesurfer.js/dist/plugins/regions.esm.js). When drag selection is activated using wsRegions.enableDragSelection(), clicking and initiating a drag on the waveform instantly instantiates a new region.

The moment this drag interaction begins, the plugin triggers the region-created event.

Code Implementation (Wavesurfer.js v7+)

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/audio.mp3',
});

// Initialize the Regions plugin
const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

// Enable drag-to-select
wsRegions.enableDragSelection({
  color: 'rgba(255, 0, 0, 0.1)',
});

// Event that fires when dragging starts and a new region is generated
wsRegions.on('region-created', (region) => {
  console.log('User started dragging to select a region:', region);
});

Related Drag-Selection Events

While region-created indicates the start of the drag-selection process, subsequent interaction lifecycle events provide continuous feedback:

  1. region-updated: Fires continuously on the wsRegions instance (or on the individual region instance) as the user extends or shrinks the selection boundary by continuing to drag the cursor.
  2. region-clicked: Fires if the user clicks inside the region boundary after selection.
  3. region-out / region-in: Fire when the playback cursor enters or leaves the selected boundary.

To monitor when the user finishes dragging and releases the mouse, listen to the region-updated event or native pointer release events on the document window.

Legacy Versions (Wavesurfer.js v6 and Below)

In older versions of Wavesurfer.js, plugins attached events directly to the root wavesurfer instance rather than the plugin instance:

// Legacy syntax (v4 - v6)
wavesurfer.on('region-created', function(region) {
  console.log('Drag selection started:', region);
});

wavesurfer.on('region-update-end', function(region) {
  console.log('Drag selection completed:', region);
});
