Accessible Play Pause Button in Wavesurfer.js

This guide explains how to build an accessible play/pause control button for an audio waveform using Wavesurfer.js. You will learn how to structure the HTML using semantic elements and ARIA attributes, initialize the Wavesurfer instance, and synchronize the button's visual and assistive states with audio playback events.

1. Semantic HTML Structure

An accessible audio toggle must use a native <button> element rather than a generic <div> or <span>. Native buttons provide keyboard accessibility out of the box (Enter and Space key activation, native focus states).

Use the aria-pressed attribute to indicate a toggle state to assistive technologies, and provide clear descriptive text using an aria-label or an embedded icon with screen-reader text.

<div id="waveform"></div>

<button 
  id="playPauseBtn" 
  type="button" 
  aria-label="Play audio" 
  aria-pressed="false"
>
  <span id="btnText">Play</span>
</button>

2. Initializing Wavesurfer.js

Load the Wavesurfer.js library and instantiate a player targeting your container element.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
});

3. Synchronizing Button State with Audio Events

Do not rely solely on the button's click event to toggle the UI labels. Audio playback can be triggered or halted by external events, buffering, or reaching the end of the file. Instead, listen directly to Wavesurfer's lifecycle events (play, pause, and finish) to keep the DOM and accessibility tree accurate.

const playPauseBtn = document.getElementById('playPauseBtn');
const btnText = document.getElementById('btnText');

// Toggle playback on user click
playPauseBtn.addEventListener('click', () => {
  wavesurfer.playPause();
});

// Update UI when audio starts playing
wavesurfer.on('play', () => {
  playPauseBtn.setAttribute('aria-label', 'Pause audio');
  playPauseBtn.setAttribute('aria-pressed', 'true');
  btnText.textContent = 'Pause';
});

// Update UI when audio pauses
wavesurfer.on('pause', () => {
  playPauseBtn.setAttribute('aria-label', 'Play audio');
  playPauseBtn.setAttribute('aria-pressed', 'false');
  btnText.textContent = 'Play';
});

// Reset UI when audio reaches the end
wavesurfer.on('finish', () => {
  playPauseBtn.setAttribute('aria-label', 'Play audio');
  playPauseBtn.setAttribute('aria-pressed', 'false');
  btnText.textContent = 'Play';
});

4. Keyboard Navigation and Focus Styles

Ensure the button retains a visible focus indicator for keyboard users navigating via the Tab key. Avoid removing CSS outlines without providing an alternative focus indicator:

#playPauseBtn {
  padding: 0.5rem 1rem;
  font-size: 1rem;
  cursor: pointer;
}

#playPauseBtn:focus-visible {
  outline: 2px solid #4F46E5;
  outline-offset: 2px;
}

By mapping the interactive state to standard ARIA attributes and listening to Wavesurfer's native event emitters, the control remains fully accessible to screen readers, keyboard-only users, and standard pointer inputs.
