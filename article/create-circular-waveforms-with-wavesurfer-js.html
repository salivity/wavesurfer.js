Create Circular Waveforms with Wavesurfer.js

This guide explains how to generate a circular waveform visualization using Wavesurfer.js. While Wavesurfer.js renders linear horizontal waveforms by default, you can leverage its audio decoding pipeline alongside custom plugins or HTML5 Canvas extensions to project peak data radially. Below, you will learn the mechanics of transforming linear peak data into polar coordinates, setting up the custom renderer, and synchronizing the circular visual with real-time playback.

Understanding Circular Waveform Architecture

Standard audio waveforms place time along the horizontal X-axis and amplitude along the vertical Y-axis. A circular or radial waveform projects these values using polar coordinates:

  • Angle (\(\theta\)): Represents time (from 0 to \(2\pi\) radians).
  • Radius (\(r\)): Represents the amplitude or peak value at each given time point.

To achieve this in Wavesurfer.js, you utilize the library to fetch and decode the audio file into channel data (peaks), bypass or supplement the default linear canvas, and draw the visual using native Canvas 2D rendering methods.

Step 1: Initialize Wavesurfer.js to Extract Peaks

First, initialize a minimal Wavesurfer instance. You can hide the default container or set its height to zero if you only plan to display the circular visualizer.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform-hidden',
  waveColor: 'transparent',
  progressColor: 'transparent',
  height: 0,
});

wavesurfer.load('path-to-your-audio.mp3');

Step 2: Create the Circular Renderer Canvas

Add an HTML canvas element where the circular waveform will be drawn:

<canvas id="circular-waveform" width="500" height="500"></canvas>

Step 3: Implement the Custom Circular Plugin Logic

Using the decoded audio data, extract the channel peaks and map them into a full circle (\(360^\circ\) or \(2\pi\) radians). Create a function or custom extension that listens to the ready and audioprocess events.

const canvas = document.getElementById('circular-waveform');
const ctx = canvas.getContext('2d');

const centerX = canvas.width / 2;
const centerY = canvas.height / 2;
const baseRadius = 80;
const maxBarHeight = 60;

function drawCircularWaveform(peaks, progress = 0) {
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  const totalBars = peaks.length;
  const angleStep = (Math.PI * 2) / totalBars;

  for (let i = 0; i < totalBars; i++) {
    const angle = i * angleStep - Math.PI / 2; // Start from top
    const barHeight = Math.abs(peaks[i]) * maxBarHeight;

    // Determine color based on playback progress
    const currentProgress = i / totalBars;
    ctx.strokeStyle = currentProgress <= progress ? '#ff0055' : '#cccccc';
    ctx.lineWidth = 2;

    // Calculate inner and outer coordinates
    const startX = centerX + Math.cos(angle) * baseRadius;
    const startY = centerY + Math.sin(angle) * baseRadius;
    const endX = centerX + Math.cos(angle) * (baseRadius + barHeight);
    const endY = centerY + Math.sin(angle) * (baseRadius + barHeight);

    // Draw radial line
    ctx.beginPath();
    ctx.moveTo(startX, startY);
    ctx.lineTo(endX, endY);
    ctx.stroke();
  }
}

Step 4: Bind Wavesurfer.js Events to the Visualizer

Connect Wavesurfer's decoded audio data and playback listeners to the circular render loop:

let audioPeaks = [];

wavesurfer.on('ready', () => {
  // Extract decoded channel data
  const decodedData = wavesurfer.getDecodedData();
  if (decodedData) {
    const rawData = decodedData.getChannelData(0);
    const samples = 180; // Number of bars along the circle
    const blockSize = Math.floor(rawData.length / samples);
    audioPeaks = [];

    for (let i = 0; i < samples; i++) {
      let sum = 0;
      for (let j = 0; j < blockSize; j++) {
        sum += Math.abs(rawData[i * blockSize + j]);
      }
      audioPeaks.push(sum / blockSize);
    }

    drawCircularWaveform(audioPeaks, 0);
  }
});

// Update progress visual on playback
wavesurfer.on('audioprocess', () => {
  const progress = wavesurfer.getCurrentTime() / wavesurfer.getDuration();
  drawCircularWaveform(audioPeaks, progress);
});

// Update on seek
wavesurfer.on('seeking', () => {
  const progress = wavesurfer.getCurrentTime() / wavesurfer.getDuration();
  drawCircularWaveform(audioPeaks, progress);
});

Optional: Real-Time Frequency Waveforms

If you require a live, reactive circular visualizer instead of static peaks, use the Wavesurfer.js Record or Web Audio Analyzer nodes. Replace the static peak array with frequency data captured via AnalyserNode.getByteFrequencyData() inside a requestAnimationFrame loop, applying the same polar coordinate formulas shown above.
