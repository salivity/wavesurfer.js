How to Download Audio Recordings in Wavesurfer.js

This guide explains how to capture microphone input, display it as a waveform, and export the recorded audio file to a user's local device using Wavesurfer.js. By pairing the core library with the official Record plugin, you can capture an audio stream, retrieve the resulting audio Blob, and trigger a browser download through dynamically generated anchor elements.

1. Include Wavesurfer.js and the Record Plugin

First, ensure you have imported both the core Wavesurfer.js package and its Record plugin. You can load them via ES modules or a CDN:

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/plugins/record.min.js"></script>

2. Set Up the HTML Interface

Create a container for the waveform visualization and provide controls for recording, stopping, and downloading:

<div id="mic-waveform"></div>
<button id="record-btn">Record</button>
<button id="stop-btn" disabled>Stop</button>
<a id="download-link" style="display: none;">Download Audio</a>

3. Initialize Wavesurfer and the Record Plugin

Instantiate Wavesurfer and register the RecordPlugin. The plugin handles permissions, streams microphone input to the canvas, and compiles the recorded audio chunks into a Blob.

const wavesurfer = WaveSurfer.create({
  container: '#mic-waveform',
  waveColor: '#4F46E5',
  progressColor: '#312E81',
});

// Initialize the Record plugin
const record = wavesurfer.registerPlugin(
  WaveSurfer.Record.create({
    scrollingWaveform: true,
    renderRecordedAudio: false,
  })
);

4. Capture the Recorded Blob and Enable Download

The Record plugin emits a record-end event once recording stops. This event supplies the recorded audio as a Blob. You convert this Blob into a temporary URL using URL.createObjectURL() and assign it to an HTML <a> element configured with the download attribute.

const recordBtn = document.getElementById('record-btn');
const stopBtn = document.getElementById('stop-btn');
const downloadLink = document.getElementById('download-link');

// Start recording
recordBtn.addEventListener('click', async () => {
  await record.startRecording();
  recordBtn.disabled = true;
  stopBtn.disabled = false;
  downloadLink.style.display = 'none';
});

// Stop recording
stopBtn.addEventListener('click', () => {
  record.stopRecording();
  recordBtn.disabled = false;
  stopBtn.disabled = true;
});

// Handle the finished recording
record.on('record-end', (blob) => {
  // Determine file extension based on MIME type (default is usually audio/webm)
  const mimeType = blob.type || 'audio/webm';
  const extension = mimeType.split(';')[0].split('/')[1] || 'webm';

  // Create an object URL from the blob
  const audioUrl = URL.createObjectURL(blob);

  // Configure the download link
  downloadLink.href = audioUrl;
  downloadLink.download = `recording-${Date.now()}.${extension}`;
  downloadLink.textContent = `Download Recording (.${extension})`;
  downloadLink.style.display = 'inline-block';
});

5. Triggering Programmatic Downloads

If you prefer to download the file automatically as soon as the recording stops without requiring the user to click a separate link, invoke the download programmatically:

record.on('record-end', (blob) => {
  const audioUrl = URL.createObjectURL(blob);
  const anchor = document.createElement('a');
  
  anchor.href = audioUrl;
  anchor.download = `audio-recording-${Date.now()}.webm`;
  document.body.appendChild(anchor);
  anchor.click();
  
  // Cleanup
  document.body.removeChild(anchor);
  URL.revokeObjectURL(audioUrl);
});

This pattern ensures recorded audio buffer data is securely saved directly onto the user's local disk without requiring server-side processing.
