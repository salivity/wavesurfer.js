Customize Hover Timestamp Format in Wavesurfer.js

This guide explains how to customize the hover timestamp format in Wavesurfer.js using the official Hover plugin. By default, Wavesurfer.js renders standard time strings, but you can override this behavior by implementing a custom time formatting function. Below, you will find a direct explanation of the required configuration and working code examples to format hover labels into minutes, seconds, or milliseconds.

Using the Hover Plugin

In Wavesurfer.js (version 7 and newer), the hover timestamp is managed by the Hover plugin. This plugin accepts a configuration object containing the formatTimeCallback property. This function receives the current hover position in seconds as a floating-point number and must return a formatted string.

Basic Implementation

To customize the display, import the Hover plugin alongside Wavesurfer.js, define your formatting logic, and pass it to the plugin options.

import WaveSurfer from 'wavesurfer.js';
import Hover from 'wavesurfer.js/dist/plugins/hover.esm.js';

// Initialize Wavesurfer with the Hover plugin
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio-file.mp3',
  plugins: [
    Hover.create({
      lineColor: '#ff0000',
      lineWidth: 2,
      labelBackground: '#222',
      labelColor: '#fff',
      labelSize: '11px',
      // Custom format function
      formatTimeCallback: (seconds) => {
        const minutes = Math.floor(seconds / 60);
        const remainingSeconds = Math.floor(seconds % 60);
        const paddedSeconds = remainingSeconds < 10 ? `0${remainingSeconds}` : remainingSeconds;
        return `${minutes}:${paddedSeconds}`;
      },
    }),
  ],
});

Advanced Formatting Examples

Depending on your requirements, you can format the time to include fractions of a second or hours.

Including Milliseconds (MM:SS.mmm)

For audio editing or precise navigation, include milliseconds by extracting decimal values:

formatTimeCallback: (seconds) => {
  const minutes = Math.floor(seconds / 60);
  const secs = Math.floor(seconds % 60);
  const millis = Math.floor((seconds % 1) * 1000);

  const formattedMin = String(minutes).padStart(2, '0');
  const formattedSec = String(secs).padStart(2, '0');
  const formattedMs = String(millis).padStart(3, '0');

  return `${formattedMin}:${formattedSec}.${formattedMs}`;
}

Including Hours (HH:MM:SS)

For long-form audio like podcasts or full recordings:

formatTimeCallback: (seconds) => {
  const hours = Math.floor(seconds / 3600);
  const minutes = Math.floor((seconds % 3600) / 60);
  const remainingSeconds = Math.floor(seconds % 60);

  const pad = (num) => String(num).padStart(2, '0');

  return hours > 0
    ? `${pad(hours)}:${pad(minutes)}:${pad(remainingSeconds)}`
    : `${pad(minutes)}:${pad(remainingSeconds)}`;
}
