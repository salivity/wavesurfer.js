How to Mock Web Audio API for Wavesurfer.js in Jest

Testing audio visualization libraries like Wavesurfer.js in Jest presents unique challenges because Jest's default environment, jsdom, lacks implementations for the Web Audio API and HTML5 Canvas. To run unit and integration tests for Wavesurfer.js without encountering runtime crashes such as TypeError: window.AudioContext is not a constructor, you must supply mock implementations for AudioContext, OfflineAudioContext, associated audio nodes, and canvas rendering methods. This article provides the specific Jest mocks required to simulate these browser elements effectively.

Essential Web Audio API Mocks

Wavesurfer.js relies on the Web Audio API to decode, process, and control audio streams. At a minimum, you must mock AudioContext (and its vendor-prefixed variant webkitAudioContext) alongside its factory methods and node connections.

Here is the base mock configuration to include in your jest.setup.js file:

// Mock standard AudioNode behavior
const createMockAudioNode = () => ({
  connect: jest.fn(),
  disconnect: jest.fn(),
  addEventListener: jest.fn(),
  removeEventListener: jest.fn(),
});

// Mock AudioContext
class MockAudioContext {
  constructor() {
    this.state = 'suspended';
    this.sampleRate = 44100;
    this.currentTime = 0;
    this.destination = createMockAudioNode();
  }

  createGain() {
    return {
      ...createMockAudioNode(),
      gain: { value: 1, setValueAtTime: jest.fn(), linearRampToValueAtTime: jest.fn() },
    };
  }

  createAnalyser() {
    return {
      ...createMockAudioNode(),
      frequencyBinCount: 1024,
      fftSize: 2048,
      getByteTimeDomainData: jest.fn(),
      getByteFrequencyData: jest.fn(),
    };
  }

  createMediaElementSource() {
    return createMockAudioNode();
  }

  createBufferSource() {
    return {
      ...createMockAudioNode(),
      buffer: null,
      start: jest.fn(),
      stop: jest.fn(),
      loop: false,
    };
  }

  createBuffer(numberOfChannels, length, sampleRate) {
    return {
      numberOfChannels,
      length,
      sampleRate,
      duration: length / sampleRate,
      getChannelData: jest.fn(() => new Float32Array(length)),
      copyFromChannel: jest.fn(),
      copyToChannel: jest.fn(),
    };
  }

  decodeAudioData(audioData, successCallback) {
    const mockBuffer = this.createBuffer(2, 44100, 44100);
    if (successCallback) {
      successCallback(mockBuffer);
    }
    return Promise.resolve(mockBuffer);
  }

  resume() {
    this.state = 'running';
    return Promise.resolve();
  }

  suspend() {
    this.state = 'suspended';
    return Promise.resolve();
  }

  close() {
    this.state = 'closed';
    return Promise.resolve();
  }
}

window.AudioContext = MockAudioContext;
window.webkitAudioContext = MockAudioContext;

OfflineAudioContext Mock

Wavesurfer.js often uses OfflineAudioContext for rendering waveforms without playing back audio in real time.

class MockOfflineAudioContext extends MockAudioContext {
  constructor(numberOfChannels, length, sampleRate) {
    super();
    this.length = length;
    this.sampleRate = sampleRate;
    this.numberOfChannels = numberOfChannels;
  }

  startRendering() {
    const buffer = this.createBuffer(this.numberOfChannels, this.length, this.sampleRate);
    return Promise.resolve(buffer);
  }
}

window.OfflineAudioContext = MockOfflineAudioContext;
window.webkitOfflineAudioContext = MockOfflineAudioContext;

Canvas and DOM Dependencies

Wavesurfer.js renders visual waveforms directly onto HTML5 Canvas elements and occasionally creates object URLs for audio blobs. Because jsdom provides only stub implementations of canvas methods, you must mock the 2D rendering context:

HTMLCanvasElement.prototype.getContext = jest.fn(() => ({
  fillRect: jest.fn(),
  clearRect: jest.fn(),
  getImageData: jest.fn(() => ({ data: new Array(4) })),
  putImageData: jest.fn(),
  createImageData: jest.fn(() => []),
  setTransform: jest.fn(),
  drawImage: jest.fn(),
  save: jest.fn(),
  restore: jest.fn(),
  beginPath: jest.fn(),
  moveTo: jest.fn(),
  lineTo: jest.fn(),
  closePath: jest.fn(),
  stroke: jest.fn(),
  fill: jest.fn(),
  scale: jest.fn(),
  translate: jest.fn(),
}));

// Mock Object URL generation
window.URL.createObjectURL = jest.fn(() => 'blob:mock-url');
window.URL.revokeObjectURL = jest.fn();

Alternative: Using Existing NPM Packages

If you prefer an external dependency instead of maintaining mock files manually, install standardized-audio-context-mock or web-audio-test-api:

npm install --save-dev web-audio-test-api

Import it in your setup file to automatically polyfill the missing Web Audio nodes:

import 'web-audio-test-api';

Note that even when using an audio mock library, you will still need to mock HTMLCanvasElement.prototype.getContext and URL.createObjectURL to prevent Canvas-related errors during Wavesurfer.js component rendering.
