Setting Fetch Credentials in Wavesurfer.js

This article explains how to configure audio fetch credentials in Wavesurfer.js when loading audio files that require authentication cookies, HTTP authorization, or cross-origin requests. It identifies the exact configuration parameters used in modern versions of the library, outlines the available credential options, and provides practical code examples for implementation.

In modern Wavesurfer.js (version 7 and newer), the parameter used to define the audio fetch credentials mode is credentials, located inside the fetchParams configuration object. Because Wavesurfer.js uses the native JavaScript Fetch API under the hood, fetchParams accepts standard RequestInit properties.

Using fetchParams in Wavesurfer.js

To define the credentials mode, pass fetchParams with the credentials property into WaveSurfer.create() during initialization:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#312E81',
  url: 'https://example.com/audio/sample.mp3',
  fetchParams: {
    credentials: 'include',
  },
});

Supported Credentials Modes

The credentials property accepts three standard Fetch API values:

  • 'same-origin': (Default) Sends user credentials such as cookies and basic authentication headers only if the audio file resides on the same origin as the application.
  • 'include': Always sends user credentials, even when requesting audio from a cross-origin resource. This is required when fetching protected audio from external APIs or storage buckets requiring session cookies.
  • 'omit': Never sends credentials with the request, ignoring cookies or HTTP authentication even if the user is authenticated.

Legacy Support (Wavesurfer.js v6 and Earlier)

In older versions of Wavesurfer.js that relied on XMLHttpRequest instead of the Fetch API, credentials were configured using the xhr parameter and the withCredentials boolean flag:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  xhr: {
    withCredentials: true,
  },
});

For any modern project, define credentials within the fetchParams object to properly handle authentication when fetching audio streams.
