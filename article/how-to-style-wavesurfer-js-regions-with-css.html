How to Style Wavesurfer.js Regions with CSS

Customizing the visual appearance of regions in the Wavesurfer.js Regions plugin is essential for matching audio segments to your application's design system. This guide explains how to apply custom CSS to audio regions, modify handle elements for resizing, and implement state-based styles such as hover and active states using both JavaScript options and global CSS selectors.

Targeting Default Region Classes

Wavesurfer.js creates HTML elements in the DOM for every region added to the waveform. By default, the wrapper element contains the class .wavesurfer-region, along with built-in child elements representing resize handles.

You can target these built-in classes directly in your CSS:

/* Base region container */
.wavesurfer-region {
  border-left: 2px solid #2563eb !important;
  border-right: 2px solid #2563eb !important;
  transition: background-color 0.2s ease;
}

/* Region hover state */
.wavesurfer-region:hover {
  background-color: rgba(37, 99, 235, 0.2) !important;
}

/* Customizing the resize handles */
.wavesurfer-handle {
  width: 4px !important;
  background-color: #1d4ed8 !important;
  opacity: 0.8;
}

.wavesurfer-handle:hover {
  opacity: 1;
}

Adding Custom Classes via JavaScript

To style individual regions differently (for example, to distinguish between different types of audio tags or markers), attach custom CSS classes directly to the region's DOM element upon creation.

When using Wavesurfer.js v7+, the addRegion method returns a Region instance containing an element property:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#rgb(200, 200, 200)',
  progressColor: '#rgb(100, 100, 100)',
});

const wsRegions = ws.registerPlugin(RegionsPlugin.create());

// Create a region
const region = wsRegions.addRegion({
  start: 2,
  end: 6,
  color: 'transparent', // Disable default inline background color
  drag: true,
  resize: true,
});

// Add your custom class directly to the region element
region.element.classList.add('custom-region-highlight');

Styling the Custom Class

Once the custom class is assigned, apply your specific visual rules in CSS:

.custom-region-highlight {
  background: linear-gradient(180deg, rgba(16, 185, 129, 0.15), rgba(16, 185, 129, 0.35));
  border-top: 1px dashed #10b981;
  border-bottom: 1px dashed #10b981;
  border-radius: 4px;
}

/* Style handles specifically for this custom region */
.custom-region-highlight .wavesurfer-handle-start {
  border-top-left-radius: 4px;
  border-bottom-left-radius: 4px;
}

.custom-region-highlight .wavesurfer-handle-end {
  border-top-right-radius: 4px;
  border-bottom-right-radius: 4px;
}

Styling Custom Region Content

You can also pass custom HTML or DOM elements into the content property of a region to display titles, icons, or action buttons inside the region:

wsRegions.addRegion({
  start: 8,
  end: 12,
  content: '<span class="region-label">Chorus</span>',
  color: 'rgba(239, 68, 68, 0.2)',
});

Format the inner content with CSS:

.region-label {
  font-family: sans-serif;
  font-size: 12px;
  font-weight: 600;
  color: #b91c1c;
  padding: 4px 8px;
  pointer-events: none; /* Prevents text selection while dragging */
  user-select: none;
}
