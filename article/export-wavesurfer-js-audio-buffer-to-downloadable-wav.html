Export Wavesurfer.js AudioBuffer to Downloadable WAV

This article outlines the process of converting edited audio data from Wavesurfer.js into a downloadable file format. It covers extracting the underlying AudioBuffer, encoding the raw pulse-code modulation (PCM) data into a standard WAV container, generating a binary Blob, and triggering a client-side download using browser APIs.

1. Extract the AudioBuffer

Wavesurfer.js renders and manipulates audio using the Web Audio API. When an audio track is loaded or modified, the raw audio data resides inside an AudioBuffer.

To retrieve this data, call:

const audioBuffer = wavesurfer.getDecodedData();

This object contains crucial metadata—such as sampleRate, numberOfChannels, and length—as well as the raw audio samples accessible via audioBuffer.getChannelData(channelNumber).

2. Encode PCM Data into a WAV Container

Browsers do not natively provide a method to convert an AudioBuffer directly into an encoded file. You must interleave the channel data (if stereo) and prepend a standard 44-byte WAV header containing the RIFF identifier, format chunks, channel count, sample rate, and byte rates.

The core encoding logic involves:

  1. Interleaving Channels: Merge separate channel float arrays into a single alternating stream (Left, Right, Left, Right).
  2. Quantization: Convert 32-bit floating-point samples (-1.0 to 1.0) into 16-bit signed integers (-32768 to 32767).
  3. Writing Header Bytes: Use a DataView over an ArrayBuffer to write ASCII markers (RIFF, WAVE, fmt, data) and structural binary data.
function audioBufferToWav(buffer) {
  const numChannels = buffer.numberOfChannels;
  const sampleRate = buffer.sampleRate;
  const format = 1; // PCM
  const bitDepth = 16;
  
  const bytesPerSample = bitDepth / 8;
  const blockAlign = numChannels * bytesPerSample;
  
  // Interleave channel data
  const length = buffer.length * numChannels;
  const data = new Int16Array(length);
  const channels = [];
  
  for (let i = 0; i < numChannels; i++) {
    channels.push(buffer.getChannelData(i));
  }

  let offset = 0;
  for (let i = 0; i < buffer.length; i++) {
    for (let channel = 0; channel < numChannels; channel++) {
      const sample = Math.max(-1, Math.min(1, channels[channel][i]));
      data[offset++] = sample < 0 ? sample * 0x8000 : sample * 0x7FFF;
    }
  }

  // Create WAV container
  const wavBuffer = new ArrayBuffer(44 + data.length * 2);
  const view = new DataView(wavBuffer);

  function writeString(view, offset, string) {
    for (let i = 0; i < string.length; i++) {
      view.setUint8(offset + i, string.charCodeAt(i));
    }
  }

  // RIFF chunk descriptor
  writeString(view, 0, 'RIFF');
  view.setUint32(4, 36 + data.length * 2, true);
  writeString(view, 8, 'WAVE');
  
  // "fmt " sub-chunk
  writeString(view, 12, 'fmt ');
  view.setUint32(16, 16, true); // Subchunk1Size (16 for PCM)
  view.setUint16(20, format, true);
  view.setUint16(22, numChannels, true);
  view.setUint32(24, sampleRate, true);
  view.setUint32(28, sampleRate * blockAlign, true);
  view.setUint16(32, blockAlign, true);
  view.setUint16(34, bitDepth, true);

  // "data" sub-chunk
  writeString(view, 36, 'data');
  view.setUint32(40, data.length * 2, true);

  // Write PCM audio data
  const pcmView = new Int16Array(wavBuffer, 44);
  pcmView.set(data);

  return wavBuffer;
}

3. Package the ArrayBuffer into a Blob

Once the binary ArrayBuffer containing both the header and PCM payload is ready, wrap it inside an immutable Blob (Binary Large Object) instance. Specify the MIME type as audio/wav.

const wavArrayBuffer = audioBufferToWav(audioBuffer);
const audioBlob = new Blob([wavArrayBuffer], { type: 'audio/wav' });

4. Trigger the File Download

To allow the user to save the file locally, generate an ephemeral DOM reference using URL.createObjectURL(), attach it to a temporary anchor element, and programmatically invoke a click event.

function downloadBlob(blob, filename = 'edited-audio.wav') {
  const url = URL.createObjectURL(blob);
  const anchor = document.createElement('a');
  
  anchor.style.display = 'none';
  anchor.href = url;
  anchor.download = filename;

  document.body.appendChild(anchor);
  anchor.click();

  // Clean up references
  document.body.removeChild(anchor);
  URL.revokeObjectURL(url);
}

// Execution
downloadBlob(audioBlob, 'output.wav');

This sequence completely packages client-side edits from Wavesurfer.js into an industry-standard WAV file without requiring server-side rendering or external conversion services.
