Lock Wavesurfer.js Timeline to BPM and Measures

By default, the Wavesurfer.js Timeline plugin renders intervals based on standard temporal units such as seconds and minutes. To lock the timeline notches to specific musical measures or a fixed Beats Per Minute (BPM), you must calculate the exact duration of beats and bars in seconds and pass those values into the Timeline plugin's interval and formatting configuration options.

Calculating Musical Time in Seconds

To align notches with musical time, calculate the duration of a single beat and a full measure using the tempo (BPM) and time signature:

  • Seconds per Beat: 60 / BPM
  • Seconds per Measure (Bar): (60 / BPM) * BeatsPerMeasure (for example, 4 beats in a 4/4 time signature)

For a song at 120 BPM in 4/4 time:

  • Beat duration = 60 / 120 = 0.5 seconds.
  • Measure duration = 0.5 * 4 = 2.0 seconds.

Configuring the Timeline Plugin

Using Wavesurfer.js (v7), import and initialize the TimelinePlugin using the calculated intervals. You configure the primary notches for bars and the secondary notches for individual beats, then override the label callback to display measure numbers instead of standard clock time.

import WaveSurfer from 'wavesurfer.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';

const bpm = 120;
const beatsPerMeasure = 4;

const secondsPerBeat = 60 / bpm;
const secondsPerMeasure = secondsPerBeat * beatsPerMeasure;

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio-track.mp3',
  plugins: [
    TimelinePlugin.create({
      container: '#timeline',
      // Base interval set to individual beats
      timeInterval: secondsPerBeat,
      // Major markers align with full measures
      primaryLabelInterval: secondsPerMeasure,
      // Minor markers align with individual beats
      secondaryLabelInterval: secondsPerBeat,
      // Format markers as musical measures and beats (Bar.Beat)
      formatTimeCallback: (seconds) => {
        const totalBeats = Math.round(seconds / secondsPerBeat);
        const bar = Math.floor(totalBeats / beatsPerMeasure) + 1;
        const beat = (totalBeats % beatsPerMeasure) + 1;
        
        // Return measure label only on the downbeat, or format as Bar.Beat
        return beat === 1 ? `Bar ${bar}` : `${bar}.${beat}`;
      },
    }),
  ],
});

Handling Offsets and Grid Alignment

If the audio file does not start precisely on the first downbeat, introduce an offset variable. Adjust the calculation within formatTimeCallback and shift the plugin container or waveform data by the offset amount so that notches lock to the actual musical transients rather than zero seconds.
