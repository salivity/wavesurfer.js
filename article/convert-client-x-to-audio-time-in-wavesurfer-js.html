Convert ClientX to Audio Time in Wavesurfer.js

This article explains how to translate a mouse or pointer event's horizontal screen position (clientX) into an exact audio timestamp in Wavesurfer.js. By determining the relative position of the click within the waveform container and scaling it by the total duration of the audio, you can programmatically seek, place custom markers, or build custom interaction layers over your waveforms.

The Mathematical Formula

The standard formula to map a viewport-relative clientX value to audio time offset in seconds is:

\[\text{Time Offset} = \left( \frac{\text{clientX} - \text{rect.left}}{\text{rect.width}} \right) \times \text{duration}\]

Variable Definitions

  • clientX: The horizontal coordinate of the mouse pointer relative to the browser viewport, provided by the pointer/mouse event (event.clientX).
  • rect.left: The left edge of the canvas or waveform container relative to the viewport, obtained via element.getBoundingClientRect().left.
  • rect.width: The rendered layout width of the waveform canvas or container, obtained via element.getBoundingClientRect().width.
  • duration: The total length of the loaded audio file in seconds, retrieved via wavesurfer.getDuration().

Step-by-Step Derivation

  1. Calculate Relative X Position: Subtract the container's left coordinate from the event coordinate to find the exact pixel position inside the element. \[\text{relativeX} = \text{clientX} - \text{rect.left}\]

  2. Normalize the Position (0 to 1): Divide the relative X position by the container's total width to get the playback progress ratio. To prevent out-of-bounds errors when dragging outside the element, clamp the value between 0 and 1. \[\text{progress} = \max\left(0, \min\left(1, \frac{\text{relativeX}}{\text{rect.width}}\right)\right)\]

  3. Convert to Audio Time: Multiply the normalized progress by the total duration of the track. \[\text{timeOffset} = \text{progress} \times \text{duration}\]

Implementation Example

function getAudioTimeFromEvent(event, wavesurfer) {
  // Get the waveform container element
  const container = wavesurfer.getWrapper();
  const rect = container.getBoundingClientRect();

  // Calculate normalized progress (clamped between 0 and 1)
  const relativeX = event.clientX - rect.left;
  const progress = Math.max(0, Math.min(1, relativeX / rect.width));

  // Map progress to audio duration
  const duration = wavesurfer.getDuration();
  return progress * duration;
}

Handling Scrollable Waveforms

If your Wavesurfer instance has zoom enabled (minPxPerSec is set, causing the waveform to scroll horizontally within its wrapper), you must account for the scroll offset:

\[\text{Time Offset} = \left( \frac{\text{clientX} - \text{rect.left} + \text{container.scrollLeft}}{\text{container.scrollWidth}} \right) \times \text{duration}\]

In this scenario:

  • container.scrollLeft: The number of pixels scrolled horizontally.
  • container.scrollWidth: The total scrollable width of the rendered waveform, rather than the visible client width.
