Register and Initialize Wavesurfer.js Plugins

Wavesurfer.js is a powerful, customizable audio waveform visualization library that supports extended functionality through an official plugin system. This guide explains how to import, register, and initialize plugins in modern Wavesurfer.js (version 7 and above). You will learn how to configure plugins directly during the initial player setup as well as how to attach them dynamically at runtime.

1. Import Wavesurfer and Desired Plugins

Plugins in Wavesurfer.js are modular and must be imported individually alongside the core library. Standard plugins include Timeline, Regions, Minimap, Spectrogram, and Record.

If using an npm-based environment, install the package and import the required modules:

import WaveSurfer from 'wavesurfer.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

If using a CDN via standard <script> tags, plugins attach directly to the global WaveSurfer object (e.g., WaveSurfer.Timeline.create(...)).

2. Initialize Plugins During Player Creation

The standard approach is to pass initialized plugin instances directly into the plugins array within the WaveSurfer.create() configuration object. Each plugin provides a static .create() method where you can supply its specific configuration options.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  plugins: [
    // Initialize TimelinePlugin
    TimelinePlugin.create({
      container: '#wave-timeline',
      formatTimeCallback: (seconds) => `${Math.round(seconds)}s`,
    }),
    // Initialize RegionsPlugin
    RegionsPlugin.create(),
  ],
});

3. Register Plugins Dynamically at Runtime

You can also register a plugin after the WaveSurfer instance has already been instantiated. This is useful for plugins that should only load under certain conditions or after specific user interactions.

Use the registerPlugin() method on the Wavesurfer instance:

// Initialize the core instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  url: '/path/to/audio.mp3',
});

// Create and register a plugin later
const timeline = TimelinePlugin.create({
  container: '#wave-timeline',
});

wavesurfer.registerPlugin(timeline);

4. Interacting with Registered Plugins

To interact with a plugin's specific API, retain a reference to the created plugin instance or retrieve it from Wavesurfer's active plugins.

// Create a reference
const wsRegions = RegionsPlugin.create();

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  plugins: [wsRegions],
});

// Use plugin-specific methods and events
wsRegions.addRegion({
  start: 10,
  end: 25,
  color: 'rgba(255, 0, 0, 0.2)',
});

wsRegions.on('region-clicked', (region) => {
  region.play();
});

5. Destroying Plugins

If you remove an element from the DOM or need to unload a dynamic plugin without destroying the main waveform, call the plugin’s destroy() method:

// Unregisters and cleans up the specific plugin
timeline.destroy();

Destroying the parent wavesurfer instance via wavesurfer.destroy() automatically unmounts and cleans up all registered plugins.
