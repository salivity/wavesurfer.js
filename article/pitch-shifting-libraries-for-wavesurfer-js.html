Pitch Shifting Libraries for Wavesurfer.js

Wavesurfer.js provides robust audio visualization and playback capabilities, but it does not include native digital signal processing (DSP) algorithms for independent pitch shifting. To alter pitch without affecting playback speed, developers must route Wavesurfer’s Web Audio pipeline through third-party DSP libraries. The most seamless libraries for this integration are SoundTouchJS, Tone.js, and Jungle.js, each offering distinct trade-offs between audio fidelity, processing overhead, and ease of implementation.

SoundTouchJS

SoundTouchJS is a JavaScript port of the well-known C++ SoundTouch library. It uses the WSOLA (Waveform Similarity Overlap-Add) algorithm, which allows developers to manipulate pitch, tempo, and playback rate independently with minimal phase distortion.

Because SoundTouchJS operates directly on raw audio buffers (Float32Array), it integrates cleanly with Wavesurfer.js when using a custom AudioWorkletNode or ScriptProcessorNode. To implement it, you intercept Wavesurfer’s decoded audio buffer (wavesurfer.backend.buffer), feed the audio chunks into the SoundTouch processing pipeline, and direct the output back to the audio context destination. It is the premier choice when high-quality musical or speech pitch preservation is necessary.

Tone.js (Tone.PitchShift)

Tone.js is a comprehensive Web Audio framework that includes a dedicated Tone.PitchShift effect node. It uses a delay-line modulation technique with crossfading to shift pitch in real time, making it exceptionally low-latency.

Tone.js integrates easily because it is built natively on top of the Web Audio API. Because Wavesurfer.js exposes its underlying AudioContext and output nodes via wavesurfer.backend, you can route Wavesurfer’s output directly through a Tone.PitchShift node using standard connection calls (Tone.connect or native .connect() methods). You set Wavesurfer’s backend to use WebAudio mode, disconnect the default output, connect Wavesurfer to the Tone.PitchShift node, and connect the pitch shifter to Tone.Destination.

Jungle.js

Jungle.js is a lightweight, zero-dependency utility originally created for Google Web Audio demos. It creates an AudioNode graph consisting of modulated delay lines and LFOs (Low-Frequency Oscillators) to achieve real-time pitch shifting.

Its primary advantage is simplicity. Jungle creates a native Web Audio composite node that features standard .connect() and .disconnect() methods. You can pass the wavesurfer.backend.ac (AudioContext) into the Jungle constructor, and insert the resulting node into the signal chain using Wavesurfer's filter methods or manual node routing. While computationally lightweight and easy to configure, Jungle introduces comb-filtering and slight flanging artifacts, making it better suited for sound effects rather than high-fidelity music manipulation.

Implementation Considerations

To integrate any of these libraries seamlessly, initialize Wavesurfer.js using the WebAudio backend rather than the default HTML5 MediaElement backend. The WebAudio backend gives you direct access to the audio graph via wavesurfer.backend.source and wavesurfer.backend.setFilter(), allowing you to insert nodes directly into the processing chain without interrupting Wavesurfer's timeline tracking or waveform rendering.
