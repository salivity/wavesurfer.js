Render Upper Half Waveform in Wavesurfer.js

Wavesurfer.js renders audio waveforms mirrored across a central horizontal axis by default, creating a symmetrical visualization. However, modern user interfaces often require a unidirectional, single-sided display that shows only the top half of the audio data. This guide explains how to use the built-in barAlign configuration option in Wavesurfer.js to align the waveform to the baseline and display only the upper half.

Using the barAlign Option

In Wavesurfer.js (version 7 and later), the property that controls the vertical alignment of the waveform is barAlign.

By default, barAlign is unset, meaning the canvas renders waveform peaks symmetrically from the center. Setting barAlign to 'bottom' aligns all amplitude bars along the bottom edge of the container, projecting peaks upward to create an upper-half waveform.

Implementation Example

To achieve an upper-half visualization, define barAlign: 'bottom' along with your preferred bar styling parameters when initializing the instance:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  height: 80,
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
  barAlign: 'bottom', // Renders only the upper half
});

wavesurfer.load('/path/to/audio.mp3');

How It Works

  • barAlign: 'bottom': Anchors the base of each audio bar to the bottom of the canvas, ensuring all values render upwards as positive values.
  • barAlign: 'top': Performs the inverse by anchoring bars to the ceiling of the canvas and rendering downwards.
  • Compatibility: The barAlign property works in conjunction with barWidth. When barWidth is defined, Wavesurfer switches to a discrete bar visualization where bottom alignment naturally produces a clean, single-sided waveform.

Custom Continuous Waveforms via renderFunction

If you are not using bar-based rendering and need a continuous path showing only positive amplitudes, use the renderFunction option to draw directly onto the canvas:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  height: 80,
  renderFunction: (peaks, ctx) => {
    const { width, height } = ctx.canvas;
    const channel = peaks[0]; // First audio channel
    const step = width / channel.length;

    ctx.fillStyle = '#4F46E5';
    ctx.beginPath();
    ctx.moveTo(0, height);

    for (let i = 0; i < channel.length; i++) {
      const peak = Math.abs(channel[i]);
      const x = i * step;
      const y = height - (peak * height);
      ctx.lineTo(x, y);
    }

    ctx.lineTo(width, height);
    ctx.closePath();
    ctx.fill();
  },
});

Using barAlign: 'bottom' is the standard, native approach for bar waveforms, while renderFunction offers complete structural control for customized single-sided paths.
