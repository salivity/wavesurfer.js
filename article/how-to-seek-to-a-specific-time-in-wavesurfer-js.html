How to Seek to a Specific Time in Wavesurfer.js

Navigating to an exact timestamp is a common requirement when building interactive audio players with Wavesurfer.js. This guide explains how to seek directly to a specific time in seconds using the current version of Wavesurfer.js, while also providing the standard calculation needed for earlier versions of the library.

The Direct Method: setTime() (Wavesurfer.js v7+)

In Wavesurfer.js version 7 and later, the dedicated method to jump to a specific time in seconds is setTime().

This method takes a single numeric argument representing the target position in seconds and immediately shifts the audio playback and cursor to that point.

// Seek directly to 45 seconds into the track
wavesurfer.setTime(45);

The Ratio Method: seekTo() (Wavesurfer.js v6 and Earlier)

In Wavesurfer.js version 6 and older versions, there is no native method that directly accepts seconds. Instead, you must use the seekTo() method, which accepts a normalized value between 0 (the beginning) and 1 (the end).

To seek to a specific second using seekTo(), divide your desired time by the total duration of the audio:

const targetSeconds = 45;
const totalDuration = wavesurfer.getDuration();

// Convert seconds into a float between 0 and 1
const progress = targetSeconds / totalDuration;

wavesurfer.seekTo(progress);

Key Differences to Keep in Mind

  • Units: setTime(seconds) uses absolute time (seconds), while seekTo(progress) uses relative progress (0.0 to 1.0).
  • Audio Readiness: Ensure the audio has finished loading and the ready or decode event has fired before attempting to seek, or getDuration() may return 0 or NaN.
