Wavesurfer.js Equalizer Bands with BiquadFilterNode

This article provides an overview of how to build multi-band equalizers using chained Web Audio API BiquadFilterNode instances in Wavesurfer.js. It details standard frequency band arrangements—such as 3-band, 5-band, and 10-band configurations—and outlines the specific filter types and parameters required to control audio frequencies effectively.

How BiquadFilterNodes Chain with Wavesurfer.js

Wavesurfer.js renders audio waveforms and provides access to the underlying Web Audio API. By inserting a chain of BiquadFilterNode instances between the audio source and the destination output, you can create a custom graphic or parametric equalizer. Each filter processes the signal and passes it to the next:

Source Node → Filter 1 → Filter 2 → ... → Filter N → Destination

To achieve transparent adjustment without phase cancellation or frequency gaps, each band targets a specific center frequency, bandwidth (Q factor), and filter type.

Common Equalizer Band Configurations

Depending on the precision required, you can implement varying numbers of frequency bands.

1. Three-Band Equalizer (Basic Tone Control)

A simple 3-band configuration handles the fundamental regions of human hearing:

  • Bass (Low-shelf): 100 Hz to 250 Hz (Controls warmth, kick drums, and bass instruments)
  • Midrange (Peaking): 1,000 Hz (Controls vocal presence and core instrument tone)
  • Treble (High-shelf): 4,000 Hz to 8,000 Hz (Controls brightness, air, and cymbal shimmer)

2. Five-Band Equalizer (Standard Graphic EQ)

A 5-band setup provides more control across distinct musical octaves:

  • 60 Hz (Low-shelf): Sub-bass and low-end punch
  • 250 Hz (Peaking): Lower midrange, body, and fullness
  • 1,000 Hz (Peaking): Midrange clarity and vocal intelligibility
  • 4,000 Hz (Peaking): Upper midrange, presence, and transient attack
  • 16,000 Hz (High-shelf): High-frequency brilliance and air

3. Ten-Band Equalizer (ISO Standard Octave Bands)

For professional audio applications, the 10-band ISO standard divides the audible spectrum (20 Hz to 20,000 Hz) into one-octave intervals:

  • 32 Hz (Low-shelf): Lowest fundamental bass frequencies
  • 64 Hz (Peaking): Bass fundamentals and kick drum weight
  • 125 Hz (Peaking): Lower bass and warmth
  • 250 Hz (Peaking): Mid-bass and lower harmonics
  • 500 Hz (Peaking): Body of acoustic instruments and lower vocals
  • 1,000 Hz (1 kHz) (Peaking): Core vocal range and instrument harmonics
  • 2,000 Hz (2 kHz) (Peaking): Attack transients, speech intelligibility
  • 4,000 Hz (4 kHz) (Peaking): Presence, clarity, and percussive snap
  • 8,000 Hz (8 kHz) (Peaking): Treble sharpness and sibilance
  • 16,000 Hz (16 kHz) (High-shelf): Ultra-high air and subtle ambience

Required Filter Node Types and Settings

To ensure the bands combine naturally across the spectrum, select the correct BiquadFilterNode.type for each position:

  1. Low-shelf (type = 'lowshelf'):
    • Used for the lowest band (e.g., 32 Hz or 60 Hz).
    • Affects all frequencies below the defined cutoff, gradually leveling off to the specified gain.
  2. Peaking (type = 'peaking'):
    • Used for all intermediate bands.
    • Boosts or cuts a bell-shaped range around the center frequency.
    • Set the Q property (typically between 1.0 and 1.4 for standard 10-band setups) to control how wide or narrow the frequency range is, preventing unwanted overlap.
  3. High-shelf (type = 'highshelf'):
    • Used for the highest band (e.g., 16 kHz).
    • Affects all frequencies above the defined cutoff, applying a constant boost or attenuation across the top end.

By instantiating an array of these nodes, setting their initial gain.value to 0 dB, and connecting them sequentially to Wavesurfer's audio graph, you create an adjustable multi-band equalizer capable of modifying frequency output in real time.
