Load Dropped Files into Wavesurfer.js via FileReader

This article explains how to use the JavaScript FileReader API to convert local audio files dropped from a desktop into playable sources for Wavesurfer.js. It covers the essential FileReader methods—specifically readAsDataURL() and readAsArrayBuffer()—and demonstrates how to handle the drop event to pass the converted audio data directly into the waveform player.

Extracting the Dropped File

When a user drops an audio file onto a designated element, the file is accessed through the event's dataTransfer property. Prevent the browser's default behavior and extract the target File object:

const dropZone = document.getElementById('drop-zone');

dropZone.addEventListener('dragover', (e) => {
  e.preventDefault();
});

dropZone.addEventListener('drop', (e) => {
  e.preventDefault();
  const file = e.dataTransfer.files[0];
  if (file && file.type.startsWith('audio/')) {
    loadAudioWithFileReader(file);
  }
});

The Primary FileReader Calls

The FileReader API offers two methods to convert the dropped file into a format that Wavesurfer.js can process:

1. FileReader.readAsDataURL()

readAsDataURL() reads the contents of the file and produces a Base64-encoded data URL string. This string can be passed directly to the wavesurfer.load() method just like a standard web URL.

function loadAudioWithDataURL(file) {
  const reader = new FileReader();

  reader.onload = (event) => {
    const dataUrl = event.target.result;
    // Pass the Base64 data URL directly to Wavesurfer
    wavesurfer.load(dataUrl);
  };

  // Converts the file into a base64-encoded Data URL
  reader.readAsDataURL(file);
}

2. FileReader.readAsArrayBuffer()

readAsArrayBuffer() reads the file's raw binary data. This approach is necessary when working with custom Web Audio pipelines, manual audio decoding, or passing raw audio buffers to Wavesurfer.js (especially in Wavesurfer v7+ where pre-decoded AudioBuffer objects or blobs are used directly).

function loadAudioWithArrayBuffer(file) {
  const reader = new FileReader();

  reader.onload = async (event) => {
    const arrayBuffer = event.target.result;

    // Decode the ArrayBuffer using the Web Audio API
    const audioContext = new (window.AudioContext || window.webkitAudioContext)();
    const audioBuffer = await audioContext.decodeAudioData(arrayBuffer);

    // Load decoded AudioBuffer into Wavesurfer
    wavesurfer.load('', audioBuffer);
  };

  // Reads the raw binary contents of the file
  reader.readAsArrayBuffer(file);
}

Choosing Between the Two Calls

  • Use readAsDataURL() for the simplest integration. It generates a single string that works universally with the standard wavesurfer.load() method across all major versions of Wavesurfer.js.
  • Use readAsArrayBuffer() when memory efficiency is critical or when you need to decode and inspect the audio channels using the Web Audio API prior to rendering the waveform.
