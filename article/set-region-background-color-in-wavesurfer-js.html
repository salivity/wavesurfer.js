Set Region Background Color in Wavesurfer.js

This guide explains how to customize and set the background color of a region using the Wavesurfer.js Regions plugin. By utilizing the color property during region creation or updating an existing region dynamically, you can easily control the visual styling and opacity of selected audio segments.

To add a background color to a region, you must use the official Regions plugin. When defining a region via the addRegion method, provide a valid CSS color string to the color parameter. It is best practice to use an rgba() or hsla() value so that the waveform underneath remains visible through a semi-transparent overlay.

Adding a Region with a Background Color

In Wavesurfer.js (version 7+), initialize the plugin and define the color attribute as follows:

import WaveSurfer from 'wavesurfer.js'
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js'

// Initialize WaveSurfer
const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
})

// Initialize the Regions plugin
const wsRegions = ws.registerPlugin(RegionsPlugin.create())

// Create a region with a custom background color
ws.on('ready', () => {
  wsRegions.addRegion({
    start: 2,
    end: 6,
    color: 'rgba(0, 123, 255, 0.3)', // Semi-transparent blue background
    drag: true,
    resize: true,
  })
})

Updating Region Color Dynamically

If a region has already been instantiated, you can update its background color at runtime using the setOptions method:

const region = wsRegions.getRegions()[0]

// Update the background color to green
region.setOptions({
  color: 'rgba(40, 167, 69, 0.4)'
})

Supported Color Formats

The color option accepts standard CSS color definitions:

  • RGBA: rgba(255, 0, 0, 0.5) (Recommended for transparency)
  • HEX with Alpha: #ff000080
  • HSLA: hsla(120, 100%, 50%, 0.3)
  • Solid Colors: red, #ff0000 (Note: fully opaque colors will hide the waveform underneath)
