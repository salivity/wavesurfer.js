Maintain Pitch When Changing Speed in Wavesurfer.js

This article explains how to adjust audio playback speed in Wavesurfer.js without altering the audio pitch (known as time-stretching). You will learn how to use the native playback rate parameters, configure HTML5 audio element properties, and handle cross-browser compatibility to ensure audio plays faster or slower without creating a "chipmunk" or deep-voice effect.

Using the setPlaybackRate Method

In Wavesurfer.js (versions 7 and newer), the primary method to change speed is setPlaybackRate(). This method accepts the playback rate as the first argument and a boolean indicating whether to maintain pitch as the second argument.

// Set speed to 1.5x and preserve pitch
wavesurfer.setPlaybackRate(1.5, true);

Setting the second argument to true instructs the underlying media engine to maintain the original pitch of the audio track.

Configuring the Underlying Media Element

If you are using an older version of Wavesurfer.js, or if you want to ensure pitch preservation globally across all speed changes, you can configure the underlying HTML5 <audio> element directly.

Modern browsers support the preservesPitch property on HTMLMediaElement. Access the media element through Wavesurfer and set this property along with standard vendor prefixes:

const mediaElement = wavesurfer.getMediaElement();

if (mediaElement) {
  mediaElement.preservesPitch = true;
  mediaElement.webkitPreservesPitch = true; // Safari / WebKit
  mediaElement.mozPreservesPitch = true;    // Firefox
}

Once this property is enabled, any subsequent call to wavesurfer.setPlaybackRate(speed) will adjust the tempo while keeping the pitch constant.

Complete Implementation Example

Here is a minimal implementation showing how to toggle between different playback speeds while maintaining pitch:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
});

wavesurfer.on('ready', () => {
  // Ensure pitch preservation is enabled on the media element
  const audio = wavesurfer.getMediaElement();
  if (audio) {
    audio.preservesPitch = true;
  }
});

// Function to safely update speed with preserved pitch
function updateSpeed(newRate) {
  // Pass true as the second parameter
  wavesurfer.setPlaybackRate(newRate, true);
}

// Example usage
document.querySelector('#speed-1x').addEventListener('click', () => updateSpeed(1.0));
document.querySelector('#speed-1-5x').addEventListener('click', () => updateSpeed(1.5));
document.querySelector('#speed-2x').addEventListener('click', () => updateSpeed(2.0));

Browser Limitations and Quality

Native browser pitch preservation uses built-in time-stretching algorithms. While this approach works reliably without extra dependencies, keep in mind:

  1. Extreme Speeds: Pitch preservation functions best between 0.5x and 2.0x speeds. Rates beyond this range may introduce audible digital artifacts or stuttering.
  2. Audio Backend: This method relies on the standard HTML5 Audio backend. If using custom Web Audio nodes that process raw PCM buffers directly, native pitch preservation will not apply automatically, and you would need a dedicated Web Audio DSP library (such as SoundTouchJS) instead.
