Replace Audio Dynamically in Wavesurfer.js

This article explains how to dynamically swap and reload audio tracks within an existing Wavesurfer.js instance. Instead of destroying and recreating the player, you can update waveforms on the fly using the built-in load() method. Below, you will find how this method works, a standard code implementation, and key considerations for handling audio switching seamlessly.

The Primary Method: wavesurfer.load()

In Wavesurfer.js, the primary method used to replace audio dynamically is load(). Calling this method on an existing WaveSurfer instance cancels any active playback, clears the previous audio buffer, resets the waveform display, and fetches the new audio source.

The method signature is:

wavesurfer.load(url, peaks, duration);
  • url (Required): The URL, path, or data URI of the new audio file.
  • peaks (Optional): An array of pre-computed waveform peak data. Providing this avoids decoding the entire audio file in the browser, rendering the waveform almost instantly.
  • duration (Optional): The duration of the audio in seconds, typically supplied alongside pre-computed peaks.

Basic Implementation

To swap tracks upon user interaction (such as a dropdown selection or a button click), simply invoke wavesurfer.load() with the new audio path:

import WaveSurfer from 'wavesurfer.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio/track1.mp3',
});

// Function to replace the track dynamically
function switchTrack(newAudioUrl) {
  wavesurfer.load(newAudioUrl);
}

// Example: Switch track via button click
document.getElementById('next-track-btn').addEventListener('click', () => {
  switchTrack('/audio/track2.mp3');
});

Handling Track Changes with Events

When swapping tracks dynamically, Wavesurfer.js emits lifecycle events that allow you to update the UI or auto-play the new source once it is loaded:

// Triggered when the new audio finishes loading and decoding
wavesurfer.on('ready', () => {
  console.log('New track is ready to play');
  wavesurfer.play();
});

// Handling loading errors for missing or corrupt files
wavesurfer.on('error', (error) => {
  console.error('Failed to load audio track:', error);
});

Loading Local Files (Blob/File Objects)

If the dynamic track comes from an <input type="file"> element instead of an external URL, you can pass a Blob URL or the file directly:

const fileInput = document.querySelector('input[type="file"]');

fileInput.addEventListener('change', (e) => {
  const file = e.target.files[0];
  if (file) {
    const fileUrl = URL.createObjectURL(file);
    wavesurfer.load(fileUrl);
  }
});

By leveraging wavesurfer.load(), you avoid the overhead of re-initializing DOM containers or re-registering plugins, ensuring smooth transitions between audio files.
