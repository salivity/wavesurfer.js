Rebuild Wavesurfer.js Waveforms on Theme Change

This guide demonstrates how to properly destroy and rebuild waveform visualizers using Wavesurfer.js when toggling between UI themes, such as light and dark modes. You will learn how to tear down an active Wavesurfer instance cleanly using the destroy() method, capture and persist the active playback state, and re-instantiate the waveform container with updated theme colors without interrupting the user experience or leaking memory.

Step 1: Capture the Current Playback State

Before destroying the active Wavesurfer instance, record the player's current state so it can be restored seamlessly after the rebuild. You need to store:

  • The current playback time (getCurrentTime()).
  • Whether audio is currently playing (isPlaying()).
  • The audio source URL or decoded audio buffer (getDecodedData()).
const savedState = {
  currentTime: wavesurfer.getCurrentTime(),
  isPlaying: wavesurfer.isPlaying(),
  audioData: wavesurfer.getDecodedData(),
  audioUrl: currentAudioUrl
};

Step 2: Destroy the Existing Instance

Call the destroy() method on the instance. This removes all internal event listeners, stops any active audio processing nodes, removes rendered canvas elements from the DOM, and frees memory.

if (wavesurfer) {
  wavesurfer.destroy();
  wavesurfer = null;
}

Step 3: Re-create the Instance with New Theme Colors

Initialize a new Wavesurfer instance using the new theme's color values. Provide your theme-specific values for waveColor and progressColor.

const themeColors = isDarkMode ? {
  waveColor: '#4A5568',
  progressColor: '#63B3ED'
} : {
  waveColor: '#CBD5E0',
  progressColor: '#3182CE'
};

wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: themeColors.waveColor,
  progressColor: themeColors.progressColor,
  cursorColor: isDarkMode ? '#FFFFFF' : '#000000',
  height: 100,
  barWidth: 2,
  barGap: 1
});

Step 4: Restore State and Audio

To avoid re-downloading or re-decoding the audio file, pass the previously cached decoded audio buffer directly to the loadAudio() method if using Wavesurfer v7+, or restore via peaks/URL. Once initialized, seek to the saved timestamp and resume playback if it was active.

wavesurfer.once('ready', () => {
  wavesurfer.setTime(savedState.currentTime);
  if (savedState.isPlaying) {
    wavesurfer.play();
  }
});

// Load the decoded audio directly to skip re-decoding
if (savedState.audioData) {
  wavesurfer.loadAudio(savedState.audioUrl, savedState.audioData);
} else {
  wavesurfer.load(savedState.audioUrl);
}

Complete Implementation Example

class ThemedAudioPlayer {
  constructor(containerId, audioUrl) {
    this.container = document.querySelector(containerId);
    this.audioUrl = audioUrl;
    this.wavesurfer = null;
    this.isDarkMode = false;

    this.initPlayer();
  }

  getThemeOptions() {
    return this.isDarkMode
      ? { waveColor: '#4A5568', progressColor: '#63B3ED', cursorColor: '#E2E8F0' }
      : { waveColor: '#E2E8F0', progressColor: '#3182CE', cursorColor: '#2D3748' };
  }

  initPlayer(savedState = null) {
    const theme = this.getThemeOptions();

    this.wavesurfer = WaveSurfer.create({
      container: this.container,
      height: 96,
      waveColor: theme.waveColor,
      progressColor: theme.progressColor,
      cursorColor: theme.cursorColor,
      barWidth: 2,
      barRadius: 2,
      barGap: 2
    });

    this.wavesurfer.once('ready', () => {
      if (savedState) {
        this.wavesurfer.setTime(savedState.currentTime);
        if (savedState.isPlaying) {
          this.wavesurfer.play();
        }
      }
    });

    if (savedState && savedState.audioData) {
      this.wavesurfer.loadAudio(this.audioUrl, savedState.audioData);
    } else {
      this.wavesurfer.load(this.audioUrl);
    }
  }

  toggleTheme(isDark) {
    if (this.isDarkMode === isDark) return;
    this.isDarkMode = isDark;

    // 1. Capture current state
    const savedState = {
      currentTime: this.wavesurfer ? this.wavesurfer.getCurrentTime() : 0,
      isPlaying: this.wavesurfer ? this.wavesurfer.isPlaying() : false,
      audioData: this.wavesurfer ? this.wavesurfer.getDecodedData() : null
    };

    // 2. Destroy active instance
    if (this.wavesurfer) {
      this.wavesurfer.destroy();
      this.wavesurfer = null;
    }

    // 3. Rebuild instance with new colors
    this.initPlayer(savedState);
  }
}

Alternative: Dynamic Updates via setOptions

If you are using Wavesurfer.js v7 or newer, a complete destroy() and rebuild cycle can often be avoided unless you are restructuring the DOM or resetting plugins. You can update colors dynamically on an existing canvas using setOptions:

wavesurfer.setOptions({
  waveColor: isDarkMode ? '#4A5568' : '#CBD5E0',
  progressColor: isDarkMode ? '#63B3ED' : '#3182CE'
});

Use setOptions for pure style adjustments. Reserve the full destroy() and rebuild workflow for scenarios where wrapper containers change, plugins require re-registration, or the audio backend must be completely re-initialized.
