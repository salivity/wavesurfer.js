Tracking Audio Listen Duration Using Wavesurfer.js

Measuring audio engagement requires capturing accurate playback behavior rather than simple click-to-play metrics. This article explains how to leverage Wavesurfer.js event hooks—such as play, pause, timeupdate, and seeking—to generate precise telemetry logs that track cumulative, active user listening duration and calculate aggregate metrics across sessions.

Key Wavesurfer.js Telemetry Events

Wavesurfer.js emits granular lifecycle events on its instance. To measure active consumption accurately while filtering out paused or skipped segments, your analytics pipeline must monitor the following event streams:

  • play: Fires when playback starts or resumes. Use this to start or continue an active listening timer and record the starting playhead position (wavesurfer.getCurrentTime()).
  • pause: Fires when playback stops manually. Use this to calculate the elapsed active segment, add it to the cumulative session duration, and reset the active timer.
  • seeking: Fires when a user scrubs forward or backward across the waveform. Seeking indicates that elapsed wall-clock time does not equal listened audio time. Capture the currentTime before and after the seek operation to prevent unlistened sections from skewing metrics.
  • finish: Fires when playback naturally reaches the end of the audio track. This acts as a terminal event to record the final audio segment and log a successful completion flag.
  • destroy: Fires when the player instance is unmounted or removed (e.g., closing a tab or navigating to a different page). Telemetry must capture this event via standard browser visibility changes or before-unload handlers to log incomplete sessions.

Constructing the Telemetry Log Schema

To calculate the average listen duration on the backend, emit structured events whenever state changes occur. A standard telemetry payload should contain the following fields:

{
  "event_id": "evt_987654321",
  "session_id": "sess_12345abcde",
  "track_id": "audio_track_42",
  "event_type": "pause",
  "client_timestamp": 1711972800000,
  "playhead_position": 45.2,
  "active_duration_delta": 15.2,
  "total_listened_seconds": 30.4
}
  • active_duration_delta: The actual seconds spent listening during the immediate segment between the last play event and the current event.
  • playhead_position: The value returned by wavesurfer.getCurrentTime().
  • total_listened_seconds: The running total of listened seconds maintained in client-side state for the current session.

Implementation Pattern

To capture these metrics, attach listeners directly to the Wavesurfer instance:

let listenStartTime = 0;
let totalListenedDuration = 0;
let isPlaying = false;

wavesurfer.on('play', () => {
  isPlaying = true;
  listenStartTime = performance.now();
  sendTelemetry('audio_play', { playhead: wavesurfer.getCurrentTime() });
});

function recordSegment() {
  if (!isPlaying) return;
  const elapsed = (performance.now() - listenStartTime) / 1000;
  totalListenedDuration += elapsed;
  isPlaying = false;
  return elapsed;
}

wavesurfer.on('pause', () => {
  const delta = recordSegment();
  sendTelemetry('audio_pause', {
    playhead: wavesurfer.getCurrentTime(),
    active_duration_delta: delta,
    total_listened_seconds: totalListenedDuration
  });
});

wavesurfer.on('seeking', () => {
  const delta = recordSegment();
  sendTelemetry('audio_seek', {
    playhead: wavesurfer.getCurrentTime(),
    active_duration_delta: delta,
    total_listened_seconds: totalListenedDuration
  });
});

wavesurfer.on('finish', () => {
  const delta = recordSegment();
  sendTelemetry('audio_finish', {
    playhead: wavesurfer.getCurrentTime(),
    active_duration_delta: delta,
    total_listened_seconds: totalListenedDuration
  });
});

Calculating Average Listen Duration

Once telemetry events are streamed to your data warehouse, compute average listen duration (ALD) using one of two methods:

  1. Delta Aggregation (Server-Side Calculation): Sum the active_duration_delta values across all events associated with a given session_id and track_id. Divide the total sum of duration across all sessions by the count of distinct sessions. This approach is resilient against dropped client exit events.
  2. Terminal Log Evaluation: Identify the maximum total_listened_seconds reported in the final telemetry log of each session, then compute the average across all unique sessions:

\[\text{Average Listen Duration} = \frac{\sum_{i=1}^{N} \text{Total Listened Seconds}_i}{N}\]

Where \(N\) represents the total number of unique user listening sessions.
