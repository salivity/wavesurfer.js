Convert Wavesurfer.js Canvas Clicks to Time

This article explains how to translate click events on a Wavesurfer.js waveform into precise audio timestamps. It details the core utility methods used in modern Wavesurfer.js (v7+) and earlier versions, showing how click coordinates are extracted, mapped through renderer utility functions, and converted into exact playback time.

In modern Wavesurfer.js (version 7 and later), the primary utility method for converting horizontal pixel coordinates to time is renderer.pixelsToTime(pixels). When a user clicks on the waveform canvas or wrapper element, the browser generates a mouse event containing screen coordinates. The internal renderer utility takes the horizontal pixel offset and maps it directly against the audio duration and sample rate to produce the corresponding time in seconds.

To perform this conversion manually from a standard click or pointer event, calculate the relative horizontal offset within the waveform container and pass that value to the utility function:

const waveformContainer = document.querySelector('#waveform');

waveformContainer.addEventListener('click', (event) => {
  const rect = waveformContainer.getBoundingClientRect();
  const clickX = event.clientX - rect.left;
  
  // Use the renderer utility method
  const clickedTime = wavesurfer.renderer.pixelsToTime(clickX);
  
  console.log(`Clicked time: ${clickedTime} seconds`);
});

The pixelsToTime method accounts for current scroll positions and audio duration automatically. Internally, the calculation derives time using the ratio between the clicked pixel position and the total rendered pixel width:

\[\text{Time} = \left(\frac{\text{clickX}}{\text{totalWidth}}\right) \times \text{duration}\]

In legacy versions of Wavesurfer.js (v6 and earlier), coordinate-to-time conversion was handled via drawer.handleEvent(event). This method evaluated the event against the canvas element and returned a normalized progress fraction between 0 and 1. Multiplying this progress value by wavesurfer.getDuration() yielded the click timestamp:

// Wavesurfer.js v6 approach
const progress = wavesurfer.drawer.handleEvent(event);
const clickedTime = progress * wavesurfer.getDuration();

Whether using modern renderer.pixelsToTime or legacy progress multipliers, these utilities ensure that interactions with the waveform canvas accurately reflect playback positions across variable zoom levels and viewport sizes.
