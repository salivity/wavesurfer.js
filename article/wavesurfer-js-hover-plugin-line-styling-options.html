Wavesurfer.js Hover Plugin Line Styling Options

This guide covers the configuration properties used to customize the appearance of the hover line in the Wavesurfer.js Hover plugin. By adjusting these options during plugin initialization, you can control the vertical indicator's dimensions, color, and visual integration with your audio waveform.

Core Hover Line Styling Options

The Wavesurfer.js Hover plugin (standard in version 7 and later) provides specific configuration parameters passed to HoverPlugin.create() to style the pointer line:

  • lineColor (string): Sets the color of the vertical indicator line. It accepts any valid CSS color value, including HEX, RGB, RGBA, or standard color names.
    • Default: 'rgba(0, 0, 0, 0.5)'
    • Example: '#ff5722' or 'rgba(255, 255, 255, 0.8)'
  • lineWidth (number | string): Defines the thickness of the vertical line. When passed as a number, it represents the width in pixels.
    • Default: 1
    • Example: 2 or '2px'

Accompanying Label Styling Options

Because the hover line is paired with a timestamp tooltip label, the plugin also includes options that style the label directly anchored to the line:

  • labelColor (string): Sets the text color of the timestamp.
    • Default: '#fff'
  • labelBackground (string): Sets the background fill of the timestamp bubble.
    • Default: 'rgba(0, 0, 0, 0.75)'
  • labelSize (string): Controls the font size of the timestamp text.
    • Default: '11px'

Implementation Example

Apply these styling options directly inside the plugin configuration object:

import WaveSurfer from 'wavesurfer.js'
import Hover from 'wavesurfer.js/dist/plugins/hover.esm.js'

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  plugins: [
    Hover.create({
      lineColor: '#00e5ff',
      lineWidth: 2,
      labelBackground: '#1e1e24',
      labelColor: '#00e5ff',
      labelSize: '12px',
    }),
  ],
})

Advanced Styling via CSS

The Hover plugin renders HTML elements inside the waveform wrapper. If you need advanced styling such as drop shadows, transitions, or custom border radii for the label, you can target the generated CSS classes in your stylesheet:

  • .wavesurfer-hover: Target the container wrapper generated by the plugin.
  • .wavesurfer-hover-line: Target the line element directly to add CSS properties like box-shadow or opacity.
