Wavesurfer.js Marker Timestamp Event Guide

This article explains which event is triggered when playback reaches a marker timestamp in Wavesurfer.js and how to properly detect it in your application. Because marker implementations vary between the dedicated Markers plugin, the Regions plugin, and custom time listeners, understanding which event fires ensures accurate synchronization with your audio playback.

In Wavesurfer.js, markers are most commonly implemented using the Regions plugin as point regions (where start and end times are identical). When playback crosses a marker timestamp created this way, the plugin triggers the region-in event.

The region-in Event

When using @wavesurfer/regions (or wavesurfer.regions.js in older versions), point-based markers emit region-in the moment the playhead enters the marker position:

const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

// Add a point marker
wsRegions.addRegion({
  start: 15, // Timestamp in seconds
  content: 'Marker 1',
  color: 'rgba(255, 0, 0, 0.5)',
});

// Listen for playback reaching the marker
wsRegions.on('region-in', (region) => {
  console.log(`Hit marker: ${region.content} at ${region.start} seconds`);
});

Because a marker is a point in time rather than a span, Wavesurfer.js will also fire a region-out event almost immediately after region-in as the playhead advances past the timestamp.

Legacy Markers Plugin and Manual Detection

In legacy versions (Wavesurfer.js v4–v6), a separate markers plugin was available. Unlike the Regions plugin, the dedicated Markers plugin only fired DOM interaction events such as marker-click and did not provide an automatic event for playback crossing a timestamp.

If you are using the legacy Markers plugin or custom UI markers, you must listen to playback progress manually to detect when a timestamp is reached:

  • Wavesurfer.js v7: Use the timeupdate event.
  • Wavesurfer.js v6 and earlier: Use the audioprocess event.
const markerTime = 15.0;
let markerTriggered = false;

wavesurfer.on('timeupdate', (currentTime) => {
  if (currentTime >= markerTime && !markerTriggered) {
    console.log('Marker reached at', currentTime);
    markerTriggered = true;
  }
});

// Reset the trigger flag when seeking backwards
wavesurfer.on('seeking', (seekTime) => {
  if (seekTime < markerTime) {
    markerTriggered = false;
  }
});

Summary

  • Standard Markers (Regions Plugin): The triggered event is region-in.
  • Interactive UI Markers: The triggered click event is marker-click or region-clicked.
  • Custom Time Markers: Track playback continuously using timeupdate (v7) or audioprocess (v6).
