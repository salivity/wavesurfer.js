Get Current Time in Wavesurfer.js

Retrieving the current audio playback position in Wavesurfer.js is a straightforward process handled through the library's built-in API. This guide explains how to fetch the exact playback position in seconds on demand using core methods, as well as how to continuously track the playback time in real time using event listeners.

Using the getCurrentTime() Method

The primary method for getting the current playback position is getCurrentTime(). This method returns a floating-point number representing the current position of the playhead in seconds.

const currentTimeInSeconds = wavesurfer.getCurrentTime();
console.log(`Current playback time: ${currentTimeInSeconds} seconds`);

If you only need whole seconds, you can round the output using standard JavaScript math functions:

const roundedSeconds = Math.floor(wavesurfer.getCurrentTime());
console.log(`Current playback time: ${roundedSeconds}s`);

Tracking Playback Time in Real Time

To monitor the playback position continuously as the audio plays, attach an event listener to the timeupdate event (or audioprocess in older versions of Wavesurfer.js).

In Wavesurfer.js version 7 and above, the timeupdate event passes the current time directly as an argument:

wavesurfer.on('timeupdate', (currentTime) => {
    console.log(`Current position: ${currentTime.toFixed(2)} seconds`);
});

For Wavesurfer.js version 6 and earlier, you can use the audioprocess event in combination with getCurrentTime():

wavesurfer.on('audioprocess', () => {
    const currentTime = wavesurfer.getCurrentTime();
    console.log(`Current position: ${currentTime.toFixed(2)} seconds`);
});

Handling User Seeking

If a user clicks on the waveform to scrub or seek to a different part of the track, the timeupdate event will capture the new position automatically in modern versions. However, you can also listen explicitly for the seeking or seek event:

wavesurfer.on('seeking', (currentTime) => {
    console.log(`Seeked to: ${currentTime} seconds`);
});
