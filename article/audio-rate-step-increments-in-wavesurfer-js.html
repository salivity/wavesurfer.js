Audio Rate Step Increments in Wavesurfer.js

Wavesurfer.js does not include a dedicated, built-in configuration option specifically designated for audio rate change step increments. While the library provides the audioRate initialization option to establish the initial playback speed and the setPlaybackRate() method to alter it dynamically, stepping logic must be managed externally. This article explains how playback rate is controlled in Wavesurfer.js and how to implement custom rate step increments using standard JavaScript and UI controls.

Understanding Wavesurfer.js Rate Options

When initializing Wavesurfer.js, the base playback speed is defined using the audioRate parameter:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'violet',
  progressColor: 'purple',
  audioRate: 1, // Sets the initial playback speed (default is 1)
});

Because Wavesurfer.js focuses on audio waveform visualization rather than complete media player interface controls, it does not provide native step-increment settings (such as a hypothetical audioRateStep). Adjusting the playback rate in defined increments is instead executed via the wavesurfer.setPlaybackRate() method.

Controlling Step Increments with an HTML Input

The standard way to provide fixed rate step increments is through an HTML <input type="range"> element using the native step attribute.

<label for="rate-slider">Playback Speed:</label>
<input 
  type="range" 
  id="rate-slider" 
  min="0.5" 
  max="2.0" 
  step="0.25" 
  value="1" 
/>

In your JavaScript, listen for user input and pass the updated value to Wavesurfer:

const rateSlider = document.getElementById('rate-slider');

rateSlider.addEventListener('input', (event) => {
  const newRate = parseFloat(event.target.value);
  wavesurfer.setPlaybackRate(newRate);
});

In this setup, the HTML step="0.25" attribute directly dictates the rate change step increments.

Programmatic Step Increments via Buttons

If you control playback rate using acceleration/deceleration buttons (such as "+0.1x" and "-0.1x"), define a constant step value in JavaScript:

const RATE_STEP = 0.1;
let currentRate = 1.0;

function increasePlaybackRate() {
  currentRate = Math.min(currentRate + RATE_STEP, 3.0); // Clamped to a max of 3.0x
  wavesurfer.setPlaybackRate(parseFloat(currentRate.toFixed(2)));
}

function decreasePlaybackRate() {
  currentRate = Math.max(currentRate - RATE_STEP, 0.25); // Clamped to a min of 0.25x
  wavesurfer.setPlaybackRate(parseFloat(currentRate.toFixed(2)));
}

Rounding the value using toFixed() prevents floating-point precision issues common in JavaScript arithmetic.

Preserving Audio Pitch During Rate Changes

When altering playback rates incrementally, you can control whether the audio pitch shifts with the speed. In modern versions of Wavesurfer.js, setPlaybackRate supports a second boolean parameter to preserve pitch:

// Sets rate to 1.5x while keeping the natural pitch intact
wavesurfer.setPlaybackRate(1.5, true);

By pairing setPlaybackRate() with either an HTML input step attribute or a JavaScript delta constant, you have full control over the audio rate step increments in your Wavesurfer.js implementation.
