Change Wavesurfer.js Wave Color Dynamically

Updating waveform colors dynamically in Wavesurfer.js allows you to adapt your audio player's appearance to theme changes, user interactions, or playback states. While earlier versions required dedicated setter functions or manual canvas redrawing, modern Wavesurfer.js (version 7 and later) simplifies this process through a unified options updater. This guide explains how to dynamically update the wave color and progress color across different versions of the library.

Modern Wavesurfer.js (Version 7+)

In Wavesurfer.js v7, you update visual properties dynamically using the setOptions() method. Calling this method updates the configuration and automatically redraws the waveform canvas with the new colors without interrupting audio playback.

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#10B981',
  url: '/path/to/audio.mp3',
});

// Update colors dynamically
function updateWaveColors(newWaveColor, newProgressColor) {
  wavesurfer.setOptions({
    waveColor: newWaveColor,
    progressColor: newProgressColor,
  });
}

// Example usage: Switch to dark mode colors
updateWaveColors('#9CA3AF', '#3B82F6');

You can pass standard color formats, including hex strings (#ffffff), RGB/RGBA values (rgba(255, 255, 255, 0.5)), or valid CSS color names.

Using Linear Gradients Dynamically (v7+)

Wavesurfer.js v7 also accepts an array of colors or an HTML5 Canvas gradient object to generate multi-stop gradients dynamically:

// Create a canvas gradient
const canvas = document.createElement('canvas');
const ctx = canvas.getContext('2d');
const gradient = ctx.createLinearGradient(0, 0, 0, 150);
gradient.addColorStop(0, '#ff7e5f');
gradient.addColorStop(1, '#feb47b');

// Apply the gradient dynamically
wavesurfer.setOptions({
  waveColor: gradient,
  progressColor: '#feb47b',
});

Legacy Wavesurfer.js (Version 6 and Earlier)

If you are using Wavesurfer.js v6 or older, the setOptions() API is not available. Instead, use the dedicated setter methods setWaveColor() and setProgressColor():

// Update individual colors in v6 and older
wavesurfer.setWaveColor('#9CA3AF');
wavesurfer.setProgressColor('#3B82F6');

If the waveform does not automatically update after changing properties in legacy builds, force a redraw using the buffer renderer:

wavesurfer.params.waveColor = '#9CA3AF';
wavesurfer.params.progressColor = '#3B82F6';
wavesurfer.drawBuffer();

Complete Implementation Example

Below is a complete implementation demonstrating dynamic color switching attached to a button click:

<div id="waveform"></div>
<button id="toggle-color-btn">Change Wave Color</button>

<script type="module">
  import WaveSurfer from 'https://unpkg.com/wavesurfer.js@7/dist/wavesurfer.esm.js';

  const wavesurfer = WaveSurfer.create({
    container: '#waveform',
    waveColor: '#d1d5db',
    progressColor: '#ef4444',
    url: 'audio.mp3',
  });

  const button = document.getElementById('toggle-color-btn');
  let isAltColor = false;

  button.addEventListener('click', () => {
    isAltColor = !isAltColor;

    wavesurfer.setOptions({
      waveColor: isAltColor ? '#3b82f6' : '#d1d5db',
      progressColor: isAltColor ? '#1d4ed8' : '#ef4444',
    });
  });
</script>
