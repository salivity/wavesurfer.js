Silence Detection Algorithm in Wavesurfer.js

This article explains the algorithm used to automatically detect and highlight silent audio segments in Wavesurfer.js. In audio visualization workflows, automatically isolating silence relies on parsing the raw PCM audio buffer using a threshold-based energy detection algorithm—typically Peak Amplitude or Root Mean Square (RMS) thresholding—combined with temporal constraints, which then feeds into the Wavesurfer.js Regions plugin to visually mark non-audible segments.

The Core Algorithm: Threshold-Based Energy Detection

Wavesurfer.js does not contain a machine-learning voice activity detector (VAD) by default; instead, it uses a time-domain thresholding algorithm. This algorithm processes the decoded audio buffer directly and identifies silence through five key phases:

1. Extracting Raw Channel Data

Once an audio file is loaded and decoded, Wavesurfer.js grants access to the underlying Web Audio API AudioBuffer. The algorithm extracts the channel data as a Float32Array, where each index represents an individual audio sample between -1.0 and 1.0.

2. Windowing and Power Calculation

The algorithm iterates through the sample array using discrete time windows (frames) to measure signal energy. Energy at each window is evaluated using one of two standard metrics:

  • Peak Absolute Amplitude: Evaluates the maximum absolute sample value within the window: \[\text{Peak} = \max(|x_i|)\]
  • Root Mean Square (RMS): Measures the average signal power over \(N\) samples, which better reflects perceived loudness: \[\text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^{N} x_i^2}\]

RMS or peak values are commonly converted to decibels relative to full scale (dBFS) using the formula: \[\text{dBFS} = 20 \log_{10}(\text{Value})\]

3. Threshold Evaluation

The calculated amplitude or RMS is compared against a predefined silence threshold. A typical threshold ranges between -30 dBFS and -50 dBFS (or approximately 0.01 to 0.003 in normalized linear amplitude). If the value falls below this threshold, the window is flagged as silent.

4. Temporal Filtering (Minimum Duration Constraints)

Individual sample drops can trigger false positives due to zero-crossings or brief pauses between syllables. To counter this, the algorithm enforces a Minimum Silence Duration condition:

  • A silent sequence starts when amplitude drops below the threshold.
  • The algorithm counts consecutive silent windows until an amplitude spike exceeds the threshold.
  • If the accumulated duration of the consecutive silent windows is greater than or equal to the minimum duration parameter (e.g., 0.5 seconds), the interval is marked as a valid silent segment.
  • Intervals shorter than this duration are discarded.

5. Region Generation

Once the boundaries (start and end timestamps in seconds) of all qualified segments are resolved, the algorithm passes these time coordinates to the Wavesurfer.js RegionsPlugin. The plugin renders visually distinct overlays across the waveform canvas at the exact coordinates of each silent stretch.
