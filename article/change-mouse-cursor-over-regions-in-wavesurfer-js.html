Change Mouse Cursor Over Regions in Wavesurfer.js

This guide explains how to customize the mouse cursor icon when hovering over regions in Wavesurfer.js. By default, the Regions plugin displays standard cursors for moving and resizing, but you can easily override these behaviors globally using CSS or per-region using the plugin's JavaScript API.

Method 1: Change Cursor Globally Using CSS

The simplest way to update the cursor across all regions is by targeting the DOM elements generated by the Wavesurfer.js Regions plugin.

Add the following rules to your stylesheet:

/* Change the cursor over the body of the region */
.wavesurfer-region {
  cursor: pointer !important; /* Options: grab, crosshair, default, etc. */
}

/* Optional: Customize the cursor when hovering over resize handles */
.wavesurfer-handle-start,
.wavesurfer-handle-end {
  cursor: col-resize !important;
}

If your implementation uses shadow DOM (common in certain custom elements or newer wrapper setups), ensure your styles target the appropriate host or part attributes if standard class targeting does not apply.

Method 2: Change Cursor per Region with JavaScript

If you need different cursors for different regions, you can manipulate the underlying DOM node directly via the region object.

When creating a region using the Regions plugin (Wavesurfer.js v7+):

import WaveSurfer from 'wavesurfer.js'
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js'

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'violet',
  progressColor: 'purple'
})

const wsRegions = ws.registerPlugin(RegionsPlugin.create())

// Create a region and apply a custom cursor
const region = wsRegions.addRegion({
  start: 10,
  end: 20,
  color: 'rgba(0, 255, 0, 0.2)',
  drag: true,
  resize: true
})

// Directly apply the cursor style to the region's DOM element
if (region.element) {
  region.element.style.cursor = 'grab'
}

Method 3: Change Cursor Dynamically on Hover Events

You can also dynamically update cursors in response to user interaction using region events:

wsRegions.on('region-mouseenter', (region) => {
  region.element.style.cursor = 'crosshair'
})

wsRegions.on('region-mouseleave', (region) => {
  region.element.style.cursor = 'default'
})

Using these methods, you can seamlessly adapt the cursor interface to match your application's design system and functional requirements.
