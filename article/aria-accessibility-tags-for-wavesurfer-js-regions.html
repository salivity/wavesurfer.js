ARIA Accessibility Tags for Wavesurfer.js Regions

This guide outlines the essential WAI-ARIA roles, states, and properties required to make interactive audio regions in Wavesurfer.js accessible to assistive technology users. By default, Wavesurfer.js renders visual overlays on an HTML canvas or unstyled <div> elements, which screen readers cannot interpret without explicit accessibility markup. Implementing the recommended ARIA attributes ensures that keyboard-only and screen reader users can perceive, navigate, and adjust custom audio regions effectively.

The Region Container

Interactive regions generated by the Wavesurfer.js Regions plugin should function semantically as discrete landmarks or actionable objects. Apply the following attributes to the main region wrapper element:

  • role="region" or role="group": Defines the container as a distinct, identifiable section of the audio track. If the region is primarily designed for playback or selection, role="button" or role="group" can also be appropriate.
  • aria-label or aria-labelledby: Provides a descriptive name for the region. For dynamic regions, this label should clearly state the context and current timestamps (for example, aria-label="Selection: 0 minutes 15 seconds to 0 minutes 45 seconds").
  • aria-roledescription="audio segment": Offers screen reader users a more intuitive description of the custom control beyond the standard generic region role.
  • tabindex="0": Places the region into the sequential keyboard navigation order so users can focus on it using the Tab key.

Region Boundary Handles (Start and End Controls)

When a region allows resizing, it includes drag handles for adjusting the start and end boundaries. These handles should be treated semantically as sliders:

  • role="slider": Informs assistive technology that the handle is an adjustable control along a range.
  • aria-label: Clearly differentiates the control, using labels such as "Region start time" or "Region end time".
  • aria-valuemin: Represents the minimum allowable timestamp in seconds (typically 0 for the start handle, or the current start time for the end handle).
  • aria-valuemax: Represents the maximum allowable timestamp in seconds (the current end time for the start handle, or total audio duration for the end handle).
  • aria-valuenow: The raw numeric value in seconds of the current handle position.
  • aria-valuetext: A human-readable time format corresponding to aria-valuenow (for example, "1 minute, 12 seconds"), preventing screen readers from reading arbitrary floating-point numbers.
  • tabindex="0": Enables direct keyboard focus for individual handle adjustment using arrow keys.

Active State and Dynamic Feedback

Regions that support selection, deletion, or continuous loop playback require dynamic state attributes:

  • aria-selected="true" or aria-selected="false": Indicates whether the region is the currently active or highlighted segment within the waveform track.
  • aria-live="polite": When placed on an associated status container, this property announces changes to the user without interrupting ongoing speech, such as when a region boundary is updated via keyboard controls or when loop playback is toggled.
  • aria-keyshortcuts: If custom keyboard commands exist for region manipulation (such as Delete to remove a region or Space to preview it), expose them via this attribute so users know which shortcuts are available.
