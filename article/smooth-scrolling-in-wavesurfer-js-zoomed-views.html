Smooth Scrolling in Wavesurfer.js Zoomed Views

When working with high-zoom audio waveforms in Wavesurfer.js, the default auto-scroll behavior can feel abrupt and visually jarring as the playhead moves across the view. This article provides a clear, step-by-step guide to achieving continuous, fluid scrolling during audio playback. You will learn how to bypass the standard stepped page-jumps and implement custom frame-by-frame auto-scrolling using modern browser rendering techniques.

The Problem with Default Scrolling

When you zoom into a Wavesurfer.js instance using wavesurfer.zoom(minPxPerSec), the waveform container overflows horizontally. Wavesurfer provides an autoCenter option, but during playback, it frequently updates the scroll position in discrete jumps rather than a continuous glide. Applying basic CSS scroll-behavior: smooth directly to the container often results in stuttering because continuous programmatic updates conflict with native CSS animation timing.

Step 1: Initialize Wavesurfer Without Native Centering

To gain full control over scrolling dynamics, disable the default auto-centering and auto-scrolling behavior in the Wavesurfer initialization configuration.

import WaveSurfer from 'wavesurfer.js';

const container = document.getElementById('waveform');

const wavesurfer = WaveSurfer.create({
  container: container,
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  minPxPerSec: 100, // Zoomed in view
  autoCenter: false, // Disable built-in centering
  autoScroll: false, // Disable built-in scrolling
});

wavesurfer.load('path/to/audio.mp3');

Step 2: Implement a requestAnimationFrame Scroll Loop

The most reliable way to achieve silky-smooth scrolling is to synchronize the container's horizontal scroll offset with the browser’s refresh rate using requestAnimationFrame.

Calculate the exact pixel position of the playhead based on the current playback progress, then offset the wrapper's scrollLeft property so the playhead stays anchored in the horizontal center.

let animationFrameId = null;

function smoothScroll() {
  if (!wavesurfer.isPlaying()) {
    return;
  }

  const wrapper = wavesurfer.getWrapper();
  const duration = wavesurfer.getDuration();
  const currentTime = wavesurfer.getCurrentTime();

  if (duration > 0 && wrapper) {
    const scrollWidth = wrapper.scrollWidth;
    const clientWidth = wrapper.clientWidth;

    // Calculate current position of the playhead in pixels
    const progress = currentTime / duration;
    const playheadPixels = progress * scrollWidth;

    // Center the playhead
    const targetScrollLeft = playheadPixels - clientWidth / 2;

    // Clamp the value within scrollable boundaries
    const maxScroll = scrollWidth - clientWidth;
    wrapper.scrollLeft = Math.max(0, Math.min(targetScrollLeft, maxScroll));
  }

  // Request the next frame
  animationFrameId = requestAnimationFrame(smoothScroll);
}

Step 3: Bind to Playback Lifecycle Events

Connect the animation frame loop to Wavesurfer's playback events to ensure that rendering occurs only when audio is actively playing, preventing unnecessary CPU and GPU usage.

wavesurfer.on('play', () => {
  cancelAnimationFrame(animationFrameId);
  animationFrameId = requestAnimationFrame(smoothScroll);
});

wavesurfer.on('pause', () => {
  cancelAnimationFrame(animationFrameId);
});

wavesurfer.on('finish', () => {
  cancelAnimationFrame(animationFrameId);
});

wavesurfer.on('destroy', () => {
  cancelAnimationFrame(animationFrameId);
});

Step 4: Handle User Seeking and Manual Scrubbing

When a user clicks on the waveform to seek, the playhead moves instantly. Trigger a one-time adjustment or allow the loop to update immediately so the viewport syncs without delay:

wavesurfer.on('seeking', () => {
  const wrapper = wavesurfer.getWrapper();
  const duration = wavesurfer.getDuration();
  const currentTime = wavesurfer.getCurrentTime();

  if (duration > 0 && wrapper) {
    const scrollWidth = wrapper.scrollWidth;
    const clientWidth = wrapper.clientWidth;
    const progress = currentTime / duration;
    const playheadPixels = progress * scrollWidth;

    wrapper.scrollLeft = Math.max(0, Math.min(playheadPixels - clientWidth / 2, scrollWidth - clientWidth));
  }
});

By delegating the viewport updates to requestAnimationFrame and managing the scrollLeft offset directly, you eliminate the discrete visual steps of native scrolling, creating a professional and fluid playback experience at any zoom level.
