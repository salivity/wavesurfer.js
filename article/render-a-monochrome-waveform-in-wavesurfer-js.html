Render a Monochrome Waveform in Wavesurfer.js

This guide explains how to render a clean, monochrome audio waveform using Wavesurfer.js by configuring its styling parameters. By standardizing the waveform and progress colors using grayscale values or identical color codes, you can eliminate default gradients and multi-colored states to achieve a minimalist, single-tone design for your audio player.

Core Configuration

Wavesurfer.js determines the appearance of the audio track primarily through the waveColor and progressColor properties passed to the WaveSurfer.create() method.

To create a monochrome look, assign neutral grayscale values (such as shades of black, white, or gray) to these options.

1. Flat Monochrome (No Progress Color Difference)

If you want the entire waveform to remain a single, unchanging color regardless of playback progress, assign the exact same color value to both waveColor and progressColor:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4a4a4a',
  progressColor: '#4a4a4a',
  cursorColor: '#000000',
  cursorWidth: 1,
  barWidth: 2,
  barGap: 1,
  barRadius: 2,
});

wavesurfer.load('path/to/audio.mp3');

2. Two-Tone Grayscale (With Progress Distinction)

To maintain visual feedback during playback while staying strictly monochrome, use contrasting values along the grayscale spectrum. A common pattern uses a lighter gray for unplayed audio and a solid black or dark charcoal for the played portion:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',     // Light gray (unplayed)
  progressColor: '#111827', // Near black (played)
  cursorColor: '#111827',   // Matches progress
  cursorWidth: 2,
  height: 80,
});

wavesurfer.load('path/to/audio.mp3');

Inverted (Dark Mode) Monochrome

For dark interfaces, invert the grayscale values so the waveform stands out against a dark background:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#374151',     // Dark gray (unplayed)
  progressColor: '#f9fafb', // Crisp white (played)
  cursorColor: '#ffffff',
});

Key Parameters for Monochrome Displays

  • waveColor: Controls the base waveform. Use hex codes (#000000, #888888), RGB strings (rgb(50, 50, 50)), or HSL values with zero saturation (hsl(0, 0%, 50%)).
  • progressColor: Dictates the color of the waveform behind the playback head. Set this equal to waveColor for a static appearance, or use a higher-contrast neutral tone for playback tracking.
  • cursorColor: Set to transparent ('transparent') if you want to completely hide the playhead line, or match it to your dark/light neutral tone to prevent unwanted color accents.
