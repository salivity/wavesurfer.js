Sync Scroll Between Two Wavesurfer.js Instances

Synchronizing horizontal scrolling across two stacked Wavesurfer.js instances requires listening to scroll events on each instance's container and mirroring the scroll position to the other. Because Wavesurfer renders its waveform inside a scrollable wrapper, the most reliable and performant method is binding native DOM scroll events directly to the wrapper elements while employing an update lock to avoid recursive event loops.

The Synchronization Method

When audio waveforms are zoomed in beyond the visible container width, Wavesurfer.js enables horizontal scrolling within its wrapper element. To synchronize two stacked instances, attach a standard DOM scroll listener to the wrapper of each instance. When one wrapper scrolls, read its scrollLeft property and assign that value to the scrollLeft property of the companion wrapper.

To prevent an infinite loop where Instance A updates Instance B, which in turn triggers an update back to Instance A, implement a boolean flag (or debounce check) that tracks active user scrolling.

Implementation

Assuming you have initialized two instances, ws1 and ws2:

// Access the scrollable wrapper elements of both instances
const wrapper1 = ws1.getWrapper();
const wrapper2 = ws2.getWrapper();

let isSyncingScroll = false;

// Sync ws2 when ws1 is scrolled
wrapper1.addEventListener('scroll', () => {
  if (!isSyncingScroll) {
    isSyncingScroll = true;
    wrapper2.scrollLeft = wrapper1.scrollLeft;
    requestAnimationFrame(() => {
      isSyncingScroll = false;
    });
  }
});

// Sync ws1 when ws2 is scrolled
wrapper2.addEventListener('scroll', () => {
  if (!isSyncingScroll) {
    isSyncingScroll = true;
    wrapper1.scrollLeft = wrapper2.scrollLeft;
    requestAnimationFrame(() => {
      isSyncingScroll = false;
    });
  }
});

Keeping Zoom and Seeking Aligned

For scroll synchronization to remain accurate across stacked tracks, both instances must maintain identical visual scales:

  1. Match Zoom Levels: Always apply zoom modifications symmetrically. Whenever ws1.zoom(pixelsPerSecond) is invoked, execute ws2.zoom(pixelsPerSecond) with the same value so that total pixel widths match.
  2. Mirror Seeking: To keep playheads aligned during manual interaction, listen to the interaction or seek events on both instances:
ws1.on('interaction', (newTime) => {
  ws2.setTime(newTime);
});

ws2.on('interaction', (newTime) => {
  ws1.setTime(newTime);
});

Using direct DOM scrollLeft synchronization paired with matching zoom levels ensures smooth, hardware-accelerated scrolling between both waveforms without visual lag or recursive call stack errors.
