Wavesurfer.js Real-Time Region Dragging Events

Synchronizing user interface input controls with region movements in Wavesurfer.js requires listening to continuous event emissions rather than completion events. This article explains the exact event bindings provided by the Wavesurfer.js Regions plugin to capture dragging and resizing coordinates in real time, and demonstrates how to bind these values to HTML input fields for seamless, two-way UI synchronization.

The Real-Time Event: region-update

In Wavesurfer.js (version 7+), the Regions plugin distinguishes between active manipulation and the completion of a change.

To track movements in real time while a user drags a region across the waveform, bind to the region-update event on the plugin instance, or the update event on an individual region instance.

  • region-update (Continuous): Fires on every mouse move frame while the region is being actively dragged or resized.
  • region-updated (Terminal): Fires only once when the user releases the mouse button (drag/resize end).

Plugin-Level Binding

Listening at the plugin level allows a single listener to handle real-time UI updates for any active region:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'violet',
  progressColor: 'purple'
});

const wsRegions = ws.registerPlugin(RegionsPlugin.create());

// Real-time listener for continuous dragging
wsRegions.on('region-update', (region, side) => {
  const startTimeInput = document.getElementById('start-time');
  const endTimeInput = document.getElementById('end-time');

  // Update input values on every drag frame
  startTimeInput.value = region.start.toFixed(2);
  endTimeInput.value = region.end.toFixed(2);
});

Instance-Level Binding

If managing a specific region reference, attach the listener directly to the Region object:

const region = wsRegions.addRegion({
  start: 2,
  end: 5,
  color: 'rgba(0, 255, 0, 0.3)',
  drag: true,
  resize: true
});

// Real-time updates for this specific region
region.on('update', (side) => {
  console.log(`Current position: ${region.start}s to ${region.end}s`);
  // side indicates dragging or resizing edge: 'start', 'end', or undefined (moving)
});

The optional side parameter indicates what action is occurring:

  • 'start': The user is dragging the left handle (resizing the start boundary).
  • 'end': The user is dragging the right handle (resizing the end boundary).
  • undefined: The entire region body is being moved (dragged along the timeline).

Complete Two-Way UI Binding

To ensure inputs can both display real-time dragging changes and update the waveform when manually edited, link the region-update event with the native HTML input event:

const startInput = document.getElementById('start-time');
const endInput = document.getElementById('end-time');

// 1. Region Dragging -> UI Inputs (Real-Time)
wsRegions.on('region-update', (region) => {
  startInput.value = region.start.toFixed(2);
  endInput.value = region.end.toFixed(2);
});

// 2. UI Inputs -> Region (Manual User Typing)
startInput.addEventListener('input', (e) => {
  const activeRegion = wsRegions.getRegions()[0];
  if (activeRegion) {
    activeRegion.setOptions({
      start: parseFloat(e.target.value) || 0
    });
  }
});

endInput.addEventListener('input', (e) => {
  const activeRegion = wsRegions.getRegions()[0];
  if (activeRegion) {
    activeRegion.setOptions({
      end: parseFloat(e.target.value) || 0
    });
  }
});

Using region-update guarantees that form inputs reflect the exact millisecond values throughout the entire duration of user interactions on the canvas.
