Wavesurfer.js Record Plugin Supported MIME Types

This article provides an overview of the MIME type formats supported by the Wavesurfer.js Record plugin, explains how browser compatibility dictates available formats, and demonstrates how to check for and set these audio formats in your implementation.

The Wavesurfer.js Record plugin relies directly on the browser's native MediaRecorder API to capture microphone input. Consequently, Wavesurfer.js does not maintain an independent list of proprietary audio encoders; it supports any audio MIME type that the host browser's MediaRecorder implementation supports.

The most common supported MIME types across modern browsers include:

  • audio/webm: The default and most widely supported format in Chromium-based browsers (Google Chrome, Microsoft Edge, Opera, Brave) and Mozilla Firefox. It often pairs with the Opus codec (audio/webm;codecs=opus).
  • audio/ogg: Supported natively by Mozilla Firefox and some Android browsers, typically using the Opus or Vorbis codecs (audio/ogg;codecs=opus).
  • audio/mp4: The standard format supported by Apple Safari across macOS and iOS devices (audio/mp4 or audio/aac).

Because format support varies between operating systems and browsers, WAV (audio/wav) is rarely supported natively by the MediaRecorder API without third-party polyfills or custom Web Audio API processing scripts.

To specify a MIME type in Wavesurfer.js, pass the mimeType option when initializing the plugin:

const record = ws.registerPlugin(
  RecordPlugin.create({
    mimeType: 'audio/webm;codecs=opus',
  })
)

If you do not specify a mimeType, or if the specified format is unsupported by the client device, the browser will fall back to its internal default format. To ensure cross-browser compatibility before initializing the plugin, query the browser support directly using the native method:

const mimeType = MediaRecorder.isTypeSupported('audio/webm;codecs=opus')
  ? 'audio/webm;codecs=opus'
  : MediaRecorder.isTypeSupported('audio/mp4')
  ? 'audio/mp4'
  : '';
