How to Resize Regions in Wavesurfer.js

This guide explains how to enable and control region resizing in the Wavesurfer.js Regions plugin. By configuring the resize option, developers can determine whether users have the ability to drag region boundaries along an interactive audio waveform to adjust start and end timestamps.

The resize Option

The option that allows resizing of regions in the Wavesurfer.js Regions plugin is the boolean property resize.

When set to true, the plugin renders draggable handles at the beginning and end of the specified region, allowing the user to interactively modify the region's duration. When set to false, the boundaries become locked, preventing any adjustments to the region's width.

How to Use the resize Option

You can define the resize property directly inside the parameters passed to the addRegion method when creating a new region.

Here is an implementation example:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
});

// Initialize the Regions plugin
const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

// Add a resizable region
wavesurfer.on('ready', () => {
  wsRegions.addRegion({
    start: 10,
    end: 25,
    content: 'Resizable Segment',
    color: 'rgba(0, 255, 0, 0.3)',
    resize: true, // Enables resizing capability
    drag: true,   // Allows moving the entire region along the timeline
  });
});

Region Event Listeners for Resizing

When resize is enabled, the plugin fires events that allow you to track changes to the region’s boundaries in real time:

  • region-updated: Fires continuously as the user drags a region's edge or moves it.
  • region-update-end: Fires once the user finishes dragging and releases the mouse cursor.

Example of listening to resize updates:

wsRegions.on('region-updated', (region) => {
  console.log(`New boundaries: Start at ${region.start}s, End at ${region.end}s`);
});

Setting resize: true provides an intuitive user experience for audio annotation, trimming, and loop selection tasks directly within the waveform interface.
