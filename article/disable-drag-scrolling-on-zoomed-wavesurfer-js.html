Disable Drag Scrolling on Zoomed Wavesurfer.js

This guide explains how to prevent users from click-dragging or panning horizontally across zoomed waveforms in Wavesurfer.js. When audio waveforms are zoomed in, the container creates a scrollable viewport where mouse or touch dragging can inadvertently scrub playback or pan the view. By tweaking Wavesurfer configuration options and applying targeted event overrides, you can lock the waveform against drag-scrolling while preserving playback and click-to-seek functionality.

Method 1: Disable Drag-to-Seek via Configuration (Wavesurfer.js v7+)

In Wavesurfer.js v7 and newer, dragging across the waveform to scroll or scrub playback is controlled directly through the dragToSeek configuration property. Setting this option to false allows users to click to jump to a specific timestamp, but prevents them from clicking and dragging across the zoomed container.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
  minPxPerSec: 100, // Zoomed state
  dragToSeek: false, // Disables click-and-drag scrubbing/panning
});

Method 2: Disabling All Direct Waveform Interactions

If you want the zoomed waveform to serve strictly as a visual display without permitting any user input (such as scrubbing, dragging, or clicking):

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
  minPxPerSec: 100,
  interact: false, // Disables all mouse and touch interactions entirely
});

To toggle this dynamically when zooming in or out, use the setOptions method:

// Disable interaction during zoom
wavesurfer.zoom(200);
wavesurfer.setOptions({ interact: false });

// Re-enable interaction when resetting zoom
wavesurfer.zoom(0);
wavesurfer.setOptions({ interact: true });

Method 3: Suppress Native Drag and Pan Events on the Wrapper

If browser-level touch actions or mouse events cause the zoomed scroll container to pan, you can intercept the pointer events on the container DOM element directly while keeping click events intact.

1. CSS Touch Action

Apply touch-action: pan-y or touch-action: none to the Wavesurfer container to prevent touch-drag panning on mobile devices:

#waveform {
  touch-action: pan-y; /* Allows vertical page scrolling, disables horizontal drag panning */
  user-select: none;
}

2. JavaScript Pointer Event Interception

To stop drag-scrolling initiated by mouse drag while still permitting standard single-click seeking, intercept the pointermove event on the container when a button is pressed:

const container = document.querySelector('#waveform');

container.addEventListener(
  'pointerdown',
  (e) => {
    const handleMove = (moveEvent) => {
      // Prevent drag propagation if the pointer moves while pressed down
      moveEvent.stopPropagation();
    };

    const handleUp = () => {
      window.removeEventListener('pointermove', handleMove, true);
      window.removeEventListener('pointerup', handleUp, true);
    };

    window.addEventListener('pointermove', handleMove, true);
    window.addEventListener('pointerup', handleUp, true);
  },
  { capture: true }
);

Using dragToSeek: false handles the internal Wavesurfer panning and scrubbing logic, while applying touch-action and pointer listeners prevents the browser container itself from scrolling when dragged.
