Adjust Time Notch Intervals in Wavesurfer.js

This guide explains how to customize the notch and label intervals in the Wavesurfer.js Timeline plugin. By default, Wavesurfer.js automatically calculates tick intervals based on zoom level and audio duration. However, you can explicitly define the spacing of primary and secondary time notches using the timeline plugin's configuration options, either as fixed second values or dynamic functions based on zoom levels.

Key Configuration Options

When initializing the Timeline plugin (specifically in Wavesurfer.js version 7 and above), notch intervals are controlled by three main properties:

  • timeInterval: Sets the interval (in seconds) between numeric time markers.
  • primaryLabelInterval: Defines which major ticks receive text labels (e.g., every 5th or 10th notch).
  • secondaryLabelInterval: Determines the frequency of minor tick marks between primary labels.

Setting Fixed Notch Intervals

To set static intervals where notches appear at uniform time steps regardless of zoom level, provide integer values representing seconds to the plugin configuration:

import WaveSurfer from 'wavesurfer.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  plugins: [
    TimelinePlugin.create({
      container: '#timeline',
      // Generate a notch every 5 seconds
      timeInterval: 5,
      // Place a primary label every 10 seconds
      primaryLabelInterval: 10,
      // Place a secondary notch every 1 second
      secondaryLabelInterval: 1,
    }),
  ],
});

Setting Dynamic Intervals Based on Zoom

If your application supports zooming, hardcoded second intervals can cause notches to overlap when zoomed out or appear too sparse when zoomed in. To resolve this, pass a callback function to timeInterval. The function receives the current pxPerSec (pixels per second) value, allowing you to adapt notch frequency dynamically:

TimelinePlugin.create({
  container: '#timeline',
  timeInterval: (pxPerSec) => {
    if (pxPerSec > 100) {
      return 0.5; // Half-second notches when zoomed in close
    } else if (pxPerSec > 50) {
      return 1;   // 1-second notches for standard view
    } else if (pxPerSec > 10) {
      return 5;   // 5-second notches when zoomed out
    }
    return 10;    // 10-second notches for wide views
  },
  primaryLabelInterval: (pxPerSec) => {
    return pxPerSec > 50 ? 5 : 10;
  },
  secondaryLabelInterval: (pxPerSec) => {
    return pxPerSec > 100 ? 0.1 : 1;
  },
});

Formatting the Time Display

When adjusting notches to sub-second or custom intervals, configure formatTimeCallback to match the precision of your intervals:

TimelinePlugin.create({
  container: '#timeline',
  timeInterval: 0.5,
  formatTimeCallback: (seconds) => {
    const minutes = Math.floor(seconds / 60);
    const remainingSeconds = (seconds % 60).toFixed(1);
    return `${minutes}:${remainingSeconds.padStart(4, '0')}`;
  },
});

Using these parameters allows you to keep timeline labels readable, prevent DOM overcrowding from too many SVG elements, and adapt tick density to any playback requirement.
