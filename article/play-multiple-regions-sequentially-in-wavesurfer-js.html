Play Multiple Regions Sequentially in Wavesurfer.js

This guide explains how to play multiple audio regions in sequence using Wavesurfer.js and its official Regions plugin. By maintaining a playlist queue of region references and listening to region-specific lifecycle events such as region-out, you can automatically advance playback to the next segment without manually tracking timestamps or recalculating offsets.

Prerequisites and Setup

To handle region events, ensure you have both the core wavesurfer.js package and the regions plugin loaded. In Wavesurfer.js v7+, plugins are registered directly on the instance.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize WaveSurfer
const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

// Initialize the Regions plugin
const wsRegions = ws.registerPlugin(RegionsPlugin.create());

Step 1: Create the Regions

Define your segments once the audio is decoded. Store references to the created regions or their IDs in an array that determines the playback order.

let regionQueue = [];
let currentQueueIndex = 0;
let isSequentialPlaying = false;

ws.on('ready', () => {
  // Define regions
  const r1 = wsRegions.addRegion({
    start: 2,
    end: 5,
    color: 'rgba(255, 0, 0, 0.2)',
    id: 'region-1',
  });

  const r2 = wsRegions.addRegion({
    start: 8,
    end: 12,
    color: 'rgba(0, 255, 0, 0.2)',
    id: 'region-2',
  });

  const r3 = wsRegions.addRegion({
    start: 15,
    end: 18,
    color: 'rgba(0, 0, 255, 0.2)',
    id: 'region-3',
  });

  // Store the order of playback
  regionQueue = [r1, r2, r3];
});

Step 2: Listen to the region-out Event

The Regions plugin provides a region-out event that fires whenever the playback cursor exits a region's boundary. Use this event to trigger the next region in the queue.

wsRegions.on('region-out', (region) => {
  if (!isSequentialPlaying) return;

  const currentRegion = regionQueue[currentQueueIndex];

  // Verify the region that just finished is the active queued region
  if (currentRegion && region.id === currentRegion.id) {
    currentQueueIndex++;

    if (currentQueueIndex < regionQueue.length) {
      // Play the next region in the queue
      regionQueue[currentQueueIndex].play();
    } else {
      // Reached the end of the queue
      stopSequentialPlayback();
    }
  }
});

Step 3: Trigger and Control Sequential Playback

Implement start and stop controller functions to manage the playback state and reset indices properly.

function startSequentialPlayback() {
  if (regionQueue.length === 0) return;

  isSequentialPlaying = true;
  currentQueueIndex = 0;

  // Begin by playing the first region
  regionQueue[currentQueueIndex].play();
}

function stopSequentialPlayback() {
  isSequentialPlaying = false;
  currentQueueIndex = 0;
  ws.pause();
}

Handling Edge Cases

  • Manual User Seeking: If a user clicks directly on the waveform while sequential playback is active, the queue can fall out of sync. To handle this, listen to the interaction event on the Wavesurfer instance and call stopSequentialPlayback() to prevent unpredictable jumping.
  • Overlapping Regions: If two regions in your sequence overlap, the region-out event of the previous region might conflict with the entry into the next. Sequential queues function most reliably with non-overlapping boundaries.
