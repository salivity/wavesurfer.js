How to Add Chapter Markers in Wavesurfer.js

This article explains how to display interactive chapter markers along a long-form podcast waveform using Wavesurfer.js. You will learn how to configure the Regions plugin to represent individual podcast chapters, style these markers for visual clarity, bind click events for instant chapter seeking, and update the active chapter dynamically during playback.

1. Prerequisites and Setup

Modern Wavesurfer.js (v7+) handles markers and segments using the official Regions Plugin. To get started, include Wavesurfer.js and the Regions plugin in your project via npm or CDN:

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/plugins/regions.min.js"></script>

2. Initialize Wavesurfer with the Regions Plugin

Initialize the main waveform container and register the RegionsPlugin. For long-form podcasts, set minPxPerSec to allow horizontal scrolling if the episode is lengthy, or leave it responsive for an overview layout.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize the Regions plugin
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',
  progressColor: '#3b82f6',
  url: '/path/to/podcast-episode.mp3',
  plugins: [wsRegions],
});

3. Define and Render Chapter Markers

Define your podcast chapters as an array of objects containing start times, end times, titles, and unique identifiers. Once the audio metadata is decoded, iterate over the list and add each chapter to the waveform.

const chapters = [
  { id: 'ch-1', start: 0, end: 120, title: 'Introduction' },
  { id: 'ch-2', start: 120, end: 480, title: 'Main Topic Discussion' },
  { id: 'ch-3', start: 480, end: 900, title: 'Guest Interview' },
  { id: 'ch-4', start: 900, end: 1100, title: 'Outro & Credits' },
];

wavesurfer.on('decode', () => {
  chapters.forEach((chapter, index) => {
    wsRegions.addRegion({
      id: chapter.id,
      start: chapter.start,
      end: chapter.end,
      content: chapter.title,
      color: index % 2 === 0 ? 'rgba(59, 130, 246, 0.1)' : 'rgba(99, 102, 241, 0.1)',
      drag: false,
      resize: false,
    });
  });
});

Setting drag: false and resize: false locks the chapter boundaries so listeners cannot accidentally alter the timestamps.

4. Enable Interactive Seeking and Events

Make the markers interactive by listening to region events. You can trigger audio playback or jump directly to the chapter start when a user clicks a marker.

// Seek and play when a user clicks on a chapter
wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation(); // Prevents default waveform click interference
  region.play();
});

5. Highlight the Current Chapter During Playback

To give listeners visual feedback on which chapter is currently playing, listen to the timeupdate event and apply an active CSS class to the corresponding region element.

wavesurfer.on('timeupdate', (currentTime) => {
  const currentChapter = chapters.find(
    (ch) => currentTime >= ch.start && currentTime < ch.end
  );

  wsRegions.getRegions().forEach((region) => {
    if (currentChapter && region.id === currentChapter.id) {
      region.element.classList.add('active-chapter');
    } else {
      region.element.classList.remove('active-chapter');
    }
  });
});

Add CSS to customize the appearance of chapters and the active state:

/* Style chapter text labels */
.wavesurfer-region {
  border-left: 2px solid #2563eb !important;
  font-size: 12px;
  font-weight: 500;
  color: #1f2937;
  padding-left: 4px;
  transition: background-color 0.2s ease;
}

/* Highlight the active playing chapter */
.wavesurfer-region.active-chapter {
  background-color: rgba(37, 99, 235, 0.2) !important;
}

6. Performance Optimization for Long Audio

Long podcast files can consume significant memory if the entire audio file must be decoded in the browser. For files longer than 30 minutes:

  • Use Pre-computed Peaks: Generate waveform peak data on your server (using tools like audiowaveform) and pass the JSON array to the peaks configuration option in Wavesurfer. This renders the waveform instantly without downloading the entire audio file upfront.
  • Point Markers vs. Bounded Regions: If you prefer discrete vertical lines rather than shaded intervals, set start and end to the same value in addRegion(). This renders a single line marker ideal for simple timestamp indexing.
