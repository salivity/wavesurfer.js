How to Add a Playhead Handle Icon in Wavesurfer.js

This guide explains how to add a custom playhead handle icon directly on top of the cursor line in Wavesurfer.js. While Wavesurfer renders a standard vertical line to track audio progress, audio applications often require a distinct visual handle—such as a triangle, diamond, or circle icon—at the top of the playhead. By wrapping the waveform in a relative container and synchronizing a custom DOM element with Wavesurfer’s playback events, you can implement a fully functional, interactive playhead handle.

Step 1: Create the HTML Structure

Wrap your waveform in a parent container with relative positioning. This container will hold both the Wavesurfer instance and the playhead handle.

<div id="waveform-wrapper" style="position: relative; width: 100%;">
  <!-- Custom Playhead Handle -->
  <div id="playhead-handle" class="playhead-handle">
    <!-- SVG or Icon -->
    <svg width="14" height="14" viewBox="0 0 24 24" fill="currentColor">
      <path d="M12 21l-10-18h20z"/>
    </svg>
  </div>
  
  <!-- Wavesurfer Container -->
  <div id="waveform"></div>
</div>

Step 2: Apply CSS Styling

Position the handle absolutely so it sits above the waveform. Use a CSS transform to center the icon horizontally over the cursor position.

#waveform-wrapper {
  position: relative;
  width: 100%;
}

.playhead-handle {
  position: absolute;
  top: -8px; /* Position slightly above the waveform edge */
  left: 0%;
  transform: translateX(-50%);
  z-index: 10;
  pointer-events: none; /* Allows clicks to pass through to the waveform */
  color: #ff3e3e; /* Icon color */
  transition: opacity 0.2s ease;
}

Step 3: Initialize Wavesurfer and Sync the Handle

Initialize Wavesurfer.js (version 7+) and use the timeupdate and seeking events to update the handle's left position as a percentage of the total track duration.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',
  progressColor: '#3b82f6',
  cursorColor: '#ff3e3e',
  cursorWidth: 2,
  url: '/path-to-audio.mp3',
});

const handle = document.getElementById('playhead-handle');

// Function to update handle position
function updatePlayheadPosition() {
  const duration = wavesurfer.getDuration();
  if (!duration) return;

  const currentTime = wavesurfer.getCurrentTime();
  const progressPercent = (currentTime / duration) * 100;
  handle.style.left = `${progressPercent}%`;
}

// Update position during playback
wavesurfer.on('timeupdate', updatePlayheadPosition);

// Update position when user clicks or seeks
wavesurfer.on('seeking', updatePlayheadPosition);

// Set initial position once the audio is ready
wavesurfer.on('ready', updatePlayheadPosition);

Step 4: Alternative Approach via CSS Pseudo-elements

If you prefer not to manage an extra DOM element, you can attach a pseudo-element (::after or ::before) directly to Wavesurfer's internal progress element.

/* Target the progress element created by Wavesurfer */
#waveform ::part(progress) {
  position: relative;
  overflow: visible !important;
}

#waveform ::part(progress)::after {
  content: '';
  position: absolute;
  right: -6px; /* Center over the progress edge */
  top: -6px;
  width: 12px;
  height: 12px;
  background-color: #ff3e3e;
  clip-path: polygon(50% 100%, 0 0, 100% 0); /* Triangle shape */
  z-index: 5;
}

Note: The ::part(progress) selector applies when Wavesurfer uses the Shadow DOM. If your setup uses standard DOM elements, target the .wavesurfer-progress or the equivalent wrapper class directly.
