Add Audio Filter Toggles in Wavesurfer.js

This guide explains how to integrate low-pass and high-pass filter toggles into a custom control bar for Wavesurfer.js. By leveraging the Web Audio API’s BiquadFilterNode, you can intercept the audio stream generated by Wavesurfer.js and dynamically alter frequency responses in real time. Below, you will find the structural HTML, Web Audio node routing, and JavaScript event listeners required to implement smooth filter switching.

1. HTML Interface

Create the layout for the waveform container alongside the filter toggle buttons.

<div id="waveform"></div>

<div class="custom-controls">
  <button id="btn-bypass" class="filter-btn active">Normal</button>
  <button id="btn-lowpass" class="filter-btn">Low-Pass Filter</button>
  <button id="btn-highpass" class="filter-btn">High-Pass Filter</button>
</div>

2. Audio Node Architecture

Wavesurfer.js uses an underlying HTML5 <audio> element by default in modern versions (v7+). To apply filtering, connect that media element to an AudioContext, pass its signal through a BiquadFilterNode, and finally route it to the output destination (audioContext.destination).

3. JavaScript Implementation

Initialize Wavesurfer, establish the audio nodes once the audio source is ready, and configure the filter toggles.

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: 'path/to/your-audio.mp3',
});

let audioContext;
let filterNode;
let sourceNode;

// 2. Set up Web Audio Routing on 'ready'
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();

  // Create or reuse an AudioContext
  audioContext = new (window.AudioContext || window.webkitAudioContext)();
  sourceNode = audioContext.createMediaElementSource(mediaElement);
  filterNode = audioContext.createBiquadFilter();

  // Default state: Allpass (no alteration)
  filterNode.type = 'allpass';

  // Connect: Media Element -> Filter Node -> Audio Destination
  sourceNode.connect(filterNode);
  filterNode.connect(audioContext.destination);
});

// Resume AudioContext if suspended (browser autoplay policy)
wavesurfer.on('play', () => {
  if (audioContext && audioContext.state === 'suspended') {
    audioContext.resume();
  }
});

4. Wiring the Toggle Buttons

Create a function to manage filter states, cutoff frequencies, and UI button updates.

const btnBypass = document.getElementById('btn-bypass');
const btnLowpass = document.getElementById('btn-lowpass');
const btnHighpass = document.getElementById('btn-highpass');
const filterButtons = [btnBypass, btnLowpass, btnHighpass];

function updateActiveButton(activeBtn) {
  filterButtons.forEach((btn) => btn.classList.remove('active'));
  activeBtn.classList.add('active');
}

// Bypass (Normal Audio)
btnBypass.addEventListener('click', () => {
  if (!filterNode) return;
  filterNode.type = 'allpass';
  updateActiveButton(btnBypass);
});

// Low-Pass Filter (Cuts higher frequencies, keeps bass/lows)
btnLowpass.addEventListener('click', () => {
  if (!filterNode) return;
  filterNode.type = 'lowpass';
  filterNode.frequency.setValueAtTime(800, audioContext.currentTime); // 800 Hz cutoff
  filterNode.Q.setValueAtTime(1, audioContext.currentTime);
  updateActiveButton(btnLowpass);
});

// High-Pass Filter (Cuts lower frequencies, keeps treble/highs)
btnHighpass.addEventListener('click', () => {
  if (!filterNode) return;
  filterNode.type = 'highpass';
  filterNode.frequency.setValueAtTime(1500, audioContext.currentTime); // 1500 Hz cutoff
  filterNode.Q.setValueAtTime(1, audioContext.currentTime);
  updateActiveButton(btnHighpass);
});

5. Key Considerations

  • Autoplay Restrictions: Browsers require user interaction to activate an AudioContext. Resuming the context inside the play event prevents silent playback bugs.
  • Cutoff Frequencies: Adjust the cutoff parameter in filterNode.frequency.setValueAtTime() to suit the profile of your audio assets. Common initial values are 500–1000 Hz for low-pass and 1000–2000 Hz for high-pass.
  • Q Factor: The Q property represents the resonance peak near the cutoff frequency. A value around 1 keeps transitions natural, while higher values create noticeable sweeps or resonant rings.
