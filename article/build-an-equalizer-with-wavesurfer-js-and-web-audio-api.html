Build an Equalizer with Wavesurfer.js and Web Audio API

This guide demonstrates how to build an interactive graphic audio equalizer using Wavesurfer.js for waveform visualization and the Web Audio API for multi-band frequency control. You will learn how to set up audio nodes using BiquadFilterNode, chain them sequentially, route the audio signal from Wavesurfer through this filter chain, and bind dynamic UI sliders to manipulate frequency gains in real time.

Step 1: Set Up the HTML Structure

Create an HTML container to host the Wavesurfer waveform, play/pause controls, and an equalizer interface containing range sliders for individual frequency bands.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Audio Equalizer</title>
  <style>
    #waveform { width: 100%; height: 128px; background: #f3f3f3; }
    .eq-container { display: flex; gap: 20px; margin-top: 20px; }
    .eq-band { display: flex; flex-direction: column; align-items: center; }
    .eq-band input[type="range"] { writing-mode: vertical-lr; direction: rtl; height: 120px; }
  </style>
</head>
<body>
  <div id="waveform"></div>
  <button id="playBtn">Play / Pause</button>

  <div class="eq-container" id="eqContainer">
    <!-- Sliders are dynamically generated or hardcoded -->
  </div>

  <script src="https://unpkg.com/wavesurfer.js"></script>
  <script src="app.js"></script>
</body>
</html>

Step 2: Initialize Wavesurfer.js

In app.js, define the desired frequency bands and instantiate Wavesurfer. Configure it to use an HTML5 audio element so that it can be hooked into an AudioContext.

const frequencies = [60, 170, 310, 600, 1000, 3000, 6000, 12000, 14000, 16000];

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: 'your-audio-file.mp3',
});

document.getElementById('playBtn').addEventListener('click', () => {
  wavesurfer.playPause();
});

Step 3: Create the Web Audio API Filter Chain

Each slider corresponds to a BiquadFilterNode. Low frequencies use lowshelf, high frequencies use highshelf, and middle frequencies use peaking filters. Connect each filter to the next in the sequence.

const audioContext = new (window.AudioContext || window.webkitAudioContext)();

const filters = frequencies.map((freq, index) => {
  const filter = audioContext.createBiquadFilter();

  if (index === 0) {
    filter.type = 'lowshelf';
  } else if (index === frequencies.length - 1) {
    filter.type = 'highshelf';
  } else {
    filter.type = 'peaking';
    filter.Q.value = 1; // Bandwidth control
  }

  filter.frequency.value = freq;
  filter.gain.value = 0; // Default 0 dB (flat response)
  return filter;
});

// Chain filters together sequentially
filters.reduce((prev, curr) => {
  prev.connect(curr);
  return curr;
});

Step 4: Route Wavesurfer Audio Through the Filters

Connect the media element from Wavesurfer through the start of the filter chain, and connect the final filter to the output destination (audioContext.destination).

wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const source = audioContext.createMediaElementSource(mediaElement);

  // Connect source -> first filter -> ... -> last filter -> speakers
  source.connect(filters[0]);
  filters[filters.length - 1].connect(audioContext.destination);
});

Step 5: Build UI Controls and Bind Input Events

Generate range inputs for each frequency band. Adjusting a slider changes the gain.value of the corresponding BiquadFilterNode in decibels (typically between -40 dB and +40 dB).

const eqContainer = document.getElementById('eqContainer');

filters.forEach((filter) => {
  const band = document.createElement('div');
  band.className = 'eq-band';

  const slider = document.createElement('input');
  slider.type = 'range';
  slider.min = -20;
  slider.max = 20;
  slider.value = 0;
  slider.step = 0.5;

  slider.addEventListener('input', (e) => {
    // Resume context if browser autoplay policy suspended it
    if (audioContext.state === 'suspended') {
      audioContext.resume();
    }
    filter.gain.value = parseFloat(e.target.value);
  });

  const label = document.createElement('label');
  label.textContent = filter.frequency.value >= 1000 
    ? `${filter.frequency.value / 1000}k` 
    : `${filter.frequency.value}Hz`;

  band.appendChild(slider);
  band.appendChild(label);
  eqContainer.appendChild(band);
});

This completes the equalizer. Wavesurfer provides the interactive track position and audio timeline, while the Web Audio API filter graph shapes the output frequency response directly based on user input.
