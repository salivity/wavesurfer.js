Position Wavesurfer.js Timeline Above or Below

This article explains how to control the placement of the timeline plugin relative to the audio waveform in Wavesurfer.js. By configuring specific plugin options—namely insertPosition or the custom container parameter—developers can effortlessly position the timeline either above or below the rendered waveform.

Using the insertPosition Option

In modern versions of Wavesurfer.js (v7+), the TimelinePlugin includes the insertPosition property. This property controls where the timeline element is injected relative to the Wavesurfer wrapper element, using standard DOM insertion keywords.

  • To place the timeline above the waveform: Set insertPosition to 'beforebegin'.
  • To place the timeline below the waveform: Set insertPosition to 'afterend' (which is commonly the default behavior).

Example Implementation

import WaveSurfer from 'wavesurfer.js'
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js'

// Timeline placed above the waveform
const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#312E81',
  plugins: [
    TimelinePlugin.create({
      insertPosition: 'beforebegin', // Positions timeline above the waveform
      height: 20,
      timeInterval: 0.5,
      primaryLabelInterval: 5,
    }),
  ],
})

If you prefer the timeline at the bottom, change insertPosition to 'afterend'.

Using a Dedicated container Element

Another approach—compatible with both current and older versions of Wavesurfer.js—is to assign the timeline to its own HTML <div> via the container option. This method provides the greatest flexibility for custom CSS and layouts.

1. Structure the HTML

Place your timeline container above or below your waveform container in your HTML markup:

<!-- Place timeline above -->
<div id="timeline"></div>
<div id="waveform"></div>

(Swap the order of the two div elements if you want the timeline below.)

2. Target the Container in the Plugin Configuration

Specify the selector or DOM node using the container option within TimelinePlugin.create():

import WaveSurfer from 'wavesurfer.js'
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js'

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#A8A29E',
  progressColor: '#1C1917',
  plugins: [
    TimelinePlugin.create({
      container: '#timeline', // Mounts to the specific DOM element
    }),
  ],
})

By leveraging either insertPosition directly in the plugin options or providing an external container, you can place the timeline above or below the waveform.
