Prevent Page Scroll When Zooming in Wavesurfer.js

Using a mouse wheel to zoom into audio waveforms in Wavesurfer.js frequently causes an annoying conflict where the entire browser page scrolls simultaneously. This article demonstrates how to isolate the mouse wheel event on the Wavesurfer container, disable the default page scrolling behavior using JavaScript, and implement a smooth, conflict-free zooming experience.

The Cause of the Conflict

Browsers bubble the wheel event up to the window object by default. Unless a listener explicitly captures the event and tells the browser to cancel the native action, the viewport will scroll up or down whenever the user rotates the mouse wheel over the waveform.

The Solution: Event Interception with preventDefault()

To stop the page from scrolling, attach a native wheel event listener directly to the container element holding the Wavesurfer instance. Within the listener callback, call e.preventDefault() to stop native page movement, then adjust the Wavesurfer zoom level based on the direction of e.deltaY.

import WaveSurfer from 'wavesurfer.js';

const container = document.querySelector('#waveform');

const wavesurfer = WaveSurfer.create({
  container: container,
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  minPxPerSec: 50,
});

// Track the current zoom level
let currentZoom = 50;
const minZoom = 10;
const maxZoom = 500;
const zoomStep = 10;

// Intercept wheel events on the container
container.addEventListener('wheel', (e) => {
  // Prevent the webpage from scrolling
  e.preventDefault();

  // Adjust zoom based on scroll direction
  if (e.deltaY < 0) {
    currentZoom = Math.min(maxZoom, currentZoom + zoomStep);
  } else {
    currentZoom = Math.max(minZoom, currentZoom - zoomStep);
  }

  // Apply the new zoom level
  wavesurfer.zoom(currentZoom);
}, { passive: false });

Important: Setting passive: false

Modern browsers treat wheel listeners as passive: true by default to optimize scrolling performance. If you do not explicitly pass { passive: false } in the third argument of addEventListener, the browser will ignore e.preventDefault(), and the page will continue to scroll.

Recommended UX Practice: Use a Modifier Key

Completely blocking the scroll wheel inside a large waveform can trap users who are trying to scroll past the audio player. A standard design pattern (used by services like Google Maps) is to require a modifier key such as Ctrl or Meta to activate the zoom functionality:

container.addEventListener('wheel', (e) => {
  // Only intercept if the Ctrl (or Cmd on Mac) key is pressed
  if (e.ctrlKey || e.metaKey) {
    e.preventDefault();

    if (e.deltaY < 0) {
      currentZoom = Math.min(maxZoom, currentZoom + zoomStep);
    } else {
      currentZoom = Math.max(minZoom, currentZoom - zoomStep);
    }

    wavesurfer.zoom(currentZoom);
  }
  // If the key is not held, the browser handles normal page scrolling
}, { passive: false });

Using this modifier key approach prevents page-trapping while ensuring that intentional zooming actions remain smooth and completely isolated from the page scroll.
