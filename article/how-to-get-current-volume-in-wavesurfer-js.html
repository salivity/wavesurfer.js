How to Get Current Volume in Wavesurfer.js

This guide explains how to check the current audio playback volume in Wavesurfer.js. You will learn the exact method used to read the volume level, understand the format of the returned value, and see a practical JavaScript code example showing how to integrate it into your audio player controls.

To retrieve the current volume setting of an active Wavesurfer instance, use the getVolume() method.

The getVolume() Method

Calling getVolume() on your Wavesurfer instance returns a floating-point number representing the current loudness level. The value is normalized:

  • 0: Complete silence (muted)
  • 1: Full standard volume (100%)
  • Values between 0 and 1 represent proportional volume percentages (for example, 0.5 represents 50% volume).

Code Example

Here is how you initialize Wavesurfer and retrieve the current volume:

import WaveSurfer from 'wavesurfer.js';

// Initialize the instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
});

// Set an initial volume (optional)
wavesurfer.setVolume(0.75);

// Retrieve the current volume
const currentVolume = wavesurfer.getVolume();

console.log(`Current volume is: ${currentVolume}`); // Outputs: Current volume is: 0.75

Common Use Cases

  • Syncing UI Sliders: When building custom media controls, use wavesurfer.getVolume() to set the initial position of a volume range input element.
  • Toggling Mute State: You can read the current volume before muting the player to save the level, allowing you to restore the previous non-zero volume when the user unmutes.
