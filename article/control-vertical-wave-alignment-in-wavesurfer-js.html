Control Vertical Wave Alignment in Wavesurfer.js

Wavesurfer.js provides built-in configuration options to manipulate how audio waveforms render visually on a canvas. This guide explains how to control vertical wave alignment using the barAlign parameter, detailing its available values and demonstrating how to align your audio visualization to the top, bottom, or center of the container.

The barAlign Option

In modern versions of Wavesurfer.js (v7 and newer), vertical wave alignment is controlled using the barAlign option during player initialization. By default, Wavesurfer.js centers the waveform vertically within the container element. Setting the barAlign property allows you to anchor the waveform either to the top or the bottom edge instead.

Supported Values

The barAlign property accepts the following values:

  • undefined (Default): Leaves the waveform vertically centered, extending equally above and below the horizontal centerline.
  • 'bottom': Aligns the baseline of the waveform to the bottom of the canvas, rendering all amplitude bars upward. This is the common layout for modern voice-message players.
  • 'top': Aligns the baseline of the waveform to the top of the canvas, rendering the amplitude bars downward.

Implementation Example

To apply vertical alignment, pass barAlign into the configuration object of WaveSurfer.create() alongside your visual preferences:

import WaveSurfer from 'wavesurfer.js'

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#312E81',
  url: '/audio/track.mp3',
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
  barAlign: 'bottom', // Controls vertical alignment ('top' or 'bottom')
})

Dynamic Updates

If you need to change alignment dynamically after initialization, use the setOptions method:

wavesurfer.setOptions({
  barAlign: 'top',
})

Using barAlign provides complete control over the vertical placement of audio bars to fit diverse interface layouts without requiring custom canvas manipulation.
