Wavesurfer.js Number Key Audio Seeking Guide

Mapping the number keys 0 through 9 to percentage-based playback positions allows users to navigate audio tracks quickly, mirroring standard media controls found on platforms like YouTube. In Wavesurfer.js, this functionality is achieved by capturing keyboard events and using the player's seeking API to move the playhead to decile fractions of the total audio duration. This article outlines the specific key-to-percentage mapping and provides a direct JavaScript implementation to integrate this feature into your audio player.

The Number Key Mapping Breakdown

Media players typically map the top-row and numpad keys 0 through 9 to 10% increments of the track, starting from the beginning (0%) through to the final tenth (90%). The mapping is calculated as the integer value of the key divided by 10:

  • 0 Key: 0% (0.0) — Jumps to the beginning of the track
  • 1 Key: 10% (0.1) — Jumps to 10% of the total duration
  • 2 Key: 20% (0.2) — Jumps to 20% of the total duration
  • 3 Key: 30% (0.3) — Jumps to 30% of the total duration
  • 4 Key: 40% (0.4) — Jumps to 40% of the total duration
  • 5 Key: 50% (0.5) — Jumps to the midpoint of the track
  • 6 Key: 60% (0.6) — Jumps to 60% of the total duration
  • 7 Key: 70% (0.7) — Jumps to 70% of the total duration
  • 8 Key: 80% (0.8) — Jumps to 80% of the total duration
  • 9 Key: 90% (0.9) — Jumps to 90% of the total duration

Implementing the Mapping in Wavesurfer.js

Wavesurfer.js provides the seekTo(progress) method, where progress is a normalized float value between 0 (start) and 1 (end). To bind the keys, attach a keydown listener to the window or the specific container element holding the player.

// Initialize Wavesurfer instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple'
});

// Listen for keyboard input
window.addEventListener('keydown', (event) => {
  // Prevent seeking when the user is typing in form inputs
  const targetTag = event.target.tagName.toLowerCase();
  if (targetTag === 'input' || targetTag === 'textarea') {
    return;
  }

  // Check if the pressed key is between '0' and '9'
  if (event.key >= '0' && event.key <= '9') {
    event.preventDefault();
    
    // Convert key to a fraction (e.g., '3' -> 0.3)
    const targetProgress = parseInt(event.key, 10) / 10;
    
    // Jump to the calculated position
    wavesurfer.seekTo(targetProgress);
  }
});

Important Considerations

  • Active Elements: Always check event.target to ensure the user is not actively typing into a text field, search bar, or editable element before triggering the jump.
  • Ready State: Ensure the audio file is fully decoded before executing seekTo(). Seeking before the ready or decode event has fired will result in errors or unresponsive controls.
  • Playback Continuity: Using seekTo() updates the playhead position immediately. If the audio is currently playing, Wavesurfer.js continues playback smoothly from the new timestamp; if the audio is paused, the playhead moves while remaining paused.
