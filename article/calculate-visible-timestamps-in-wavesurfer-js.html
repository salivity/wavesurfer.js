Calculate Visible Timestamps in Wavesurfer.js

This article explains the mathematical formula and implementation details required to calculate the visible start and end timestamps in a scrollable Wavesurfer.js waveform. By obtaining the container's horizontal scroll offset, visible client width, total rendered width, and the audio file's total duration, you can accurately track which segment of the audio track is currently in the user's viewport.

The Required Variables

To calculate the visible time range, you need access to the DOM element wrapping the rendered waveform and the audio duration metadata provided by Wavesurfer.js:

  1. scrollLeft: The horizontal pixel distance the waveform container has been scrolled from the left edge.
  2. clientWidth: The visible width in pixels of the waveform's scrollable container (the viewport).
  3. scrollWidth: The total pixel width of the entire rendered waveform (visible and hidden areas combined).
  4. duration: The total duration of the loaded audio file in seconds.

The Mathematical Formula

The ratio of the scrolled distance to the total width directly corresponds to the ratio of elapsed time to the total audio duration.

  • Visible Start Time (seconds): \[\text{startTime} = \left(\frac{\text{scrollLeft}}{\text{scrollWidth}}\right) \times \text{duration}\]

  • Visible End Time (seconds): \[\text{endTime} = \left(\frac{\text{scrollLeft} + \text{clientWidth}}{\text{scrollWidth}}\right) \times \text{duration}\]

Alternatively, if you define your zoom level using pixels per second (minPxPerSec), you can compute the visible timestamps without relying on scrollWidth:

  • startTime = scrollLeft / minPxPerSec
  • endTime = (scrollLeft + clientWidth) / minPxPerSec

JavaScript Implementation

In modern versions of Wavesurfer.js (v7+), the scrollable wrapper element can be obtained via the getWrapper() method. You can attach a scroll listener to dynamically compute the time boundaries whenever the user pans across the audio:

const wrapper = wavesurfer.getWrapper();

function getVisibleTimeRange() {
  const scrollLeft = wrapper.scrollLeft;
  const clientWidth = wrapper.clientWidth;
  const scrollWidth = wrapper.scrollWidth;
  const duration = wavesurfer.getDuration();

  // Guard against division by zero if duration or width is not yet loaded
  if (!scrollWidth || !duration) {
    return { start: 0, end: 0 };
  }

  const startTime = (scrollLeft / scrollWidth) * duration;
  const endTime = Math.min(
    duration,
    ((scrollLeft + clientWidth) / scrollWidth) * duration
  );

  return {
    start: startTime,
    end: endTime
  };
}

// Listen to scroll events on the wrapper
wrapper.addEventListener('scroll', () => {
  const { start, end } = getVisibleTimeRange();
  console.log(`Visible range: ${start.toFixed(2)}s to ${end.toFixed(2)}s`);
});

Using Math.min(duration, ...) ensures that rounding inaccuracies or scroll-bouncing effects on mobile viewports do not produce an end timestamp greater than the actual audio duration.
