Wavesurfer.js Envelope Plugin Volume Automation

This article provides a practical guide on implementing volume automation points using the Wavesurfer.js Envelope plugin. You will learn how to initialize the plugin within a Wavesurfer instance, define initial volume control points, programmatically add new automation points, and link these points to real-time audio volume control.

Installing and Importing the Plugin

The Envelope plugin is part of the official Wavesurfer.js package (version 7 and newer). Import the core library alongside the Envelope plugin:

import WaveSurfer from 'wavesurfer.js';
import EnvelopePlugin from 'wavesurfer.js/dist/plugins/envelope.esm.js';

Initializing WaveSurfer with the Envelope Plugin

To create volume automation points, instantiate the Envelope plugin and pass it into the plugins array of your WaveSurfer configuration. You can define initial points directly in the plugin options using time markers (in seconds) and volume levels (typically ranging from 0 to 1).

// Create the Envelope plugin instance
const envelope = EnvelopePlugin.create({
  fadeInEnd: 0,
  fadeOutStart: 0,
  volume: 0.8, // Default base volume
  points: [
    { time: 0, volume: 0.2 },
    { time: 2, volume: 1.0 },
    { time: 5, volume: 0.5 },
  ],
  dragPointSize: 8,
  lineColor: 'rgba(0, 102, 255, 0.8)',
  lineWidth: 2,
  pointColor: '#0066ff',
});

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#ddd',
  progressColor: '#555',
  url: '/path/to/audio.mp3',
  plugins: [envelope],
});

Adding Volume Points Programmatically

You can add new automation points dynamically after initialization using the addPoint method provided by the plugin instance. This method accepts an object specifying the timestamp and target volume.

// Add a point at 3.5 seconds with 70% volume
envelope.addPoint({
  time: 3.5,
  volume: 0.7,
});

Connecting Envelope Points to Audio Output

By default, the Envelope plugin visually maps and emits volume values. To alter the actual audio gain dynamically as the playhead advances, listen to the envelope's change events and apply the calculated volume to WaveSurfer's audio output:

// Update volume on drag or point changes
envelope.on('volume-change', (newVolume) => {
  wavesurfer.setVolume(newVolume);
});

For continuous, frame-accurate automation during playback, read the interpolated volume at the current playback time using envelope.getCurrentVolume():

wavesurfer.on('timeupdate', (currentTime) => {
  const currentVolume = envelope.getCurrentVolume();
  wavesurfer.setVolume(currentVolume);
});

Managing Existing Points

The Envelope plugin provides methods to manage and clear points as needed:

  • Remove a Point: Call envelope.removePoint(point) where point is a reference to an existing point object.
  • Get All Points: Access the array of current automation nodes via envelope.getPoints().
  • Clear Points: Replace points dynamically using envelope.setPoints([]) to clear the envelope or reset to default configurations.
