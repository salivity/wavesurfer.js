Pass HLS.js Media Element to Wavesurfer.js

Integrating HLS.js with Wavesurfer.js allows you to stream HTTP Live Streaming (HLS) audio while visualizing the waveform in real time. This article explains how to instantiate an HTML5 audio element, attach an HLS source using HLS.js, and pass that media element directly into Wavesurfer.js to keep playback and visualization synchronized.

Prerequisites

To implement this solution, ensure you have imported both the HLS.js and Wavesurfer.js libraries into your project via npm or CDN scripts:

<script src="https://cdn.jsdelivr.net/npm/hls.js@latest"></script>
<script src="https://unpkg.com/wavesurfer.js@7"></script>

1. Set Up the DOM Elements

Create a container for the waveform visualization and an optional audio element. Wavesurfer.js can either consume an existing DOM element or create one programmatically.

<div id="waveform"></div>
<audio id="audio-element" controls></audio>

2. Initialize HLS.js on the Media Element

Instantiate HLS.js, load the .m3u8 source manifest, and attach the stream to the HTML <audio> element.

const audio = document.getElementById('audio-element');
const streamUrl = 'https://example.com/path/to/stream.m3u8';

if (Hls.isSupported()) {
  const hls = new Hls();
  hls.loadSource(streamUrl);
  hls.attachMedia(audio);

  hls.on(Hls.Events.MANIFEST_PARSED, () => {
    initWaveSurfer(audio);
  });
} else if (audio.canPlayType('application/vnd.apple.mpegurl')) {
  // Native HLS support for Safari
  audio.src = streamUrl;
  audio.addEventListener('loadedmetadata', () => {
    initWaveSurfer(audio);
  });
}

3. Pass the Media Element to Wavesurfer.js

Wavesurfer.js (v7+) accepts an existing HTMLMediaElement through its media configuration property. When provided, Wavesurfer synchronizes directly with the native element's playback state rather than decoding audio buffers independently.

function initWaveSurfer(mediaElement) {
  const wavesurfer = WaveSurfer.create({
    container: '#waveform',
    waveColor: '#4F46E5',
    progressColor: '#818CF8',
    media: mediaElement, // Passes the HLS-connected element
  });

  wavesurfer.on('ready', () => {
    console.log('WaveSurfer is ready with the HLS media element.');
  });
}

Key Considerations

  • Waveform Generation: Because HLS delivers segmented media (.ts or .m4s chunks), Wavesurfer.js cannot automatically pre-decode the entire file into a full waveform buffer. To display a static waveform upfront, you must provide pre-computed peak data via the peaks array option in Wavesurfer's configuration.
  • CORS Headers: Ensure the server hosting the HLS segments and playlists includes proper Access-Control-Allow-Origin headers. Without CORS permissions, the browser will block the Web Audio API context from processing the stream.
  • Live vs. VOD Streams: This implementation works best with Video on Demand (VOD) HLS streams that have a fixed duration. Live streams have shifting timelines, which require dynamically redrawing peaks as segments arrive.
