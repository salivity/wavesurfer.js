Export Wavesurfer.js Waveforms as PNG Images

Exporting rendered audio waveforms from Wavesurfer.js as PNG snapshots is accomplished using the built-in exportImage() method in modern versions of the library, which relies on the standard HTML5 Canvas toDataURL() method under the hood. This guide explains how to extract waveform image data as a PNG and trigger an automatic client-side file download.

The Primary Export Method

In Wavesurfer.js (version 7 and newer), the primary method to generate image snapshots is wavesurfer.exportImage().

By default, this method invokes the native HTML5 Canvas method HTMLCanvasElement.toDataURL('image/png') on the internal rendering canvases, returning a Promise that resolves to an array of Data URLs (base64-encoded strings) representing the waveform.

// Export waveform as PNG Data URLs
wavesurfer.exportImage('image/png', 1, 'dataURL').then((dataURLs) => {
  const pngDataUrl = dataURLs[0];
  downloadImage(pngDataUrl, 'waveform.png');
});

Direct Canvas Export: toDataURL()

If you are interacting directly with the underlying HTML <canvas> element rendered by Wavesurfer.js, the core browser method used is:

const canvas = document.querySelector('#waveform canvas');
const dataUrl = canvas.toDataURL('image/png');

For large or multi-canvas waveforms, HTMLCanvasElement.toBlob() can also be used to prevent memory overhead caused by large base64 strings:

canvas.toBlob((blob) => {
  const url = URL.createObjectURL(blob);
  downloadImage(url, 'waveform.png');
}, 'image/png');

Implementing the PNG Snapshot Download

To download the exported waveform as an image file on the user's computer, dynamically create an anchor (<a>) element, assign the generated PNG URL, and trigger a click event.

function downloadWaveform(wavesurfer, filename = 'waveform.png') {
  // Ensure the audio is decoded and rendered before exporting
  wavesurfer.exportImage('image/png', 1, 'dataURL').then((images) => {
    if (!images || images.length === 0) return;

    const link = document.createElement('a');
    link.href = images[0];
    link.download = filename;
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  });
}

Exporting in Wavesurfer.js v6 and Older

In legacy versions (v6 and below), exportImage() returns the Data URL directly rather than a Promise:

// Wavesurfer.js v6 syntax
const dataUrl = wavesurfer.exportImage('image/png', 1);

const link = document.createElement('a');
link.href = dataUrl;
link.download = 'waveform-v6.png';
link.click();
