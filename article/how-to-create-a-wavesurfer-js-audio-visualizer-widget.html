How to Create a Wavesurfer.js Audio Visualizer Widget

This article provides a step-by-step guide to building a lightweight, interactive audio visualizer widget using Wavesurfer.js that can be embedded on any external website. You will learn how to load the library, initialize customizable waveform rendering, implement essential playback controls, and package the entire solution into a single, embeddable script or iframe for seamless third-party integration.

1. Include Wavesurfer.js

To ensure the widget works independently on external websites, load Wavesurfer.js via a Content Delivery Network (CDN) or bundle it directly into your script.

<script src="https://unpkg.com/wavesurfer.js@7"></script>

2. Define the Widget Markup

Create a minimal container structure to hold the visualizer canvas and the user controls.

<div id="audio-widget-container" class="audio-widget">
  <div id="waveform"></div>
  <div class="controls">
    <button id="play-pause-btn" type="button">Play</button>
    <span id="time-display">0:00 / 0:00</span>
  </div>
</div>

3. Initialize the Waveform

Instantiate Wavesurfer by targeting your container element and defining visual properties such as wave colors, cursor appearance, and bar dimensions.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#d1d5db',
  progressColor: '#3b82f6',
  cursorColor: '#1d4ed8',
  barWidth: 2,
  barGap: 1,
  barRadius: 2,
  height: 80,
  responsive: true,
  url: 'https://example.com/audio/sample.mp3'
});

4. Implement Playback and Event Handling

Bind the user controls to Wavesurfer's API methods and update the playback time dynamically using event listeners.

const playBtn = document.getElementById('play-pause-btn');
const timeDisplay = document.getElementById('time-display');

playBtn.addEventListener('click', () => {
  wavesurfer.playPause();
});

wavesurfer.on('play', () => {
  playBtn.textContent = 'Pause';
});

wavesurfer.on('pause', () => {
  playBtn.textContent = 'Play';
});

const formatTime = (seconds) => {
  const minutes = Math.floor(seconds / 60);
  const remainingSeconds = Math.floor(seconds % 60);
  return `${minutes}:${remainingSeconds < 10 ? '0' : ''}${remainingSeconds}`;
};

wavesurfer.on('ready', (duration) => {
  timeDisplay.textContent = `0:00 / ${formatTime(duration)}`;
});

wavesurfer.on('audioprocess', (currentTime) => {
  timeDisplay.textContent = `${formatTime(currentTime)} / ${formatTime(wavesurfer.getDuration())}`;
});

5. Package for External Embedding

To distribute the visualizer to external sites, you can use an iframe or a self-contained JavaScript snippet.

Method A: The Iframe Embed

Host your visualizer HTML file on a public server and provide users with a standard iframe tag. This isolates all styles and scripts from the host website's environment:

<iframe 
  src="https://yourdomain.com/widget.html?audio=https://example.com/song.mp3" 
  width="100%" 
  height="140" 
  frameborder="0" 
  allow="autoplay">
</iframe>

Method B: The Script Embed

Create a single JavaScript file (e.g., widget.js) that automatically scans for target elements, injects required styles, and sets up Wavesurfer:

<div data-audio-widget="https://example.com/song.mp3"></div>
<script src="https://yourdomain.com/widget.js" async></script>

In widget.js, read the data-audio-widget attribute, dynamically load Wavesurfer if not already present, build the inner HTML elements, and run the initialization logic. This approach allows the visualizer to blend seamlessly with the parent site's responsive layout.
