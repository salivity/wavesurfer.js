How to Mute Audio in Wavesurfer.js

Muting audio in Wavesurfer.js is a straightforward process that allows developers to silence playback dynamically without stopping or resetting track progress. This guide outlines the primary methods for toggling and controlling the mute state using Wavesurfer's built-in API, handling volume restoration, and implementing a functional mute toggle button in your web application.

Using the setMuted Method

The most direct way to mute and unmute audio in modern versions of Wavesurfer.js (version 7 and later) is by using the setMuted() method. This method accepts a boolean argument: true to mute the audio, and false to unmute it.

// Mute the audio
wavesurfer.setMuted(true);

// Unmute the audio
wavesurfer.setMuted(false);

To check whether the player is currently muted, use the getMuted() method:

const isMuted = wavesurfer.getMuted(); // Returns true or false

Implementing a Mute Toggle Button

You can combine getMuted() and setMuted() to create a simple toggle button in your user interface.

<button id="mute-btn">Mute</button>

<script>
  const muteButton = document.getElementById('mute-btn');

  muteButton.addEventListener('click', () => {
    const isMuted = wavesurfer.getMuted();
    
    // Toggle the mute state
    wavesurfer.setMuted(!isMuted);

    // Update button text
    muteButton.textContent = isMuted ? 'Mute' : 'Unmute';
  });
</script>

Alternative Approach: Adjusting Volume

In legacy versions of Wavesurfer.js where setMuted() might not be available, or if you need granular control, you can achieve the same effect by manipulating the volume using setVolume().

// Store the previous volume before muting (values range from 0 to 1)
let previousVolume = wavesurfer.getVolume() || 1;

function toggleMute() {
  const currentVolume = wavesurfer.getVolume();

  if (currentVolume > 0) {
    previousVolume = currentVolume;
    wavesurfer.setVolume(0); // Silence the audio
  } else {
    wavesurfer.setVolume(previousVolume); // Restore previous volume
  }
}

Listening for Volume and Mute Events

Wavesurfer emits events when volume levels change, allowing you to synchronize other UI elements, such as volume sliders or icons.

wavesurfer.on('volume', (newVolume) => {
  console.log(`Current volume: ${newVolume}`);
  if (wavesurfer.getMuted()) {
    console.log('Audio is currently muted.');
  }
});
