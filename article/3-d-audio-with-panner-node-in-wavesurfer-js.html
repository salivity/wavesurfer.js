3D Audio with PannerNode in Wavesurfer.js

Integrating 3D spatial audio into a Wavesurfer.js workflow requires routing the audio pipeline through the Web Audio API’s PannerNode and configuring its spatial properties alongside the AudioListener. By setting parameters such as panning models, distance attenuation, directional cones, and 3D coordinate vectors, developers can place and move audio sources in a simulated three-dimensional soundstage while maintaining accurate waveform rendering and playback synchronization.

Connecting the Web Audio Graph in Wavesurfer.js

Wavesurfer.js can utilize an existing AudioContext or instantiate its own. To apply 3D audio, you must route Wavesurfer’s audio output through a PannerNode before it reaches AudioContext.destination.

In Wavesurfer.js v7, you can create a custom Web Audio graph using an external AudioContext and media element, or pipe the nodes directly:

const audioContext = new AudioContext();

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio-sample.mp3',
  audioContext: audioContext,
});

const panner = audioContext.createPanner();

wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const source = audioContext.createMediaElementSource(mediaElement);

  source.connect(panner);
  panner.connect(audioContext.destination);
});

Essential PannerNode Configurations for 3D Space

To achieve realistic 3D positioning, several core configurations must be defined on the PannerNode:

1. Panning Model

The panningModel determines the spatialization algorithm:

  • HRTF (Head-Related Transfer Function): Essential for true 3D spatial positioning. It simulates how sound waves interact with human anatomy (ears, head, torso) and yields convincing depth and elevation, particularly over headphones.
  • equalpower: Computes stereo panning primarily across the left-to-right axis. While computationally cheaper, it does not provide true 3D elevation or behind-the-head perception.
panner.panningModel = 'HRTF';

2. Distance Models and Attenuation

The distanceModel dictates how the volume decreases as the source moves away from the listener:

  • inverse: Standard inverse-distance curve. Default and most natural sounding for general environments.
  • linear: Linear attenuation between refDistance and maxDistance. Useful for games or restricted interaction spaces.
  • exponential: Steep drop-off as distance increases.

Key attenuation properties include:

  • refDistance: The distance at which volume is at full scale (e.g., 1).
  • maxDistance: The maximum distance past which attenuation no longer increases.
  • rolloffFactor: How quickly the volume diminishes over distance.
panner.distanceModel = 'inverse';
panner.refDistance = 1;
panner.maxDistance = 10000;
panner.rolloffFactor = 1;

3. Directional Sound Cones

By default, a sound source radiates omnidirectionally. Setting cone parameters makes the sound directional (like a megaphone or a speaker facing forward):

  • coneInnerAngle: Angle (in degrees) where volume is unaffected (e.g., 60).
  • coneOuterAngle: Angle beyond which the volume drops to coneOuterGain (e.g., 120).
  • coneOuterGain: Volume multiplier outside the outer cone (e.g., 0.1).
panner.coneInnerAngle = 60;
panner.coneOuterAngle = 120;
panner.coneOuterGain = 0.2;

4. Coordinates and Orientation

Position and orientation can be updated dynamically during Wavesurfer playback. Modern implementations use standard AudioParam attributes:

// Positioning source in 3D space: (x = left/right, y = up/down, z = front/back)
panner.positionX.setValueAtTime(2, audioContext.currentTime);  // 2 meters to the right
panner.positionY.setValueAtTime(0, audioContext.currentTime);  // Eye level
panner.positionZ.setValueAtTime(-1, audioContext.currentTime); // 1 meter in front

// Orientation vector (facing forward along the Z axis)
panner.orientationX.setValueAtTime(0, audioContext.currentTime);
panner.orientationY.setValueAtTime(0, audioContext.currentTime);
panner.orientationZ.setValueAtTime(1, audioContext.currentTime);

Configuring the AudioListener

For 3D placement to resolve accurately, the AudioContext.listener position and forward/up vectors must be established:

const listener = audioContext.listener;

// Place listener at the origin
listener.positionX.setValueAtTime(0, audioContext.currentTime);
listener.positionY.setValueAtTime(0, audioContext.currentTime);
listener.positionZ.setValueAtTime(0, audioContext.currentTime);

// Facing down the negative Z-axis with Y as the upward direction
listener.forwardX.setValueAtTime(0, audioContext.currentTime);
listener.forwardY.setValueAtTime(0, audioContext.currentTime);
listener.forwardZ.setValueAtTime(-1, audioContext.currentTime);
listener.upX.setValueAtTime(0, audioContext.currentTime);
listener.upY.setValueAtTime(1, audioContext.currentTime);
listener.upZ.setValueAtTime(0, audioContext.currentTime);

By binding these spatial parameters to UI sliders, canvas inputs, or mouse movements, you can adjust 3D audio positioning in real time alongside Wavesurfer.js visual timeline markers.
