Styling Active vs Inactive Wavesurfer Waveforms

Customizing visual styles for active and inactive states in Wavesurfer.js allows developers to create intuitive, modern audio interfaces that clearly show playback progress. In Wavesurfer.js, the "inactive" state refers to the unplayed portion of the audio track, while the "active" state represents the played portion. This guide demonstrates how to configure these states using basic color properties, multi-stop canvas gradients, and dynamic runtime updates.

Understanding Waveform States

Wavesurfer.js handles state visualization primarily through two core properties:

  • waveColor: Controls the color or pattern of the unplayed (inactive) portion of the waveform.
  • progressColor: Controls the color or pattern of the played (active) portion of the waveform that tracks behind the playhead.

Basic Color Configuration

The simplest way to differentiate active from inactive states is during the initialization of the WaveSurfer instance using hex, RGB, or CSS color strings.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4a5568',      // Inactive waveform (dark gray)
  progressColor: '#3182ce',  // Active waveform (vibrant blue)
  cursorColor: '#e2e8f0',    // Playhead indicator
  cursorWidth: 2,
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
});

wavesurfer.load('path/to/audio.mp3');

Advanced Styling with Canvas Gradients

To achieve sophisticated visuals, both waveColor and progressColor accept an HTML5 Canvas CanvasGradient object instead of simple color strings. This enables vertical, horizontal, or multi-stop gradients that distinguish the played section from the unplayed section.

const canvas = document.createElement('canvas');
const ctx = canvas.getContext('2d');

// Define dimensions matching the waveform height
const height = 128;

// Create inactive gradient (subtle top-to-bottom fade)
const inactiveGradient = ctx.createLinearGradient(0, 0, 0, height);
inactiveGradient.addColorStop(0, '#718096');
inactiveGradient.addColorStop(1, '#2d3748');

// Create active gradient (bright top-to-bottom accent)
const activeGradient = ctx.createLinearGradient(0, 0, 0, height);
activeGradient.addColorStop(0, '#63b3ed');
activeGradient.addColorStop(1, '#3182ce');

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  height: height,
  waveColor: inactiveGradient,
  progressColor: activeGradient,
});

Dynamic State Updates

If you need to change the visual states dynamically—such as dimming the entire waveform when paused or changing the active color based on playback events—use the setOptions method.

// Dim styling when paused (inactive state overall)
wavesurfer.on('pause', () => {
  wavesurfer.setOptions({
    waveColor: '#2d3748',
    progressColor: '#4a5568',
  });
});

// Highlight styling when playing (active playback state)
wavesurfer.on('play', () => {
  wavesurfer.setOptions({
    waveColor: '#4a5568',
    progressColor: '#38a169', // Switch to active green
  });
});

Handling Hover and Interactive States

To visually indicate hover states before a user clicks to seek:

  1. Target the waveform container with standard CSS to adjust opacity or cursors.
  2. Listen to pointer events on the container and call setOptions() to alter the cursorColor or waveform intensity when the user interacts with the track.
