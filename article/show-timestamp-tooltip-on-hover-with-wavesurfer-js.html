Show Timestamp Tooltip on Hover with Wavesurfer.js

This guide explains how to display an accurate, interactive timestamp tooltip when hovering over an audio waveform using Wavesurfer.js. You will learn the easiest approach using the modern Wavesurfer.js Hover plugin, as well as a custom DOM-based approach for developers who require granular control over tooltip styling and positioning.

Method 1: Using the Official Hover Plugin (Wavesurfer.js v7+)

Wavesurfer.js version 7 includes a dedicated Hover plugin designed specifically to render a tracking line and a timestamp label at the cursor's location.

1. Import and Initialize

Install or load Wavesurfer.js along with the Hover plugin:

<!-- HTML Structure -->
<div id="waveform"></div>

<!-- Script setup using ES modules -->
<script type="module">
  import WaveSurfer from 'https://unpkg.com/wavesurfer.js@7/dist/wavesurfer.esm.js'
  import Hover from 'https://unpkg.com/wavesurfer.js@7/dist/plugins/hover.esm.js'

  const wavesurfer = WaveSurfer.create({
    container: '#waveform',
    waveColor: '#A8DBA8',
    progressColor: '#3B8686',
    url: 'path/to/your-audio.mp3',
    plugins: [
      Hover.create({
        lineColor: '#ff0000',
        lineWidth: 2,
        labelBackground: '#222',
        labelColor: '#fff',
        labelSize: '12px',
      }),
    ],
  })
</script>

2. Configuration Options

The Hover.create() function accepts the following visual styling properties:

  • lineColor: The color of the vertical guide line tracking the pointer.
  • lineWidth: The thickness of the tracking line in pixels.
  • labelBackground: The background color of the timestamp tooltip bubble.
  • labelColor: The font color of the timestamp text.
  • labelSize: Font size (e.g., '11px').
  • formatTimeCallback: An optional custom function to format the displayed seconds into custom text.

Method 2: Creating a Custom HTML/CSS Tooltip

If you need full control over custom HTML markup, animations, or styling, you can listen to pointer events directly on the waveform container.

1. HTML and CSS

Create the container and a hidden tooltip element:

<div id="waveform-wrapper" style="position: relative; width: 100%;">
  <div id="waveform"></div>
  <div id="hover-tooltip" style="
    position: absolute;
    top: 5px;
    display: none;
    background: rgba(0, 0, 0, 0.8);
    color: #fff;
    padding: 3px 8px;
    font-size: 12px;
    border-radius: 4px;
    pointer-events: none;
    transform: translateX(-50%);
    white-space: nowrap;
    z-index: 10;
  ">0:00</div>
</div>

2. JavaScript Event Handling

Calculate the timestamp from mouse coordinates and update the tooltip:

import WaveSurfer from 'https://unpkg.com/wavesurfer.js@7/dist/wavesurfer.esm.js'

const container = document.getElementById('waveform')
const tooltip = document.getElementById('hover-tooltip')

const wavesurfer = WaveSurfer.create({
  container: container,
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: 'path/to/your-audio.mp3',
})

// Time formatter utility (Converts seconds to M:SS)
function formatTime(seconds) {
  const minutes = Math.floor(seconds / 60)
  const remainingSeconds = Math.floor(seconds % 60)
  return `${minutes}:${remainingSeconds < 10 ? '0' : ''}${remainingSeconds}`
}

// Track mouse position over the waveform
container.addEventListener('pointermove', (event) => {
  const duration = wavesurfer.getDuration()
  if (!duration) return

  const rect = container.getBoundingClientRect()
  const offsetX = event.clientX - rect.left
  const progressRatio = Math.max(0, Math.min(offsetX / rect.width, 1))
  const hoverTime = duration * progressRatio

  // Update tooltip content and position
  tooltip.textContent = formatTime(hoverTime)
  tooltip.style.left = `${offsetX}px`
  tooltip.style.display = 'block'
})

// Hide tooltip on mouse leave
container.addEventListener('pointerleave', () => {
  tooltip.style.display = 'none'
})

Summary of Implementation Choice

Use the Hover plugin when you want an immediate, built-in solution with minimal code. Choose the Custom HTML/CSS method when you require complex layouts, CSS transitions, or dynamic UI components within the tooltip.
