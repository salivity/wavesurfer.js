TypeScript Definitions for Wavesurfer.js

Official TypeScript definitions for Wavesurfer.js are bundled directly inside the core wavesurfer.js npm package starting with version 7. This article explains where these type files are located in modern releases, how they differ from legacy versions, and how to access them in your development workflow.

Modern Wavesurfer.js (Version 7+)

Starting with version 7.0.0, Wavesurfer.js was completely rewritten from the ground up in TypeScript. Because the source code itself is written in TypeScript, the type definitions are generated automatically during the build process and shipped natively with the package.

You do not need to install any separate packages like @types/wavesurfer.js. When you install the library using an npm client:

npm install wavesurfer.js

The type declarations are automatically resolved by TypeScript. Within your project, the compiled declaration files reside in:

node_modules/wavesurfer.js/dist/

You can view the original TypeScript source files directly in the official GitHub repository in the src/ directory.

Legacy Wavesurfer.js (Version 6 and Below)

For older versions of Wavesurfer.js (v6 and earlier), the library was written in vanilla JavaScript without bundled typings. For these legacy versions, community-maintained TypeScript definitions are hosted on DefinitelyTyped and distributed via npm under the @types/wavesurfer.js namespace:

npm install --save-dev @types/wavesurfer.js

These definitions should only be used if your project is constrained to Wavesurfer.js version 6 or older.

Using Types in Your Project

In modern TypeScript projects using Wavesurfer.js v7+, you can import both the main class and specific type interfaces directly from the package:

import WaveSurfer, { WaveSurferOptions } from 'wavesurfer.js';

const options: WaveSurferOptions = {
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio.mp3',
};

const wavesurfer: WaveSurfer = WaveSurfer.create(options);

Plugins distributed in modern Wavesurfer.js packages also include their own dedicated types, located inside their respective subdirectories within the primary package distribution (e.g., wavesurfer.js/dist/plugins/).
