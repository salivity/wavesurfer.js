How to Mock Canvas in Wavesurfer.js Tests

Running automated unit or integration tests for Wavesurfer.js often results in failures because headless environments like Jest and jsdom do not natively implement the HTML5 Canvas API. Wavesurfer relies heavily on the 2d rendering context to draw waveforms, meaning you must provide mock implementations of canvas methods to allow your test suite to run without crashing. This guide explains why these failures occur and provides both automated and manual methods to mock the canvas context for Wavesurfer.js.

Why Canvas Needs to Be Mocked

In Node-based testing environments such as Jest, Vitest, or Mocha running on top of jsdom, HTMLCanvasElement.prototype.getContext('2d') returns null or throws an error by default. When Wavesurfer initializes, it attempts to access this context to measure dimensions and render audio peaks. Without an active context, Wavesurfer will throw runtime exceptions such as TypeError: Cannot read properties of null (reading 'fillRect') or fail to complete rendering hooks.

Method 1: Using jest-canvas-mock (Recommended)

The standard and most comprehensive approach for Jest and Vitest is to use the jest-canvas-mock package. It provides a full mock implementation of the Canvas API.

1. Install the Package

Run the following command in your terminal:

npm install --save-dev jest-canvas-mock

2. Configure Your Test Setup

If you are using Jest, add the library to your setupFiles array inside jest.config.js:

module.exports = {
  setupFiles: ['jest-canvas-mock'],
  testEnvironment: 'jsdom',
};

Alternatively, you can import it directly inside your dedicated test setup file (e.g., setupTests.js):

import 'jest-canvas-mock';

If using Vitest, import jest-canvas-mock inside your setupFiles script defined in vitest.config.ts.

Method 2: Manual Context Mocking

If you prefer to avoid adding external dependencies, you can manually stub HTMLCanvasElement.prototype.getContext before your tests run. Wavesurfer only calls a subset of the 2D context methods during typical lifecycle events.

Add this setup script in a test setup file or before initializing Wavesurfer:

beforeAll(() => {
  HTMLCanvasElement.prototype.getContext = function (contextType) {
    if (contextType === '2d') {
      return {
        canvas: this,
        fillRect: () => {},
        clearRect: () => {},
        getImageData: (x, y, w, h) => ({
          data: new Uint8ClampedArray(w * h * 4),
        }),
        putImageData: () => {},
        createImageData: () => [],
        setTransform: () => {},
        drawImage: () => {},
        save: () => {},
        fillText: () => {},
        restore: () => {},
        beginPath: () => {},
        moveTo: () => {},
        lineTo: () => {},
        closePath: () => {},
        stroke: () => {},
        translate: () => {},
        scale: () => {},
        rotate: () => {},
        arc: () => {},
        fill: () => {},
        measureText: () => ({ width: 0 }),
        transform: () => {},
        rect: () => {},
        clip: () => {},
        createLinearGradient: () => ({
          addColorStop: () => {},
        }),
      };
    }
    return null;
  };
});

Additional Requirement: Mocking Web Audio

In addition to Canvas, Wavesurfer.js requires the Web Audio API (AudioContext), which is also missing in jsdom. To prevent audio-related exceptions during your canvas tests, mock AudioContext and OfflineAudioContext alongside your canvas mock:

window.AudioContext = window.AudioContext || class {
  createGain() {
    return { connect: () => {} };
  }
  createMediaElementSource() {
    return { connect: () => {} };
  }
  close() {
    return Promise.resolve();
  }
};

window.OfflineAudioContext = window.OfflineAudioContext || window.AudioContext;

Verifying the Setup

You can verify that your context mock works as expected with a simple test verifying Wavesurfer initialization:

import WaveSurfer from 'wavesurfer.js';

describe('Wavesurfer Initialization', () => {
  let container;

  beforeEach(() => {
    container = document.createElement('div');
    document.body.appendChild(container);
  });

  afterEach(() => {
    container.remove();
  });

  it('initializes without throwing canvas errors', () => {
    expect(() => {
      const ws = WaveSurfer.create({
        container,
        waveColor: '#ff0000',
        progressColor: '#0000ff',
      });
      ws.destroy();
    }).not.toThrow();
  });
});
