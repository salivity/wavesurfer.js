Build a Right-Click Annotations Menu in Wavesurfer.js

Adding a custom right-click context menu to Wavesurfer.js allows users to dynamically insert markers, tags, and region annotations at exact timestamps in an audio track. This guide demonstrates how to suppress the default browser context menu over the waveform canvas, calculate the audio playback position from cursor coordinates, display a custom contextual menu, and attach region-based annotations using the official Wavesurfer.js Regions plugin.

Prerequisites and Initialization

To build this feature, you need the core wavesurfer.js library along with its regions plugin. The following implementation uses Wavesurfer.js v7:

<div id="waveform-container" style="position: relative;">
  <div id="waveform"></div>
  <div id="custom-menu" class="context-menu">
    <button id="add-marker">Add Marker</button>
    <button id="add-region">Add 2s Region</button>
  </div>
</div>
.context-menu {
  display: none;
  position: absolute;
  z-index: 1000;
  background: #ffffff;
  border: 1px solid #cccccc;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15);
  border-radius: 4px;
  padding: 4px 0;
}

.context-menu button {
  display: block;
  width: 100%;
  padding: 8px 16px;
  background: none;
  border: none;
  text-align: left;
  cursor: pointer;
  font-size: 14px;
}

.context-menu button:hover {
  background-color: #f0f0f0;
}

Initializing Wavesurfer with Regions

Create the Wavesurfer instance and register the RegionsPlugin:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const wsRegions = RegionsPlugin.create();

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  plugins: [wsRegions],
});

Intercepting the Right-Click Event

To attach the context menu to the audio timeline, listen for the contextmenu event on the waveform's wrapper element. You must call event.preventDefault() to stop the native browser menu from appearing, then calculate the audio timestamp based on the horizontal click position:

const waveformContainer = document.getElementById('waveform-container');
const menu = document.getElementById('custom-menu');
let targetTime = 0;

waveformContainer.addEventListener('contextmenu', (e) => {
  e.preventDefault();

  const rect = waveformContainer.getBoundingClientRect();
  const clickX = e.clientX - rect.left;
  const containerWidth = rect.width;
  const duration = wavesurfer.getDuration();

  // Calculate audio timestamp based on relative cursor position
  targetTime = (clickX / containerWidth) * duration;

  // Position and display the context menu
  menu.style.left = `${clickX}px`;
  menu.style.top = `${e.clientY - rect.top}px`;
  menu.style.display = 'block';
});

Handling Actions and Creating Annotations

Once the menu is visible and the target timestamp is stored, wire the menu options to trigger annotation actions in the Regions plugin:

// Add a single-point marker annotation
document.getElementById('add-marker').addEventListener('click', () => {
  wsRegions.addRegion({
    start: targetTime,
    content: 'Marker Note',
    color: 'rgba(255, 0, 0, 0.5)',
  });
  hideMenu();
});

// Add a spanned region annotation
document.getElementById('add-region').addEventListener('click', () => {
  wsRegions.addRegion({
    start: targetTime,
    end: Math.min(targetTime + 2, wavesurfer.getDuration()),
    content: 'Region Note',
    color: 'rgba(0, 123, 255, 0.3)',
  });
  hideMenu();
});

function hideMenu() {
  menu.style.display = 'none';
}

// Dismiss the menu on outside clicks
document.addEventListener('click', (e) => {
  if (!menu.contains(e.target)) {
    hideMenu();
  }
});

Managing Region Events

Once regions are placed, listen for region interactions to support editing, dragging, or removing existing annotations:

wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation();
  const label = prompt('Update annotation label:', region.content?.innerText || '');
  if (label !== null) {
    region.setOptions({ content: label });
  }
});

wsRegions.on('region-double-clicked', (region, e) => {
  e.stopPropagation();
  region.remove();
});

This configuration ensures accurate spatial mapping between screen coordinates and audio time while keeping the user interface responsive and isolated from standard browser shortcuts.
