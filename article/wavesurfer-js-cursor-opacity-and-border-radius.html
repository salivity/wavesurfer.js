Wavesurfer.js Cursor Opacity and Border Radius

This guide covers how to adjust the opacity and border radius of the playback cursor in Wavesurfer.js. While Wavesurfer.js provides built-in initialization options for cursor color and dimensions, it does not include a dedicated parameter for border radius. Opacity is handled directly through the cursorColor option using alpha-supported color formats, whereas applying a border radius requires targeting the cursor element through CSS or utilizing custom plugin configurations.

Setting Cursor Opacity

Wavesurfer.js does not feature an independent cursorOpacity property in its core API. Instead, opacity is set directly through the cursorColor option using CSS color notations that support an alpha channel, such as rgba(), hsla(), or 8-digit hexadecimal values.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  cursorWidth: 4,
  // 50% opacity using RGBA
  cursorColor: 'rgba(255, 0, 0, 0.5)',
});

Using standard hex codes with alpha channels is also valid (for example, #ff000080 for 50% opacity).

Setting Cursor Border Radius

There is no native cursorBorderRadius option in the Wavesurfer.js configuration object. The method to round cursor corners depends on the version and the rendering mode used:

Method 1: Using Custom CSS (DOM-based cursors)

In modern Wavesurfer.js versions (v7+) where UI elements and wrappers are rendered in the DOM, you can target the cursor element or child elements via CSS.

If the cursor is rendered as an HTML element or part of the Hover plugin, target the generated class in your stylesheet:

/* Target the hover/cursor line if rendered as a DOM element */
.wavesurfer-cursor,
part(cursor) {
  border-radius: 4px;
}

Method 2: Custom HTML/CSS Overlays

If you need complete control over the visual presentation of the cursor—including rounded pill shapes (border-radius), box shadows, and distinct borders—the recommended pattern is to disable the native cursor by setting cursorWidth: 0 and creating a synced custom HTML marker:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  cursorWidth: 0, // Disable default cursor
});

// Update a custom DOM element on timeupdate/audioprocess
wavesurfer.on('timeupdate', (currentTime) => {
  const progress = currentTime / wavesurfer.getDuration();
  const customCursor = document.getElementById('custom-cursor');
  customCursor.style.left = `${progress * 100}%`;
});
#custom-cursor {
  position: absolute;
  top: 0;
  width: 4px;
  height: 100%;
  background-color: rgba(255, 255, 255, 0.8);
  border-radius: 2px;
  pointer-events: none;
}

Summary of Options

Desired Effect Configuration / Approach
Opacity Set cursorColor to an rgba() or hex alpha string.
Width Set the numerical cursorWidth option (in pixels).
Border Radius Target cursor DOM elements via CSS or render a custom cursor overlay with cursorWidth: 0.
