Real-Time Pitch Shifting with Web Audio and Wavesurfer

Altering the pitch of an audio track without affecting its tempo requires time-stretching digital signal processing (DSP) algorithms rather than standard playback rate adjustments. This article explains how to achieve real-time, independent pitch shifting by integrating Wavesurfer.js with the Web Audio API and custom processing nodes using the AudioWorklet interface.

Understanding the Limitation of Default Playback

By default, changing the playback speed via wavesurfer.setPlaybackRate(rate) or the HTML5 media element’s playbackRate scales both tempo and pitch together (the "vinyl record" effect). Modern browsers provide a preservesPitch boolean on HTMLMediaElement, but this only allows changing tempo while keeping pitch constant; it does not allow shifting pitch independently while keeping tempo unchanged.

To shift pitch independently in real time, you must intercept the audio buffer or stream and pass it through a pitch-shifting algorithm—such as a Phase Vocoder or the Pitch Synchronous Overlap-Add (PSOLA) / SoundTouch algorithm—via the Web Audio API.

Step 1: Set Up Wavesurfer with an External AudioContext

To route audio through custom Web Audio nodes, instantiate an AudioContext and pass it directly to Wavesurfer.js.

import WaveSurfer from 'wavesurfer.js';

// 1. Create a single AudioContext
const audioContext = new (window.AudioContext || window.webkitAudioContext)();

// 2. Initialize Wavesurfer with the shared AudioContext
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  audioContext: audioContext,
});

Step 2: Implement a Pitch-Shift AudioWorklet

Direct sample manipulation in the main JavaScript thread causes stuttering and high latency. Instead, use an AudioWorkletProcessor to run DSP computations on a separate audio rendering thread.

Create a separate file, pitch-shifter-processor.js:

// pitch-shifter-processor.js
class PitchShifterProcessor extends AudioWorkletProcessor {
  static get parameterDescriptors() {
    return [
      {
        name: 'pitchFactor',
        defaultValue: 1.0,
        minValue: 0.5,
        maxValue: 2.0,
      },
    ];
  }

  constructor() {
    super();
    // Buffer allocations for phase-vocoder or granular overlap-add
    this.bufferSize = 2048;
    this.buffer = new Float32Array(this.bufferSize);
    this.writeIndex = 0;
    this.readIndex = 0;
  }

  process(inputs, outputs, parameters) {
    const input = inputs[0];
    const output = outputs[0];
    const pitchFactor = parameters.pitchFactor[0];

    if (!input || !input[0]) return true;

    const inputChannel = input[0];
    const outputChannel = output[0];

    for (let i = 0; i < inputChannel.length; i++) {
      // Write incoming samples to circular buffer
      this.buffer[this.writeIndex] = inputChannel[i];
      this.writeIndex = (this.writeIndex + 1) % this.bufferSize;

      // Resample based on pitch factor using linear interpolation
      const baseIndex = Math.floor(this.readIndex);
      const nextIndex = (baseIndex + 1) % this.bufferSize;
      const frac = this.readIndex - baseIndex;

      outputChannel[i] =
        this.buffer[baseIndex] * (1 - frac) + this.buffer[nextIndex] * frac;

      this.readIndex = (this.readIndex + pitchFactor) % this.bufferSize;
    }

    return true;
  }
}

registerProcessor('pitch-shifter-processor', PitchShifterProcessor);

(Note: For production-grade pitch shifting without artifacts, replace the basic linear resampling above with a complete phase-vocoder or SoundTouch.js library bundled inside the worklet).

Step 3: Route Wavesurfer Audio Through the Worklet Node

Once Wavesurfer decodes the audio and prepares playback, intercept the media element source and insert the worklet node before sending the signal to audioContext.destination.

let pitchNode;

async function setupAudioPipeline() {
  // Load the AudioWorklet processor module
  await audioContext.audioWorklet.addModule('pitch-shifter-processor.js');

  // Create the worklet node instance
  pitchNode = new AudioWorkletNode(audioContext, 'pitch-shifter-processor');

  wavesurfer.on('ready', () => {
    const mediaElement = wavesurfer.getMediaElement();

    // Disconnect default outputs and create a custom source
    const sourceNode = audioContext.createMediaElementSource(mediaElement);

    // Audio Graph: MediaElement -> PitchShifterNode -> Destination
    sourceNode.connect(pitchNode);
    pitchNode.connect(audioContext.destination);
  });
}

setupAudioPipeline();

Step 4: Dynamically Control Pitch in Semitones

Pitch is commonly represented in semitones rather than raw frequency ratios. Convert semitone values to a frequency multiplier using the formula:

\[\text{Pitch Factor} = 2^{(\text{semitones} / 12)}\]

function setPitchSemitones(semitones) {
  if (!pitchNode) return;

  // Convert semitones (-12 to +12) to multiplier
  const pitchFactor = Math.pow(2, semitones / 12);

  // Set the parameter directly or smooth it out
  const param = pitchNode.parameters.get('pitchFactor');
  param.setValueAtTime(pitchFactor, audioContext.currentTime);
}

// Example usage with a range slider:
const slider = document.querySelector('#pitch-slider');
slider.addEventListener('input', (event) => {
  setPitchSemitones(parseFloat(event.target.value));
});

Summary Checklist

  1. Provide an external AudioContext to Wavesurfer.js to maintain control of the signal graph.
  2. Load an AudioWorkletProcessor implementing phase-vocoder or granular pitch-shifting.
  3. Tap into the audio source via audioContext.createMediaElementSource(wavesurfer.getMediaElement()).
  4. Route audio through the pitch node to audioContext.destination.
  5. Modulate the pitchFactor parameter via exponential semitone calculation for musical adjustments.
