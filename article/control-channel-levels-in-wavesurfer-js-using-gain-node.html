Control Channel Levels in Wavesurfer.js Using GainNode

Controlling individual channel levels in Wavesurfer.js requires integrating custom Web Audio API nodes into the playback graph. By intercepting the audio source with a ChannelSplitterNode, you can separate stereo signals into discrete left and right paths, route each path through its own GainNode for independent volume adjustments, and recombine them using a ChannelMergerNode before sending the audio to the output destination.

Understanding the Audio Graph

By default, Wavesurfer.js routes audio directly from its source to the audio destination. To manipulate channels independently, you must rewire this connection using the following chain:

  1. Source Node: The audio generated by Wavesurfer.js.
  2. ChannelSplitterNode: Splits the stereo signal into distinct mono channels (Channel 0 for Left, Channel 1 for Right).
  3. GainNodes: Two individual GainNode instances that control the volume for each channel.
  4. ChannelMergerNode: Combines the adjusted mono channels back into a single multi-channel stream.
  5. Destination: The output speakers (audioContext.destination).

Step-by-Step Implementation

Ensure Wavesurfer is configured to use the Web Audio backend to access the underlying AudioContext.

import WaveSurfer from 'wavesurfer.js';

// 1. Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  backend: 'WebAudio', // Required for direct node manipulation
});

let gainNodeLeft;
let gainNodeRight;

wavesurfer.on('ready', () => {
  // 2. Extract the AudioContext and Media Source
  const audioContext = wavesurfer.backend.ac;
  const sourceNode = wavesurfer.backend.source;

  // Disconnect the source from its default destination
  sourceNode.disconnect();

  // 3. Create Splitter, Merger, and Gain Nodes
  const splitter = audioContext.createChannelSplitter(2);
  const merger = audioContext.createChannelMerger(2);

  gainNodeLeft = audioContext.createGain();
  gainNodeRight = audioContext.createGain();

  // 4. Connect the Source to the Splitter
  sourceNode.connect(splitter);

  // 5. Connect Splitter outputs to respective GainNodes
  // Output 0 = Left Channel, Output 1 = Right Channel
  splitter.connect(gainNodeLeft, 0);
  splitter.connect(gainNodeRight, 1);

  // 6. Connect GainNodes back into the Merger inputs
  gainNodeLeft.connect(merger, 0, 0); // Input 0 = Left Channel
  gainNodeRight.connect(merger, 0, 1); // Input 1 = Right Channel

  // 7. Route the Merger to the destination
  merger.connect(audioContext.destination);
});

Adjusting Channel Levels in Real Time

Once the nodes are wired, you can independently adjust the volume of the left and right channels by updating the gain.value property of each GainNode. The values typically range from 0.0 (silent) to 1.0 (full volume), though values above 1.0 can be used for amplification.

// Adjust Left Channel Level
function setLeftChannelVolume(value) {
  if (gainNodeLeft) {
    gainNodeLeft.gain.setValueAtTime(value, wavesurfer.backend.ac.currentTime);
  }
}

// Adjust Right Channel Level
function setRightChannelVolume(value) {
  if (gainNodeRight) {
    gainNodeRight.gain.setValueAtTime(value, wavesurfer.backend.ac.currentTime);
  }
}

// Example usage: Mute right channel, keep left at full
setLeftChannelVolume(1.0);
setRightChannelVolume(0.0);

Using setValueAtTime prevents audio clicks or pops when changing levels during active playback. This setup provides complete stereo isolation and real-time panning or balancing directly over your Wavesurfer.js waveforms.
