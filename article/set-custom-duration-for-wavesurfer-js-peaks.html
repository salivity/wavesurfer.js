Set Custom Duration for Wavesurfer.js Peaks

Using pre-calculated peaks in Wavesurfer.js allows you to render audio waveforms instantly without downloading and decoding the entire audio file. However, because the browser does not decode the audio immediately, Wavesurfer cannot automatically detect the file's length, making it necessary to provide the duration manually. This guide explains how to properly set a custom audio duration alongside pre-computed peak data to ensure accurate waveform scaling, timeline alignment, and playback tracking.

Passing Duration in the load Method

In modern versions of Wavesurfer.js (v7+), the recommended approach to supply a custom duration alongside pre-calculated peaks is through the load method. The load function accepts the audio source URL, an array of peaks, and the duration in seconds as its third argument.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
});

// Define your pre-calculated peaks and explicit duration
const audioUrl = 'path/to/audio.mp3';
const precalculatedPeaks = [[0.1, 0.5, 0.8, ...]]; // Array of peak values
const audioDuration = 184.5; // Duration in seconds

// Pass the duration as the third parameter
wavesurfer.load(audioUrl, precalculatedPeaks, audioDuration);

Initializing Duration with WaveSurfer.create

If you are initializing the player with an existing media element or passing options directly during creation, you can also define the duration parameter inside the configuration object:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: 'path/to/audio.mp3',
  peaks: precalculatedPeaks,
  duration: 184.5, // Total duration in seconds
});

When configured this way, Wavesurfer constructs the waveform canvas proportionally to the specified duration immediately, bypassing the need to wait for the media element's loadedmetadata event.

Usage in Wavesurfer.js v6 and Older

If you are working with an older release (Wavesurfer.js v6 or below), the method signature for load differs slightly. The duration parameter is passed as the fourth argument, following the preload option:

// Wavesurfer v6 syntax:
// wavesurfer.load(url, peaks, preload, duration)
wavesurfer.load('path/to/audio.mp3', precalculatedPeaks, 'auto', 184.5);

Rendering Waveforms Without Audio Files

You can also use custom durations and pre-calculated peaks to render a visual-only waveform without loading any audio source. In Wavesurfer v7, pass an empty string or omit the URL entirely while supplying peaks and duration:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#9CA3AF',
  peaks: precalculatedPeaks,
  duration: 120, // 2-minute visual waveform
});

Explicitly passing the duration ensures that helper plugins—such as the Timeline or Regions plugins—calculate positions and timestamps accurately from the moment the container renders.
