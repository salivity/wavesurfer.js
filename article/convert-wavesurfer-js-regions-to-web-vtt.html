Convert Wavesurfer.js Regions to WebVTT

This article provides a practical overview of converting user-created audio regions from Wavesurfer.js into valid WebVTT (Web Video Text Tracks) text format. While Wavesurfer.js provides dynamic visualization and interactive segment handling through its Regions plugin, it does not include a native, hardcoded VTT serialization method in its core API. Consequently, developers rely on an exporter utility function—commonly implemented as exportWebVTT() or regionsToWebVTT()—to parse region metadata, format audio timestamps to WebVTT standards, and generate the final cue list.

Understanding the Exporter Function

The exporter function retrieves the active instances managed by the Regions plugin (wavesurfer.plugins.regions or the standalone RegionsPlugin), extracts each region's properties (start, end, and any custom content or label), and serializes them into standard WebVTT format.

A valid WebVTT string requires:

  1. An opening header line containing WEBVTT.
  2. Cue identifiers or sequence blocks separated by double line breaks.
  3. Timestamps defined precisely in HH:MM:SS.mmm or MM:SS.mmm format separated by -->.
  4. Cue text directly following the timestamp line.

Implementing the Exporter Function

To export user-created regions directly into WebVTT text, use the following exportWebVTT exporter function:

function formatVTTTimestamp(seconds) {
    const pad = (num, size) => num.toString().padStart(size, '0');
    const hrs = Math.floor(seconds / 3600);
    const mins = Math.floor((seconds % 3600) / 60);
    const secs = Math.floor(seconds % 60);
    const ms = Math.floor((seconds % 1) * 1000);

    return `${pad(hrs, 2)}:${pad(mins, 2)}:${pad(secs, 2)}.${pad(ms, 3)}`;
}

function exportWebVTT(regionsPlugin) {
    // Retrieve all region objects
    const regions = regionsPlugin.getRegions();

    // Sort regions chronologically by their start time
    regions.sort((a, b) => a.start - b.start);

    // Build the WebVTT string
    let vttOutput = "WEBVTT\n\n";

    regions.forEach((region, index) => {
        const start = formatVTTTimestamp(region.start);
        const end = formatVTTTimestamp(region.end);
        
        // Retrieve text from region attributes or DOM element
        const content = region.content ? region.content.innerText || region.content : `Cue ${index + 1}`;

        vttOutput += `${index + 1}\n`;
        vttOutput += `${start} --> ${end}\n`;
        vttOutput += `${content.trim()}\n\n`;
    });

    return vttOutput.trim();
}

How to Use the Output

Pass the instance of your RegionsPlugin directly to the exportWebVTT function whenever a region is created, edited, or when the user requests an export:

const vttString = exportWebVTT(wsRegions);

// Trigger a download or store the result
const blob = new Blob([vttString], { type: 'text/vtt' });
const downloadUrl = URL.createObjectURL(blob);

By querying the start and end properties of each region and routing them through a millisecond-accurate timestamp conversion, this exporter function bridges the gap between Wavesurfer.js user interfaces and standard accessibility/caption formats.
