How to Format Wavesurfer.js Timeline Labels

This article explains how to customize and format time labels in the Wavesurfer.js Timeline plugin. By leveraging the plugin’s built-in callback configuration, you can transform default raw second intervals into standard clock formats such as minutes, seconds, milliseconds, or professional SMPTE-style timecodes.

The formatTimeCallback Function

The primary method for formatting time labels in the Wavesurfer.js Timeline plugin is the formatTimeCallback option. When instantiating the Timeline plugin, you pass a custom function to this property.

The callback receives a single argument—the current time in seconds as a number—and expects a formatted string in return.

import WaveSurfer from 'wavesurfer.js'
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js'

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  plugins: [
    TimelinePlugin.create({
      container: '#wave-timeline',
      formatTimeCallback: (seconds) => {
        // Custom formatting logic here
        return formatTime(seconds)
      },
    }),
  ],
})

Standard Formats

1. Minutes and Seconds (MM:SS)

To display labels in a standard music or podcast layout (01:23):

formatTimeCallback: (seconds) => {
  const minutes = Math.floor(seconds / 60)
  const remainingSeconds = Math.floor(seconds % 60)
  const paddedMinutes = String(minutes).padStart(2, '0')
  const paddedSeconds = String(remainingSeconds).padStart(2, '0')
  
  return `${paddedMinutes}:${paddedSeconds}`
}

2. Hours, Minutes, and Seconds (HH:MM:SS)

For long-form audio like audiobooks or long recordings:

formatTimeCallback: (seconds) => {
  const hours = Math.floor(seconds / 3600)
  const minutes = Math.floor((seconds % 3600) / 60)
  const remSeconds = Math.floor(seconds % 60)

  const parts = [
    hours > 0 ? String(hours).padStart(2, '0') : null,
    String(minutes).padStart(2, '0'),
    String(remSeconds).padStart(2, '0'),
  ].filter(Boolean)

  return parts.join(':')
}

3. Including Milliseconds (MM:SS.ms)

For audio editors or precision workflows requiring sub-second precision:

formatTimeCallback: (seconds) => {
  const minutes = Math.floor(seconds / 60)
  const remainingSeconds = Math.floor(seconds % 60)
  const milliseconds = Math.floor((seconds % 1) * 100)

  const formattedMin = String(minutes).padStart(2, '0')
  const formattedSec = String(remainingSeconds).padStart(2, '0')
  const formattedMs = String(milliseconds).padStart(2, '0')

  return `${formattedMin}:${formattedSec}.${formattedMs}`
}

Adjusting Label Density

Formatting changes often require adjusting the frequency of the labels to prevent text overlapping. Use the following Timeline plugin properties alongside formatTimeCallback:

  • timeInterval: Defines the base step in seconds between timeline notches.
  • primaryLabelInterval: Specifies how often a primary (labeled) notch appears.
  • secondaryLabelInterval: Controls the interval for smaller, unlabeled tick marks.
TimelinePlugin.create({
  container: '#wave-timeline',
  timeInterval: 5,
  primaryLabelInterval: 10,
  secondaryLabelInterval: 1,
  formatTimeCallback: (seconds) => {
    return `${Math.round(seconds)}s`
  },
})
