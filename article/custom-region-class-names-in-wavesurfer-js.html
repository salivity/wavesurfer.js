Custom Region Class Names in Wavesurfer.js

In Wavesurfer.js, styling and identifying audio regions often requires attaching custom CSS classes to the generated DOM elements. This guide explains how to configure custom class names using the Regions plugin, highlighting the core configuration options available in classic versions of the library as well as DOM-based approaches used in modern releases.

The attributes Option

In Wavesurfer.js (versions 4 through 6), the configuration option used to assign custom class names to generated regions is attributes.

When calling addRegion() on the Regions plugin instance, you can pass an attributes object containing standard HTML attributes. The plugin iterates over these keys and sets them directly on the region’s wrapper HTMLElement using setAttribute().

// Initialize or retrieve the regions plugin
const wsRegions = wavesurfer.registerPlugin(WaveSurfer.regions.create());

// Add a region with a custom class name
wsRegions.addRegion({
  start: 2,
  end: 6,
  color: 'rgba(0, 123, 255, 0.2)',
  attributes: {
    class: 'custom-region-highlight',
    'data-label': 'Chorus'
  }
});

Using attributes: { class: 'your-class-name' } appends or overrides the class attribute on the region element, allowing you to target it directly in your CSS stylesheets for custom borders, shadows, or hover behaviors.

Setting Classes in Wavesurfer.js v7+

In Wavesurfer.js version 7, the Regions plugin was rewritten to be more lightweight and modular. The legacy attributes option was replaced in favor of direct DOM access and the content parameter.

1. Direct Access via region.element

When creating a region in v7, addRegion() returns a Region instance. You can modify its class list directly using standard JavaScript DOM APIs:

import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

const region = wsRegions.addRegion({
  start: 1,
  end: 4,
  color: 'rgba(255, 0, 0, 0.2)'
});

// Add your custom class directly to the region's container
region.element.classList.add('custom-region-highlight');

2. Dynamically Created Regions (region-created Event)

If regions are generated automatically through user interaction—such as dragging on the waveform via enableDragSelection—you can listen to the region-created event to automatically append your class names:

wsRegions.on('region-created', (region) => {
  region.element.classList.add('user-generated-region');
});

3. The content Property

For applying styles or classes to region labels and inner elements, v7 provides the content option. This accepts either a plain HTML string or an HTMLElement:

wsRegions.addRegion({
  start: 5,
  end: 8,
  content: '<span class="region-badge">Verse 1</span>'
});
