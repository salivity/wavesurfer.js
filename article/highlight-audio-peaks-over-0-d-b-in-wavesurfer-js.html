Highlight Audio Peaks Over 0 dB in Wavesurfer.js

This guide explains how to detect and visually highlight clipped audio peaks over 0 dBFS in Wavesurfer.js. Standard waveform rendering in Wavesurfer.js normalizes audio display but does not inherently flag digital clipping out of the box. By accessing the decoded audio buffer data, identifying sample values that reach or exceed the 0 dBFS threshold (values \(\ge 1.0\) or \(\le -1.0\)), and utilizing the Wavesurfer.js Regions plugin, you can automatically mark clipped areas with visible colored overlays across your waveform.

Understanding 0 dBFS in the Web Audio API

In digital audio decoded by browsers via the Web Audio API, samples are stored as 32-bit floating-point numbers ranging from -1.0 to 1.0. A sample value of 1.0 or -1.0 corresponds to 0 dBFS (decibels relative to full scale). Any digital signal attempting to exceed this range results in clipping, causing harmonic distortion. To visually flag these sections in Wavesurfer.js, you must analyze the underlying AudioBuffer and map the timestamps of these peak values onto the visual timeline.

Step-by-Step Implementation Using the Regions Plugin

The most effective way to highlight clipped peaks without altering the core waveform drawing algorithm is using the official RegionsPlugin.

1. Initialize Wavesurfer and the Regions Plugin

Set up your Wavesurfer instance alongside the Regions plugin:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const wsRegions = RegionsPlugin.create();

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#312E81',
  plugins: [wsRegions],
});

wavesurfer.load('path/to/audio-file.wav');

2. Analyze the AudioBuffer for Clipping

Listen for the decode event, which fires as soon as the audio file has been downloaded and decoded into an AudioBuffer. Iterate through the channel data to locate samples where the absolute amplitude meets or exceeds the clipping threshold (typically 0.99 to 1.0 to catch near-clipping and hard-clipped limits).

wavesurfer.on('decode', () => {
  const buffer = wavesurfer.getDecodedData();
  if (!buffer) return;

  const sampleRate = buffer.sampleRate;
  const numChannels = buffer.numberOfChannels;
  const threshold = 0.999; // Peak threshold for 0 dBFS
  const clipRanges = [];

  for (let channel = 0; channel < numChannels; channel++) {
    const channelData = buffer.getChannelData(channel);
    let isClipping = false;
    let clipStart = 0;

    for (let i = 0; i < channelData.length; i++) {
      const isPeak = Math.abs(channelData[i]) >= threshold;

      if (isPeak && !isClipping) {
        isClipping = true;
        clipStart = i / sampleRate;
      } else if (!isPeak && isClipping) {
        isClipping = false;
        const clipEnd = i / sampleRate;
        clipRanges.push({ start: clipStart, end: clipEnd });
      }
    }

    // Handle audio that ends on a clipped sample
    if (isClipping) {
      clipRanges.push({ start: clipStart, end: channelData.length / sampleRate });
    }
  }

  highlightClippedPeaks(clipRanges);
});

3. Draw Red Overlay Regions on the Waveform

Because individual clipped peaks can be as brief as a single sample (a fraction of a millisecond), expand extremely short durations to a minimum visible width (e.g., 20 to 50 milliseconds) so users can easily see them on the interface.

function highlightClippedPeaks(clipRanges) {
  // Clear any existing regions before drawing
  wsRegions.clearRegions();

  const minVisualDuration = 0.03; // Minimum display width in seconds (30ms)

  clipRanges.forEach((range) => {
    let { start, end } = range;

    if (end - start < minVisualDuration) {
      end = start + minVisualDuration;
    }

    wsRegions.addRegion({
      start: start,
      end: end,
      color: 'rgba(239, 68, 68, 0.6)', // Semi-transparent red
      drag: false,
      resize: false,
    });
  });
}

Alternative: Colorized Custom Peak Rendering

If you do not want to use floating region overlays, you can calculate the peaks beforehand and use Wavesurfer's custom rendering hooks:

  1. Extract peak arrays manually from the AudioBuffer.
  2. Split the waveform peaks into linear segments.
  3. Pass a custom renderFunction option to WaveSurfer.create() that iterates over peak coordinates in the internal HTML5 <canvas> context, rendering path strokes in red (#EF4444) whenever a sample reaches the maximum canvas height boundaries.
