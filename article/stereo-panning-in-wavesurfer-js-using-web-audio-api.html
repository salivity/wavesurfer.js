Stereo Panning in Wavesurfer.js Using Web Audio API

Controlling stereo panning in Wavesurfer.js requires tapping into the Web Audio API by inserting a StereoPannerNode into the audio processing graph. This article demonstrates how to initialize Wavesurfer, instantiate a stereo panner within the audio context, route the audio signal through the panner node to the destination, and bind a range slider to adjust the audio balance dynamically between the left and right channels.

Understanding the Audio Signal Flow

By default, modern versions of Wavesurfer.js play audio using an HTML5 media element. To apply Web Audio effects such as stereo panning, you must route the audio stream through an AudioContext.

The signal chain looks like this:

MediaElementAudioSourceNode (Wavesurfer Media) -> StereoPannerNode -> AudioDestinationNode (Speakers)

The StereoPannerNode provides an AudioParam called pan, which accepts values ranging from -1 (full left) to 1 (full right), with 0 representing center balance.

Implementation Steps

1. Set Up the HTML

Create a container for the waveform and a range slider for stereo panning.

<div id="waveform"></div>

<label for="panner">Stereo Balance:</label>
<input type="range" id="panner" min="-1" max="1" step="0.05" value="0">

2. Initialize Wavesurfer and Web Audio Nodes

Initialize Wavesurfer.js, create the AudioContext, and set up the StereoPannerNode once the audio element is available.

import WaveSurfer from 'wavesurfer.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#A8DBA8',
  progressColor: '#3B8686',
  url: 'audio-file.mp3',
});

// Set up Web Audio API nodes
const audioContext = new (window.AudioContext || window.webkitAudioContext)();
const pannerNode = audioContext.createStereoPanner();

// Connect the media element to the panner node on ready
wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const sourceNode = audioContext.createMediaElementSource(mediaElement);

  // Connect source -> panner -> speakers
  sourceNode.connect(pannerNode);
  pannerNode.connect(audioContext.destination);
});

3. Handle Browser Autoplay Policies

Browsers suspend AudioContext instances created without direct user interaction. Resume the context when playback starts:

wavesurfer.on('play', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
});

4. Adjust the Pan Balance

Attach an event listener to the HTML range input to update the pan value in real time.

const pannerInput = document.getElementById('panner');

pannerInput.addEventListener('input', (event) => {
  const panValue = parseFloat(event.target.value);
  
  // Set the pan value smoothly using the AudioContext timestamp
  pannerNode.pan.setValueAtTime(panValue, audioContext.currentTime);
});

Using setValueAtTime ensures immediate and glitch-free parameter updates as the slider is dragged. Setting the input to -1 will silence the right speaker, 1 will silence the left speaker, and 0 will distribute the signal evenly across both channels.
