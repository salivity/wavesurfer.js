Wavesurfer.js fillParent False Explained

Setting fillParent to false in Wavesurfer.js changes the rendering behavior of the waveform from stretching to fit the parent container to rendering based strictly on audio duration and pixel density. This overview covers how disabling this setting affects container sizing, how it interacts with zoom controls like minPxPerSec, and when you should use it in your web audio projects.

Default Behavior vs. fillParent: false

By default, Wavesurfer.js sets fillParent to true. In this standard configuration, the rendered waveform always stretches to occupy 100% of the parent container's width, regardless of the audio track's length or the pixel ratio.

When you configure fillParent: false, the waveform stops automatically conforming to the container's boundaries. Instead, Wavesurfer.js calculates the canvas width using the audio file's duration multiplied by the minPxPerSec (minimum pixels per second) parameter.

Key Effects of Disabling fillParent

  1. Width Based on Duration: The canvas width is determined mathematically: Width = Duration (seconds) * minPxPerSec. If an audio clip is 10 seconds long and minPxPerSec is set to 20, the rendered waveform will be exactly 200 pixels wide, even if the parent container is 800 pixels wide.

  2. No Automatic Stretching for Short Audio: With short audio files, the waveform will not stretch unnaturally to fill an empty screen. It leaves the remaining space inside the parent wrapper empty, keeping the visual density of the waveform peaks accurate.

  3. Enables True Zooming and Horizontal Scrolling: Disabling fillParent is essential when implementing audio zoom features. When zoomed in, the calculated width will typically exceed the parent container. As long as the container has overflow-x: auto (or standard scrolling enabled), the user can scroll horizontally across the full, uncompressed waveform.

  4. Consistency Across Multiple Tracks: If you are building a multitrack editor or comparing multiple audio tracks side by side, setting fillParent: false ensures that all tracks share the exact same visual time scale. A 5-second track will visually appear half as long as a 10-second track, rather than both being forced into the same container width.

When to Set fillParent: false

You should set fillParent: false whenever your interface requires:

  • An audio timeline where time corresponds directly to horizontal distance.
  • Interactive zooming where increasing minPxPerSec expands the waveform beyond the viewport.
  • Multi-track alignments where visual synchronization between different audio lengths is critical.
