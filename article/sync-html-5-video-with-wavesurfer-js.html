Sync HTML5 Video with Wavesurfer.js

Synchronizing an HTML5 video element with Wavesurfer.js creates an interactive waveform timeline aligned directly with your video playback. This synchronization is achieved either automatically by passing the video element as the media controller in Wavesurfer configuration, or manually by binding the video element's timeupdate event to Wavesurfer's setTime() method.

Method 1: Direct Media Binding (Recommended)

In modern versions of Wavesurfer.js (v7+), the cleanest way to synchronize an HTML5 <video> element is by passing the DOM element directly into the media configuration parameter during initialization. This eliminates the need to manually manage playback events, seeking, and frame timing.

const videoElement = document.querySelector('video');

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  media: videoElement // Binds all playback and time tracking natively
});

When you pass the video element to the media parameter, Wavesurfer automatically mirrors the video’s timeupdate, play, pause, and seeking behaviors natively without additional code.

Method 2: Manual Synchronization with timeupdate

If your implementation requires decoupled audio and video, or if you are working with an older release of Wavesurfer.js, you can manually capture the video element’s timeupdate event and map it to Wavesurfer's timeline using the setTime() method.

const video = document.querySelector('video');

video.addEventListener('timeupdate', () => {
  // Sync Wavesurfer's playhead to the current video playback time
  if (!wavesurfer.isPlaying()) {
    wavesurfer.setTime(video.currentTime);
  }
});

In older versions (v6 and below), setTime() does not exist, and synchronization requires calculating progress proportionally via seekTo():

video.addEventListener('timeupdate', () => {
  const progress = video.currentTime / video.duration;
  if (!isNaN(progress)) {
    wavesurfer.seekTo(progress);
  }
});

Implementing Bi-Directional Seeking

When using the manual timeupdate approach, you must also handle user interactions on the waveform so that clicking or scrubbing the waveform updates the video position accordingly:

wavesurfer.on('seeking', (currentTime) => {
  video.currentTime = currentTime;
});

wavesurfer.on('play', () => video.play());
wavesurfer.on('pause', () => video.pause());

Using the native media option in Wavesurfer handles these bi-directional controls automatically, while the manual timeupdate with setTime() method offers complete programmatic control over how and when time state changes propagate.
