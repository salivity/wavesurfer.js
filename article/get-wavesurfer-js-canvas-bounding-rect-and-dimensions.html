Get Wavesurfer.js Canvas Bounding Rect and Dimensions

This article explains how to retrieve the exact dimensions and bounding rectangle of the waveform rendering area in Wavesurfer.js. While the library does not provide a custom standalone method solely called to calculate bounding boxes, it exposes the rendering container through API methods, allowing you to use standard DOM methods like getBoundingClientRect() alongside built-in dimension properties. Below is a concise guide on accessing these dimensions in both modern (v7+) and legacy versions of Wavesurfer.js.

Modern Wavesurfer.js (Version 7+)

In Wavesurfer.js v7 and later, the primary method used to obtain the waveform container is wavesurfer.getWrapper(). You can call the standard Web API method getBoundingClientRect() directly on this wrapper element.

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'violet',
  progressColor: 'purple'
});

// Wait for the waveform to be ready
wavesurfer.on('ready', () => {
  // Get the wrapper element
  const wrapper = wavesurfer.getWrapper();
  
  // Retrieve the bounding rectangle
  const rect = wrapper.getBoundingClientRect();

  console.log('Bounding Rect:', rect);
  console.log('Width:', rect.width);
  console.log('Height:', rect.height);
  console.log('Top:', rect.top);
  console.log('Left:', rect.left);
});

Accessing the Canvas Directly

If you specifically need the <canvas> element's dimensions rather than the wrapper container, query the canvas directly from the wrapper:

const canvas = wavesurfer.getWrapper().querySelector('canvas');
if (canvas) {
  const canvasRect = canvas.getBoundingClientRect();
  console.log('Canvas Dimensions:', canvasRect.width, canvasRect.height);
}

Legacy Wavesurfer.js (Version 6 and Earlier)

In Wavesurfer.js v6 and older versions, rendering was handled by the drawer module. You access the wrapper and dimensions through the drawer object:

wavesurfer.on('ready', function () {
  // Get bounding rect via the drawer wrapper
  const rect = wavesurfer.drawer.wrapper.getBoundingClientRect();
  
  // Get width directly from drawer properties
  const width = wavesurfer.drawer.getWidth();
  const height = wavesurfer.drawer.getHeight();

  console.log('Bounding Rect:', rect);
  console.log('Dimensions:', width, height);
});

Summary of Properties Returned by getBoundingClientRect()

Calling getBoundingClientRect() on the wrapper element returns a DOMRect object containing the following read-only properties:

  • width: The horizontal width of the element.
  • height: The vertical height of the element.
  • top: The distance from the top of the viewport to the top edge.
  • bottom: The distance from the top of the viewport to the bottom edge.
  • left: The distance from the left edge of the viewport to the left edge.
  • right: The distance from the left edge of the viewport to the right edge.
  • x: Equivalent to left.
  • y: Equivalent to top.
