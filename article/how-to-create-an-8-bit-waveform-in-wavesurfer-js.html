How to Create an 8-Bit Waveform in Wavesurfer.js

This guide explains how to render a retro, 8-bit arcade-style audio waveform using built-in configuration options in Wavesurfer.js. By adjusting bar dimensions, removing corner rounding, and applying classic chiptune color palettes, you can transform standard smooth audio visualizations into blocky, pixelated waveforms reminiscent of vintage video game hardware without writing custom canvas renderers.

Key Wavesurfer.js Properties for the 8-Bit Look

To achieve a pixelated, retro appearance, you must configure Wavesurfer.js to draw flat, chunky bars rather than smooth or rounded continuous lines. The primary options controlling this behavior are:

  • barWidth: Set to a larger integer (such as 4, 6, or 8) to simulate wide, chunky pixel columns.
  • barGap: Set to a distinct width (such as 2 or 4) to introduce deliberate spacing between pixel blocks.
  • barRadius: Must be set strictly to 0 to eliminate modern rounded corners and preserve sharp, square pixel edges.
  • waveColor and progressColor: Use high-contrast, limited-palette colors such as Game Boy greens (#8bac0f and #0f380f), amber CRT monitor tones (#ffb000), or classic arcade neon.
  • height: Setting a lower canvas height (e.g., 40 to 60 pixels) further reinforces the low-resolution feel.

Configuration Example

Here is a complete setup using Wavesurfer.js v7 demonstrating the retro 8-bit aesthetic:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#8bac0f',      // Retro light green (unplayed)
  progressColor: '#0f380f',  // Retro dark green (played)
  height: 50,                // Compact height for lower resolution feel
  barWidth: 6,               // Thick pixel blocks
  barGap: 2,                 // Sharp spacing between blocks
  barRadius: 0,              // Hard edges, zero corner rounding
  normalize: true,           // Scales waveform to maximize vertical block height
  cursorWidth: 2,
  cursorColor: '#306230',
});

wavesurfer.load('path-to-your-chiptune.mp3');

Enhancing the Retro Effect with CSS

The canvas waveform can be further stylized by placing it in an authentic retro container using standard CSS:

#waveform {
  background-color: #9bbc0f; /* Game Boy screen background */
  border: 4px solid #0f380f;
  padding: 8px;
  image-rendering: pixelated; /* Ensures canvas edges remain crisp */
}

By enforcing zero border-radius and using thick, separated bars, Wavesurfer.js provides an authentic chiptune visual style directly through its configuration parameters.
