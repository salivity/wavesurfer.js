Convert Float Audio Samples to Int8 for Wavesurfer.js

Audio decoded natively by the Web Audio API outputs 32-bit floating-point numbers ranging from -1.0 to 1.0, but pre-rendering waveforms in Wavesurfer.js is far more bandwidth-efficient when using 8-bit signed integers (Int8Array). Converting float samples into an Int8Array reduces waveform data payloads by up to 75% without noticeable loss in visual rendering quality. This guide explains how to convert floating-point audio data into Int8Array format using custom JavaScript utility functions and external waveform generators compatible with Wavesurfer.js.

The Scaling Logic

A standard audio buffer represents silence at 0.0, the positive peak limit at 1.0, and the negative peak limit at -1.0. A signed 8-bit integer (Int8) spans from -128 to 127.

To convert normalized floating-point samples to signed 8-bit integers without clipping distortion:

  • Positive samples (\(0.0\) to \(1.0\)) scale by multiplying by 127.
  • Negative samples (\(-1.0\) to \(0.0\)) scale by multiplying by 128.

Pure JavaScript Conversion Utility

When processing audio on the client side or inside a Node.js backend using standard decoded AudioBuffer channel data, a direct typed array mapping loop provides the fastest conversion.

/**
 * Converts a Float32Array of audio samples into an Int8Array.
 * @param {Float32Array} floatSamples - Input samples in the range [-1.0, 1.0]
 * @returns {Int8Array} Quantized 8-bit signed integer samples
 */
function floatToInt8(floatSamples) {
  const length = floatSamples.length;
  const int8Data = new Int8Array(length);

  for (let i = 0; i < length; i++) {
    // Clamp sample between -1.0 and 1.0 to prevent overflow
    const s = Math.max(-1, Math.min(1, floatSamples[i]));
    
    // Scale according to positive or negative boundary
    int8Data[i] = s < 0 ? Math.round(s * 128) : Math.round(s * 127);
  }

  return int8Data;
}

Extracting Peaks and Converting in One Step

Wavesurfer.js typically does not need every raw sample of a track, but rather the min/max peak pairs over given intervals (windows). Combining downsampling and Int8Array quantization in a single utility provides ready-to-render peaks:

/**
 * Downsamples float audio channel data to Int8 min/max peaks for Wavesurfer.js.
 * @param {Float32Array} channelData - The raw audio channel float data.
 * @param {number} targetLength - Desired total number of peak points.
 * @returns {Int8Array} Alternating min and max Int8 peak values.
 */
function extractInt8Peaks(channelData, targetLength) {
  const step = Math.floor(channelData.length / (targetLength / 2));
  const peaks = new Int8Array(targetLength);
  let peakIndex = 0;

  for (let i = 0; i < channelData.length; i += step) {
    let min = 1.0;
    let max = -1.0;
    const end = Math.min(i + step, channelData.length);

    for (let j = i; j < end; j++) {
      const val = channelData[j];
      if (val < min) min = val;
      if (val > max) max = val;
    }

    // Convert min and max to Int8
    peaks[peakIndex++] = min < 0 ? Math.round(min * 128) : Math.round(min * 127);
    peaks[peakIndex++] = max < 0 ? Math.round(max * 128) : Math.round(max * 127);

    if (peakIndex >= targetLength) break;
  }

  return peaks;
}

Using audiowaveform CLI for Precomputed Peaks

For server-side automation, the C++ utility audiowaveform is the most widely adopted external tool for generating Wavesurfer-compatible data. It natively converts floating-point source audio into 8-bit peak arrays directly from the terminal.

To produce an 8-bit binary peak file:

audiowaveform -i input.mp3 -o output.dat -b 8

To output directly to 8-bit JSON:

audiowaveform -i input.mp3 -o output.json -b 8 --pixels-per-second 20

The resulting output.dat file contains an 8-bit signed byte stream representing the waveform, which can be fetched directly as an ArrayBuffer in the browser and passed to new Int8Array(buffer).

Loading Int8 Data into Wavesurfer.js

Wavesurfer.js expects peak values normalized between -1 and 1 when reading from the peaks array configuration option. When using an Int8Array, convert the values back into normalized floating points or pass the array directly if using a custom backend renderer:

// Fetch precomputed Int8 binary data
fetch('/peaks/track-1.dat')
  .then((response) => response.arrayBuffer())
  .then((buffer) => {
    const int8Peaks = new Int8Array(buffer);
    
    // Normalize to Float32 [-1, 1] for the standard Wavesurfer instance
    const normalizedPeaks = new Float32Array(int8Peaks.length);
    for (let i = 0; i < int8Peaks.length; i++) {
      normalizedPeaks[i] = int8Peaks[i] / (int8Peaks[i] < 0 ? 128 : 127);
    }

    const wavesurfer = WaveSurfer.create({
      container: '#waveform',
      waveColor: '#4F4A85',
      progressColor: '#383351',
      peaks: [normalizedPeaks]
    });
  });

Using these utilities allows large audio catalogs to store compact peak metadata over the network while maintaining compatibility with the visual expectations of Wavesurfer.js.
