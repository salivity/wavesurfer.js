Programmatically Select Regions in Wavesurfer.js

This guide explains how to programmatically create, highlight, and manipulate specific audio segments using Wavesurfer.js and its official Regions plugin. You will learn how to initialize the plugin, define custom start and end boundaries, apply distinct visual styles, and control playback within a selected region via code.

1. Initialize the Regions Plugin

Wavesurfer.js handles visual selections using the RegionsPlugin. You must register the plugin instance with your main Wavesurfer instance before manipulating regions.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Create the Wavesurfer instance
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio-file.mp3',
});

// Initialize and register the Regions plugin
const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

2. Create and Highlight a Region

To select and highlight a section programmatically, call the addRegion method on the wsRegions instance. Pass the start and end timestamps (in seconds) along with custom RGBA color values to control the highlight appearance.

// Wait for audio to be ready before adding regions
wavesurfer.on('ready', () => {
  const selectedRegion = wsRegions.addRegion({
    start: 10.5,                    // Start time in seconds
    end: 20.0,                      // End time in seconds
    content: 'Highlighted Segment', // Optional label
    color: 'rgba(0, 123, 255, 0.3)',// Semi-transparent highlight color
    drag: true,                     // Allow user to drag
    resize: true,                   // Allow user to resize handles
  });
});

3. Clear Existing Selections

If your application requires only one active selection at a time, clear prior selections before creating a new one using the clearRegions() method.

function highlightNewSegment(startTime, endTime) {
  // Remove existing regions
  wsRegions.clearRegions();

  // Highlight the new selection
  return wsRegions.addRegion({
    start: startTime,
    end: endTime,
    color: 'rgba(255, 193, 7, 0.4)',
  });
}

4. Update an Existing Region

If a region has already been initialized, you can modify its boundaries or styles directly without recreating it by calling the setOptions method on the region reference:

const region = wsRegions.addRegion({
  start: 5,
  end: 15,
  color: 'rgba(0, 255, 0, 0.3)',
});

// Programmatically shift the boundaries later
region.setOptions({
  start: 8,
  end: 18,
  color: 'rgba(255, 0, 0, 0.3)',
});

5. Play and Seek to the Highlighted Region

To direct user attention to the selection immediately after creating it, use the built-in region playback and seek methods:

const myRegion = wsRegions.addRegion({
  start: 30,
  end: 45,
  color: 'rgba(75, 192, 192, 0.3)',
});

// Seek the playhead to the region's start point
wavesurfer.setTime(myRegion.start);

// Alternatively, loop playback within this specific region
myRegion.play();
