Calculate Timestamp on Mousemove in Wavesurfer.js

This guide explains how to calculate exact audio timestamps in real time when hovering over a Wavesurfer.js waveform. By capturing the cursor's horizontal position relative to the waveform container and scaling it against the total audio duration, you can create dynamic hover timestamps, tooltips, or scrubbing previews.

The Calculation Logic

To determine the exact timestamp under the mouse cursor, calculate the ratio of the cursor's horizontal position relative to the container width, then multiply that ratio by the track's total duration:

\[\text{Timestamp} = \left( \frac{\text{Cursor } X}{\text{Container Width}} \right) \times \text{Total Duration}\]

Implementation

Bind a standard mousemove event listener to the container element hosting the Wavesurfer instance. Use getBoundingClientRect() to ensure accuracy even if the page layout shifts.

import WaveSurfer from 'wavesurfer.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

const container = document.querySelector('#waveform');

// Calculate timestamp on mousemove
container.addEventListener('mousemove', (event) => {
  const duration = wavesurfer.getDuration();
  
  // Ensure audio is loaded and has a valid duration
  if (!duration) return;

  const rect = container.getBoundingClientRect();
  const offsetX = event.clientX - rect.left;
  
  // Clamp progress between 0 and 1
  const progress = Math.max(0, Math.min(offsetX / rect.width, 1));
  
  // Calculate precise timestamp in seconds
  const timestamp = progress * duration;

  console.log(`Current Hover Timestamp: ${timestamp.toFixed(2)}s`);
});

Handling Scrollable and Zoomed Waveforms

If your waveform uses the minPxPerSec configuration or is contained within a horizontally scrollable container, the calculation must account for the scroll offset:

container.addEventListener('mousemove', (event) => {
  const duration = wavesurfer.getDuration();
  if (!duration) return;

  const rect = container.getBoundingClientRect();
  
  // Account for horizontal scroll
  const scrollOffset = container.scrollLeft || 0;
  const offsetX = (event.clientX - rect.left) + scrollOffset;
  const totalWidth = container.scrollWidth;

  const progress = Math.max(0, Math.min(offsetX / totalWidth, 1));
  const preciseTimestamp = progress * duration;

  displayHoverTime(preciseTimestamp);
});

function displayHoverTime(seconds) {
  const minutes = Math.floor(seconds / 60);
  const remainingSeconds = Math.floor(seconds % 60);
  const milliseconds = Math.floor((seconds % 1) * 100);

  const formatted = `${String(minutes).padStart(2, '0')}:${String(remainingSeconds).padStart(2, '0')}.${String(milliseconds).padStart(2, '0')}`;
  
  // Update your tooltip or UI element here
  document.getElementById('time-display').textContent = formatted;
}

Using Built-in Plugins

Wavesurfer.js provides an official Hover plugin (wavesurfer.js/dist/plugins/hover.esm.js) that automates this behavior. If you do not require a custom event implementation, the plugin automatically renders a vertical line and timestamp label at the cursor location during mouse movement.
