Build Karaoke Word Highlighting with Wavesurfer.js

This guide explains how to build an interactive, karaoke-style word highlighting user interface synchronized with an audio waveform using Wavesurfer.js. You will learn how to structure word-level timestamp data, render the lyrics into manageable DOM nodes, listen to the Wavesurfer playback events, and dynamically toggle CSS highlighting classes to match the playhead in real time.

1. Prepare Word-Level Timestamp Data

To highlight individual words accurately, you need audio transcription data containing start and end timestamps for each word. This is typically obtained from speech-to-text APIs (like Whisper) or manual synchronization. Format this data as an array of objects:

const transcript = [
  { text: "Hello", start: 0.0, end: 0.4 },
  { text: "world,", start: 0.45, end: 0.9 },
  { text: "welcome", start: 0.95, end: 1.4 },
  { text: "to", start: 1.45, end: 1.7 },
  { text: "the", start: 1.75, end: 1.9 },
  { text: "show.", start: 1.95, end: 2.5 }
];

2. Render the Lyric Elements

Render each word as an individual <span> element within a container. Store each word's index or timestamps in data-* attributes so they can be matched during playback:

<div id="waveform"></div>
<div id="lyrics-container"></div>
const lyricsContainer = document.getElementById('lyrics-container');

transcript.forEach((item, index) => {
  const span = document.createElement('span');
  span.textContent = item.text + ' ';
  span.id = `word-${index}`;
  span.dataset.start = item.start;
  span.dataset.end = item.end;
  span.classList.add('lyric-word');
  lyricsContainer.appendChild(span);
});

3. Style the States

Define the visual state for inactive, currently active, and already sung words in CSS:

.lyric-word {
  color: #888888;
  transition: color 0.1s ease, transform 0.1s ease;
  display: inline-block;
}

/* Active word currently being sung */
.lyric-word.active {
  color: #ff0055;
  font-weight: bold;
  transform: scale(1.1);
}

/* Words that have already finished playing */
.lyric-word.played {
  color: #000000;
}

4. Initialize Wavesurfer.js and Bind Time Events

Initialize Wavesurfer and use the timeupdate event (available in modern versions of Wavesurfer.js) to detect playhead movement. Compare the current audio time against your transcript timestamps:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
});

let activeIndex = -1;

wavesurfer.on('timeupdate', (currentTime) => {
  // Find the word that corresponds to the current playback position
  const currentIndex = transcript.findIndex(
    (word) => currentTime >= word.start && currentTime <= word.end
  );

  if (currentIndex !== activeIndex) {
    // Remove active class from previous word
    if (activeIndex !== -1) {
      const prevElement = document.getElementById(`word-${activeIndex}`);
      if (prevElement) {
        prevElement.classList.remove('active');
        prevElement.classList.add('played');
      }
    }

    // Add active class to current word
    if (currentIndex !== -1) {
      const currentElement = document.getElementById(`word-${currentIndex}`);
      if (currentElement) {
        currentElement.classList.add('active');
        currentElement.scrollIntoView({ behavior: 'smooth', block: 'center' });
      }
    }

    activeIndex = currentIndex;
  }
});

5. Handle Scrubbing and Seeking

When users click the waveform to jump to a different part of the audio, ensure past words are marked correctly and future words are reset:

wavesurfer.on('seeking', (currentTime) => {
  transcript.forEach((word, index) => {
    const el = document.getElementById(`word-${index}`);
    el.classList.remove('active');
    
    if (currentTime > word.end) {
      el.classList.add('played');
    } else {
      el.classList.remove('played');
    }
  });
  activeIndex = -1;
});

This synchronization loop guarantees the UI highlights the exact active word as the Wavesurfer playhead moves, cleanly handles manual seeking, and keeps the text centered on screen.
