How to Create Bezier Waveforms in Wavesurfer.js

This article explains how to replace the default blocky or linear canvas visualizations in Wavesurfer.js with continuous, mathematically smoothed Bézier curves. By utilizing the custom renderFunction hook available in Wavesurfer.js alongside HTML5 Canvas path methods, you can transform discrete audio peak arrays into fluid, modern audio waveforms.

Understanding the Custom Rendering Pipeline

Wavesurfer.js (version 7 and later) exposes a renderFunction configuration option that bypasses default bar or line drawing routines. The function receives two critical arguments: the normalized peaks array (representing audio amplitude) and the destination Canvas rendering context (ctx).

Because raw peak arrays contain discrete minimum and maximum sample points, connecting them with standard lineTo calls creates jagged edges. To produce a smooth wave, you must iterate over the peak values and generate intermediate control points for quadratic or cubic Bézier curves.

Calculating Control Points for Smooth Transitions

The most efficient and visually stable technique for audio curves is using midpoint quadratic Bézier interpolation. Instead of drawing straight lines between coordinates \((x_i, y_i)\) and \((x_{i+1}, y_{i+1})\), each segment calculates a midpoint:

\[\text{midX} = \frac{x_i + x_{i+1}}{2}, \quad \text{midY} = \frac{y_i + y_{i+1}}{2}\]

The current point acts as the control point, and the midpoint becomes the curve's endpoint via ctx.quadraticCurveTo(). This eliminates sharp angular turns and prevents overshoot artifacts common with high-order polynomials.

Implementing the Custom Renderer

Configure Wavesurfer.js with the renderFunction callback. The implementation loops through the channel peaks, maps normalized values to canvas dimensions, and draws mirrored upper and lower Bézier curves.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'rgba(74, 144, 226, 0.8)',
  progressColor: 'rgba(46, 91, 255, 1)',
  renderFunction: (peaks, ctx) => {
    const { width, height } = ctx.canvas;
    const halfHeight = height / 2;
    
    // Support mono or stereo peak channels
    const channelData = peaks[0] || peaks;
    const totalPoints = channelData.length;
    const step = width / totalPoints;

    ctx.clearRect(0, 0, width, height);
    ctx.beginPath();

    // Map audio peak data to top coordinates
    const topPoints = [];
    const bottomPoints = [];

    for (let i = 0; i < totalPoints; i++) {
      const x = i * step;
      const amplitude = channelData[i] * halfHeight;
      topPoints.push({ x, y: halfHeight - amplitude });
      bottomPoints.push({ x, y: halfHeight + amplitude });
    }

    // 1. Draw top smooth curve
    ctx.moveTo(topPoints[0].x, topPoints[0].y);
    for (let i = 0; i < topPoints.length - 1; i++) {
      const current = topPoints[i];
      const next = topPoints[i + 1];
      const midX = (current.x + next.x) / 2;
      const midY = (current.y + next.y) / 2;
      ctx.quadraticCurveTo(current.x, current.y, midX, midY);
    }

    // 2. Connect to the bottom curve and reverse path
    const lastBottom = bottomPoints[bottomPoints.length - 1];
    ctx.lineTo(lastBottom.x, lastBottom.y);

    for (let i = bottomPoints.length - 1; i > 0; i--) {
      const current = bottomPoints[i];
      const prev = bottomPoints[i - 1];
      const midX = (current.x + prev.x) / 2;
      const midY = (current.y + prev.y) / 2;
      ctx.quadraticCurveTo(current.x, current.y, midX, midY);
    }

    ctx.closePath();
    ctx.fillStyle = ctx.canvas.parentElement.style.color || '#4a90e2';
    ctx.fill();
  }
});

Handling HiDPI Screens and Performance

Smooth Bézier rendering increases the number of canvas drawing commands. To maintain high performance and sharp lines:

  • Downsample Peaks: If the audio file is long, reduce the peak array resolution using the barWidth or barGap equivalents by grouping multiple raw samples into a single coordinate point before curve calculation.
  • Pixel Density Adjustments: Canvas contexts supplied by Wavesurfer.js are already scaled for device pixel ratio (window.devicePixelRatio). Use standard canvas dimensions (ctx.canvas.width and ctx.canvas.height) divided by the DPR if calculations require CSS pixel metrics.
  • Style Filling vs. Stroking: To draw single-line oscillating waveforms rather than filled regions, split the loop into a single forward pass without closing the path, adjusting ctx.lineWidth and executing ctx.stroke().
