Make Wavesurfer.js Bars Pulsate with Audio

This guide demonstrates how to create a dynamic pulsating effect for Wavesurfer.js waveform bars that reacts to real-time audio volume dynamics. By integrating the native Web Audio API AnalyserNode with Wavesurfer's playback engine, you can extract instantaneous volume levels and dynamically modulate the waveform’s visual dimensions using a continuous animation loop.

Core Concept

By default, Wavesurfer.js renders a static waveform derived from pre-decoded audio peaks. To make it react dynamically to audio volume during playback, you must:

  1. Route Wavesurfer’s underlying HTML audio element through a Web Audio API AnalyserNode.
  2. Extract real-time amplitude or frequency data on every frame using requestAnimationFrame.
  3. Compute the current volume level (such as Root Mean Square or peak amplitude).
  4. Apply that volume value to scale the waveform container or its internal canvas via CSS transforms.

Step-by-Step Implementation

1. Initialize Wavesurfer.js

Create a standard Wavesurfer instance with bar styling options enabled:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  barWidth: 3,
  barGap: 2,
  barRadius: 2,
  url: '/path-to-your-audio.mp3',
});

2. Connect the Web Audio Analyser

Once the audio element is ready, connect an AudioContext and AnalyserNode to read live playback amplitude:

let analyser;
let dataArray;

wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();
  const audioContext = new (window.AudioContext || window.webkitAudioContext)();
  
  const source = audioContext.createMediaElementSource(mediaElement);
  analyser = audioContext.createAnalyser();
  
  analyser.fftSize = 256;
  const bufferLength = analyser.frequencyBinCount;
  dataArray = new Uint8Array(bufferLength);

  source.connect(analyser);
  analyser.connect(audioContext.destination);
});

3. Create the Pulsation Animation Loop

Track playback states and compute the average volume inside a requestAnimationFrame loop. Scale the vertical axis of the waveform container according to the instantaneous volume:

let animationFrameId;
const waveformContainer = document.querySelector('#waveform');

function getVolumeLevel() {
  analyser.getByteFrequencyData(dataArray);

  let sum = 0;
  for (let i = 0; i < dataArray.length; i++) {
    sum += dataArray[i];
  }

  // Calculate normalized average amplitude (0.0 to 1.0)
  return sum / dataArray.length / 255;
}

function updatePulse() {
  if (wavesurfer.isPlaying()) {
    const volume = getVolumeLevel();

    // Map volume to a scale multiplier (e.g., base 1.0 up to 1.35)
    const scale = 1 + volume * 0.35;

    waveformContainer.style.transform = `scaleY(${scale})`;
    waveformContainer.style.transformOrigin = 'center';

    animationFrameId = requestAnimationFrame(updatePulse);
  }
}

wavesurfer.on('play', () => {
  updatePulse();
});

wavesurfer.on('pause', () => {
  cancelAnimationFrame(animationFrameId);
  waveformContainer.style.transform = 'scaleY(1)';
});

wavesurfer.on('finish', () => {
  cancelAnimationFrame(animationFrameId);
  waveformContainer.style.transform = 'scaleY(1)';
});

Enhancing Visual Smoothness

Direct amplitude readings can fluctuate abruptly, causing visual jitter. To ensure a smooth pulsation effect, apply linear interpolation (lerp) or use CSS transitions:

#waveform {
  transition: transform 0.05s ease-out;
  will-change: transform;
}

This setup ensures the bars scale fluidly along the vertical axis in perfect synchronization with beats, drops, and volume shifts in the audio track.
