Handling Region Click Events in Wavesurfer.js

In Wavesurfer.js, detecting user interactions with marked audio segments depends on whether you are using the modern version (v7+) or legacy versions (v4–v6). In modern Wavesurfer.js, the Regions plugin emits the region-clicked event, and the individual region instance emits a click event. In legacy versions of Wavesurfer.js, the main instance emitted a region-click event. This guide outlines the exact event names and code implementations for handling region clicks across both architectures.

Modern Wavesurfer.js (Version 7+)

In version 7 and newer, Wavesurfer.js uses an updated modular plugin structure. When a user clicks on an audio region, two events are triggered depending on whether you are listening on the plugin instance or directly on a specific region.

1. Listening via the Regions Plugin (region-clicked)

The Regions plugin instance emits the region-clicked event globally for any region created through it. The callback receives two arguments: the target Region object and the original DOM mouse event (MouseEvent).

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const ws = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
});

// Initialize the Regions plugin
const wsRegions = ws.registerPlugin(RegionsPlugin.create());

// Listen for clicks on any region
wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation(); // Prevent playback from starting or triggering container clicks
  console.log('Region clicked:', region.id);
  region.play();
});

2. Listening Directly on a Region (click)

When a region is generated, it acts as an event emitter. You can attach a click listener directly to the specific region object. The callback receives the DOM MouseEvent.

const region = wsRegions.addRegion({
  start: 2,
  end: 6,
  color: 'rgba(0, 255, 0, 0.3)',
});

region.on('click', (e) => {
  e.stopPropagation();
  console.log(`Clicked specifically on region ${region.id}`);
});

Legacy Wavesurfer.js (Version 4 through 6)

In legacy versions, the event name used a hyphen without the past tense: region-click. This event was emitted directly on the core Wavesurfer instance rather than the plugin object.

// Legacy setup
wavesurfer.on('region-click', function (region, e) {
  e.stopPropagation();
  console.log('Legacy region-click triggered:', region);
  region.play();
});

Individual legacy regions also supported the click event directly:

region.on('click', function (e) {
  e.stopPropagation();
});

Event Parameter Details

Regardless of the version, click handlers provide access to key data:

  • Region Object: Contains properties such as id, start time, end time, color, and manipulation methods such as .play(), .remove(), and .setOptions().
  • DOM Event (e): The standard browser MouseEvent. Using e.stopPropagation() inside the handler is commonly recommended to prevent the waveform container from receiving the click and immediately seeking the playback head to the clicked position.
