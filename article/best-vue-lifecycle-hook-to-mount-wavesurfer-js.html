Best Vue Lifecycle Hook to Mount Wavesurfer.js

Integrating Wavesurfer.js into a Vue.js application requires interacting directly with the Document Object Model (DOM) to render the audio waveform canvas. This article explains the ideal Vue lifecycle hook for initializing Wavesurfer.js, why earlier hooks fail, and how to properly clean up the audio instance when the component is destroyed.

The Ideal Lifecycle Hook: mounted / onMounted

The optimal lifecycle hook for initializing Wavesurfer.js is mounted in the Options API or onMounted in the Composition API (Vue 3).

Wavesurfer.js requires an existing, rendered HTML container element—typically referenced via a standard selector like #waveform or a Vue template ref—to attach its canvas and visual components.

Why Earlier Hooks Fail

Hooks such as created, beforeMount, or the root of the Vue 3 setup() function execute before the component's virtual DOM is converted into actual DOM nodes. If you attempt to instantiate Wavesurfer.js in these earlier stages:

// This will throw an error because the container does not yet exist in the DOM
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
});

Wavesurfer will throw an error (such as Container element not found or an error referencing a null target) because the specified element does not yet exist on the page.

Implementation Example (Vue 3 Composition API)

Using onMounted along with a template ref ensures that the target container is accessible:

<template>
  <div ref="waveformContainer"></div>
</template>

<script setup>
import { ref, onMounted, onBeforeUnmount } from 'vue';
import WaveSurfer from 'wavesurfer.js';

const waveformContainer = ref(null);
let wavesurfer = null;

onMounted(() => {
  if (waveformContainer.value) {
    wavesurfer = WaveSurfer.create({
      container: waveformContainer.value,
      waveColor: '#4F4A85',
      progressColor: '#383351',
      url: '/path-to-audio.mp3',
    });
  }
});

onBeforeUnmount(() => {
  if (wavesurfer) {
    wavesurfer.destroy();
  }
});
</script>

Don't Forget Cleanup: onBeforeUnmount

Whenever you initialize Wavesurfer.js inside mounted or onMounted, you must pair it with a cleanup hook: beforeUnmount / onBeforeUnmount (or beforeDestroy in Vue 2).

Calling wavesurfer.destroy() removes event listeners, stops audio playback, releases the Web Audio context, and clears the generated DOM nodes. Neglecting this step can lead to significant memory leaks and overlapping audio playback across route transitions.
