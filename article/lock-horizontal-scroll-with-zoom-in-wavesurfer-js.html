Lock Horizontal Scroll with Zoom in Wavesurfer.js

This guide explains how to disable horizontal scrolling in Wavesurfer.js while keeping the audio zoom feature functional. By combining Wavesurfer's native initialization options with targeted CSS overflow controls, you can zoom into waveforms at high resolution without allowing manual or automatic horizontal scrollbars to shift the view.

The Solution: CSS Container Rules and autoScroll

Wavesurfer.js calculates waveform dimensions dynamically when zooming using minPxPerSec or the zoom() method. By default, expanding the waveform beyond the viewport enables horizontal scrolling inside the container.

To lock horizontal scrolling completely while preserving zoom, you must apply a CSS constraint to the wrapper and disable playback scrolling in the configuration.

1. Configure the Wavesurfer Instance

Set autoScroll to false during initialization to prevent the player from automatically scrolling the container along with the playhead during playback:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  minPxPerSec: 100, // Zoom level
  autoScroll: false, // Prevents automatic horizontal scroll during playback
  autoCenter: false  // Prevents auto-centering the waveform
});

2. Apply CSS to Lock the Scrollbar

Lock manual scrolling by applying overflow-x: hidden directly to the waveform container element in your CSS. This clips the expanded waveform to the container’s boundaries without affecting Wavesurfer's internal zoom calculations:

#waveform {
  width: 100%;
  height: 128px;
  overflow-x: hidden !important; /* Locks horizontal scrolling */
  overflow-y: hidden;
  position: relative;
}

If targeting Wavesurfer's internal wrapper dynamically in JavaScript:

wavesurfer.on('ready', () => {
  const wrapper = wavesurfer.getWrapper();
  wrapper.style.overflowX = 'hidden';
});

3. Dynamically Zooming Without Scroll

You can now adjust zoom levels programmatically via the zoom() API. The waveform will re-render with higher fidelity, but the visible area remains strictly anchored inside your container:

// Increases detail without allowing horizontal movement
wavesurfer.zoom(200);

Summary of Configuration

  • autoScroll: false: Disables playhead tracking and automatic viewport panning.
  • autoCenter: false: Ensures the waveform does not center itself horizontally.
  • overflow-x: hidden: Hides the scrollbar and locks the horizontal viewport to the width of the parent element.
