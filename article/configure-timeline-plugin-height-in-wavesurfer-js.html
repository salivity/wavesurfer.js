Configure Timeline Plugin Height in Wavesurfer.js

This article explains how to adjust the height of the timeline plugin in Wavesurfer.js. You will learn the exact configuration property required, see code examples for implementation, and understand how this setting impacts the visual layout of your audio waveform player.

In Wavesurfer.js, the option used to configure the height of the timeline plugin is height. This property accepts a numeric value that defines the height of the timeline track in pixels.

How to Set the Timeline Height

When initializing the Timeline plugin, pass the height property inside the plugin's options object.

Here is an example using Wavesurfer.js version 7:

import WaveSurfer from 'wavesurfer.js'
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js'

// Initialize the Timeline plugin with a custom height
const timeline = TimelinePlugin.create({
  height: 30, // Sets the timeline height to 30 pixels
  insertPosition: 'beforebegin', // Optional: place timeline above or below the waveform
})

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio.mp3',
  plugins: [timeline],
})

Usage in Wavesurfer.js v6 and Earlier

If you are maintaining an older version of Wavesurfer.js, the property remains the same. You pass height within the WaveSurfer.timeline.create() initialization options:

var wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: 'violet',
  progressColor: 'purple',
  plugins: [
    WaveSurfer.timeline.create({
      container: '#wave-timeline',
      height: 25 // Height in pixels
    })
  ]
});

Additional Considerations

  • Default Value: If omitted, the timeline defaults to a standard height (typically 20 pixels in modern versions).
  • Font and Notch Scaling: When increasing the height substantially, adjust the fontSize and notchPercentHeight options to ensure the notch markers and text labels remain proportional to the larger container.
