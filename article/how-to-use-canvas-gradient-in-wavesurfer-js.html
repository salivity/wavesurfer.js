How to Use CanvasGradient in Wavesurfer.js

Yes, CanvasGradient objects can be assigned directly to the waveColor property in Wavesurfer.js. Because Wavesurfer.js utilizes the HTML5 Canvas 2D API for rendering waveforms, properties like waveColor and progressColor accept any valid canvas fill style, including solid color strings, patterns, and linear or radial gradients. This article explains how the integration works, provides a practical implementation example, and covers essential considerations such as gradient dimensions and dynamic resizing.

How Wavesurfer.js Handles Gradients

Under the hood, Wavesurfer.js assigns the values of waveColor and progressColor directly to the fillStyle property of the rendering canvas context. Because the HTML5 Canvas fillStyle property accepts a CanvasGradient object, Wavesurfer.js can natively render gradients without third-party plugins or complex configuration.

To use a gradient, you generate a CanvasGradient instance using standard canvas methods and pass that instance to the WaveSurfer.create() configuration object.

Implementation Example

To create a gradient, instantiate an off-screen canvas element or context, build the linear gradient, and apply color stops before initializing Wavesurfer.

import WaveSurfer from 'wavesurfer.js';

// 1. Create a dummy canvas to generate the CanvasGradient
const canvas = document.createElement('canvas');
const ctx = canvas.getContext('2d');

// 2. Define the gradient dimensions (x0, y0, x1, y1)
// For a vertical gradient matching a 128px high waveform:
const waveGradient = ctx.createLinearGradient(0, 0, 0, 128);
waveGradient.addColorStop(0, '#ff5e62');
waveGradient.addColorStop(1, '#ff9966');

// 3. Define an optional progress gradient
const progressGradient = ctx.createLinearGradient(0, 0, 0, 128);
progressGradient.addColorStop(0, '#4facfe');
progressGradient.addColorStop(1, '#00f2fe');

// 4. Initialize Wavesurfer with the gradients
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  height: 128,
  waveColor: waveGradient,
  progressColor: progressGradient,
  url: '/path/to/audio.mp3',
});

Key Considerations

Coordinate Matching

A CanvasGradient relies on fixed pixel coordinates. If you set a vertical gradient using createLinearGradient(0, 0, 0, 128), the coordinate range (0 to 128) must match the height option passed to Wavesurfer. If the waveform container height differs from the gradient's coordinate boundaries, the gradient may appear cut off, stretched, or solid.

Horizontal Gradients

While vertical gradients depend only on the waveform height, horizontal gradients require the width of the waveform container. Because canvas containers often have responsive widths, a horizontal gradient must be calculated based on the actual pixel width of the container element at render time.

Responsive Resizing

If your player allows dynamic resizing or re-renders on window size changes, you must recreate the CanvasGradient with updated dimensions and apply it using wavesurfer.setOptions({ waveColor: newGradient }) to maintain proper color distribution.
