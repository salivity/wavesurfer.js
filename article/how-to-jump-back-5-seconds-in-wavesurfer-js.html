How to Jump Back 5 Seconds in Wavesurfer.js

Navigating audio playback by fixed time intervals is a fundamental feature for web-based audio applications. This guide explains how to programmatically rewind audio by five seconds in Wavesurfer.js by retrieving the current playback position, calculating the target offset, clamping the value to prevent negative timestamps, and updating the player position using native methods.

Getting the Current Time and Calculating the Offset

To jump backward by five seconds, you must first read the active playback position using the getCurrentTime() method. Subtract 5 from this value, and wrap the calculation with Math.max() to ensure the playback position does not drop below 0 if the user triggers the action within the first five seconds of the track.

const currentTime = wavesurfer.getCurrentTime();
const targetTime = Math.max(0, currentTime - 5);

Applying the New Time in Wavesurfer.js v7+

In modern versions of Wavesurfer.js (v7 and newer), you can pass the target timestamp directly in seconds using the setTime() method:

function rewindFiveSeconds(wavesurfer) {
  const currentTime = wavesurfer.getCurrentTime();
  const targetTime = Math.max(0, currentTime - 5);
  wavesurfer.setTime(targetTime);
}

Applying the New Time in Legacy Versions (v6 and Older)

In older versions of Wavesurfer.js, seeking directly by seconds is handled either via relative skipping or by converting the timestamp to a normalized float between 0 and 1 using getDuration():

function rewindFiveSecondsLegacy(wavesurfer) {
  const currentTime = wavesurfer.getCurrentTime();
  const duration = wavesurfer.getDuration();
  const targetTime = Math.max(0, currentTime - 5);

  // Normalize to a 0 - 1 float for seekTo
  const progress = duration > 0 ? targetTime / duration : 0;
  wavesurfer.seekTo(progress);
}

Complete Event Listener Example

Attach the function to a button click event in your application interface:

<button id="rewind-btn">Rewind 5s</button>

<script>
  const rewindButton = document.getElementById('rewind-btn');

  rewindButton.addEventListener('click', () => {
    if (!wavesurfer.isReady) return;
    
    const targetTime = Math.max(0, wavesurfer.getCurrentTime() - 5);
    wavesurfer.setTime(targetTime);
  });
</script>
