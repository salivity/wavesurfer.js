Export Waveform Peak Data in Wavesurfer.js

This guide explains how to extract and export waveform peak data from an audio track loaded in Wavesurfer.js. Generating and saving peak data allows you to cache audio visualizations on your server, significantly reducing client-side processing overhead and drastically speeding up initial player rendering on subsequent page loads.

The Primary Method: exportPeaks()

In modern versions of Wavesurfer.js (v7 and newer), the primary method used to export waveform data is exportPeaks(). This method reads the decoded audio buffer directly from the player instance and computes the min/max peak points.

// Ensure audio is fully decoded before exporting
wavesurfer.on('ready', () => {
  const peaks = wavesurfer.exportPeaks({
    channels: 1,
    maxLength: 8000,
    precision: 10000,
  });

  console.log(peaks);
  // peaks returns an array of arrays containing float values
});

Configuration Options for exportPeaks()

The exportPeaks() function accepts an optional configuration object with the following parameters:

  • channels (number, default: 2): Determines how many channels to extract. Setting this to 1 merges the audio data into a single mono channel, which is typically sufficient for standard waveform displays and cuts data size in half.
  • maxLength (number, default: 8000): The maximum number of data points returned per channel. A lower value reduces JSON payload size, while a higher value preserves higher visual fidelity when zooming in.
  • precision (number, default: 10000): The rounding factor applied to the peak values. Using 10000 rounds the peaks to four decimal places, drastically reducing file size when saving the output as text or JSON.

Storing and Reusing Exported Peaks

Once you obtain the array from exportPeaks(), you can serialize it to JSON and store it in a database or static file:

const peaksJson = JSON.stringify(peaks);
// Send peaksJson to your backend via fetch or XMLHttpRequest

To load the precomputed peaks later, pass the stored data directly into the peaks property during Wavesurfer initialization. When peak data is provided upfront, Wavesurfer renders the waveform immediately without waiting to download or decode the full audio file:

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/audio/track.mp3',
  peaks: precomputedPeaksData, // Direct pass of exported peak array
});

Legacy Wavesurfer.js (Version 6 and Earlier)

If you are maintaining a legacy implementation using Wavesurfer.js v6 or earlier, exportPeaks() is not available. Instead, you extract peaks using the backend instance via wavesurfer.backend.getPeaks():

wavesurfer.on('ready', function () {
  // Pass the target length for the peak array
  var peaks = wavesurfer.backend.getPeaks(1024);
  console.log(JSON.stringify(peaks));
});

Alternatively, older versions offered wavesurfer.exportPCM(), which exported PCM peak data formatted as a JSON string, array, or data URI.
