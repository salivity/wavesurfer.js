How to Get a Region by ID in Wavesurfer.js

Retrieving a specific region by its unique ID in Wavesurfer.js is a fundamental task when building interactive audio editors, looping tools, or annotation interfaces. This article explains how to target and fetch a specific region instance using its unique identifier, with straightforward code examples covering both the modern Wavesurfer.js (v7+) API and legacy versions.

Retrieving a Region in Wavesurfer.js v7+

In modern versions of Wavesurfer.js, region functionality is managed by the @wavesurfer/regions plugin. Instead of a direct key-value lookup map, the plugin provides a method that returns an array of all active regions. You can find your specific region using JavaScript's native .find() array method.

1. Initialize the Plugin and Keep a Reference

When creating the Regions plugin, store its reference in a variable:

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple'
});

// Initialize and save the reference
const wsRegions = wavesurfer.registerPlugin(RegionsPlugin.create());

2. Find the Region by ID

Use the getRegions() method provided by the plugin instance to query for the region with the matching id:

function getRegionById(regionId) {
  const regions = wsRegions.getRegions();
  return regions.find(region => region.id === regionId);
}

// Example usage:
const myRegion = getRegionById('custom-region-id');

if (myRegion) {
  console.log(`Found region starting at: ${myRegion.start}s`);
  // Perform actions like playing or updating the region
  myRegion.play();
} else {
  console.warn('Region not found.');
}

If you do not have direct access to the wsRegions variable in your current scope, you can retrieve the plugin instance from the main Wavesurfer instance:

const pluginInstance = wavesurfer.getActivePlugins().find(p => p instanceof RegionsPlugin);
const myRegion = pluginInstance ? pluginInstance.getRegions().find(r => r.id === 'custom-region-id') : null;

Retrieving a Region in Wavesurfer.js v6 and Earlier

In older versions of Wavesurfer.js (v6 and below), regions were stored directly in an object named list under the regions plugin namespace. You can retrieve a region instantly using standard bracket notation:

// Access the region directly by key in v6
const regionId = 'custom-region-id';
const myRegion = wavesurfer.regions.list[regionId];

if (myRegion) {
  myRegion.play();
}

Common Actions Once the Region is Retrieved

Once you have obtained the region object, you can interact with it directly using its built-in methods:

  • Play the region: myRegion.play()

  • Remove the region: myRegion.remove()

  • Update region properties (v7+):

    myRegion.setOptions({
  start: 5,
  end: 10,
  color: 'rgba(0, 255, 0, 0.3)'
});
