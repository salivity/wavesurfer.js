How to Import Wavesurfer.js into React

Integrating audio waveforms into web applications adds a professional touch to audio playback, and Wavesurfer.js is the leading library for the job. This guide provides a straightforward walkthrough on how to install, import, and configure Wavesurfer.js within a React functional component. You will learn how to initialize the waveform using React hooks, manage playback states, and properly clean up instances to prevent memory leaks.

1. Installation

First, install the latest version of Wavesurfer.js in your React project via npm or yarn:

npm install wavesurfer.js

or

yarn add wavesurfer.js

2. Setting Up the React Component

In React, Wavesurfer.js requires a reference to a physical DOM node to render the waveform canvas. You can achieve this using the useRef hook, while the useEffect hook handles the library's lifecycle (creation and destruction).

Here is a complete, minimal implementation:

import React, { useEffect, useRef, useState } from 'react';
import WaveSurfer from 'wavesurfer.js';

const AudioPlayer = ({ audioUrl }) => {
  const containerRef = useRef(null);
  const wavesurferRef = useRef(null);
  const [isPlaying, setIsPlaying] = useState(false);

  useEffect(() => {
    if (!containerRef.current) return;

    // Initialize WaveSurfer
    const ws = WaveSurfer.create({
      container: containerRef.current,
      waveColor: '#4F46E5',
      progressColor: '#818CF8',
      cursorColor: '#312E81',
      barWidth: 2,
      barGap: 1,
      barRadius: 2,
      height: 100,
      url: audioUrl,
    });

    wavesurferRef.current = ws;

    // Event listeners
    ws.on('play', () => setIsPlaying(true));
    ws.on('pause', () => setIsPlaying(false));

    // Cleanup on unmount
    return () => {
      ws.destroy();
    };
  }, [audioUrl]);

  const handlePlayPause = () => {
    if (wavesurferRef.current) {
      wavesurferRef.current.playPause();
    }
  };

  return (
    <div>
      <div ref={containerRef} />
      <button onClick={handlePlayPause}>
        {isPlaying ? 'Pause' : 'Play'}
      </button>
    </div>
  );
};

export default AudioPlayer;

3. Key Concepts Explained

DOM Container Reference (containerRef)

Wavesurfer attaches directly to the DOM. By assigning ref={containerRef} to a standard <div>, you give the library a stable DOM element to inject its canvas into.

Instance Reference (wavesurferRef)

Storing the created Wavesurfer instance in a ref (wavesurferRef.current = ws) allows you to interact with the player—such as calling play(), pause(), or setVolume()—from other functions inside the component without triggering unnecessary re-renders.

Lifecycle Management and Cleanup

Failing to destroy Wavesurfer instances on component unmount causes duplicate waveforms to render and creates memory leaks. Returning ws.destroy() in the useEffect cleanup function ensures that the instance, its audio context, and all attached event listeners are properly removed when the component unmounts or when the audioUrl changes.

4. Adding Wavesurfer Plugins

To import plugins (such as Timeline, Minimap, or Regions) in modern versions of Wavesurfer.js, import them directly from their respective subpaths and pass them into the plugins array:

import WaveSurfer from 'wavesurfer.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';

// Inside useEffect:
const ws = WaveSurfer.create({
  container: containerRef.current,
  url: audioUrl,
  plugins: [
    TimelinePlugin.create({
      container: '#wave-timeline',
    }),
  ],
});
