Wavesurfer.js Spectrogram Plugin Canvas Element

This article explains the specific canvas element generated by the Wavesurfer.js Spectrogram plugin, detailing its structure in the Document Object Model (DOM), its rendering context, and how audio frequency data is drawn to the screen.

The Generated Canvas Element

The Wavesurfer.js Spectrogram plugin dynamically generates a standard HTML5 <canvas> element inside a dedicated wrapper container. When initialized, the plugin creates a <div> wrapper element—typically styled to sit underneath or alongside the primary waveform display—and appends an internal <canvas> element created using document.createElement('canvas').

Rendering Context and Dimensions

The generated canvas utilizes a standard 2D rendering context (CanvasRenderingContext2D). The plugin does not use WebGL; instead, it processes frequency information through the Web Audio API's AnalyserNode using Fast Fourier Transform (FFT) algorithms.

The canvas element's dimensions are determined by:

  • Width: Matches the total pixel width of the audio visualization or the container, scaling dynamically if the waveform is scrollable or zoomed.
  • Height: Determined by the height property defined in the spectrogram plugin configuration options (defaulting to 256 pixels in most versions).

Pixel Rendering Technique

Rather than drawing individual vector paths for audio data, the spectrogram plugin directly manipulates pixel buffers. It calculates frequency bin magnitudes over time slices and converts those values into RGBA color data using a specified color map. These values are committed to an ImageData object and painted directly onto the canvas using the 2D context's putImageData() or drawImage() methods.

Frequency Label Canvas

If the plugin option labels: true is configured, the plugin generates an additional secondary <canvas> element. This element is positioned as an overlay along the edge of the spectrogram to render numerical frequency markers (e.g., 500 Hz, 1 kHz, 2 kHz) and notch lines, separating the coordinate axis text from the underlying spectral visualization.
