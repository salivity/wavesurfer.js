Connect Web Audio API Filters to Wavesurfer.js

Integrating custom Web Audio API filters into Wavesurfer.js allows you to build equalizers, dynamic tone controls, and audio effects directly into your web applications. This guide explains how to intercept Wavesurfer.js's audio pipeline, instantiate native BiquadFilterNode instances, route the audio stream through custom processing nodes, and dynamically manipulate filter frequencies and gains in real time.

Understanding the Audio Routing

Wavesurfer.js plays audio either via an HTML5 audio element or through an internal Web Audio API graph. To apply custom filters, you capture the audio stream, route it through one or more Web Audio API nodes (such as lowpass, highpass, or peaking filters), and finally connect the processed signal to the audio destination (your speakers).

Step 1: Initialize Wavesurfer.js

Create your Wavesurfer instance normally. Ensure you have an audio source loaded.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  url: '/path/to/audio.mp3',
});

Step 2: Create the Audio Context and Filter Nodes

Instantiate a standard AudioContext and the specific filter nodes you want to chain. The BiquadFilterNode interface provides common filter types like lowpass, highpass, bandpass, and peaking.

// Create an AudioContext
const audioContext = new (window.AudioContext || window.webkitAudioContext)();

// Create a lowpass filter
const lowpassFilter = audioContext.createBiquadFilter();
lowpassFilter.type = 'lowpass';
lowpassFilter.frequency.value = 1000; // Cutoff frequency in Hz

// Create a peaking (equalizer) filter
const equalizerBand = audioContext.createBiquadFilter();
equalizerBand.type = 'peaking';
equalizerBand.frequency.value = 500;
equalizerBand.Q.value = 1.0;
equalizerBand.gain.value = 0; // Gain in dB

Step 3: Route Wavesurfer Audio Through the Filters

Once the audio is ready to play, extract Wavesurfer's underlying HTML media element, attach it to your AudioContext via createMediaElementSource, and build your processing chain.

wavesurfer.on('ready', () => {
  const mediaElement = wavesurfer.getMediaElement();

  // Create a MediaElementSourceNode from Wavesurfer's media element
  const sourceNode = audioContext.createMediaElementSource(mediaElement);

  // Connect the nodes in sequence:
  // Source -> Lowpass -> Peaking -> Destination
  sourceNode.connect(lowpassFilter);
  lowpassFilter.connect(equalizerBand);
  equalizerBand.connect(audioContext.destination);
});

Note: Browsers require user interaction before an AudioContext can play sound. Resume the context when playback starts:

wavesurfer.on('play', () => {
  if (audioContext.state === 'suspended') {
    audioContext.resume();
  }
});

Step 4: Dynamically Update Filter Parameters

You can change filter properties on the fly using HTML inputs such as sliders. Modifying the value property updates the audio in real time.

<label for="cutoff">Cutoff Frequency:</label>
<input id="cutoff" type="range" min="100" max="10000" step="10" value="1000" />
const cutoffSlider = document.getElementById('cutoff');

cutoffSlider.addEventListener('input', (event) => {
  const frequency = parseFloat(event.target.value);
  lowpassFilter.frequency.setValueAtTime(frequency, audioContext.currentTime);
});

Step 5: Bypassing or Removing Filters

To bypass a filter without destroying the entire audio graph, connect the source node directly to audioContext.destination, or adjust the filter parameters to a neutral state (e.g., setting the gain to 0 or setting a lowpass frequency beyond the human hearing range).

function bypassFilter(isBypassed) {
  if (isBypassed) {
    lowpassFilter.frequency.setValueAtTime(20000, audioContext.currentTime);
  } else {
    lowpassFilter.frequency.setValueAtTime(1000, audioContext.currentTime);
  }
}
