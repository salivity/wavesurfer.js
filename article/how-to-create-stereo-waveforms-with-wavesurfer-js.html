How to Create Stereo Waveforms with Wavesurfer.js

Visualizing multi-channel audio provides deeper insights into audio mastering, editing, and sound design. This guide explains how to render a split stereo waveform using Wavesurfer.js, separating the left and right audio channels into distinct visual tracks. By utilizing native multi-channel configuration settings, you can customize the appearance, dimensions, and colors of each channel independently.

Step 1: Set Up the HTML Container

Create a basic HTML structure containing a target element where the waveform will render, along with a basic control to test playback.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Stereo Waveform</title>
</head>
<body>
  <div id="waveform"></div>
  <button id="playBtn">Play / Pause</button>

  <!-- Load Wavesurfer.js via CDN -->
  <script src="https://unpkg.com/wavesurfer.js@7"></script>
  <script src="app.js"></script>
</body>
</html>

Step 2: Initialize Wavesurfer with splitChannels

In modern versions of Wavesurfer.js (v7+), the splitChannels property enables independent channel visualization. By providing an array of channel configurations, you can customize the color and appearance for each channel (typically Channel 0 for Left and Channel 1 for Right).

In your app.js file:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  cursorColor: '#EF4444',
  cursorWidth: 2,
  barWidth: 2,
  barGap: 1,
  barRadius: 2,
  height: 100, // Height of each individual channel waveform
  // Configure stereo separation
  splitChannels: [
    {
      waveColor: '#2563EB',
      progressColor: '#1D4ED8',
    },
    {
      waveColor: '#059669',
      progressColor: '#047857',
    }
  ]
});

// Load a stereo audio file
wavesurfer.load('path/to/stereo-audio.mp3');

// Hook up playback controls
const playBtn = document.getElementById('playBtn');
playBtn.addEventListener('click', () => {
  wavesurfer.playPause();
});

Step 3: Understanding splitChannels Behavior

When splitChannels is configured:

  1. Automatic Detection: Wavesurfer parses the decoded audio buffer. If the audio is stereo, it splits channel 0 (Left) and channel 1 (Right) into distinct visual canvases stacked vertically within the main container.
  2. Per-Channel Styling: The objects defined inside the splitChannels array map directly to each audio channel index. The first object controls the top waveform (Left), while the second object controls the bottom waveform (Right).
  3. Dimensions: The height property applies to each individual channel canvas rather than the total height of the container. If you set height: 100, the total height of a two-channel display will be 200 pixels.

Step 4: Styling and Separation (Optional)

To improve clarity, you can add spacing or labels between the stereo channels using CSS. Wavesurfer wraps each channel in an internal container element:

#waveform {
  width: 100%;
  max-width: 800px;
  margin: 2rem auto;
}

/* Add separation between split channel canvases */
#waveform > div {
  margin-bottom: 8px;
  background-color: #f8fafc;
  border-radius: 4px;
}

With this configuration, your application will render distinct, synchronized left and right channel waveforms that respond in real time to playback, seeking, and user interaction.
