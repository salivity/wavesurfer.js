Target Wavesurfer.js Canvas in Shadow DOM With CSS

This article explains how to apply custom CSS to the canvas elements generated inside the Shadow DOM by modern versions of Wavesurfer.js. Because Wavesurfer.js encapsulates its rendering markup inside a Shadow Root, standard global CSS selectors cannot pierce the boundary to style the internal canvas. Below, you will find direct solutions to target and style these encapsulated canvas elements using CSS injection, Shadow Root access, and host-level styling.

Understanding the Shadow DOM Barrier

Starting in version 7, Wavesurfer.js encapsulates its internal elements—including the scroll containers, wrapper, and <canvas> elements—inside an open Shadow Root attached to your target container.

A traditional stylesheet rule such as:

#waveform canvas {
  filter: drop-shadow(0 2px 4px rgba(0, 0, 0, 0.2));
}

will fail because standard CSS selectors cannot cross the boundary into a shadow tree.

Method 1: Injecting CSS via the Shadow Root

Because Wavesurfer creates an open shadow root, you can access the shadow tree via JavaScript and inject a custom <style> tag or use Constructable Stylesheets.

Using an Injected Style Element

Once Wavesurfer is initialized, access the container's shadowRoot property and append custom CSS directly:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
});

wavesurfer.on('ready', () => {
  const container = document.querySelector('#waveform');
  const shadowRoot = container.shadowRoot;

  if (shadowRoot) {
    const style = document.createElement('style');
    style.textContent = `
      canvas {
        filter: drop-shadow(0 4px 6px rgba(0, 0, 0, 0.15));
        border-radius: 4px;
      }
    `;
    shadowRoot.appendChild(style);
  }
});

Using Constructable Stylesheets

For modern browsers, adoptedStyleSheets provides a cleaner implementation:

wavesurfer.on('ready', () => {
  const container = document.querySelector('#waveform');
  const shadowRoot = container.shadowRoot;

  if (shadowRoot && 'adoptedStyleSheets' in Document.prototype) {
    const sheet = new CSSStyleSheet();
    sheet.replaceSync(`
      canvas {
        opacity: 0.9;
        transition: opacity 0.2s ease;
      }
      canvas:hover {
        opacity: 1;
      }
    `);
    shadowRoot.adoptedStyleSheets = [...shadowRoot.adoptedStyleSheets, sheet];
  }
});

Method 2: Styling the Shadow Host

CSS properties that inherit down the tree can be applied directly to the host container. While internal layout properties of the <canvas> will not inherit, visual filters, CSS variables, and sizing constraints applied to the host can cascade or affect the rendered visual output:

#waveform {
  /* Applies to the overall container, including shadow output */
  filter: contrast(1.1) brightness(0.95);
  border-radius: 8px;
  overflow: hidden;
}

Limitations of Canvas CSS Styling

CSS can only manipulate the box properties and hardware-accelerated post-processing (such as filter, opacity, transform, and dimensions) of the <canvas> element.

CSS cannot modify the individual waveform lines, peaks, or progress gradients drawn inside the canvas bitmap. To adjust waveform colors, dimensions, and line widths, use Wavesurfer's built-in configuration options (waveColor, progressColor, barWidth, barGap, and height) during initialization or dynamically via wavesurfer.setOptions().
