Wavesurfer.js Event When Audio Finishes Loading

When integrating audio into web applications using Wavesurfer.js, determining exactly when an audio track has finished loading and is ready for playback is essential for user experience. This article explains the primary event that signals audio loading is complete, details alternative events related to the loading lifecycle, and provides practical code examples for implementing these listeners in your application.

The primary event that fires when audio finishes loading, decoding, and rendering in Wavesurfer.js is the ready event. Listening to this event ensures that the audio buffer has been completely parsed, the waveform has been drawn, and the player is fully prepared for playback or user interaction.

How to Use the ready Event

You can attach a listener to the ready event immediately after initializing your Wavesurfer instance:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
});

wavesurfer.on('ready', (duration) => {
  console.log(`Audio is ready! Total duration: ${duration} seconds.`);
  // Enable play buttons, hide spinners, or start playback
});

Related Loading Events

Depending on your application's architecture and performance needs, Wavesurfer.js provides other related lifecycle events:

  • decode: Fires as soon as the audio data has been decoded into an audio buffer, before the waveform visuals are rendered. This is useful if you want to perform calculations on the raw audio data before rendering finishes.
  • loading: Fires continuously during the network download phase, passing a percentage integer (from 0 to 100) representing download progress.
  • redraw: Fires whenever the waveform has finished redrawing, which can happen upon initial load or when resizing the container.

For almost all standard player implementations, relying on the ready event is the best practice to confirm the audio file is fully loaded and ready to play.
