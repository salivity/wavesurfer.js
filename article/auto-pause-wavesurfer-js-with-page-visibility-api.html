Auto-Pause Wavesurfer.js with Page Visibility API

Managing media playback when users switch browser tabs or minimize their window is essential for delivering a clean user experience and saving device resources. This guide demonstrates how to bind the native HTML5 Page Visibility API to Wavesurfer.js playback controls, ensuring that audio automatically pauses when the document is hidden and optionally resumes only if it was playing previously.

The Page Visibility API and Wavesurfer.js

The Page Visibility API provides the visibilitychange event along with the document.hidden and document.visibilityState properties. Wavesurfer.js exposes playback controls through methods like isPlaying(), pause(), and play().

To integrate them properly, you must track whether audio was actively playing before the user left the tab. Simply calling play() whenever the page becomes visible would erroneously start playback even if the user had deliberately paused the track earlier.

Implementation

Below is a complete implementation demonstrating how to bind these systems together:

import WaveSurfer from 'wavesurfer.js';

// Initialize Wavesurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path-to-audio.mp3',
});

// State flag to track whether audio was playing when the tab lost focus
let wasPlayingBeforeHidden = false;

function handleVisibilityChange() {
  if (document.hidden) {
    // Tab is hidden or window is minimized
    if (wavesurfer.isPlaying()) {
      wasPlayingBeforeHidden = true;
      wavesurfer.pause();
    } else {
      wasPlayingBeforeHidden = false;
    }
  } else {
    // Tab has returned to focus
    if (wasPlayingBeforeHidden) {
      wavesurfer.play();
      wasPlayingBeforeHidden = false;
    }
  }
}

// Bind the listener to the document
document.addEventListener('visibilitychange', handleVisibilityChange);

// Clean up listener when wavesurfer is destroyed
wavesurfer.on('destroy', () => {
  document.removeEventListener('visibilitychange', handleVisibilityChange);
});

Key Considerations

  • User Intent Preservation: Storing the playback state in wasPlayingBeforeHidden avoids unwanted autoplay behavior when users navigate back to an intentionally paused player.
  • Autoplay Policies: If the track was loaded but never started via direct user interaction, modern browser autoplay policies may block .play() calls when returning to the tab. Ensure initial playback is initiated by a user gesture.
  • Cleanup: When tearing down a single-page application component or destroying the Wavesurfer instance using wavesurfer.destroy(), always remove the visibilitychange event listener from the document to avoid memory leaks.
