Typed Event Listeners in Custom Wavesurfer.js Plugins

Building robust custom plugins for modern Wavesurfer.js (v7+) requires subscribing to host player events while preserving strict TypeScript type safety. This article covers how to create a custom plugin class extending BasePlugin, access the host WaveSurfer instance, hook into native typed events using the built-in WaveSurferEvents contract, and maintain clean lifecycle management to prevent memory leaks.

Inheriting from BasePlugin

Custom plugins in Wavesurfer.js should extend the generic BasePlugin<EventTypes, OptionsType> class provided by the library. When Wavesurfer initializes a plugin via wavesurfer.registerPlugin(...), it injects the host instance into the plugin and triggers the onInit() lifecycle method. Inside this method, the host instance becomes accessible through this.wavesurfer.

import { BasePlugin } from 'wavesurfer.js/dist/base-plugin.js';
import type WaveSurfer from 'wavesurfer.js';
import type { WaveSurferEvents } from 'wavesurfer.js';

export interface MyPluginOptions {
  enableLogging?: boolean;
}

export interface MyPluginEvents {
  'custom-plugin-event': [data: string];
}

export class MyCustomPlugin extends BasePlugin<MyPluginEvents, MyPluginOptions> {
  protected wavesurfer!: WaveSurfer;

  constructor(options: MyPluginOptions) {
    super(options);
  }

  public static create(options?: MyPluginOptions): MyCustomPlugin {
    return new MyCustomPlugin(options || {});
  }

  onInit(): void {
    if (!this.wavesurfer) {
      throw new Error('WaveSurfer instance is not initialized');
    }
    this.registerHostListeners();
  }
}

Subscribing to Native Host Events with Full Typing

The WaveSurfer class utilizes an event emitter mapped against the WaveSurferEvents interface, where each key represents an event name and each value is an array of typed arguments passed to the callback. Calling this.wavesurfer.on() natively enforces type inference based on these event signatures without requiring manual casting.

private registerHostListeners(): void {
  // TypeScript correctly infers 'currentTime' as number
  const unsubTimeUpdate = this.wavesurfer.on('timeupdate', (currentTime: number) => {
    if (this.options.enableLogging) {
      console.log(`Current playback time: ${currentTime}`);
    }
  });

  // TypeScript correctly infers 'duration' as number
  const unsubReady = this.wavesurfer.on('ready', (duration: number) => {
    console.log(`Audio loaded. Total duration: ${duration}s`);
  });

  // Store unsubscription callbacks
  this.subscriptions.push(unsubTimeUpdate, unsubReady);
}

Managing Subscriptions and Disposal

Every .on() call on the host instance returns an unsubscribe callback function of type () => void. Base plugins include a built-in subscriptions array designated to hold cleanup tasks. By pushing each unsubscribe function returned by this.wavesurfer.on() into this.subscriptions, the plugin automatically unregisters all host listeners when destroy() is called on either the plugin or the parent Wavesurfer instance.

export class MyCustomPlugin extends BasePlugin<MyPluginEvents, MyPluginOptions> {
  // ...
  
  onInit(): void {
    // Automatically cleaned up on destroy() via this.subscriptions
    this.subscriptions.push(
      this.wavesurfer.on('play', () => {
        this.emit('custom-plugin-event', 'Playback started');
      }),
      this.wavesurfer.on('pause', () => {
        this.emit('custom-plugin-event', 'Playback paused');
      })
    );
  }

  public destroy(): void {
    // Custom pre-destruction logic goes here
    super.destroy(); // Invokes each cleanup function in this.subscriptions
  }
}

Augmenting Host Events with Declaration Merging

If your plugin introduces new events directly onto the host WaveSurfer instance rather than through the plugin's own emitter, TypeScript's declaration merging allows you to augment the WaveSurferEvents interface globally:

declare module 'wavesurfer.js' {
  interface WaveSurferEvents {
    'plugin-ready': [pluginName: string];
  }
}

// Inside the plugin:
this.wavesurfer.emit('plugin-ready', 'MyCustomPlugin');

// Consuming application:
wavesurfer.on('plugin-ready', (pluginName) => {
  // pluginName is strictly typed as a string
});

Using BasePlugin, registering typed listeners through this.wavesurfer.on(), and relying on this.subscriptions guarantees type-safe interaction with the host engine alongside proper resource deallocation.
