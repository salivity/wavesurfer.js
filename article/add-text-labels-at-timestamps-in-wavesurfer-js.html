Add Text Labels at Timestamps in Wavesurfer.js

This article explains how to display text labels at specific timestamps along an audio waveform using Wavesurfer.js. By utilizing the official Regions plugin, you can render custom markers and textual annotations at exact points in time, style them via CSS, and trigger interactive events during playback.

1. Install and Import Wavesurfer.js and the Regions Plugin

In modern Wavesurfer.js (version 7+), text labels are best implemented using the Regions plugin. The Markers plugin from older versions has been unified into Regions, which supports point-in-time markers alongside range selections.

Include Wavesurfer.js and the Regions plugin via CDN or npm:

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/plugins/regions.min.js"></script>

2. Initialize the Waveform and Register the Plugin

Set up your HTML container, initialize the main Wavesurfer instance, and register the RegionsPlugin.

<div id="waveform"></div>

<script>
  // Initialize Regions plugin
  const wsRegions = WaveSurfer.Regions.create();

  // Initialize WaveSurfer
  const wavesurfer = WaveSurfer.create({
    container: '#waveform',
    waveColor: '#4F4A85',
    progressColor: '#383351',
    url: 'audio.mp3',
    plugins: [wsRegions],
  });
</script>

3. Add Text Labels at Specific Timestamps

Use the addRegion method on the Regions plugin instance. To create a point marker with a label instead of a time span, set start to your desired timestamp (in seconds) and omit the end property (or set end equal to start). Pass a string or an HTML element to the content property.

wavesurfer.on('ready', () => {
  // Label at 5 seconds
  wsRegions.addRegion({
    start: 5,
    content: 'Intro Ends',
    color: 'rgba(255, 0, 0, 0.5)',
  });

  // Label at 24.5 seconds
  wsRegions.addRegion({
    start: 24.5,
    content: 'Chorus Begins',
    color: 'rgba(0, 128, 0, 0.5)',
  });

  // Label with custom HTML
  const customLabel = document.createElement('span');
  customLabel.innerText = 'Solo';
  customLabel.className = 'custom-marker';

  wsRegions.addRegion({
    start: 60,
    content: customLabel,
    color: 'rgba(0, 0, 255, 0.5)',
  });
});

4. Style the Labels with CSS

Wavesurfer attaches a class to the region element. You can style the text labels to adjust their alignment, font, and positioning relative to the playhead:

/* Style all region content labels */
[part*="region-content"] {
  font-family: sans-serif;
  font-size: 12px;
  font-weight: bold;
  color: #333;
  background: #fff;
  padding: 2px 6px;
  border-radius: 4px;
  border: 1px solid #ccc;
  transform: translateY(-20px);
  white-space: nowrap;
}

5. Handle Marker Events

You can detect user interactions with your labels or trigger actions when playback reaches a timestamp:

// Trigger an action when clicking a label/marker
wsRegions.on('region-clicked', (region, e) => {
  e.stopPropagation(); // Prevent playback toggle
  wavesurfer.setTime(region.start);
});

// Trigger an action when playback enters a labeled timestamp
wsRegions.on('region-in', (region) => {
  console.log(`Reached marker: ${region.content.innerText || region.content}`);
});
