Restrict Region Creation by Role in Wavesurfer.js

This guide explains how to restrict audio region creation in Wavesurfer.js based on user roles by conditionally enabling interactive drag-to-create features, managing UI events dynamically, and securing the implementation on the backend.

Understand the Plugin Mechanics

Wavesurfer.js delegates region handling to the RegionsPlugin. By default, users create new regions on the waveform when the plugin has drag-selection capabilities activated. Restricting creation involves controlling whether the drag-selection functionality is initialized or enabled for the current user's role.

Check the User Role

Before setting up the waveform, retrieve the authenticated user's role from your state management system, authentication context, or user session object.

// Example user context
const currentUser = {
  id: 'usr_123',
  role: 'viewer' // Options: 'admin', 'editor', 'viewer'
};

const canCreateRegions = ['admin', 'editor'].includes(currentUser.role);

Conditionally Enable Drag Selection

When initializing the RegionsPlugin, configure drag selection conditionally using the authorization flag.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize the Regions plugin
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#violet',
  progressColor: '#purple',
  url: '/path/to/audio.mp3',
  plugins: [wsRegions],
});

// Enable region creation only for permitted roles
wavesurfer.on('ready', () => {
  if (canCreateRegions) {
    wsRegions.enableDragSelection({
      color: 'rgba(255, 0, 0, 0.1)',
    });
  }
});

If canCreateRegions is false, enableDragSelection is never invoked, preventing unauthorized users from clicking and dragging on the waveform to generate new regions.

Handle Dynamic Role Changes

If permissions change without reloading the page—such as during role switching or privilege expiration—you must remove the drag-selection listeners.

Calling wsRegions.enableDragSelection() returns an unsubscribe function in Wavesurfer.js v7. Store this cleanup function to disable creation when necessary:

let disableDrag = null;

function updateRegionPermissions(userRole) {
  const allowed = ['admin', 'editor'].includes(userRole);

  if (allowed && !disableDrag) {
    // Activate drag selection and store the teardown callback
    disableDrag = wsRegions.enableDragSelection({
      color: 'rgba(0, 123, 255, 0.2)',
    });
  } else if (!allowed && disableDrag) {
    // Deactivate drag selection
    disableDrag();
    disableDrag = null;
  }
}

Restrict Existing Region Editing

Prevent unauthorized users from resizing or dragging existing regions by setting the drag and resize properties to false when adding regions to the waveform:

wsRegions.addRegion({
  start: 10,
  end: 20,
  content: 'Intro',
  drag: canCreateRegions,
  resize: canCreateRegions,
});

Enforce Backend Validation

Client-side restrictions in JavaScript only adjust the user interface and can be bypassed by modifying local state or DOM events. Always validate the user's role on your backend API endpoints that receive, save, update, or delete region data (such as timestamps, labels, and metadata). Reject any modification requests sent by unauthorized roles with an HTTP 403 Forbidden response.
