Render Rounded Bar Peaks in Wavesurfer.js Canvas

Wavesurfer.js utilizes the HTML5 Canvas 2D API to render waveform visualizations, offering options to display audio amplitude data as discrete vertical bars with rounded tops or ends. This article breaks down the specific Canvas API methods and path-generation techniques Wavesurfer.js relies on to draw rounded bar peaks when the barRadius parameter is configured.

The Native Method: roundRect()

In modern iterations of Wavesurfer.js (such as version 7), the library primarily utilizes the native Canvas API method:

  • ctx.roundRect(x, y, width, height, [radii]): Defines a path for a rectangle with rounded corners directly on the canvas context. When rendering a bar with a rounded peak, x and y specify the bar coordinates, while width and height correspond to the calculated bar dimensions based on audio amplitude. The radii parameter accepts either an individual number or an array of values (e.g., [radius, radius, 0, 0]) to round only the top corners (peaks) while leaving the base flat.

Path Construction: Fallback and Legacy Approaches

When targeting environments where roundRect is not supported, or in older versions of the library, Wavesurfer.js calculates the geometry manually using standard path-drawing primitives:

  • ctx.beginPath(): Clears the current sub-paths and starts a new vector path for each audio bar.
  • ctx.moveTo(x, y): Moves the virtual pen to the starting vertex of the bar, typically at the base corner or below the rounded peak.
  • ctx.lineTo(x, y): Draws straight segments along the sides of the bar leading up to the start of the rounded corner.
  • ctx.arcTo(x1, y1, x2, y2, radius): Constructs the rounded peak. By supplying tangent points and a radius derived from the barRadius option, arcTo() inserts circular arcs smoothly connecting the vertical edges to the horizontal top.
  • ctx.arc(x, y, radius, startAngle, endAngle): Used alternatively to draw a half-circle cap across the entire top width of the bar when the peak is fully rounded.
  • ctx.closePath(): Connects the path back to the origin coordinates at the baseline to create an enclosed shape.

Applying Fills and Styles

Once the outline of the rounded bar is calculated, the shape is rendered using the configured waveform color:

  • ctx.fillStyle: Sets the color or gradient for the waveform.
  • ctx.fill(): Fills the interior geometry defined by roundRect() or the custom path commands, finalizing the rendering of the rounded peak.

Line-Cap Rendering for Symmetrical Bars

When rendering waveforms centered across a zero-axis where individual vertical strokes represent bars, Wavesurfer.js can also create rounded peaks via line styles rather than filled shapes:

  • ctx.lineWidth: Sets the thickness of the bar to the specified barWidth.
  • ctx.lineCap = 'round': Automatically rounds both the top and bottom endpoints of any drawn path segment.
  • ctx.stroke(): Renders the vertical line segment created with moveTo() and lineTo(), producing semicircular caps at the amplitude peaks without requiring complex path arcs.
