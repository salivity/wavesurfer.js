How to Implement Dark Mode in Wavesurfer.js

Implementing dark mode in Wavesurfer.js involves configuring specific color options during player initialization and dynamically updating those parameters when a theme switch occurs. This guide covers defining the appropriate light and dark color palettes, applying them through the Wavesurfer instance, and using modern JavaScript to toggle themes seamlessly based on user action or system preferences.

Core Color Parameters

Wavesurfer.js controls its visual canvas through initialization options. To create a dark theme, the primary properties you need to adjust are:

  • waveColor: The color of the unprocessed, background waveform.
  • progressColor: The color of the waveform that has already been played.
  • cursorColor: The color of the playback head line.

Step 1: Define Your Color Palettes

Create theme configuration objects to keep light and dark styling organized and maintainable.

const themes = {
  light: {
    waveColor: '#d1d5db',
    progressColor: '#3b82f6',
    cursorColor: '#1f2937',
  },
  dark: {
    waveColor: '#374151',
    progressColor: '#60a5fa',
    cursorColor: '#f9fafb',
  }
};

Step 2: Initialize Wavesurfer.js

Initialize the player using your default theme. You can pass the color object directly into the WaveSurfer.create() configuration.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  url: '/path/to/audio.mp3',
  ...themes.light,
});

Step 3: Switch Themes Dynamically

In Wavesurfer.js version 7 and later, you can update options at runtime without re-rendering the entire player from scratch by calling the setOptions method.

function applyTheme(themeName) {
  const selectedTheme = themes[themeName];
  
  if (selectedTheme) {
    wavesurfer.setOptions({
      waveColor: selectedTheme.waveColor,
      progressColor: selectedTheme.progressColor,
      cursorColor: selectedTheme.cursorColor,
    });
  }
}

// Example: Trigger on a button click
const themeToggleBtn = document.getElementById('theme-toggle');
let isDark = false;

themeToggleBtn.addEventListener('click', () => {
  isDark = !isDark;
  applyTheme(isDark ? 'dark' : 'light');
  document.body.classList.toggle('dark-mode', isDark);
});

Step 4: Detect and Sync with System Preferences

To automatically adapt the player to the user's operating system settings, use the prefers-color-scheme media query.

const prefersDarkScheme = window.matchMedia('(prefers-color-scheme: dark)');

// Set initial theme based on system preference
if (prefersDarkScheme.matches) {
  applyTheme('dark');
}

// Listen for system theme changes in real time
prefersDarkScheme.addEventListener('change', (e) => {
  applyTheme(e.matches ? 'dark' : 'light');
});

Using wavesurfer.setOptions() ensures the audio continues playing smoothly during the transition while instant redraws update the waveform colors to match the rest of your interface.
