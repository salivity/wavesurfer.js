How to Add Custom HTML to Wavesurfer.js Regions

This guide explains how to insert and manage custom HTML elements inside Wavesurfer.js audio regions. By using the official Regions plugin, you can render custom labels, action buttons, icons, or badges directly inside a designated audio selection. You will learn how to use the built-in content property in modern Wavesurfer.js (v7+) as well as how to directly manipulate the region's DOM element for advanced interactivity.

Initializing Wavesurfer and the Regions Plugin

First, ensure you have initialized your Wavesurfer instance with the Regions plugin registered.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

// Initialize the plugin
const wsRegions = RegionsPlugin.create();

// Initialize WaveSurfer
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  plugins: [wsRegions],
});

Method 1: Using the Built-in content Property

In Wavesurfer.js v7 and newer, the addRegion method accepts a content property. This property accepts either a raw HTML string or an HTMLElement object.

Passing an HTML String

wsRegions.addRegion({
  start: 2,
  end: 6,
  color: 'rgba(0, 123, 255, 0.2)',
  content: '<div class="custom-region-label"><strong>Intro</strong>: Vocal Lead</div>',
});

Passing a DOM Element with Event Listeners

If you need your custom HTML to perform actions (such as deleting the region or playing the section), create a standard DOM element with native event listeners before passing it to content:

// Create a container
const container = document.createElement('div');
container.className = 'region-custom-content';

// Create a title
const title = document.createElement('span');
title.innerText = 'Chorus';

// Create an action button
const deleteBtn = document.createElement('button');
deleteBtn.innerText = '✕';
deleteBtn.className = 'region-delete-btn';

container.appendChild(title);
container.appendChild(deleteBtn);

// Add the region
const region = wsRegions.addRegion({
  start: 10,
  end: 20,
  color: 'rgba(40, 167, 69, 0.2)',
  content: container,
});

// Attach event handler
deleteBtn.addEventListener('click', (e) => {
  e.stopPropagation(); // Prevent triggering region drag/click events
  region.remove();
});

Method 2: Appending Elements Directly to region.element

If you are modifying a region dynamically after creation, you can directly access its root DOM element via region.element.

wavesurfer.on('ready', () => {
  const region = wsRegions.addRegion({
    start: 25,
    end: 35,
    color: 'rgba(255, 193, 7, 0.2)',
  });

  // Create custom HTML
  const badge = document.createElement('span');
  badge.className = 'custom-badge';
  badge.textContent = 'Bookmark';

  // Append directly to the region's DOM wrapper
  region.element.appendChild(badge);
});

Handling Click Events and CSS Conflicts

Wavesurfer regions listen for mouse events to handle dragging and resizing. When adding interactive elements like inputs or buttons inside a region, apply the following practices:

  1. Stop Event Propagation: Always call event.stopPropagation() on interactive elements so clicking them does not trigger region dragging or waveform playback.
  2. CSS Positioning: Use position: absolute or flexbox layouts to ensure custom elements stay visible inside narrow selections.
/* Style for custom container inside region */
.region-custom-content {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 4px;
  font-size: 12px;
  color: #000;
  pointer-events: none; /* Let drag events pass through non-interactive areas */
}

/* Ensure interactive children remain clickable */
.region-custom-content button {
  pointer-events: auto;
  cursor: pointer;
}
