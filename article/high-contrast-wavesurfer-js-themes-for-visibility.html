High-Contrast Wavesurfer.js Themes for Visibility

Making audio players accessible is essential for users with low vision or visual impairments, requiring visual elements that stand out clearly against their backgrounds. Wavesurfer.js provides customizable properties that allow developers to build high-contrast waveforms meeting Web Content Accessibility Guidelines (WCAG) 2.1 standards. By implementing dedicated high-contrast palettes, increasing cursor dimensions, and normalizing audio spikes, developers can dramatically improve waveform tracking, scrub positioning, and overall readability.

Essential Wavesurfer.js Accessibility Parameters

Wavesurfer.js relies on several configuration parameters that directly dictate visual clarity:

  • waveColor: The color of the unplayed portion of the audio canvas.
  • progressColor: The color showing the played portion.
  • cursorColor: The playback head marker.
  • cursorWidth: The thickness of the playhead line (default is 1px, which is often too thin for low-vision users).
  • normalize: Setting this to true scales the audio peaks to fill the canvas height, ensuring faint audio signals remain visible.

Theme 1: True Dark High-Contrast (OLED Black)

Dark themes reduce eye strain and allow neon and primary colors to project with maximum contrast ratios, well above the WCAG 3:1 graphical requirement.

  • Container Background: #000000 (Pure Black)
  • waveColor: #00FFFF (Vivid Cyan)
  • progressColor: #FFFF00 (Electric Yellow)
  • cursorColor: #FFFFFF (Pure White)
  • cursorWidth: 3

Cyan and yellow provide clear separation against pitch black and also maintain a distinguishable boundary between the played and unplayed states. The white cursor stands out against both colors.

Theme 2: High-Contrast Light Mode

For environments requiring a bright background, deep saturated hues prevent the waveform from washing out into the canvas.

  • Container Background: #FFFFFF (Pure White)
  • waveColor: #002B49 (Deep Navy)
  • progressColor: #D9381E (Vivid Vermilion)
  • cursorColor: #000000 (Solid Black)
  • cursorWidth: 3

This palette provides a contrast ratio greater than 7:1 against the white background. The vermilion and navy tones offer a stark distinction between played and unplayed audio.

Theme 3: Color-Vision-Deficiency Safe (Colorblind Optimized)

Standard red-and-green pairings fail for individuals with protanopia or deuteranopia. This palette utilizes an accessible blue-and-amber pairing.

  • Container Background: #1A1A1A (Charcoal)
  • waveColor: #4393C3 (Accessible Soft Blue)
  • progressColor: #F4A582 (Light Peach/Amber)
  • cursorColor: #FEE090 (Bright Pale Yellow)
  • cursorWidth: 4

This palette preserves brightness contrast while ensuring users across all spectrums of color perception can identify audio progress.

Structural Adjustments for Readability

Color alone does not resolve all visibility issues. Incorporating the following structural options ensures the waveform geometry remains readable:

  1. Bar Formatting: Instead of a continuous waveform, use defined bars. Set barWidth: 3 and barGap: 2. Distinct bars create visual separation, making peaks and troughs easier to discern.
  2. Playhead Enclosure: Pair the increased cursorWidth with CSS focus indicators around the container so users navigating via keyboard can confirm active focus.
  3. Dynamic Theme Toggling: Store theme parameters in JavaScript objects, allowing users to switch between standard rendering and a high-contrast mode via user preferences or system-level prefers-contrast media queries.
