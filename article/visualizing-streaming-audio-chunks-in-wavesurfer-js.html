Visualizing Streaming Audio Chunks in Wavesurfer.js

Visualizing streaming audio chunks in Wavesurfer.js requires capturing incoming binary data, extracting peak values in real time, and dynamically updating the waveform renderer. Because Wavesurfer.js traditionally expects a complete audio file to decode, handling incoming streams—such as from a WebSocket, WebRTC, or a chunked Fetch stream—requires a strategy that bypasses full-file decoding by working directly with raw PCM data and peak arrays.

1. Understanding the Peak-Based Visualization Strategy

Wavesurfer.js can render a waveform without loading an entire audio file if you provide pre-computed peak data. Rather than passing an entire audio blob to wavesurfer.load(), you can maintain an array of waveform peaks (minimum and maximum amplitude values) and append new data as chunks arrive from the network.

2. Initializing Wavesurfer.js

Initialize Wavesurfer.js with an empty container and configure it to accept custom peak data:

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#818CF8',
  cursorWidth: 0,
  interact: false // Disable user seeking while streaming
});

// Master array holding aggregated peaks
let allPeaks = [];

3. Decoding Incoming Chunks to PCM

Incoming chunks typically arrive as raw PCM, Opus, or chunked audio segments (such as WebM or MP3). If chunks are raw PCM (Float32Array), you can process them directly. If they arrive as encoded audio slices, use an AudioContext to decode the slices into PCM:

const audioContext = new (window.AudioContext || window.webkitAudioContext)();

async function decodeChunk(arrayBuffer) {
  try {
    const audioBuffer = await audioContext.decodeAudioData(arrayBuffer);
    return audioBuffer.getChannelData(0); // Extract Float32Array from channel 0
  } catch (error) {
    console.error('Error decoding audio chunk:', error);
    return null;
  }
}

Note: In streaming protocols like WebM/Opus, individual chunks cannot always be decoded in isolation via decodeAudioData. In these scenarios, use a dedicated WebAssembly/JS decoder (such as a WebAssembly-compiled Opus decoder) or stream raw PCM directly.

4. Extracting Peaks from PCM Data

To convert high-frequency PCM samples into a lightweight format suitable for visualization, compute the minimum and maximum values over specific intervals (sub-sampling):

function extractPeaks(channelData, samplesPerPixel = 100) {
  const peaks = [];
  const length = channelData.length;

  for (let i = 0; i < length; i += samplesPerPixel) {
    let min = 0;
    let max = 0;
    const end = Math.min(i + samplesPerPixel, length);

    for (let j = i; j < end; j++) {
      const val = channelData[j];
      if (val > max) max = val;
      if (val < min) min = val;
    }

    // Push min and max values representing the segment's vertical bounds
    peaks.push(max, min);
  }

  return peaks;
}

5. Appending Peaks and Redrawing

As chunks arrive (for example, from a WebSocket connection), compute their peaks, append them to the master array, and update Wavesurfer:

const socket = new WebSocket('wss://example.com/audio-stream');
socket.binaryType = 'arraybuffer';

socket.onmessage = async (event) => {
  const pcmData = await decodeChunk(event.data);
  if (!pcmData) return;

  const newPeaks = extractPeaks(pcmData, 100);
  allPeaks = allPeaks.concat(newPeaks);

  // Redraw the waveform with the updated peaks array
  // Format: [min_val, max_val, min_val, max_val, ...]
  wavesurfer.load('', [allPeaks], computeDuration(allPeaks));
};

function computeDuration(peaks, samplesPerSecond = 44100, samplesPerPixel = 100) {
  const totalSamples = (peaks.length / 2) * samplesPerPixel;
  return totalSamples / samplesPerSecond;
}

6. Alternative: Using the Native Record Plugin for Live Streams

If you are streaming live audio from a local or WebRTC MediaStream, Wavesurfer.js provides an official Record plugin that handles live chunk visualization natively via an internal AnalyserNode:

import RecordPlugin from 'wavesurfer.js/dist/plugins/record.esm.js';

const record = wavesurfer.registerPlugin(
  RecordPlugin.create({
    renderRecordedAudio: true,
    scrollingWaveform: true
  })
);

// Visualize from an incoming MediaStream
navigator.mediaDevices.getUserMedia({ audio: true }).then((stream) => {
  record.renderStream(stream);
});

Using manual peak extraction gives you low-level control over network-streamed buffers, while the RecordPlugin provides a direct pipeline for standard MediaStream objects.
