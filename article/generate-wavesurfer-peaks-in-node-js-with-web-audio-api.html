Generate Wavesurfer Peaks in Node.js with Web Audio API

Pre-computing waveform peak data on the backend allows frontend applications using Wavesurfer.js to render audio visualizations instantly without downloading or decoding entire media files. This guide details how Node.js services leverage headless web-audio-api implementations to read audio files, decode PCM data in memory, calculate amplitude peaks, and format the output specifically for Wavesurfer.js consumption.

Why Pre-compute Peaks on the Backend?

Client-side decoding of full-length audio tracks consumes considerable CPU and memory, often leading to visual lag or delayed page rendering on mobile devices. When peak data is generated on a Node.js server, the client only needs to download a lightweight JSON array representing the audio peaks alongside the audio file. This enables Wavesurfer.js to render the waveform immediately before the audio stream has even finished loading.

Setting Up the Node.js Environment

Node.js does not have a native implementation of the browser's Web Audio API. To emulate this environment, services use packages like web-audio-api, which provide an AudioContext that relies on native audio decoding libraries under the hood.

Install the necessary packages:

npm install web-audio-api

Reading and Decoding Audio Data

The AudioContext provided by web-audio-api operates similarly to the browser standard. It ingests an in-memory buffer, decodes it into a standard PCM AudioBuffer, and exposes the raw channel data.

const fs = require('fs');
const { AudioContext } = require('web-audio-api');

function decodeAudio(filePath) {
  return new Promise((resolve, reject) => {
    const audioContext = new AudioContext();
    const fileBuffer = fs.readFileSync(filePath);

    // Convert Node Buffer to an ArrayBuffer
    const arrayBuffer = fileBuffer.buffer.slice(
      fileBuffer.byteOffset,
      fileBuffer.byteOffset + fileBuffer.byteLength
    );

    audioContext.decodeAudioData(
      arrayBuffer,
      (audioBuffer) => resolve(audioBuffer),
      (error) => reject(error)
    );
  });
}

Extracting Peaks from the Audio Buffer

Once the AudioBuffer is available, you extract sample arrays using getChannelData(channelIndex). The raw data contains floating-point values between -1.0 and 1.0.

Wavesurfer.js requires an array of peak numbers representing the waveform shape. Typically, this is achieved by splitting the total number of audio samples into a discrete number of "buckets" (bins) and finding the maximum amplitude within each bucket.

function extractPeaks(audioBuffer, targetPeakCount = 1000) {
  const numberOfChannels = audioBuffer.numberOfChannels;
  const sampleLength = audioBuffer.length;
  const step = Math.floor(sampleLength / targetPeakCount);
  
  // Extract mono or merged channel data
  const channelData = audioBuffer.getChannelData(0);
  const peaks = [];

  for (let i = 0; i < targetPeakCount; i++) {
    const start = i * step;
    const end = start + step;
    let max = 0;

    for (let j = start; j < end; j++) {
      const value = Math.abs(channelData[j]);
      if (value > max) {
        max = value;
      }
    }

    // Rounding reduces JSON payload size
    peaks.push(Number(max.toFixed(4)));
  }

  return peaks;
}

If stereo support is needed, repeat the process for audioBuffer.getChannelData(1) and return an array containing both channel arrays (e.g., [leftPeaks, rightPeaks]).

Complete Server-Side Pipeline

The complete pipeline combines file retrieval, decoding, peak extraction, and output serialization:

const fs = require('fs');
const { AudioContext } = require('web-audio-api');

async function generatePeaks(filePath, targetPeakCount = 1000) {
  const audioContext = new AudioContext();
  const fileBuffer = fs.readFileSync(filePath);
  
  const arrayBuffer = fileBuffer.buffer.slice(
    fileBuffer.byteOffset,
    fileBuffer.byteOffset + fileBuffer.byteLength
  );

  return new Promise((resolve, reject) => {
    audioContext.decodeAudioData(
      arrayBuffer,
      (audioBuffer) => {
        const step = Math.floor(audioBuffer.length / targetPeakCount);
        const channelData = audioBuffer.getChannelData(0);
        const peaks = [];

        for (let i = 0; i < targetPeakCount; i++) {
          const start = i * step;
          const end = start + step;
          let max = 0;

          for (let j = start; j < end; j++) {
            const val = Math.abs(channelData[j]);
            if (val > max) max = val;
          }
          peaks.push(Number(max.toFixed(4)));
        }

        resolve({
          duration: audioBuffer.duration,
          length: peaks.length,
          peaks: peaks
        });
      },
      (err) => reject(err)
    );
  });
}

Consuming Generated Peaks in Wavesurfer.js

On the client side, provide the pre-computed peak array directly to the Wavesurfer initialization or load method. This instructs the library to bypass the decoding phase:

import WaveSurfer from 'wavesurfer.js';

// Fetch the peaks and instantiate Wavesurfer
fetch('/api/audio-peaks/track-123.json')
  .then((response) => response.json())
  .then((data) => {
    const wavesurfer = WaveSurfer.create({
      container: '#waveform',
      waveColor: '#4F4A85',
      progressColor: '#383351',
      url: '/audio/track-123.mp3',
      peaks: data.peaks,
      duration: data.duration
    });
  });

Providing both peaks and duration ensures accurate rendering of the waveform timeline and playback progress immediately upon execution.
