Restricting Region Movement in Wavesurfer.js

This article explains how region boundary constraints work in Wavesurfer.js, detailing the parameters and mechanisms that prevent regions from moving outside the audio track limits, as well as how to enforce custom boundaries using the Regions plugin.

In Wavesurfer.js, restricting a region from moving beyond the audio boundaries is handled natively by the audio's duration limit. When dragging or resizing a region, the library internally clamps the region coordinates so that the start parameter cannot go below 0 seconds and the end parameter cannot exceed the total duration of the loaded audio buffer (wavesurfer.getDuration()).

Core Parameters for Region Movement

While the audio duration defines the outer bounds automatically, several parameters control how regions behave within those boundaries:

  • drag (boolean): Passed in the region configuration object. Setting drag: false disables movement completely, locking the region to its initial start and end times.
  • resize (boolean): Determines whether the boundaries of the region can be expanded or shrunk. Setting resize: false prevents users from resizing the region past specific edges while still allowing dragging if drag: true.
  • minLength and maxLength (numbers): Define the minimum and maximum duration (in seconds) that a region can span. While these parameters do not change the outer boundaries of the audio file, they prevent a region from collapsing to zero or expanding past a defined threshold.

Implementing Custom Boundary Restrictions

If you need to restrict a region to a sub-segment of the audio rather than the entire track length, Wavesurfer.js does not provide an arbitrary sub-boundary parameter out of the box. Instead, you enforce constraints using the region-update (or update in newer versions) event listener:

wsRegions.on('region-update', (region) => {
  const minBoundary = 5;  // Minimum allowed start time in seconds
  const maxBoundary = 25; // Maximum allowed end time in seconds

  if (region.start < minBoundary) {
    region.setOptions({ start: minBoundary });
  }

  if (region.end > maxBoundary) {
    region.setOptions({ end: maxBoundary });
  }
});

By leveraging the native duration clamping alongside drag, resize, and event-driven clamping, you can fully control the operational range of any region within Wavesurfer.js.
