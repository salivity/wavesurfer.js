Style Waveform Background Opacity in Wavesurfer.js

Controlling the background and waveform opacity in Wavesurfer.js allows you to blend the audio visualizer seamlessly into your web application's user interface. You can adjust the opacity either programmatically during instance initialization by using color formats that support alpha transparency—such as RGBA or 8-digit HEX codes—or by directly applying CSS opacity rules to the container or canvas elements.

Method 1: Using RGBA or Hex Alpha in Wavesurfer Parameters

The cleanest way to adjust opacity without affecting other UI elements is by defining colors with an alpha channel directly in the Wavesurfer configuration object.

Wavesurfer accepts CSS-valid color strings for its color properties, including waveColor, progressColor, and backgroundColor.

import WaveSurfer from 'wavesurfer.js';

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  // Background color with 50% opacity using RGBA
  backgroundColor: 'rgba(0, 0, 0, 0.5)',
  
  // Waveform line color with 30% opacity
  waveColor: 'rgba(74, 144, 226, 0.3)',
  
  // Progress color with full opacity
  progressColor: '#4a90e2',
  
  // Optional: 8-digit hex values (#RRGGBBAA) also work
  // waveColor: '#4a90e24d', // 30% opacity
});

wavesurfer.load('/path/to/audio.mp3');

Using this approach:

  • backgroundColor sets the background opacity behind the waveform bars.
  • waveColor adjusts the transparency of the unplayed portion of the audio wave.
  • progressColor controls the transparency of the played audio wave.

Method 2: Styling the Container Element with CSS

If you need the entire waveform component (including the background and audio peaks) to have uniform transparency, apply CSS opacity directly to the container <div>.

HTML:

<div id="waveform" class="waveform-container"></div>

CSS:

.waveform-container {
  background-color: #f0f0f0;
  opacity: 0.75; /* Sets 75% opacity to the container and its children */
}

Alternatively, to set only the background transparent while keeping the waveform peaks fully opaque via CSS:

.waveform-container {
  /* Use an RGBA background instead of the opacity property */
  background-color: rgba(240, 240, 240, 0.6);
}

Method 3: Dynamically Updating Opacity at Runtime

To update the background or waveform opacity dynamically after the instance has already loaded, use the setOptions method:

// Change background opacity on the fly
wavesurfer.setOptions({
  backgroundColor: 'rgba(0, 0, 0, 0.2)',
  waveColor: 'rgba(255, 255, 255, 0.6)'
});

This method redraws the canvas automatically to reflect the updated alpha values without requiring a full re-instantiation of the player.
