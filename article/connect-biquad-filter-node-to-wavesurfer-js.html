Connect BiquadFilterNode to Wavesurfer.js

Integrating a custom BiquadFilterNode into Wavesurfer.js allows you to apply real-time equalization and frequency shaping, such as low-pass, high-pass, or peaking filters, directly to your audio waveform. This article explains how to create a filter node using the Web Audio API and route it into the Wavesurfer playback pipeline using the setFilters() method.

The Connection Method: setFilters()

The primary method used to connect a custom BiquadFilterNode to Wavesurfer.js is setFilters(). This method accepts an array of Web Audio AudioNode instances and inserts them in series between the audio source and the destination output.

Depending on your Wavesurfer.js version:

  • In Wavesurfer.js (v6 and earlier), call wavesurfer.backend.setFilters([filterNode]) or wavesurfer.setFilters([filterNode]).
  • In custom Web Audio setups or Wavesurfer v7, you connect to the underlying AudioContext nodes or pass Web Audio processing chains via the media element source.

Step-by-Step Implementation

1. Retrieve the AudioContext

Wavesurfer initializes an AudioContext during setup. Access the existing context directly from the instance to ensure your filter runs in the same audio graph:

const audioContext = wavesurfer.backend.getAudioContext();

2. Create and Configure the BiquadFilterNode

Instantiate the filter using the Web Audio API factory method createBiquadFilter() and configure the desired audio parameters:

const lowpassFilter = audioContext.createBiquadFilter();

// Configure filter properties
lowpassFilter.type = 'lowpass';
lowpassFilter.frequency.setValueAtTime(1000, audioContext.currentTime);
lowpassFilter.Q.setValueAtTime(1, audioContext.currentTime);

3. Attach the Filter to Wavesurfer.js

Pass the configured filter inside an array to setFilters(). You can pass multiple filters sequentially to create an EQ chain:

wavesurfer.backend.setFilters([lowpassFilter]);

Once executed, Wavesurfer automatically disconnects the original path and routes the audio stream through the filter node before sending it to the speakers.

Updating Filter Parameters in Real Time

Because the node remains referenced in your code, you can adjust frequency, gain, or Q values on the fly without calling setFilters() again:

// Dynamically adjust cutoff frequency (e.g., via a UI slider)
function updateCutoffFrequency(newFreq) {
  lowpassFilter.frequency.setValueAtTime(newFreq, audioContext.currentTime);
}

To remove custom filters and restore standard playback routing, call setFilters() with an empty array:

wavesurfer.backend.setFilters([]);
