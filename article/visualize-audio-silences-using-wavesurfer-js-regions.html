Visualize Audio Silences Using Wavesurfer.js Regions

Visualizing silence in speech recordings helps editors, transcribers, and developers identify pauses, cut unwanted dead air, or prepare data for speech-to-text models. By combining the waveform rendering of Wavesurfer.js with its Regions plugin, you can programmatically analyze raw audio data for amplitudes below a specific threshold and visually mark those silence intervals directly on the interactive waveform.

1. Initialize Wavesurfer and the Regions Plugin

To get started, set up Wavesurfer.js along with the Regions plugin (version 7+ syntax). The Regions plugin provides visual overlays that represent time ranges over the audio track.

import WaveSurfer from 'wavesurfer.js';
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions.esm.js';

const wsRegions = RegionsPlugin.create();

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#312E81',
  plugins: [wsRegions],
});

wavesurfer.load('path/to/speech-sample.mp3');

2. Implement the Silence Detection Algorithm

Wavesurfer decodes the audio into an AudioBuffer. Once loaded, extract the raw pulse-code modulation (PCM) channel data and calculate the Root Mean Square (RMS) or peak amplitude over short time slices. If the amplitude stays below a chosen threshold for a minimum required duration, flag that range as silence.

function extractSilences(audioBuffer, threshold = 0.01, minSilenceDuration = 0.5) {
  const channelData = audioBuffer.getChannelData(0); // Analyze the first audio channel
  const sampleRate = audioBuffer.sampleRate;
  const stepSize = Math.floor(sampleRate * 0.05); // 50ms evaluation window
  const minSilenceSamples = minSilenceDuration * sampleRate;

  const silences = [];
  let silenceStart = null;

  for (let i = 0; i < channelData.length; i += stepSize) {
    // Calculate RMS amplitude for the window
    let sum = 0;
    const end = Math.min(i + stepSize, channelData.length);
    for (let j = i; j < end; j++) {
      sum += channelData[j] * channelData[j];
    }
    const rms = Math.sqrt(sum / (end - i));

    if (rms < threshold) {
      if (silenceStart === null) {
        silenceStart = i;
      }
    } else {
      if (silenceStart !== null) {
        if (i - silenceStart >= minSilenceSamples) {
          silences.push({
            start: silenceStart / sampleRate,
            end: i / sampleRate,
          });
        }
        silenceStart = null;
      }
    }
  }

  // Handle trailing silence
  if (silenceStart !== null && channelData.length - silenceStart >= minSilenceSamples) {
    silences.push({
      start: silenceStart / sampleRate,
      end: channelData.length / sampleRate,
    });
  }

  return silences;
}

3. Render Detected Silences as Regions

Attach an event listener to wavesurfer.on('decode', ...) to ensure the AudioBuffer is fully decoded before running the detection. Iterate through the detected intervals and add them to the waveform using the Regions plugin.

wavesurfer.on('decode', () => {
  const audioBuffer = wavesurfer.getDecodedData();
  
  // Detect silences quieter than 0.02 amplitude lasting at least 0.4 seconds
  const silences = extractSilences(audioBuffer, 0.02, 0.4);

  // Clear existing regions if reloading
  wsRegions.clearRegions();

  // Draw regions over the silent ranges
  silences.forEach((silence) => {
    wsRegions.addRegion({
      start: silence.start,
      end: silence.end,
      color: 'rgba(239, 68, 68, 0.25)', // Semi-transparent red overlay
      drag: false,
      resize: false,
    });
  });
});

4. Fine-Tuning Parameters

  • threshold: Sets the sensitivity. Values closer to 0 (e.g., 0.005) only catch complete digital silence, while higher values (e.g., 0.03 to 0.05) account for background room noise.
  • minSilenceDuration: Prevents natural micropause phonemes in human speech (like stop consonants) from incorrectly registering as pauses. Setting this between 0.3 and 0.6 seconds reliably detects real speech pauses.
