Format Wavesurfer.js Timeline to HH:MM:SS

This guide explains how to format timeline labels into a standard HH:MM:SS (hours, minutes, seconds) format using the Timeline plugin in Wavesurfer.js. By leveraging the plugin's configuration options, developers can override the default second-based display and render custom, padded timestamps across audio waveforms.

To format timeline labels into HH:MM:SS, use the formatTimeCallback parameter within the Wavesurfer Timeline plugin configuration.

Using formatTimeCallback

The TimelinePlugin does not feature a static string pattern parameter (such as "HH:MM:SS"). Instead, it provides the formatTimeCallback function parameter, which receives the current tick value in seconds and returns a formatted string.

Here is an implementation example using Wavesurfer.js (v7+):

import WaveSurfer from 'wavesurfer.js'
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js'

// Helper function to convert seconds into HH:MM:SS string
const formatToHHMMSS = (totalSeconds) => {
  const hours = Math.floor(totalSeconds / 3600)
  const minutes = Math.floor((totalSeconds % 3600) / 60)
  const seconds = Math.floor(totalSeconds % 60)

  const pad = (num) => String(num).padStart(2, '0')

  return `${pad(hours)}:${pad(minutes)}:${pad(seconds)}`
}

// Initialize Wavesurfer with the Timeline plugin
const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/audio.mp3',
  plugins: [
    TimelinePlugin.create({
      container: '#wave-timeline',
      formatTimeCallback: formatToHHMMSS,
    }),
  ],
})

Parameter Details

  • Parameter Name: formatTimeCallback
  • Type: Function
  • Input Argument: seconds (number) – The point on the timeline represented as a float or integer representing total seconds.
  • Return Value: string – The string label rendered at that timeline notch.

Alternative Method (Using Built-in JS Dates)

For audio tracks under 24 hours in duration, the JavaScript Date object can generate the HH:MM:SS string directly inside the callback:

TimelinePlugin.create({
  container: '#wave-timeline',
  formatTimeCallback: (seconds) => {
    return new Date(seconds * 1000).toISOString().substring(11, 19)
  },
})

Both methods overwrite the default formatting and display every primary notch on the timeline in two-digit hours, minutes, and seconds.
