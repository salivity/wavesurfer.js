How to Set Volume in Wavesurfer.js

Controlling playback volume in Wavesurfer.js is straightforward using its built-in API. This guide explains how to set the volume during player initialization, dynamically adjust it during playback using the setVolume() method, and connect it to a standard HTML volume slider.

The setVolume() Method

To change the audio volume of an active Wavesurfer instance, call the setVolume() method. The method accepts a single floating-point number between 0 (muted) and 1 (full volume).

// Set volume to 50%
wavesurfer.setVolume(0.5);

// Mute the audio
wavesurfer.setVolume(0);

// Set to maximum volume
wavesurfer.setVolume(1);

Setting Initial Volume on Creation

You can define the default volume level when initializing your Wavesurfer instance by passing the volume option into the WaveSurfer.create() configuration object.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F4A85',
  progressColor: '#383351',
  url: '/path/to/audio.mp3',
  volume: 0.8 // Sets initial volume to 80%
});

If omitted, the volume defaults to 1 (100%).

Getting the Current Volume

To check the current volume level of the player, use the getVolume() method, which returns the current level as a float between 0 and 1.

const currentVolume = wavesurfer.getVolume();
console.log(`Current volume: ${currentVolume * 100}%`);

Creating a Volume Slider Control

A common use case is connecting Wavesurfer's volume to an HTML range input.

HTML

<label for="volumeSlider">Volume:</label>
<input type="range" id="volumeSlider" min="0" max="1" step="0.01" value="1">

JavaScript

const volumeSlider = document.querySelector('#volumeSlider');

volumeSlider.addEventListener('input', (e) => {
  const volumeValue = parseFloat(e.target.value);
  wavesurfer.setVolume(volumeValue);
});

Using parseFloat ensures the value from the input field is passed to setVolume() as a number rather than a string.
