Record Microphone Audio Using Wavesurfer.js

Capturing live microphone input allows developers to build interactive audio recording, visualization, and editing applications directly within the web browser. This article explains how to capture and visualize real-time microphone audio using Wavesurfer.js and its official Record plugin. You will learn how to configure the required HTML structure, initialize the plugin, manage recording states, and export the resulting audio file.

1. Include Wavesurfer.js and the Record Plugin

To get started, load the Wavesurfer.js core library along with the Record plugin into your project. You can install them via npm or include them directly via a CDN in your HTML file.

<script src="https://unpkg.com/wavesurfer.js@7"></script>
<script src="https://unpkg.com/wavesurfer.js@7/dist/plugins/record.min.js"></script>

2. Set Up the HTML Container and Controls

Create a container element to host the rendering waveform alongside basic UI buttons to manage the recording lifecycle.

<div id="waveform"></div>
<button id="record-btn">Record</button>
<button id="pause-btn" disabled>Pause</button>

3. Initialize the Wavesurfer Instance and Plugin

Instantiate Wavesurfer, register the Record plugin, and configure visual properties such as waveform color and scrolling behavior.

const wavesurfer = WaveSurfer.create({
  container: '#waveform',
  waveColor: '#4F46E5',
  progressColor: '#312E81',
});

// Register the Record plugin
const record = wavesurfer.registerPlugin(
  WaveSurfer.Record.create({
    scrollingWaveform: true,
    renderRecordedAudio: false,
  })
);

4. Capture Microphone Stream and Handle States

Use the plugin's built-in methods to request microphone permissions, start capturing the audio stream, and toggle pause or resume states.

const recordBtn = document.getElementById('record-btn');
const pauseBtn = document.getElementById('pause-btn');

recordBtn.onclick = () => {
  if (record.isRecording() || record.isPaused()) {
    record.stopRecording();
    recordBtn.textContent = 'Record';
    pauseBtn.disabled = true;
    return;
  }

  // Start recording from the default audio input device
  record.startRecording().then(() => {
    recordBtn.textContent = 'Stop';
    pauseBtn.disabled = false;
  }).catch((err) => {
    console.error('Microphone access denied or unavailable:', err);
  });
};

pauseBtn.onclick = () => {
  if (record.isPaused()) {
    record.resumeRecording();
    pauseBtn.textContent = 'Pause';
  } else {
    record.pauseRecording();
    pauseBtn.textContent = 'Resume';
  }
};

5. Access and Play the Recorded Audio

When recording stops, the Record plugin fires the record-end event, passing an audio Blob. You can use this Blob to create an object URL for playback or upload the file to a remote server.

record.on('record-end', (blob) => {
  const recordedUrl = URL.createObjectURL(blob);
  
  // Load the recorded audio back into Wavesurfer for playback
  wavesurfer.load(recordedUrl);

  // Optional: Create a downloadable link
  const downloadLink = document.createElement('a');
  downloadLink.href = recordedUrl;
  downloadLink.download = 'recording.webm';
  downloadLink.textContent = 'Download Recording';
  document.body.appendChild(downloadLink);
});
